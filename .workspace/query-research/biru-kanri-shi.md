# ビル管理士

> 調査日: 2026-06-09  
> カテゴリ: ビル管理  
> 備考: 正式名称は「建築物環境衛生管理技術者」。必置資格。

---

## 概要

特定建築物（床面積3,000㎡以上等）の環境衛生管理を監督する国家資格。法律上の選任義務があり、ビルメンテナンス業界の上位資格。

| 項目 | 内容 |
|------|------|
| 正式名称 | 建築物環境衛生管理技術者 |
| 通称 | ビル管理士・ビル管 |
| 資格種別 | 国家資格（厚生労働省） |
| 受験資格 | 実務経験2年以上（または講習修了） |
| 試験 | 多肢選択式（180問・6時間） |
| 合格率 | 10〜20%（年1回） |

---

## 学習時間

| バックグラウンド | 目安時間 | 期間目安 |
|------------------|----------|----------|
| 無知識・初学者 | 600〜1,000時間 | 10〜18ヶ月 |
| ビルメン実務経験者 | 400〜600時間 | 6〜12ヶ月 |
| 電験・エネ管取得済み | 300〜400時間 | 4〜8ヶ月 |

出題範囲が広い（7科目）が、暗記問題が多く過去問攻略が有効。問題数の多さが勉強時間を押し上げる。

---

## 人気度

- ビルメン三種の神器の一角。書店のビル管理コーナーでテキストが複数並ぶ
- 電験三種・エネルギー管理士と並ぶ難関資格として知名度が高い
- 合格率が電験三種に次いで低い（ビルメン系資格内で2番目に難しい）
- 必置資格のため、ビルメン業界では取得者への安定需要

---

## 平均年収

| 区分 | 年収目安 |
|------|----------|
| 資格保有（平均） | 380〜490万円 |
| 選任前 | 350〜450万円 |
| 選任後 | 450〜600万円 |
| 電験・エネ管との複合 | 500〜700万円 |

資格手当は月5,000〜10,000円。選任手当が別途つく場合あり。無資格者との差は約200万円程度。

---

## 需要・職業実態

- 3,000㎡以上のビル・商業施設・ホテル等で選任が義務
- 建物が存在する限り需要は続く（景気に左右されにくい）
- 主な就職先: ビルメンテナンス会社、設備管理会社、デベロッパー系管理会社
- 1人が原則2物件までしか兼務できないため、物件数に比例して需要が発生

### 管理者として必要なケース

**必置資格。** 特定建築物の環境衛生管理責任者として選任が法律で義務づけられている。現場主任クラスではないが、管理責任者としてのポジション。

---

## テキスト平均価格

| 種類 | 価格帯（1冊・税込） |
|------|---------------------|
| 総合テキスト | 2,500〜4,000円 |
| 科目別テキスト（7科目） | 2,500〜2,750円/冊 |
| 問題集・過去問 | 2,500〜3,000円 |
| フルセット（テキスト＋問題集） | 約15,000〜25,000円 |

7科目分のテキストを揃えると総額が大きくなる。オーム社のシリーズが定番。

---

## 未来展望

| 要因 | 見通し |
|------|--------|
| ビルストックの増加 | 管理対象物件が増え続ける |
| 環境衛生への関心 | 空気環境・衛生管理の重要性が高まる |
| 高齢化 | 有資格者の引退で若手需要増 |
| 複合資格化 | 電験＋エネ管＋ビル管の三種セットが市場価値を押し上げ |

「短期的な高収入」より「長く安定して働く力」を身につける資格。

---

## 生成AIナレッジ適性（サイト視点）

| 観点 | 評価 |
|------|------|
| 7科目の整理 | 科目ごとにAI学習テキストを分割生成しやすい |
| 暗記問題 | 過去問パターン化しやすく、クイズアプリ向き |
| 問題数の多さ | AIで要約・一問一答化すると学習効率が大幅改善 |
| 注意点 | 最新の環境基準・法改正の反映が必要 |

**サイトとの相性: 高い。** 問題数が多く「机に広げて読むのが面倒」というユーザーのペインに直結。
