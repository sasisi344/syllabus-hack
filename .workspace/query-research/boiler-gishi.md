# ボイラー技士（二級）

> 調査日: 2026-06-09  
> カテゴリ: ボイラー技士  
> 備考: ビルメン4点セットの一角。ボイラー運転・管理の国家資格。

---

## 概要

一定規模以上のボイラーを安全に運転・管理・点検するための国家資格。労働安全衛生法に基づく必置資格。

| 項目 | 内容 |
|------|------|
| 資格種別 | 国家資格（厚生労働省） |
| 区分 | 特級・1級・2級・3級 |
| ビルメンで一般的 | 二級ボイラー技士 |
| 試験 | 学科（マークシート） |
| 合格率 | 約60%（2級） |
| 試験回数 | 年6回程度 |
| 受験料 | 6,800円 |

---

## 学習時間

| 級・バックグラウンド | 目安時間 | 期間目安 |
|---------------------|----------|----------|
| 2級・無知識 | 60〜100時間 | 2〜3ヶ月 |
| 2級・設備系経験者 | 40〜60時間 | 1〜2ヶ月 |
| 1級 | 200時間程度 | 4〜6ヶ月 |
| 特級 | 300時間以上 | 6ヶ月以上 |

2級は4点セットの中で電工2種・冷凍3種と同程度の難易度。

---

## 人気度

- ビルメン4点セットの定番。書店で専門テキストが並ぶ
- 商業ビル・オフィスビルの暖房・給湯設備で需要が高い
- 試験回数が多く（年6回）、取得しやすい
- 未経験者は入社後取得が多いが、転職前取得も評価される

---

## 平均年収

| 区分 | 年収目安 |
|------|----------|
| 2級単独 | 350〜450万円 |
| 4点セット揃え | 320〜400万円 |
| 1級以上 | 400〜500万円 |

資格手当は月5,000〜10,000円。単体では年収へのインパクトは限定的。

---

## 需要・職業実態

- ボイラー設備を持つ施設で運転・点検に必須
- ビルメンテナンスでは空調・給湯の熱源管理が主業務
- 製造業・病院・学校等のボイラー室でも需要
- 主な就職先: ビルメンテナンス、設備管理、製造業

### 管理者として必要なケース

一定規模以上のボイラーを運転する施設で「ボイラー技士」の選任が法律で義務づけられている。

## 未来展望

| 要因 | 見通し |
|------|--------|
| ビルストック | ボイラー設備の維持管理需要は継続 |
| 省エネ化 | 高効率ボイラーへの更新で専門知識が必要 |
| 4点セット | 入門〜中堅の基礎資格として地位は安定 |
| 1級・特級 | 大型施設では上位資格の需要あり |

単体より「ビルメンキャリアの基盤」としての価値が大きい。
