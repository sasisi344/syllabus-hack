## サイト記事化の優先度メモ

AI学習テキスト・出題アプリとの相性が高い題材:

1. **ビジネス著作権検定** — 学習時間短・AI時代のトピック直結
2. **危険物乙4 / 秘書検定3級 / FP3級** — 入門・短時間で効果実感しやすい
3. **ビル管理士 / 電験三種** — 問題数多・分厚いテキストのペインに直結
4. **土木施工管理技士** — 過去問パターン化しやすくクイズアプリ向き

- 法改正・試験要項は年度ごとに要確認
