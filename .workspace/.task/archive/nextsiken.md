## ③ 本当のギャップ（優先着手すべき4点）

### ギャップ1：Negative-Narrativeの「型」が横展開クラスターに移植されていない

IPA系で最も効いた型（具体的な絶望ワード起点）を、簿記・宅建・MOS・FPにまだ使っていない。例：

- 簿記：「仕訳 覚えられない 心が折れる」「工業簿記 原価計算 意味不明」
- 宅建：「権利関係 民法 何も頭に入らない」「宅建業法 暗記量 心折れる」
- MOS：「関数 覚えられない エクセル アレルギー」
- FP：「タックスプランニング 計算 心折れる」

実績のある型を使い回すだけなので、新規ジャンル開拓より着手コストが低く優先度が高い。

### ギャップ2：波3（国家資格・実務系免許）のインフラが未整備のまま記事だけ先行している

電験三種・危険物取扱者・ビル管理クラスター・土木施工管理技士は examId 登録済みだが：

- `cert-keyword-db/` にKW-DBファイルが1つもない（denken-kw-db.md 等が存在しない）
- `restructure-plan-2026-06.md` の充足率表に波3クラスターの行が存在しない
- Hubだけでスポーク（Theory/Method/Career/App）が0件 = クラスターとして「孤立したHub」状態

この波は実は元の構想にあった「アフィリエイト商品が多いジャンル」「難易度が高いジャンル」に最も合致する（電験三種・施工管理技士は資格学校・通信講座のアフィリエイト単価が高い）。**狙いとしては正しいが、計画外で走っているため抜け漏れが出やすい。**

### ギャップ3：「ほぼ完成」クラスターの仕上げが止まっている（新規クラスター開拓より優先すべき）

`priority-roadmap-todo.md` によれば：

| クラスター | 状態 |
| --- | --- |
| 日商簿記 | Hubのみ。Method×2・Career×1が未着手 |
| MOS | Hub・Career済み。Theory×3が未着手 |
| G検定 | Hubのみ。Method×2・Trend×1が未着手 |
| 宅建 | Hubのみ。Method×2が未着手 |

Hubを作って終わりになっているクラスターが4つある。新しい波3・波4を増やすより、ここを完走させたほうが**内部リンク構造とSEO評価が先に積み上がる**（Hub単体は被リンク・回遊の起点として弱い）。

### ギャップ4：Appクラスター（クイズ/ドリル）がIPA系以外すべてゼロ

`app` カテゴリ23件は全てIPA系（ITP/FE/AP/SG/高度試験/生成AI関連）。簿記・宅建・MOS・G検定・CCNA・AWSは記事だけでアプリが一切ない。`restructure-plan-2026-06.md` 課題Dで「日本一を名乗るなら他資格にもアプリ展開すべき」と指摘されたまま着手0件。サイトの最大の差別化資産（独自開発アプリ）が新規クラスターに展開されていないのは機会損失が大きい。

## ③b. 維持する構造原則 + 新設する軸（2026-06-19 追記）

### 維持する原則：Hub＝資格名KW軸、スポーク＝サジェストKW記事

現行の「examId＝資格名そのもののKWをHubとして固定し、そこに検索サジェスト（具体的な悩み・比較・手続き等のKW）をスポーク記事として紐づける」構造は変更しない。Negative-Narrative型もこの構造の中の「スポークの書き方の型」の一つであり、構造自体を置き換えるものではない。今後のクラスター追加・仕上げも、この**Hub固定→サジェスト肉付け**の流れを継続する。

### 新設する軸：受験资格区分（社会人向け／学生でも可）

資格には「誰でも受験可」と「実務経験年数・事前条件が必須」のものが混在している。この区分はスポーク記事の**ペルソナ・訴求方向**を決める重要な軸になるため、examIdごとに分類して持たせる。

| 区分 | 該当examId（確認済み） | スポークの訴求方向 |
| --- | --- | --- |
| 学生でも可（条件なし） | `it-passport` / `fe` / `ap` / `sg` / 高度試験各区分 / `ccna` / AWS / `g-kentei` / `ds-kentei` / `boki` / `takken` / `mos` / 秘書検定 / 危険物**乙種**（`kiken-butsu`） / `denken`（電験三種は受験自体は無条件） / マンション管理士・エネルギー管理士（`biru-kanri`クラスターの一部） | 「将来こういう分野・キャリアがあると知ってもらう」**認知形成**が主目的。今すぐ受けさせる訴求でなくてよい。既存の`itp-vs-info1-comparison-hack`（情報I比較）の型をテンプレ化して他資格へ展開 |
| 社会人向け（実務経験・事前条件が受験资格に必須） | FP**2級**（3級合格 or 実務2年等） / ビル管理士＝建築物環境衛生管理技術者（実務2年以上、`biru-kanri`クラスターの一部） / `doboku-sekou`（学歴別の実務経験年数） / 危険物**甲種**（乙種全種合格等） / E資格（JDLA認定講座修了が事前条件） | 「資格手当・転職・資格単価」など実務直結の訴求が刺さる層。**まだ条件を満たさない読者**には「条件達成までの準備ロードマップ」という記事タイプが空白で狙い目 |

**注意点**: `biru-kanri` Hubは内部に条件不問（マンション管理士・エネルギー管理士）と実務経験必須（ビル管理士）が混在している。Hub記事自体は資格名KW軸でまとめてよいが、スポーク記事を作る際は**サブ資格ごとに訴求対象を分けて書く**必要がある（同じHubでも「学生に薦める記事」と「実務経験者向けの記事」を両方作れる）。

### スポーク企画への反映ルール

1. examId選定時に「学生でも可／社会人向け」をまず判定する
2. 学生でも可 → 認知形成型スポーク（「こんな選択肢もある」「将来のキャリアの一手として」）を最低1本は用意する。特にまだ存在しないクラスター（簿記・宅建・MOS・G検定等）は`itp-vs-info1-comparison-hack`型の移植先として優先度が高い
3. 社会人向け → 実務直結型（資格手当・転職・単価）を主軸にしつつ、「条件未達成者向けの準備記事」を1本検討する（この記事タイプは現状サイト全体でゼロ）
