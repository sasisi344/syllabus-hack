## B. 記事構成（H2／H3）

> 見出しルール: 番号付けなし、見出し全体を「」で囲まない（部分引用はOK）。本文の強調は `<strong>`（1段落1〜2個）。水平線は frontmatter 直後と「まとめ」直前のみ。内部リンクは `/{category}/{slug}/` 形式。1〜2文で改行。

### 冒頭（結論先出し・3行以内）

- 例: 「結論：サイバー攻撃は<strong>『自社が狙われたとき』ではなく『自社のサービスや取引先が止まったとき』に経営の問題になります</strong>。そのリスクを認知して備えるか、受け入れるか。決めるのは現場ではなく経営トップです。」
- この記事で分かること: ①被害の最新状況 ②AI攻撃で何が変わったか ③トップが決める3つのこと

### H2: ランサムウェア被害は過去最多｜「他人事」の根拠がそろった（Problem）

- 警察庁 令和8年上半期: ランサムウェア被害報告 **123件で半期として過去最多**（35都道府県）。復旧費用1,000万円以上が約6割、復旧に約1か月が約5割、VPN機器経由が約5割（※報道ベース・§D-1）
- IPA 10大脅威2026（組織）: **1位ランサム（11年連続）／2位サプライチェーン・委託先を狙った攻撃／3位 AIの利用をめぐるサイバーリスク（初選出）**
- 主張は1つ: <strong>被害は特別な企業の話ではなく、毎年増えている公的データがある</strong>

> 「VPNだから安心」と慢心している人ほど危ない。インターネットに接続している限りはリスクを避けられないと自覚したほうがいい、ただ日本においてはその意識が「自宅を守る、自分を守る」段階にもないので根本の意識から変える必要がある。

### H2: AIで攻撃の敷居が下がった｜経営層こそ理解が必要（Problem／Affinity）　★forAIの軸①

**H3: 快活CLUB事件が示したこと**
- 2025年1月発覚、最大7,290,087件の会員情報流出の可能性。2025年12月に高校生が逮捕（生成AIでプログラムを作成とされる）、2026年5月に書類送検、7月に別の男を逮捕（約724万人分取得の疑い）。**複数人が関与**した事件
- 「天才ハッカーの話」ではなく、<strong>生成AIで経験の浅い人でも攻撃に参加できる</strong>という点が経営への示唆（美談化の危うさは元ノートの記事を参照）
- 同社は2025年3月時点で個別の補償は予定せず、と発表（対応コストは補償以外にも及ぶ点は断定せず、事実のみ）

**H3: 攻撃側だけでなく、自社の『AI利用』もリスクになる**
- 10大脅威3位の新設が示すもの: Shadow AI（未承認AIでの情報流出）、プロンプトインジェクション、AIエージェントの権限設計
- 元ノート③の数字（ディープフェイク検出数1500%増など）は**出典未確認**のため、原典確認が取れるまで本文には使わない（§D-1）
- 結論: AI攻撃は<strong>技術部門だけで理解して済む話ではなく、判断者が仕組みを知らないと投資も規程も決められない</strong>

### H2: 自社が狙われなくても業務は止まる｜サプライチェーンと事業停止（Affinity）　★forAIの軸②

**H3: アサヒ・アスクルの事例**
- アサヒ: 2025年9月29日に攻撃。国内の受注・出荷・コールセンターが停止、全品の出荷再開は2026年4月7日。2025年12月期は売上収益2兆8,946億円（前年比1.5%減）、営業利益1,858億円（同30.9%減）。個人情報は約11.5万件の漏洩を確認
- アスクル: 2025年6〜11月期で売上高12.3%減、営業損益は約30億円の赤字、営業利益は前年同期比で約90億円悪化
- 書き方の注意: アサヒの営業利益減には**原材料高など攻撃以外の要因も含む**。「攻撃で○○億円減った」と断定しない。受発注の停止という<strong>事業継続の問題</strong>として描く
- 『情報漏えい』より『<strong>止まる</strong>』が経営判断のポイント、というメッセージ

**H3: 取引先・関連会社が止まる側の立場**
- アスクルのように、止まったのは攻撃を受けた会社だけではなく、**その会社に発注・納品していた企業の業務**にも影響する（具体的な影響先は報道で確認できた範囲のみ。無ければ一般論に留める）
- IPA 10大脅威2位とあわせて「自社の対策だけでは守りきれない」構造を説明

**H3: 取引条件になる時代へ｜サプライチェーン対策評価制度（星制度）**
- 経産省・国家サイバー統括室。2026年3月27日に構築方針公表、★3・★4が評価対象、運用開始は2027年3月ごろの見込み
- 切り口: セキュリティは『コスト』から『<strong>取引を続けるための条件</strong>』へ。基礎としてIPAの SECURITY ACTION などが位置づけられている

### H2: 守れた領域と守れなかった領域｜ニコニコの教訓（Solution の根拠）　★forAIの軸③

- ドワンゴ: 2022年のAWS移行当初からセキュリティを優先し、2024年6月の攻撃で**AWS環境への侵害は防げた**
- 一方で同じ攻撃でニコニコ等のサービスは2024年6月8日から停止、再開は8月。個人情報254,241人の外部漏洩を確認。侵入経路・方法は公式に不明のまま
- 結論: 『守れた』は<strong>投資した領域の話</strong>。事前投資の効果と、守る範囲が全体に及んでいない場合の限界の両方を書く（「全体を守れた」と読める書き方は避ける）
- 示唆: 守る対象を<strong>社内システムだけでなく、インターネットを含むサービス提供のすべて</strong>に広げる必要（forAIの主張）。WordPress“野良サイト”のような**部門サイト放置**も同じ構造

### H2: 経営トップが決める3つのこと（Solution／Offer）　★記事の核

**H3: 一　まず上が手本を示す｜CISOまたは同等の役職を置く**
- 経産省『サイバーセキュリティ経営ガイドライン Ver3.0』: 経営者が認識すべき3原則と、CISO等に指示すべき重要事項。後継版は確認できず、Ver3.0が最新（2026年10月時点）
- 中小企業ではCISO専任が難しい前提で、<strong>責任者を一人決めて、役員会に定期報告させる</strong>形から（兼任・外部の活用。IPA『令和7年度セキュリティ人材活用環境整備』報告書の外部人材リストへ）
- 『経営者自身が手本を見せる』具体例（フィッシング訓練に経営も参加、多要素認証の率先導入など）は、**一般論の範囲で**。出典がある事例のみ固有名詞を出す

**H3: 二　守る対象を『サービス提供のすべて』に広げる**
- 社内ネットワーク／クラウド／公開Web・EC／VPN機器／AI利用／取引先の接続口。棚卸しの観点を表で示す（§C-3）
- 警察庁統計でVPN機器経由が約5割（※報道）→ 『入口機器の管理』の優先度を示す根拠に

**H3: 三　リスクを『認知して備える』か『享受する』かを明示的に決める**
- どの事業停止を何日まで許容するか、停止時の取引先対応・復旧手順・保険を誰が決めるか。<strong>決めないこと自体が『享受』という選択になる</strong>
- 判断材料: 復旧に約1か月かかった組織が約5割（※報道）、アサヒは全品出荷再開まで約6か月
- 『他社事例は対岸の火事ではなく、いつ自社に起きてもおかしくない』を、チェック質問にして終える

### H2: 人への投資｜資格補助と社内人材（Offer）

- 『セキュリティ未経験から3年でCISSP合格』の個人記録を、<strong>社内の資格補助制度が人材投資として機能した実例</strong>として紹介（個人の事例であり、一般化しない）
- 経営者向けの含意: 外部採用が難しい中小企業は<strong>社内で育てる</strong>選択が現実的。入口は SG、さらに SC、国際資格は枝（導線: §E。詳細は `column-outline-cyber-cert-roadmap-sg-to-sc.md` の記事へ送る）
- 注意: 資格を取れば対策が進む、とは書かない。『人材を育てる仕組みを持つ』の一例に留める

### H2: AIで学び方を変える（Syllabus Hack Points）

- 経営層向けの『机上演習』をAIで作る: 自社の業種・規模・主要システムを入れ、『取引先ECが2週間停止』『自社の公開サイトが改ざん』などのシナリオを生成させ、役員会で判断させる（プロンプト例1本。コードフェンス内は Markdown の `**太字**`）
- 『AI攻撃の理解』もAIに聞く: 自社の公開情報から攻撃者がどう下調べするか、を平易に説明させる（防御目的の範囲）
- 時間資産: 役員会前の準備を短時間で

### C-2. 経営が決める3点（図解案）

```
① 責任者を決める   CISO／CISO相当＋役員会への定期報告
② 範囲を決める     社内IT → クラウド → 公開サイト・EC → VPN → AI利用 → 取引先接続
③ 許容を決める     何日止まれるか／誰が判断するか／取引先への連絡
```

> IPAの情報セキュリティマネジメント(SG)はネット知識があるなら難しくはないしセキュリティ分野の入門なので、会社が資格をとるためのサポートをしてあげる制度作りも重要。ランサムウェアなどメール添付できやすいウイルスは、部署での対応よりも個人意識の改革が効く。そのリスク判断と社員への投資に躊躇しない経営がこの先、生き残りやすくなるのでは。

### D-2. 書かないこと・書き方の約束

- <strong>特定企業を『投資を怠った』と批判しない</strong>。アサヒ・アスクル・快活CLUBについて、原因が対策不足だったかを公式発表で示されていない限り断定しない（『被害が事業にどう影響したか』に限定）
- 損失額・営業利益減を『攻撃が原因』と断定しない（原材料高など他要因あり）
- 『いずれ必ず攻撃される』『投資すれば被害を防げる』と断定しない。『備えの有無で影響が変わる』に留める
- 未成年が関与した事件は、**個人を特定しない**表現にする（氏名・学校・居住地等は書かない）
- 恐怖訴求だけにせず、必ず『経営が決める3点』の行動に着地させる
- 受験者向けのブログである点を踏まえ、『この記事は経営者に向けたものだが、担当者が経営に説明する材料にもなる』と冒頭で一文
- 画像生成は指示があるまで実行しない。下書きにはコメントのみ: `<!-- IMAGE_PROMPT: minimalist pictogram, white shield with a crack and a chain link on dark navy background, flat design, 16:9 -->`
