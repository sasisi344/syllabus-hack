- 脅威の現状（2026年更新を主役に）: IPA『情報セキュリティ10大脅威2026』組織編（1位ランサム攻撃・11年連続、2位サプライチェーン・委託先、3位**AIの利用をめぐるサイバーリスク（初選出）**）

### H2: セキュリティ資格の地図（Advantage: 全体像）

**H3: 3つの軸で見る**
1. 領域: 管理・ガバナンス／技術・防御／攻撃側（診断・侵入テスト）／ネットワーク／クラウド／監査
2. レベル: 入門／基礎／専門
3. 発行元: 国内（IPA＝国家試験）／国際（ISC2・ISACA・CompTIA・EC-Council・GIAC ほか）

**H3: 資格マップ（図＋表）**— §C-1 の表を図解化（縦=レベル、横=領域）。資格名には**取得難度の優劣をつけない**（目的が違うため）

### H2: 国内の本線：SGから支援士へ（Advantage: 道筋の優位性）　★主役・最長

**H3: 本線の全体像（ステップ表・§C-2）**
- ITパスポート（任意の入口）→ **SG（現場の守り方）** →（FE／応用情報で土台を補強）→ **SC（国家資格のスペシャリスト）**
- 「SG→SC」は**同じ中分類番号の別の深さ**（2027年案）: セキュリティ4中分類（23〜26）の用語数は SG 307語／PD・SC科目A-1 287語／SC専門 550語。SC専門はSGの約1.8倍（§C-3）。数字は前稿・レポートの機械集計

**H3: ステップ1 SG｜入口で身につくこと**
- 対象は部門の情報セキュリティ担当者。非IT職でも受けられる入口（既存: `/method/sg-hub/`、`/method/sg-beginner-roadmap/`、`/career/sg-company-security-roadmap/`）
- 2027年度版で変わる点を3行（AI関連語の増加、管理策の体系化、範囲は約3割減）→ 詳細は前稿へ
- 「SGで止まる人／先に進む人」の見極め: 担当者として守るだけで足りるか、設計・調査・助言まで担うか

**H3: ステップ2 土台の補強｜FEと応用情報**
- SCはネットワーク・DB・開発方法論などの専門知識も問う。2027年案の公式マトリクスで、SCの専門知識（●）は**ネットワーク（16）とセキュリティ4中分類（23〜26）**、SCがその他（○）として問うのは**サービスマネジメント（4）、ガバナンス・監査（12）、データベース（17）、システムライフサイクル（20）・開発運用方法論（21）**（`exam-scope-matrix-2027.json`）
- ここでの結論案: SGだけからSCへは**範囲の飛びが大きい**ため、FE（または応用情報）を挟むとSCの科目A-1で既習範囲が増える（A-1用語の約43%がFE2027案と共通、応用情報シラバスとは約76%共通）
- 免除制度の有無は §D の要確認（IPA資料では「SCの科目A-2免除制度は変更しない」とだけ確認済み）

**H3: ステップ3 SC｜国家資格のスペシャリスト**
- 位置づけ: 名称独占の登録制国家資格。令和7年度の合格率は**春19.0%／秋22.3%**（IPA発表）。**令和8年度からCBT方式**（令和7年度秋期が紙の最後の回）
- 2027年度の新制度: 科目A-1（共通知識・30問）／A-2（専門知識・25問）／科目B（12問）に再編（IPA資料整理）。**A-1はPDと共通**
- 登録するかどうかの判断軸は既存記事に委ねる（`/career/sc-unregistered-benefit-hack/`）。維持費の数字は本稿では再掲しない
- 学習の入口: `/method/sc-hub/`、記述式は `/method/sc-descriptive-self-loop-hack/`、全体は `/method/advanced-ipa-hub/`

### H2: 国際資格をどう位置づけるか（Feature: 比較）

**H3: 国内資格と国際資格の違い（切り口）**
| 切り口 | 国内（SC） | 国際（CISSP等） |
| --- | --- | --- |
| 認定の性格 | 国家試験・登録制（名称独占） | 民間の認定団体。**実務経験年数の要件**を課すものが多い |
| 受験の入口 | 受験資格の制限なし | 経験年数や推奨資格が付く資格がある（資格ごとに異なる） |
| 活かせる場 | 国内の公共・企業、官公庁調達 | グローバル企業、外資・海外案件（求人要件は要実査） |
| 維持 | 登録更新（講習・費用） | 継続教育（CPE）と年会費 |

→ 上表は一般論。**各項目は資格ごとに §D の確認を終えてから**書く。

**H3: 目的別の主な国際資格（§C-1 の表から抜粋して解説）**
- 管理・ガバナンス: **CISSP**（ISC2。CBKの8ドメインのうち2つ以上で累計5年以上の実務経験が基本要件。経験不足でも合格すればアソシエイトになれる）、**CISM**（ISACA。情報セキュリティ実務5年以上、うち3年以上は管理。CISSP保持者は一般経験2年分の免除）
- 技術・実務の入口: **CompTIA Security+（SY0-701）**（最大90問・90分、合格点750/900）。ベンダー中立で入門〜初級の位置づけ
- 攻撃側・診断: **CEH**（EC-Council）、**OSCP**（Offensive Security。実技型）、**GIAC**（SANS）系
- クラウド: **CCSP**（ISC2）ほか、AWS／Microsoft のセキュリティ系認定
- 監査: **CISA**（ISACA）← 国内の `システム監査技術者` との関係も1行
- 入門: **ISC2 CC（Certified in Cybersecurity）**（提供条件・費用は要確認）

**H3: ネットワークセキュリティの入口（Cisco系）**
- ネットワークの土台は CCNA やネットワークスペシャリスト。セキュリティ専門を名乗る前に「通信の仕組み」を押さえる流れ。既存記事: `/method/ccna-hub/`、`/career/ccna-network-engineer-career/`
- Cisco のセキュリティ系認定の現行ラインナップは**要確認**（改廃が多い領域）

**H3: SCと国際資格の組み合わせ（任意節）**
- 「SC＋CISSP」「SG＋Security+」など、組み合わせの意味づけ。**相互の受験免除・経験年数の認定可否は未確認**のため、確認が取れるまで断定しない

### H2: 目的別の進み方（T: 次の行動）

| あなたの状況 | 進み方の例 | 補足 |
| --- | --- | --- |
| 非IT職（総務・経理・営業）で、会社のセキュリティ担当を任された | SG → 社内規程・インシデント対応の実務 | `/career/sg-company-security-roadmap/`、`/career/backoffice-sg-strategy/`（地域版あり） |
| IT初学者・エンジニア志望 | ITパスポート → FE → SG → SC。並行して Security+ で技術の入口 | 国内本線＋国際入門のハイブリッド |
| セキュリティ業務の実務経験あり | SC（名称独占・国内での通用）か CISSP／CISM（国際・管理）を、働く場所で選ぶ | 実務年数の要件は §D で確認 |
| ネットワークエンジニア | CCNA → ネットワークスペシャリスト／セキュリティ系認定 → SC | `/method/ccna-hub/` |

- **迷ったときの質問**: ①国内の官民で通用させたいか、海外・外資か ②守る側（管理）か、検証する側（診断）か ③実務年数は足りているか

### H2: AIで学び方を変える（Syllabus Hack Points）

- 時間資産: 複数資格の試験範囲の突き合わせを、数十分で一覧化

### D-2. 書かないこと・書き方の約束

- 受験料・合格率・年収・求人件数など**変動する数字は、出典と取得日を併記**。確認できなければ載せない
- 「この資格が一番」「取るべき順番はこれ」と断定しない。**目的別の分岐**として示す
- 資格の優劣・難易度ランキングは作らない（目的が違う。難易度は前稿の『知識範囲の目安』にとどめる）
- 「取れば年収が上がる」「求人が増える」などの効果は、一次データが無ければ書かない
- 受験者数・登録者数から「人材が足りない」「需要が高い」と結論づけない（需給の根拠データを別途用意できる場合のみ）
- 国際資格の日本語表記・略称は初出で正式名称を併記
- 画像生成は指示があるまで実行しない。下書きにはコメントのみ: `<!-- IMAGE_PROMPT: minimalist pictogram, white shield with network nodes on dark navy background, flat design, 16:9 -->`
