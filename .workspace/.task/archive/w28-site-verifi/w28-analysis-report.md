## 4. 競合に勝てていない構造要因の分析

順位8〜15位滞留の背後にある要因を、データから読める範囲で整理する。

1. **CTRシグナルの喪失**: 順位8〜10位で表示されてもクリック0が続くと、Googleに「このクエリへの適合度が低い」というシグナルを返し続けることになり、順位押し上げの芽を自ら摘んでいる。競合（過去問道場・大手スクール系）は「無料」「過去問○年分」「合格率」等の具体数値でSERPを制している。**タイトルの抽象度が高い記事は数値・年号・固有便益に書き換える**のが先決。
2. **勝ちクエリへの集中不足**: 唯一順位2位を取れた `new-ipa-exam-study-strategy` のようなページに内部リンクとコンテンツ追補を集中させず、新規記事の量産（W28時点で先行実施分）に資源が向いていた。**小規模サイトは「勝てているクエリの隣接面」から広げる**方が、ドメイン全体の評価が薄い状態で新面を開くより効率が良い。
3. **URL正規化の残課題**: スラッシュあり/なしの重複インデックスと /strategy/→/theory/ 移行の過渡期が重なり、評価が分散・不安定化している疑い。技術面で自滅している分を先に止血する。
4. **需要の季節性**: 表示の中心は「CBT移行」「IPA 2026」系。秋期試験（10月）に向けて7〜9月に検索需要が立ち上がる領域であり、**今が仕込みの最終期**。順位を上げるなら8月中に完了させる必要がある。
