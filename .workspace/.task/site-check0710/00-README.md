## 体制

### 監督エージェント（Supervisor）
- 各WPごとに**作業エージェント（Worker）を起動**し、完了報告を受けて**評価**する
- 評価に合格したWPのみ完了とし、`supervision-log.md` に「WP名 / 実施内容 / 検証結果 / 合否 / 差し戻し理由」を記録
- 本 README 下部の進行状況表を更新する
- 自ら修正作業は行わない（差し戻しはWorkerに再指示）

### 評価プロトコル（各WP共通の合格条件）
1. WPファイル記載の「完了条件」をすべて満たす（Workerの自己申告ではなく監督が実際に検証コマンドを実行）
2. `pnpm build` が成功する（コード・記事に触れたWPのみ）
3. CLAUDE.md ルール違反の新規混入がない（本文 `**bold**` 禁止・lastmod更新・publishDate不変・frontmatter形式）
4. 変更が WP のスコープ内に収まっている（無関係ファイルの変更がない）

### 全体制約
- **`git push` 禁止**（本番デプロイが走る）。`git commit` もユーザー指示があるまで行わない
- 画像生成は明示指示があるまで実行しない（ドラフトは `<!-- IMAGE_PROMPT: ... -->` コメントで対応）
- 記事の新規執筆は該当スキル（`.agents/post_writer.md` 等）を必ず Read してから
- KWリサーチは `.agents/kw_pattern_research.md` 経由必須
