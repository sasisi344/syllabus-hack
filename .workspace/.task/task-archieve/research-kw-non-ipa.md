## 1. MOS（マイクロソフト オフィス スペシャリスト）

### 市場規模
- 累計受験者数 **530万人超**（2025年12月時点）
- 対象ソフト: Word / Excel / PowerPoint / Access / Outlook
- レベル: 一般（アソシエイト）/ 上級（エキスパート）

### 狙えるKW（ネガティブ起点が高需要）

| キーワード | 方向性 | 競合レベル |
|---|---|---|
| MOS 役に立たない | 否定→逆転 | 高（大手多数） |
| MOS 意味ない 就職 | 否定→逆転 | 高 |
| MOS 履歴書 恥ずかしい | 否定→逆転 | 中 |
| MOS エキスパート 独学 難しい | ニッチ | 低〜中 |
| MOS Excel エキスパート 勉強時間 | ニッチ | 低 |
| MOS PowerPoint 意味ない | ニッチ | 低 |
| MOS vs ITパスポート どっち | 比較 | 低〜中 |
| MOS AI活用 勉強法 | 新規 | 低 |

### 競合状況
- 大手: レバテックルーキー・Midworks・U-Can・キャリカレが「役に立たない」KWを占拠
- ニッチ余地: エキスパートレベル詳細、PowerPoint単体、AI活用での短時間合格

### アフィリエイト商品
- 通信講座: U-Can（MOS講座）、キャリカレ
- 書籍: FOM出版テキスト、日経BP
- Udemy: Microsoft Office 系コース

### Syllabus Hack での攻め方
- 「AIで短時間MOS合格」フレーム（method）
- 「MOS エキスパート vs 基本情報 どっちが就職に強い？」比較記事（trend）
- 勉強法はBEAFフレーム（他手法との圧倒的Advantage強調）

## 2. FP2級（ファイナンシャルプランナー2級）

### 市場規模
- 合格率約50%（半数が不合格）→「受からない」KW需要大
- 2025年からCBT方式導入 → 通年受験可能、リベンジ需要急増
- 必要勉強時間: 150〜300時間

### 狙えるKW

| キーワード | 方向性 | 競合レベル |
|---|---|---|
| FP2級 落ちた 原因 | 脱落 | 低〜中 |
| FP2級 受からない なぜ | 脱落 | 中 |
| FP2級 難しすぎる | 脱落 | 低 |
| FP2級 2回落ちた 対策 | ニッチ | 低 |
| FP2級 CBT いつ受けられる | 新規 | 低 |
| FP2級 社会人 勉強時間 3ヶ月 | 実践 | 中 |
| FP2級 意味ない キャリア | 否定→逆転 | 中 |
| FP2級 G検定 DS検定 文系 どっち | 比較 | 低 |
| FP2級 独学 挫折 乗り越え | 感情 | 低 |

### 競合状況
- アガルート・TACが「合格率・勉強時間」KWを占拠
- ニッチ余地: 脱落者向けKW、CBT活用、文系AI資格との比較

### Syllabus Hack との親和性
- DS検定記事（`trend/ds-kentei/`）との内部リンク設計が可能
- 「文系の資格戦略: FP2級 vs G検定 vs DS検定」比較記事で既存コンテンツを活かせる
- PASONAフレーム向き（「落ちた恐怖」→「今すぐCBTでリベンジ」）

> [!forAI]
> FPは実生活に関わる資産形成に役立つ意味としてあまり知られていない。資格ありきではなく「知識」として学ぶ価値があることを優先にしたい。受からなくても、資格がなくても、自分自身とか身内の資産改善には繋がるから受からなくても活用できる知識はある。これをもとにKWを再考。

## 3. 秘書検定

### 市場規模
- 年間受験者 **10万人超**、累計 **700万人超**
- 2級・3級はCBT対応（2026年も拡大）
- 合格率: 2級 50〜61%、3級 70%超

### 狙えるKW

| キーワード | 方向性 | 競合レベル |
|---|---|---|
| 秘書検定 意味ない | 否定→逆転 | 高（U-Can占拠） |
| 秘書検定 いきなり2級 | 実践 | 中 |
| 秘書検定 転職 有利 | 就職 | 中 |
| 秘書検定 vs ビジネスマナー検定 どっち | 比較 | 低〜中 |
| 秘書検定 フリーランス 意味ある | ニッチ | 低 |
| 秘書検定 マルチワーク 副業 | ニッチ | 低 |
| 秘書検定2級 CBT 攻略 | 新規 | 低 |
| 秘書検定 男性 受けても良い | ニッチ | 低 |

### 競合状況
- careerpark-agent / U-Can / theport が「就職」「転職」KWを占拠
- ニッチ余地: フリーランス・副業文脈、男性受験者向け、CBT活用

### Syllabus Hack との親和性
- **非IT層ターゲット**として開拓余地あり（career / method カテゴリ）
- 「事務職 × AI活用」「ビジネスマナー × ChatGPT学習法」フレームで差別化可能
- ただし現状のコアミッション（IPA試験・データ系）からの乖離が大きいため **優先度: 中〜低**

> [!forAI]
> 秘書検定はビジネスマナーを学ぶのに適しているし、それを教える社内・社外セミナーをやる講師としての活用も見込まれる。ただ近年はAIテック以外でも生成AI活用の場が増えているため、ビジネスマナーだけではなくAIを駆使して「秘書としてもAIで効率化を図る」みたいなアプローチを優先したい。

## 4. AWS・ネットワーク系資格（CCNA / AWS SAA / AWS ANS）

### 市場規模
- CCNA求人数: **25,000件以上**（未経験歓迎多数）
- CCNA合格率: **20〜30%**（難易度高め）
- 推奨学習ロードマップ: CCNA → AWS SAA → AWS Advanced Networking

### 狙えるKW

| キーワード | 方向性 | 競合レベル |
|---|---|---|
| CCNA 独学 勉強時間 未経験 | 入口 | 高 |
| CCNA 難しすぎる 受からない | 脱落 | 中 |
| CCNA 落ちた 何回目 | 脱落 | 低 |
| CCNA 文系 独学 合格 | ニッチ | 低〜中 |
| LPIC CCNA AWS どっち 先に取る | 比較 | 中 |
| AWS Advanced Networking 難易度 | ニッチ | 低 |
| ネットワークエンジニア 資格 ロードマップ 2026 | 全体像 | 高 |
| CCNA 意味ない クラウド時代 | 否定→逆転 | 低〜中 |
| AWS SAA 未経験 転職 本当に取れる | 感情 | 中 |

### 競合状況
- infla-lab.com がロードマップ系KWを多数占拠
- ニッチ余地: 「文系独学」「脱落者向け」「CCNA意味ない反論」「AWS ANS詳細」

### Syllabus Hack との親和性
- NW / SC 試験記事との内部リンク設計が可能（AP/NW/SC フラッシュカードと接続）
- 「シラバスハック」フレームで「CCNAの出題範囲をAIで攻略」という記事に展開しやすい
- **優先度: 高**（既存インフラ記事との親和性大、高度試験ユーザーとの重複が高い）

> [!forAI-AWS]
> AWSの特徴は資格がプラットフォームごとにあるので多岐に渡ること。エンジニアにとっては何を取ればいいのかわからないこともある。フロントエンドとバックエンドで違うけれど、AWSの特性からしてバックエンドポイントの需要がそれなりにあるし、クラウド×AIの構築がこれからピークを迎えるはず。なのでシラバスハックとしては、エンジニアとかそれ以外でもAWS資格の必要製を考えるうえで、「おすすめのAWS資格診断」で選択式質問でベストを見つけるアプローチを取り入れたい。

> [!forAI-CCNA]
> グローバルエンジニアになるなら必須ともいえる資格。取得の難しさよりも腕試しで挑戦してみるのがいい感じだろう。日本では試験自体の知名度も低いため、エンジニアの証明としては業界によって差が出るはず、むしろこの資格を履歴書に書いていて無反応であるならそこの経営層と人事部はゴミであるし何を必要としているか不透明だから、CCNAに反応する企業をメインに就職先を探す方向性も欲しい。だから学生のときに取得するなら新卒でテック系にエンジニアで入るつもりなら勉強する価値はあるのではないだろうか。

## 優先度まとめ

| カテゴリ | 優先度 | 理由 |
|---|---|---|
| AWS・ネットワーク系 | **高** | 既存コンテンツ（NW/SC/AP）との接続、技術系読者と親和性高 |
| FP2級 | **中〜高** | DS検定記事と内部リンク可能、CBT新需要、脱落KWのニッチ余地 |
| MOS | **中** | 市場大だが大手に占拠され差別化要求が高い。AI活用フレームで一点突破 |
| 秘書検定 | **低〜中** | コアミッションとの乖離大。副業・マルチワーク文脈なら可 |
