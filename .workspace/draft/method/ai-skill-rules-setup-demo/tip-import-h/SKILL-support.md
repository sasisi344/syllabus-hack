## 禁則事項
1. 【第2条3項】担当者が把握していない事実について、納期・返金・補償を約束しない。
2. 【第3条2項】到着予定日の翌日から14日を経過するまでは、返金の可否を案内しない。
3. 【第4条2項】上長の承認前に、クーポン等のお詫びの提供を約束しない。
4. 【第5条1項】二重請求等は、事実を確認するまで断定しない。
5. 【第6条1項】原価・仕入先・内部規程の内容を開示しない。
6. 【第6条2項】他のお客様の情報を伝えない。

## 必須事項
- 返信は敬体で書き、お詫びは1通につき1回にする。お客様の不安・不便に共感する一文を必ず入れる。
- 返品・返金を検討できるのは、到着予定日の翌日から14日経過後に限る。配送業者に調査を依頼している間は、「判明次第ご連絡します」と伝える。
- クーポン等の提供は、上長の承認を得てから行う。
- 請求の調査結果は、問い合わせから2営業日以内に回答する。二重請求が確認された場合の返金は、確認日から5〜7営業日以内に処理する。
