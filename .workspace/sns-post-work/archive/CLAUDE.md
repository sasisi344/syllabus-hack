# archive — 投稿済みログ管理ルール

`post-task.md` でチェック（`[x]`）が入った投稿を移動・記録する場所。

## 処理手順

1. `post-task.md` 内でチェック済みの投稿ブロック（日付・時間・型・元記事・連投の目印・各スレッド本文）を丸ごとコピーする。**予約した実際の文面と `post-task.md` の本文が違う場合は、実際に投稿した文面を記録する**（ユーザーに確認する）
2. `log.md` の末尾に、投稿日の新しい順ではなく**時系列の古い順で追記**する（既存ログを並べ替えない、常に追記のみ）
3. ログ1件のフォーマットは以下に固定する（2026-09-28更新: 元記事はフルURL、本文は引用記号なし。2026-10-06更新: 連投（スレッド）形式に対応。各スレッドを ```` ```post ```` ブロックで記録する）：

   ````markdown
   ### YYYY-MM-DD（曜日）HH:MM — 型X
   - 元記事: https://syllabushack.com/{category}/{slug}/（なければ「なし」）
   - 連投の目印: 「（1/N）」方式 または 「続きます👇」方式

   **スレッド1（ルート）**

   ```post
   スレッド1の本文
   ```

   **スレッド2**

   ```post
   スレッド2の本文
   ```
   ````

   - 2026-10-05以前の単発投稿は従来の「本文:」＋インデント付きプレーンテキスト形式のまま残す（既存ログは書き換えない）
   - スレッド形式のログも、本文ブロックの中身には見出し・チェックボックス・メタ情報を含めない

4. `post-task.md` から該当ブロックを削除する
5. [`../used-topics.md`](../used-topics.md) の該当行のステータスを「投稿済み」に更新する

## ログの用途

- **重複防止**: 新しい週の投稿を作る前に、直近の `log.md` を見て同じ元記事・似た切り口を避ける
- **振り返り**: 2〜4週間ごとに型（A〜E）ごとの投稿頻度をログから集計し、[`../../draft/sns/posting-strategy.md`](../../draft/sns/posting-strategy.md) の配分見直しに使う
- **ログは編集しない**: 過去の記録は消さない・書き換えない。訂正が必要な場合は取り消し線ではなく、新しいエントリで注記する
