# weekly-rotation-template — 週次投稿作成の手順

`post-task.md` を新しい週分作るときに、この順番で作業する。

## 手順

1. **前週のペルソナ配分を確認する**: `archive/log.md` の直近1〜2週間分を見て、どのペルソナ番号（[`persona-channel-map.md`](persona-channel-map.md)の#1〜8）をどの型で使ったか把握する
2. **今週のペルソナを割り当てる**: 下記の基本ローテーション雛形をベースに、直近と重複しないよう曜日ごとにペルソナ番号を仮決めする。新規コース公開・重要な制度ニュースなど「今週固有の出来事」があれば、該当日をペルソナ#6（型E）に固定してよい
3. **各ペルソナに対応する元記事・アプリを選ぶ**: `persona-channel-map.md`の「元ネタとなるコンテンツの性質」列を見て、`.workspace/task-results/article-index.md`（`node .workspace/scripts/index-articles.js`で更新済みのもの）から候補を探す。型Fの場合は先に[`app-directory.md`](app-directory.md)でstable/betaアプリを確認し、そのexamIdから記事を逆算する
4. **重複チェックをスクリプトで実行する（必須）**: `used-topics.md`を目視するだけでなく、必ず以下を実行して機械的に確認する。目視・記憶だけでの判断は禁止。

   ```bash
   node .workspace/scripts/check-sns-topic.js <候補1のcategory/slug> <候補2のcategory/slug> ...
   ```

   🔴（使用不可）と出た候補は別の記事に差し替えて再実行する。引数なしで実行すると、全履歴のクールダウン状況（🔴使用不可・🟢使用可能・再使用可能日）を一覧で確認できる
5. **本文を執筆**: 型ごとのPREP構成・フック文末（？または絵文字）・CTA絵文字のランダム性ルールは[`posting-strategy.md`](../../draft/sns/posting-strategy.md)に従う。350〜480字目安
6. **`post-task.md`に追記、`used-topics.md`に「予定」で登録**: 元記事はフルURL（`https://syllabushack.com/{category}/{slug}/`）で記載する

## 基本ローテーション雛形（週7投稿の場合）

曜日固定ではなく目安。直近の使用状況やニュース性のある出来事があれば柔軟に入れ替える。

| 曜日目安 | ペルソナ# | 型 | 備考 |
|---|---|---|---|
| 1日目 | #1（入門検討層） | A | 週の入口として分かりやすい一点教育から入る |
| 2日目 | #4（実利・数字を見たい層） | D | |
| 3日目 | #2（学習中・演習不足層） | B | |
| 4日目 | #5（懐疑層・俗説に影響された層） | C | |
| 5日目 | #3（実践演習を求める層） | F | 対応アプリがない週はペルソナ#8（G）や#1（A）で代替 |
| 6日目 | #8（読み物として関心がある層） | G | 適した記事がない週はペルソナ#5（C）で代替 |
| 7日目 | #7（既存フォロワー・振り返り） | E | 週の振り返り、または新規性のある告知があればそちらを優先 |

## 「今週固有の出来事」による上書き例

- 新規コース公開・記事公開など明確な告知がある日 → その日はペルソナ#6（型E）に差し替える
- 制度ニュース（シラバス改訂・新設試験の続報等）が出た場合 → 該当日をペルソナ#6にし、鮮度を優先する

## チェックリスト（`post-task.md`確定前）

- [ ] 週内で同じ型を連続させていないか
- [ ] 週内で同じペルソナ番号を連続させていないか
- [ ] `node .workspace/scripts/check-sns-topic.js`を実行し、全候補が🟢（使用可能）と判定されたか
- [ ] 型F・Gを使った場合、それぞれ本当に元記事・アプリの組み合わせが揃っているか（無理に埋めていないか）
- [ ] フックの文末（？／絵文字）が週内で単調になっていないか（[`posting-strategy.md`](../../draft/sns/posting-strategy.md)「フック・CTAのランダム性」参照）
- [ ] 「IPA」を単独略称で使っていないか
