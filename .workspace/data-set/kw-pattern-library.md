# KWパターンライブラリ — 資格試験名横断データ

> **目的**: 「資格試験の名称」を主軸変数として、どの資格にも再現するKW生成パターンをデータ化する。
> **用途**: `.agents/kw_pattern_research.md`（スキル定義）から読み込まれる。記事執筆テンプレートではなく、リサーチ（候補KW生成→競合占拠度判定→ニッチKW選定）専用のデータセット。
> **元データ**: `.workspace/.task/research-kw-non-ipa.md`（MOS / FP2級 / 秘書検定 / AWS・CCNA の実地調査）から方向性を抽出・汎用化。

---

## 変数定義

| 変数 | 意味 | 例 |
| --- | --- | --- |
| `{C}` | 資格名（正式名称・通称どちらでも） | MOS、FP2級、CCNA、宅建 |
| `{C2}` | 比較対象の資格名 | ITパスポート、AWS SAA、簿記 |
| `{ATTR}` | 検索母数が一定あるニッチ属性 | 文系、未経験、社会人、フリーランス、学生、男性、40代 |
| `{N}` | 回数 | 2回、3回 |
| `{Y}` | 年 | 2026 |
| `{T}` | 期間 | 3ヶ月、半年 |

## パターン一覧（P1〜P9）

| コード | パターン名 | KWテンプレート | 競合占拠度（既定値） | ニッチ化のコツ |
| --- | --- | --- | --- | --- |
| P1 | 否定→逆転 | `{C} 意味ない` / `{C} 役に立たない` / `{C} 恥ずかしい` | **高**（大手通信講座が独占） | 属性・職種を1段加える（`{C} 意味ない {職業}`）でロングテール化しないと勝てない |
| P2 | 脱落・失敗 | `{C} 落ちた 原因` / `{C} 受からない なぜ` / `{C} 難しすぎる` / `{C} {N}回落ちた 対策` | **低〜中**（心理検索は大手が手薄） | 最有力の狙い目。感情×具体的失敗状況の組み合わせほど競合が薄い |
| P3 | 比較 | `{C} vs {C2} どっち` / `{C} {C2} どちらが先` | **中** | 自社の既存Hub同士をリンクできる組み合わせを優先（内部リンク資産化） |
| P4 | 属性ニッチ | `{C} {ATTR} 独学 合格` / `{C} {ATTR} 意味ある` | **低** | 属性を増やすほど競合は減るが需要も減る。検索母数が確認できる属性のみ選定（文系・社会人・未経験など実績のある属性に限定） |
| P5 | 制度変化・新規 | `{C} CBT いつ` / `{C} {Y} 変更点` | **低**（鮮度勝負） | 公式発表直後が最大チャンス。半年〜1年で占拠度が「高」に変わるため定期再調査が必要 |
| P6 | 実践・期間限定 | `{C} {T} 勉強時間` / `{C} 社会人 勉強法` | **中** | 期間・属性を掛け合わせるとロングテール化。単独の「勉強時間」だけだと占拠度が高くなりがち |
| P7 | 感情・心理 | `{C} 独学 挫折` / `{C} 怖い` / `{C} 自信ない` | **低** | 検索ボリュームは小さいが滞在時間・共感性が高くCVに繋がりやすい。PASONAフレームと相性が良い |
| P8 | 網羅・ロードマップ | `{C} 独学 勉強時間 未経験` / `{C} ロードマップ {Y}` | **高**（入口KWは大手が必ず押さえる） | ニッチKW狙いには非推奨。Hub記事の入口導線としてのみ割り当てる |
| P9 | キャリア訴求 | `{C} 転職 有利` / `{C} 意味ある 職業` / `{C} 資格 評価` | **高〜中** | career系メディアが強い。「AI活用」「フリーランス」等のSyllabus Hack差別化軸と必ず掛け合わせる |

## 競合占拠度の実査基準

候補KWをWebSearchで実査し、上位5件のドメインで判定する。

| 占拠度 | 判定基準 |
| --- | --- |
| 高 | 上位5件中3件以上が大手通信講座・転職メディア |
| 中 | 上位5件中1〜2件が大手、残りは個人ブログ・Q&Aサイト |
| 低 | 上位5件に大手なし、または検索結果自体が少ない（ロングテール） |

### 頻出競合プレイヤー（横断的に出現。資格ごとに追加調査が必要）

通信講座・スクール系: U-Can、TAC、アガルート、キャリカレ、フォーサイト、スタディング
転職・キャリアメディア系: careerpark-agent、レバテックルーキー、Midworks、type、doda、マイナビ
資格特化メディア系: infla-lab.com（インフラ系資格）、theport

> 上記は `research-kw-non-ipa.md` で実際に確認された占拠プレイヤーの一部。資格ジャンルが変わると占拠プレイヤーも変わるため、新規資格では必ずWebSearchで個別に確認すること。

## ニッチ×需要ありKWの選定基準（AND条件）

1. 競合占拠度が「低〜中」
2. パターンが P2 / P4 / P5 / P6 / P7 のいずれか（構造的に大手が手薄になりやすいパターン）
3. KWだけで読者の状況・検索意図が具体的に想像できる（属性・期間・状況の修飾語を含む）

P1・P8・P9 は占拠度が高い前提のため、新規スポーク記事の主軸KWには採用しない。Hub記事の入口導線、または既存差別化角度（AI活用等）を強く掛け合わせた場合のみ例外採用する。
