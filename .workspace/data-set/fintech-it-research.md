### 難易度の実態（体験記ベース）

- 合格率は**非公表**。ただし合格体験記では「公式テキスト1周＋サンプル問題で計5〜6時間」の短期合格例が複数（note 2件・偏差値48想定の評あり）
- 頻出は「API」「KYC」「AML」など金融IT特有の略語・概念。ITパスポート知識があれば大幅に短縮できる構造
- **ITパスポートより明確に軽い**。「ITパスポートの次」というより「ITパスポート＋金融ドメイン語彙の上乗せ」が実態

## 4. クラスター記事材料（2026-07-12 追加調査）

### 4-1. 一次情報の追加ファクト（記事の武器になる順）

1. **上級・プロフェッショナルは未実施**: 3級構成のうち現在受験できるのは初級のみ（2024年秋開始）。上級=中堅〜マネジャー、プロフェッショナル=管理職〜役員が想定対象。「上級はいつから？」を明記した整理記事は不在で、続報ウォッチ枠（P5）が取れる
2. **金融大手が結集して創設**: みずほ・三菱UFJ・住友生命らが参画（日経xTECH報道）。「業界標準を狙う本気の検定」という権威付けが一次情報で書ける
3. **過去問が存在しない**: 演習素材は公式サンプル問題10問のみ＋公式テキスト＋eラーニング。「公式テキストなしでも合格可能」という体験記もあり、**シラバス用語をAIに解説させる学習法（シラバスハック本流）が構造的に最適**な試験
4. **合格の実態**: 公式テキスト1周＋サンプル10問・計5〜6時間の合格体験記が複数（メガバンク社員・銀行PM等）。シラバス記載キーワードは全て出題対象という運用

### 4-2. 出題シラバスの用語材料（3分野）

- **ITシステム分野**: LLM・ブロックチェーン・Web3・クラウド・RPA・API・OSS・NoSQL・5G・仮想化・ランサムウェア・リスクベース認証・アジャイル・ITIL・WBS・SLA・ITガバナンス等 — **ITパスポート/FE既習者はほぼ既知**（学習短縮の根拠。既存theory記事群への内部リンク資産になる）
- **金融デジタルビジネス分野**: 銀行・保険・証券それぞれのDX事例・デジタル金融サービス
- **金融ITシステム分野**: 勘定系／情報系／事務系、CIF、オープンAPI、全銀ネット・全銀EDI、統合ATMスイッチングサービス、ことら、CAFIS、ペイジー、SWIFT、EDINET、個人信用情報機関（CIC）、コロケーション、モダナイゼーション、切り戻し、目標稼働率等 — **一般IT学習者に馴染みのない金融固有レイヤー**。ここが試験の実質的な学習対象であり、AI対話学習ハックの主戦場
