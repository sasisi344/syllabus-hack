## 1. 試験制度の一次情報

### 区分と受験資格

| 区分 | できること | 受験資格 |
| --- | --- | --- |
| 乙種（1〜7類） | 整備・点検のみ | **なし（誰でも受験可）** |
| 甲種（特類・1〜5類） | 工事＋整備・点検 | あり（下記） |

甲種の主な受験資格ルート:
- **電気工事士（一種・二種）／電気主任技術者（電験一〜三種）の免状**（ビルメン読者に最重要: 電工二種持ちはそのまま甲種へ行ける）
- 乙種免状取得後、**整備の実務経験2年以上**
- 消防用設備工事の補助者として実務5年以上
- 大学・短大・高専で機械・電気・工業化学・土木・建築系学科を修了
- 管工事施工管理技士・建築士・技術士二次合格者ほか

### 試験日程・申込（2026年度）

- 都道府県ごとに実施（消防試験研究センター）。**年1回の県から3〜4回の県まで差が大きく、全国的には前期・後期の年2回が一般的**
- 令和8年度は4〜6月分の日程が公開済み、7月以降〜令和9年3月分は2026-03-02掲載予定
- 申込は電子申請＋書面の併用だが、**令和10年度から原則電子申請のみ**に移行予定（制度変化ネタ・P5）

### 試験内容（乙6＝消火器の例）

| 項目 | 内容 |
| --- | --- |
| 筆記 | 30問（法令共通6＋法令類別4＋機械の基礎知識5＋構造・機能・整備15）マーク式 |
| 実技（鑑別等） | **5問・記述式**。写真を見て名称・操作方法・作業手順を書く（機器の実操作はない） |
| 試験時間 | 1時間45分（筆記＋実技を通しで解く） |
| 合格基準 | 筆記: **科目ごと40%以上**かつ全体60%以上、**かつ**実技60%以上（5問中3問） |

- 足切り構造が二重（科目別40%＋実技60%）で、「基礎的知識（機械5問）」の全滅で法令満点でも落ちる
- 「基礎的知識」は中学〜高校レベルの数学・物理を含み、文系受験者の主要な脱落点

### 試験内容（甲4 — 2026-07-12追記・実査済み）

| 項目 | 内容 |
| --- | --- |
| 筆記 | 45問（法令共通8＋法令類別7＋電気の基礎10＋構造・機能・工事整備20）・2時間15分 |
| 実技 | 7問（**鑑別5＋製図2**）・1時間。総試験時間3時間15分 |
| 製図 | 甲種のみの難関。平面図の完成＋系統図の完成の2問構成 |
| 合格基準 | 乙種と同じ二重構造（科目別40%＋全体60%＋実技60%） |

### 合格率・受験者数（規模感）

| 区分 | 受験者数 | 合格率 |
| --- | --- | --- |
| 乙6（消火器） | 年2〜2.5万人（**最多区分**） | 36.2%（2024年度）、概ね35〜40% |
| 乙4（自火報） | — | 31.2%（令和5年度）、30〜35%で推移 |
| 甲4 | 19,767人（2024年） | 34% |
| 乙7 | — | 約60%（電工免除の影響で易しい） |
| 全体 | — | 30〜40%で推移。甲乙で大差なし |

### 免状・法定講習（合格後の制度 — 記事の独自ネタ）

- 免状交付後も**定期講習の受講義務**あり: 初回は交付後最初の4/1から**2年以内**、以降は**5年以内**サイクル
- 未受講は消防法違反で**違反点数5点**（1年ごとに5点追加）。3年間で累積20点超で**免状返納命令**の対象
- ただし「未受講だけでは直ちに罰則・返納にはならないグレーゾーン」という実態があり、解説需要がある
- boiler-refrigeration-hub の「試験合格と免許取得は別物」と同型の、**取得後の制度罠**コンテンツが成立する

## 2. 競合状況の要点（KW-DBから再掲＋補強）

- 過去問・鑑別のまとめは青木マーケ（aokimarke/aokibosai）が最強。正面から過去問まとめでは勝てない
- 「鑑別の覚え方」「落ちた原因」は大手不在（占拠度: 低〜中）
- **AI活用×消防設備士はほぼ空白**。写真記述式の実技という試験構造は、本サイトの「AI添削・連想生成」ハックと構造的に相性が良い
- ビルメン文脈では「ボイラー・冷凍の需要減→消防設備士優先」というトレンド言説が個人系メディアで拡散中（P5的な鮮度）

## 3. クラスター方向性の提言（ユーザー確認用）

### 推奨構成: Hub 1本＋スポーク2本で開始

| # | 記事 | 想定KW／パターン | 骨子 |
| --- | --- | --- | --- |
| Hub | `method/shobo-setsubi-hub`「消防設備士 完全攻略ガイド」 | 消防設備士 独学／どれから（P8入口） | 乙6→乙4→甲種の定石ルート、二重足切りの構造、県別日程の調べ方、電工二種→甲種の接続、免状・法定講習まで一気通貫。cert_hub_template の2セグメント構成（これから勉強する人／ビルメン現場経験者） |
| ス1 | 鑑別×AIハック（method） | 消防設備士 鑑別 覚え方（P6・占拠度低） | 写真記述式を「外観特徴の言語化→名称→用途」の連想セットでAIに生成させる。採点基準が名称だけでは満点にならない近年傾向に対応した記述添削プロンプト |
| ス2 | 落ちた原因診断（method） | 消防設備士 乙6 落ちた 原因（P2） | 二重足切り＋機械の基礎知識（数学）を診断型で解説。NW候補③と同型のリベンジ記事 |

### 差別化軸（この順で押す）

1. **実技（鑑別）が記述式である**ことを正面に据えた「AI添削」ハック — 競合空白かつサイトの得意型（ap-pm-descriptive-ai-prompts・nw-kakomon-ai-hack と同系譜）
2. **合格後の制度罠**（法定講習2年/5年サイクル・違反点数）— boiler-hubの成功パターン移植
3. **ビルメン4点セット→消防優先シフト**の文脈で denken-hub／kiken-butsu-hub／boiler-refrigeration-hub と相互リンク（クラスター相乗）

### 実装メモ

- examId `shobo-setsubi` を `src/content/config.ts` へ登録（Hub執筆と同時）
- `src/data/cert-hubs.ts` の「設備・施工」グループにHubを追記（資格ナビに自動反映）
- タグ: `消防設備士`／`ビルメンテナンス`（既存クラスターと統一）
- 鑑別写真クイズアプリはアプリ適性が高いが、**写真素材の権利がボトルネック**のため当面見送り（テキスト連想クイズなら可）
