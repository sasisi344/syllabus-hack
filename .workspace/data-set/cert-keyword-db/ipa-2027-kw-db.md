## メモ

- PassDojo・IPA資格の森（`dm-kw-db.md`）は区分ごとのクラスターが強いが、今回の横断クエリの上位には出ていない
- IPA のサンプル問題のページ（https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260622.html、2026-10-30 更新）は7本。教育目的なら問題集・テキストへの使用に許諾と使用料は要らず、出典の明記を求めている
- P5 は半年〜1年で占拠度が上がる。hub の `lastmod` 更新時と、シラバスの確定版が出たときに再実査する
