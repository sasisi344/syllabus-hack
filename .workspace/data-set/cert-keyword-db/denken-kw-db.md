## AIハック適性（詰まりポイント）

| 分野 | 詰まり | AI活用の切り口 |
| --- | --- | --- |
| 理論科目 | 数式変形の意味が腹落ちしない | 「なぜこの式変形が成立するか」を対話で分解 |
| 機械科目 | モーター・発電機の動作原理が図なしで理解不能 | AIに図的説明・比喩（回転磁界＝回るコマ）を作らせる |
| 法規科目 | 数値基準の暗記が丸暗記になりがち | 数値の背景（安全率・許容電流）を説明させる |
| 科目合格戦略 | 4科目を1年でやるか分割するか判断できない | 自分の可処分時間からAIに分割プランを設計させる |

## 競合占拠度リサーチ（WebSearch実査済み・2026-07-10）

「電験三種 落ちた 原因」実査結果: 上位10件中 agaroot（3種の資格予備校コラム）・SAT・brush-up・studying等の**資格予備校系が上位を占有（占拠度：高）**。個人ブログ・Yahoo!知恵袋も混在するため、P2（脱落・失敗）単独では占拠度中〜高と判定。属性を掛け合わせるニッチ化が必須。
