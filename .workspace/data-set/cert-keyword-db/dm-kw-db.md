## 競合占拠度リサーチ（WebSearch実査済み・2026-09-27）

**結論: 「新設試験だから競合が薄い」という前提は誤り。2026-03〜06の公式発表を起点に、専門特化型の新興サイトが約3ヶ月で先行してクラスターを構築済み。** シラバスハックのDMコース公開（2026-09-19）はこの competitive window に対して後発になっている。

- 「データマネジメント試験とは／難易度／勉強法・ロードマップ／サンプル問題」のほぼ全パターンで **PassDojo（`passdojo.jp/ipa/data-management/`）が上位常連**。overview・difficulty・study-guide・exam-preparation・sample-questionsの記事を揃えたフルクラスターを既に構築済み（**占拠度: 中〜高**、ただし「大手通信講座」ではなく新興の専門特化サイト1社が突出している点が特殊）
- 「IPA資格の森（`ipa-shikaku.com/dm/`）」も同様に `/dm/` 配下でハブ構築中。図解・サンプル問題解説で重複
- 「データマネジメント試験 サンプル問題」: IPA公式・ITmedia・Impress Watch等のニュース勢に加え、PassDojo・note個人（ikepo氏の科目B解法編等、非常に具体的）・YouTube解説まで多メディアが即応（**占拠度: 高**。ただし2026-06-22公開からまだ日が浅く、シラバスハックが未着手の状態）
- 「データマネジメント試験 予想問題 AI」: **日経クロステックがTACと協力し、政府サンプル公開に先駆けて「AI予想問題」を作成・公開済み**（占拠度: 高、権威性も強い）。ただしこれは「筆者が生成AIを分析パートナーとして使い、完成品の予想問題を読者に提供する」という**受け身消費型**のアプローチ。一方「読者自身がAIで想定問題を自作するプロンプトを配布する」という**参加型・自走支援型**のアプローチは、DM関連クエリでは競合が見当たらず（**占拠度: 低・白地**）。これはシラバスハック既存の`fe-subject-b-drill`（無限ドリル生成メソッド）等と同型で、サイトの得意パターンがそのまま通用する
- 「データマネジメント試験 ITパスポート 違い」: gihyo.jp（ITパスポート専門サイト）・日経xTECH・PassDojo・Study Shelf等が並ぶ（**占拠度: 中〜高**）
- 「データマネジメント試験 いつから／2027」: IPA公式・ITmedia・日経xTECH・Impress Watchなどニュースメディアが上位（**占拠度: 高**。一次情報の速報勝負でニュースサイトに勝つのは困難）
- 「データマネジメント試験 転職／意味ある」: doda・JAC Recruitment等の一般転職メディアとseraku.co.jp・PassDojo等が混在（**占拠度: 中**。大手一強ではなくやや手薄）

## Act候補（w40週報・2026-09-27ずらし戦略検討からの引き継ぎ）

1. **最優先（確定・2026-09-27）**: 「データマネジメント試験に過去問は存在しない」を逆手に取った【プロンプト配布】型記事を新規作成。`fe-subject-b-drill`と同型で、読者自身がAIで想定問題を無限生成できるプロンプトを配布する。日経xTECH+TACの「AI予想問題を作って渡す」受け身消費型とは逆の「読者のAI活用力そのものを伸ばす」参加型アプローチで差別化する。IPA公式サンプル問題（2026-06-22公開）の解説は導入部に短く吸収し、本題はプロンプト配布＋自作手順に置く
   - 想定タイトル案: 「【プロンプト配布】データマネジメント試験『無限想定問題』生成メソッド｜過去問ゼロでもAIで演習量を確保する」
   - 構成案: (1)DM試験には過去問が存在しない構造的な不安の提示 → (2)日経+TAC等が代わりに予想問題を作ってくれているが数に限りがある現状紹介 → (3)自分でAIに無限生成させるプロンプト配布（科目A用語ドリル・科目B事例問題の両方） → (4)生成結果の検証方法（シラバス案との突き合わせ、公式サンプルとの形式比較）→ (5)DMコース第4章・第8章への回遊導線
   - 演習アプリ: **2026-09-27決定・記事のみ先行公開**。新規アプリ開発は`.agents/quiz_app_rules.md`準拠の別ワークフロー（examId登録・`src/apps/index.ts`編集等）になるためスコープ外とし、反応を見てから別タスクとして着手判断する
2. `course/dm/index.mdx` 内の「ITパスポートとの違い」言及を、独立したtrend/career記事に切り出して比較記事化を検討（IP・DM両コースを保有する自社の強みを活かせる）
3. 次回KWリサーチ時は「データマネジメント試験 科目B 解法」を優先実査（ikepo氏の記事が具体的すぎる場合は占拠度を「高」に格上げして主軸から外す）
