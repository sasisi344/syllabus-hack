## Syllabus Hack の差別化方針

> restructure-plan Phase 2 優先度 **B** — 競合激戦のため全面攻略は避ける。

**狙うべき角度（AI×シラバス適合）:**

- AI音声・シャドーイング・逐語訳の**対話型**学習設計
- Part別弱点の**診断プロンプト**（なぜ間違えたかの言語学的説明）
- スコア帯別（600/730/800/900）の**学習計画の根拠**をAIに説明させる
- 暗記単語帳の代替ではなく「文脈で覚える」対話理解型

**避けるべきKW（レッドオーシャン）:**

- 単純な「TOEIC 勉強法 おすすめ」一覧
- 教材ランキングのみ
- スコアアップの一般論（差別化なし）
