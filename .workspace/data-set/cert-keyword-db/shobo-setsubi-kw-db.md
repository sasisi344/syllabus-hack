## 試験サマリー

| 項目 | 内容 |
| --- | --- |
| 区分 | 甲種（特類・1〜5類: 工事・整備・点検）／乙種（1〜7類: 整備・点検のみ） |
| 入門の鉄板 | **乙6（消火器）**・**乙4（自動火災報知設備）**。乙種は受験資格なし（誰でも受験可） |
| 甲種の受験資格 | 電気工事士・電験等の資格、実務経験、大学等の学歴のいずれかが必要 |
| 合格率目安 | 乙6: 約35〜40%、乙4: 約30%台。**科目ごとに40%の足切り**あり |
| 標準学習時間 | 乙6: 約24時間〜2ヶ月（合格者体験談ベース）。1ヶ月での取得体験記が多数 |
| 試験の特徴 | 筆記（マーク）＋**実技（鑑別等・記述式）**。甲種はさらに製図。実技は写真を見て名称・用途を記述する形式 |
| 需要動向 | ビルメン界隈で「ボイラー・冷凍の需要減 → 消防設備士優先」へのシフトが進行中。全建物に消防設備が設置され法定点検需要が安定 |

## AIハック適性（詰まりポイント）

| 分野 | 詰まり | AI活用の切り口 |
| --- | --- | --- |
| 実技（鑑別） | 写真問題で機器名称・用途を**記述**させられる。似た感知器・消火器の見分けがつかない | AIに「外観の特徴→名称→用途」の連想セットを作らせる。特徴の言語化（蛍光灯のように丸い→差動式スポット型）はLLMの得意領域 |
| 採点基準の変化 | 近年は機器名だけでは満点にならず、機能・理由まで記述が必要 | AIに模範解答を採点者視点で添削させる（ap-pm-descriptive-ai-prompts と同型の添削ハック） |
| 基礎的知識の数学 | 中学〜高校レベルの計算問題で足切りされる文系受験者が多い | AIに苦手単元だけ個別指導させる（分野診断→重点配分） |
| 科目足切り | 法令で稼いでも「機械」全滅で不合格になる構造に気づかない | AIに模試結果から足切りリスク科目を診断させる |
| 類選び | 乙1〜7のどれから取るべきか迷う | Hub内で「乙6→乙4→甲種」の定石ルートを提示 |
