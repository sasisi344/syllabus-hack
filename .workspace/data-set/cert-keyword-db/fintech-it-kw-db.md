## AIハック適性（詰まりポイント）

| 分野 | 詰まり | AI活用の切り口 |
| --- | --- | --- |
| 演習素材の不足 | 過去問がなくサンプル10問のみ | シラバス用語をAIに「なぜ金融で必要か」から解説させる（シラバスハック本流の型がそのまま効く） |
| 金融固有用語 | 勘定系・CIF・全銀ネット・CAFIS・SWIFT等がIT系学習者に馴染みなし | ITパスポート知識との対応表・例え話をAIに生成させる |
| 3分野のバランス | ITシステム分野はITパスポートと重複、金融分野だけ未知 | 既習範囲の診断→金融分野へ学習時間を集中配分 |
