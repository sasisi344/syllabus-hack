## パターンと占拠度の読み方

[手順](../../../.agents/kw_pattern_research.md)と[パターンライブラリ](../kw-pattern-library.md)の非資格コンテンツへの読み替えを適用。`{C}` をマーケティング・章の技能に置き換えた。P6は実践形式（練習問題・演習・ワーク・ケース）にも適用する。P4は新卒・内定者・入社前・文系・未経験・初心者・配属の状況、P2は用語を覚えられない失敗、P7は挫折・不安、P10はツール名つきの練習。P1・P3・P8・P9は比較対象として記録する。

P5は制度変化の一次情報を材料として与えられていないため、日付だけを付けた変更KWを作らない。各パターンの機械的な同数生成より、指示書で指定された状況・練習・章テーマを優先した。

占拠度は上位5件中の大手講座・研修／講座比較・就職転職メディアの件数で判定（3件以上=高、1〜2件=中、0件=低）。既存プレイヤーに加えて、今回の結果の次の媒体・サービスを集計対象とした。これは検索結果の分類であり、会社規模の数値調査ではない。

- 講座・研修: ユーキャン、グロービス、JMA、Udemy（企業別テナントを含む）、WEBMARKS、ALL DIFFERENT、MURCの研修資料、ソフトキャンパス。
- 講座比較・就職転職メディア: マイナビ、就活市場、インターンシップガイド、コエテコ、Indeed、For Marketer、Chapter Two、リクナビ、求人ボックス。
- Google・Salesforce・HubSpot・Asana・Shopify・LINEヤフー・GMO、官公庁、大学、検定主催団体は上の講座／転職メディア件数には含めない。該当結果が多い場合は判定メモに記録した。「低」は競合が個人だけ、または勝ちやすいという意味ではない。
- Wantedlyに掲載された企業の採用記事は比較・転職ノウハウ記事と分けて計上外とした。通常の事業会社の解説、規模未確認の専門サイトも自動的に「大手」扱いしない。
- 上位ドメイン欄の「※」は集計対象。判定メモと件数を合わせて再検収できる。5件を確認できない場合は占拠度を「未実査」とする（今回は該当なし）。
