## AIハック適性（詰まりポイント）

| 分野 | 詰まり | AI活用の切り口 |
| --- | --- | --- |
| 試験と免許の違い | 「合格＝資格取得」だと思い込み、免許申請で実技講習が必要と後から知って焦る | AIに受験〜免許取得までのロードマップを時系列で整理させる |
| 引っ掛け問題 | ボイラー技士は法令の数値・用語のひっかけが多く、過去問暗記だけでは対応できない | AIに「なぜこの数値基準なのか」を背景ごと説明させ、丸暗記を理解に変える |
| 科目の足切り | 科目ごとの40%足切りに気づかず、苦手科目を放置して不合格になる | AIに自分の模試結果から弱点科目を診断させ、重点配分を提案させる |
| 冷凍サイクルの原理 | 冷媒の状態変化（圧縮・凝縮・膨張・蒸発）が図なしでは理解できない | AIに身近な例え（エアコン・冷蔵庫の仕組み）で状態変化を解説させる |

## 競合占拠度リサーチ（WebSearch実査済み・2026-07-10）

- 「ボイラー技士 落ちた 原因」: 上位10件中、個人ブログ（脱線おじさん・平太の雑談ブログ）・Yahoo!知恵袋・note等の**個人発信が大半を占め、資格予備校の独占は見られない（占拠度：低〜中）**。P2として狙い目
- 「冷凍機械責任者 社会人 勉強法 独学」: 個人の独学ブログが上位を占有し、大手予備校コラムはほぼ登場せず（占拠度：低）。P4/P6の掛け合わせが特に有効
- 「ボイラー技士 二級 独学 未経験 合格」: SAT・ユーキャン等の実務系資格予備校コラムが上位に一部混在するが、個人ブログとの混在で占拠度は中程度
