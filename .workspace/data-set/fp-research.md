## 2. 等級と難易度

| 等級 | 位置づけ | 備考 |
| --- | --- | --- |
| 3級 | 入門 | CBT試験。◯✕と3肢択一。「制度の名前」「基本ルール」中心 |
| 2級 | 実生活・仕事で幅広く使える業務担当者レベル | 4肢択一。例外規定・具体的計算・書類読解の記述式あり |
| 1級 | 上級。難易度は高い | **2級合格＋実務経験が必要**（受験資格は§8で要確認） |

- 難易度の感覚は簿記（3級＝入門／2級＝実務／1級＝高難度）と同じ構造
- 市販テキストが「3級・2級」のみなのは、1級は受験資格の壁があり、実務にも使える2級までで十分という実態の反映と推測（本人所感）

### 2級と3級の違い

- 2級は3級の上位互換。**出題範囲（6分野）は同じ**で、深さと実務度が違う
- 6分野: ①ライフプランニングと資金計画 ②リスク管理 ③金融資産運用 ④タックスプランニング ⑤不動産 ⑥相続・事業承継

| 分野 | 主な内容 |
| --- | --- |
| ライフプランニングと資金計画 | 公的年金、健康保険、ライフプラン策定 |
| リスク管理 | 生命保険、損害保険 |
| 金融資産運用 | 投資信託、株式、債券 |
| タックスプランニング | 所得税、住民税の計算 |
| 不動産 | 取引、登記、建築基準法 |
| 相続・事業承継 | 贈与税、相続税、遺産分割 |

| 比較軸 | 3級 | 2級 |
| --- | --- | --- |
| 問われること | 制度の名前・基本ルール | 例外規定・具体的計算（実務レベル） |
| 形式 | ◯✕＋3肢択一（穴埋め・簡単な計算） | 4肢択一＋実技（源泉徴収票・登記簿・保険証券を読み解く複雑な計算） |

## 3. 国家資格と民間資格

| 区分 | 資格 | 内容 |
| --- | --- | --- |
| 国家資格 | FP技能士（1〜3級） | 主催は**日本FP協会**と**金融財政事情研究会（きんざい）** |
| 民間資格 | **AFP**（Affiliated Financial Planner） | 日本FP協会認定の中級資格。**FP2級相当** |
| 民間資格 | **CFP®**（Certified Financial Planner） | 世界24カ国・地域共通の国際ライセンス。民間資格の最高峰 |

> 原本は AFP を「アリエイド」と表記していたが、正式な英語名は **Affiliated** Financial Planner。記事では「AFP（Affiliated Financial Planner）」と書く

### 実務での位置づけ

- **AFP**: 金融パーソンとして「あって当然」レベル（FP2級程度）
- **CFP®**: 富裕層ビジネスや資産コンサルティングを担うプロの証。外資系・世界で活躍する証券アナリスト志向、または独立を前提としたキャリアアップならマストの選択（本人所感）

### 認知度のギャップ

- 金融業界内: 金融機関の**約8割がAFP・CFPを「ともに知っている」**と回答、専門性を高く評価。証券会社では約9割が取得を奨励（日本FP協会の調査）
  - ⚠ 出典は**2019年1月**のプレスリリース／記事。現在の数値としては使わず「2019年の調査では」と明記する
- 一般層: FPという名前は知っていても、AFP・CFPは「？」となりやすい（金融業界外へアピールしても伝わりにくい）

## 4. 保有者数（希少価値）

出典: 日本FP協会 認定者統計（原本は「2026年時点」と記載。記事化時に最新値を再確認）

| 資格 | 区分 | 国内保有者数（目安） |
| --- | --- | --- |
| FP3級 | 国家資格（入門） | 約185万人 |
| FP2級 | 国家資格（中級） | 約122万人 |
| AFP | 民間資格（2級レベル） | 約15万人 |
| FP1級 | 国家資格（上級） | 約6万人 |
| CFP® | 民間資格（最上級・国際） | 約2.8万人 |

読み取りポイント:
- 同レベルのFP2級（122万人）→ AFP（15万人）で**約8分の1**に急減。2級合格者の大半はAFPに進んでいない
- FP1級はFP2級の**約5%**（6万 ÷ 122万）。原本の「1割に満たない」はこの比較を指す
- CFP®はAFPの**約2割弱**（2.8万 ÷ 15万）。上位資格ほど希少価値が高い
- 「資格の知名度」と「何に役立つか」の情報が、専門側と一般側で乖離している（本人所感）

## 5. 年収（FP1級・CFP®）

- ボリュームゾーン: **700万〜1,000万円超**
- FP1級とCFP®の**資格間の年収差は小さい**。決まるのは「どの業界に属するか」「独立しているか」
- 資格手当: FP1級・CFP®に月数万円（年換算で数十万円）を支給、または昇格・昇給の必須条件にしている企業がある

### 企業勤務型（目安）

| 業界 | 年収目安 | 主な職務 |
| --- | --- | --- |
| 大手銀行・信託銀行 | 650万〜1,200万円 | 資産承継・遺言信託・M&A・PB部門の専門職 |
| 証券会社・アセットマネジメント | 750万〜1,400万円 | 富裕層向け運用提案、私募投信の運用 |
| 生命保険・損害保険会社 | 800万〜1,300万円以上 | 本社の企画・専門部署、インセンティブ率の高い個人営業 |
| 不動産会社・ハウスメーカー | 600万〜1,200万円 | 用地仕入れ、富裕層向け不動産コンサル |

### 独立開業型

- 個人の実績に大きく左右され、所得層の幅が広い（原本に具体値なし。記事化するなら別途調査）

### FP1級とCFP®の違い

| 資格 | 強みが出る領域 |
| --- | --- |
| FP1級 | 国内金融機関での評価・キャリアアップ |
| CFP® | 外資系企業での評価、独立時の個人ブランディング |

**結論（本人所感）**: 両方とも独立のほうが期待値は高いが、自分を売り込む営業力が前提。現実的・堅実には「**大手金融へアサインされるための手段**」として持つと考える。

## 6. FPの需要がある就職先

> ⚠ 信頼性注意: 本章の「優遇」「強み」は予備校・資格サイトの記述にもとづく**一般論**で、各採用・人事制度が実際にFPを優遇するという一次情報ではない。記事では「業務知識が直結する」「評価されやすい」の表現にとどめ、「優遇される」と断定しない（YMYL配慮）

### 6-1. 公務員

- 公務員は2〜5年で定期異動が基本。FPの学習範囲（年金・税金・不動産・相続・社会保険）は行政サービスそのものであり、特定部署で即戦力になる

| 区分 | 部署・職種 | 直結する知識 |
| --- | --- | --- |
| 地方自治体 | 税務課（市民税・資産税・固定資産税） | タックスプランニング、不動産。減免申請などに根拠を持って説明できる |
| 地方自治体 | 国民健康保険課・後期高齢者医療課 | 高額療養費、扶養条件、任意継続（ライフプランニング／社会保険） |
| 地方自治体 | 福祉課・子育て支援課 | 児童手当、ひとり親支援、生活保護、介護保険。横断的な公的支援の案内 |
| 地方自治体 | 都市計画課・管財課 | 都市計画法・建築基準法（不動産分野の法令知識） |
| 国の機関 | 国税専門官 | 法人のタックスプランニング、相続・事業承継（FP1級／CFP®レベルで強み） |
| 国の機関 | 日本年金機構（年金事務所） | 公的年金（老齢・障害・遺族）の知識が直結 |
| 組織内部 | 人事課・総務課（給与・福利厚生） | 年末調整、社会保険手続き、退職金計算。FP受検資格の実務経験要件にも「官公庁の福利厚生・財務担当者」が該当 |
| 教員 | 公立学校（商業高校など） | 高校の家庭科・公民で金融教育（資産形成・ライフプラン）が必修化。マネーリテラシーを教えられる人材 |

**総括**: 公務員の多くは自分の部署の法律しか知らない。税・年金・保険・不動産を横断的に理解しているFP保有者は、部署をまたぐ住民の複合相談を処理でき、組織内で一目置かれうる。

### 6-2. 民間企業（金融・保険以外）

> 共通する価値: 「顧客（社員）のライフステージの『お金の不安』を解消できる」こと。特に不動産など高額商材の営業で、FPは「売るトーク」ではなく「顧客を守る提案」ができる信頼の証になる

| 業界 | 職種 | FPが活きる場面 |
| --- | --- | --- |
| 不動産・ハウスメーカー | 住宅営業 | 30年のライフプランシミュレーション、団信の選び方、住宅ローン控除の提案。成約率に直結 |
| 不動産・ハウスメーカー | 賃貸管理・土地活用コンサル | 地主（高齢オーナー）に不動産＋相続税対策・贈与の知識を絡めた提案 |
| バックオフィス（全業界） | 人事・労務・総務 | 給与計算、年末調整、社会保険、iDeCo・企業型DCの相談対応 |
| バックオフィス（全業界） | 経理・財務 | 税金・金融資産運用の基礎が財務戦略・キャッシュフロー理解の土台に |
| 士業事務所 | 税理士・会計事務所スタッフ（無資格のアソシエイト） | 確定申告、決算、相続税申告補助。未経験でもサポート役として採用されやすい |
| FinTech・IT | 家計簿・資産運用アプリの開発・マーケティング | サービス設計、コンテンツ企画・執筆・編集監修（例: マネーフォワード、WealthNavi） |
| BtoCコンサル | 結婚・教育・シニア関連 | ブライダル（生活設計）、教育（学資）、老人ホーム紹介（老後資金・資産売却） |

## 9. 記事・20hoursコースの方向性（原本メモの整理）

### コラム記事（AFP・CFPを一般層にも伝える）

- AFPとCFP®の存在を**資格を知らない一般人にも知ってもらう**コラム
  - CFP®: 外資系／世界で活躍する証券アナリスト志向、独立前提のキャリアなら必須
  - AFP: FP2級と同列の扱い。ただし**シラバスに差分があれば調査して反映**（§8-1）
- 切り口候補:
  - 「人数データで見る希少価値」（§4）
  - 「FP1級／CFP®は何ができるか・年収は」（§5）
  - 「FPが活きる職場（公務員・不動産・バックオフィス）」（§6）
  - 「FP 仕事 なくなる／意味ない」への回答（§7）
  - 「FP1級 vs 宅建」の難易度・キャリア比較（§7）

### 教養としてのFP

- 節約、税金、書類の処理など日常生活と密接。**資格取得が目的でなくても教養として学ぶ価値がある**分野
- 法改正が頻繁なため、学習時は「最新制度の確認」を必ず添える（YMYL）

### 20hoursコース設計

- 原本の見出しは「20hoursの設計」だが、**具体的な設計案は原本に記載なし**。素材として使える要素:
  - 6分野構造（§2）と3級→2級の差（制度名／実務計算）
  - 難所: 計算（タックス・不動産）、記述式、法改正への追従
  - `fp-kw-db.md` のAIハック適性（年金の「なぜ」、控除の目的理解、NISA/iDeCoの目的別整理）
- 注意: `fp-kw-db.md` では FP2級の標準学習時間が 150〜200h（未経験）。20hoursコースは「全範囲の合格」ではなく**全体像の把握・入口設計**として位置づける必要あり
