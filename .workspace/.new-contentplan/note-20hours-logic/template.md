# 20時間コース 章立てテンプレート（読者向け）

> note記事の有料パートにそのまま貼る本文。社内版との違いは「Webサイトに実装する前提をすべて外し、シラバスとチャットAIだけで回せる形」にしたこと。
> 表はnoteで表示できないため、公開時は table2png で画像化する（ALT・キャプションは記事側に書く）。

---

## このテンプレートでできること

手元にある資格試験のシラバスから、20時間で基礎の全体像をつかむための自分用コースを作れます。

ここで作るのは、合格するための教材ではありません。試験範囲の地図をつかむための入口です。仕上げには、公式テキストや過去問、模擬試験を組み合わせてください。

---

## コースの骨組み

1つの資格につき、1つのコースを作ります。中身は次の4つです。

| パーツ | 中身 | 時間 |
| --- | --- | --- |
| 診断テスト | 1章あたり2〜3問、合計16〜24問 | 0.5時間 |
| 章（6〜8章） | 1章あたり節3〜5個＋章末の小テスト3〜4問 | 合計18時間 |
| 総復習 | 20問。正答率60%を目安にする | 1.5時間 |
| 合計 |  | 20時間 |

---

## 章の切り方の5つのルール

**1. 章はジャンルで切る**

シラバスに書かれている区分の順番どおりには並べません。学ぶ人が「いま何を学んでいるか」をすぐ分かる単位にまとめます。

例（ITパスポート）: PC用語／ネットワーク／経営戦略／マネジメント／セキュリティ／生成AI

**2. 章の数は6〜8**

8章を超えたら、近いジャンルを統合します。章が多いと「20時間で終わる」という感覚が崩れるためです。

**3. 章ごとに、どのシラバス項目を受け持つか表にする**

章の中身の根拠は、必ずシラバスに置きます。「第2章＝シラバスの中分類A・B・C」のように対応表を作っておくと、範囲外の内容が混ざったときにすぐ気づけます。

**4. 時間は出題比率で配分する**

公式が出題比率や配点を公開していれば、それをもとに18時間を章ごとに割り振ります。公開されていなければ、シラバスの項目数（キーワード数）の比で代用します。

**5. 用語は4〜5割に絞る**

シラバスのキーワードを全部扱うと、20時間には収まりません。次の3つを基準に、4〜5割まで絞り込みます。

- 過去に出題された実績がある
- 他の用語を理解する土台になる（知らないと先に進めない）
- 最近の改訂で追加された・注目されている

---

## 章の中身の型

1つの章は、次の順番で作ります。

| 順 | パーツ | 書き方 |
| --- | --- | --- |
| 1 | この章で学ぶこと | 3〜5行。受け持つシラバス項目の名前を入れる |
| 2 | 節（3〜5個） | 各節は「要点の説明（10〜20行）→ 扱う用語のリスト」。用語はシラバスの表記どおりに書く |
| 3 | AIで深掘りするプロンプト | 分からなかった用語を、比較表つきでAIに聞き直すためのプロンプトを1〜2本 |
| 4 | 章末の小テスト | 3〜4問。間違えたら該当する節に戻る |
| 5 | この章のまとめ | 2文。この章の要約と、次の章で学ぶことの一言紹介 |

**読む時間より、解く時間を厚くする**

20時間の中心は「本番形式の問題に答えること」に置きます。どの章も「読む → 解く → 間違えた節に戻る」の往復を基本にして、読んで終わりにしないようにします。

---

## 診断テストで進め方を決める

最初の診断テストの正答率で、進め方を1つに決めます。

| 全体の正答率 | 進め方 |
| --- | --- |
| 80%以上 | 模擬試験を1回解く → 落とした分野の章だけ読む → 総復習 |
| 40〜79% | 正答率の低い章から順に学ぶ。得意な章は章末の小テストだけ解いて確認する |
| 40%未満 | 第1章から順に進める |

- 4択問題は勘でも25%前後は当たります。そのため「基礎から」の線は、勘の水準より上の40%に置いています
- 章の中で半分以上を間違えた章を、重点的に学ぶ章とします
- 試験まで時間がない場合は、正答率に関係なく一番上の進め方にします

---

## AIの出力を確かめるチェックリスト

AIが作ったテキストや問題は、そのまま信じずに次の項目で確かめます。

**章立て（P1の出力）**

- [ ] シラバスのすべての中分類が、どこかの章に割り当てられている（抜けがない）
- [ ] 1つの中分類が、2つ以上の章に重複して入っていない
- [ ] 章の数が6〜8に収まっている
- [ ] 時間の合計が18時間ちょうどになっている（診断0.5h＋総復習1.5hを足して20h）

**学習テキスト（P2・P3の出力）**

- [ ] 用語の表記がシラバスの原文と一致している（表記ゆれがない）
- [ ] シラバスに載っていない用語・話題が混ざっていない
- [ ] 数字・年号・法律名・人名を、公式の情報で照らし合わせた
- [ ] 1つの節が長くなりすぎていない（10〜20行の目安）

**問題（P4の出力）**

- [ ] 正解の選択肢が本当に1つだけになっている
- [ ] 解説の内容と、正解の選択肢が食い違っていない
- [ ] 正解の位置が「A」や「C」に偏っていない
- [ ] 章ごとの難しさがおおむね揃っている（1つの章だけ難問だと、診断の判定が偏る）

**スケジュール（P5の出力）**

- [ ] 1日の学習時間が、伝えた条件を超えていない
- [ ] 「読む日」だけで終わらず、解く時間・戻る時間が入っている
- [ ] 試験日の前に、模擬試験と総復習の日がある
