## 道具別のルート（記事の無料パートにはA〜Cの表だけ載せる）

P1〜P5の中身はどのルートでも同じ。違うのは「シラバスをどう渡すか」と「出力をどこに残すか」だけ。
記事の前提は「無料でできる」なので、**記事で案内するのはA〜Cの無料ルートだけ**。Dは有料ツールのため記事のルートには入れず、「サイトのコースは有料ツールも使って作った」という開示に留める（2026-10-17決定）。

| ルート | 道具 | シラバスの渡し方 | 向いている人 | 手間 |
| --- | --- | --- | --- | --- |
| A. 入れるだけ | NotebookLM（無料） | PDFをソースに追加するだけ | まず試したい人。回答がソースに基づくので範囲外の話が混ざりにくい | 小 |
| B. プロジェクト | ChatGPT・Claude のプロジェクト機能 | プロジェクトにPDFを入れ、章ごとにチャットを分ける | 普段チャットAIを使っている人 | 小〜中 |
| C. 都度貼り付け | 無料のチャットAI全般 | 章ごとに、シラバスの該当部分をコピーして貼る | 追加の機能を使わずに済ませたい人 | 中 |
| （参考・記事外）D. CLIで一括 | Claude Code・Codex（有料） | PDFをテキストやJSONに変換し、全章をまとめて生成してファイルに保存 | サイト用に複数の資格を量産する場合 | 初回は大、2回目以降は小 |

問題集を印刷・並べ替えしたい場合は、どのルートでも最後に P6（出力形式の変換）で Excel（CSV）や文書ファイルにする。

### ルートごとの進め方の違い

**A. NotebookLM**

- シラバスのPDFをソースに追加し、チャット欄に P1〜P5 を順に入力する
- 1つのノートブックの中でソースが共有されるので、工程ごとにシラバスを貼り直す必要がない
- 出力は「メモに保存」で残しておき、次の工程のプロンプトに貼る

**B. ChatGPT・Claude のプロジェクト機能**

- プロジェクトを1つ作り、ファイル（ナレッジ）にシラバスのPDFを入れる
- P1 のチャットを1つ、そのあとは**1章につき1チャット**で P2〜P4 を回す。シラバスはプロジェクト全体で共有されるので、会話が長くなって前半を忘れる問題を避けられる
- P1 の章立ての出力も、ファイルとしてプロジェクトに追加しておくと、以降のチャットで参照させられる

**C. 都度貼り付け**

- 1つの工程ごとに新しいチャットを始める。会話が長くなると、AIが前半の内容を忘れやすくなるため
- 工程と工程の間は、前の出力とシラバスの該当部分をコピーして次のプロンプトに貼り付けてつなぐ
- PDFが長くて読み込めないときは、シラバスの目次（大分類・中分類）だけを貼って P1 を回し、P2 で章ごとのキーワードを貼る

**（参考・記事には載せない）D. Claude Code・Codex（CLI・有料）**

- 最初に、シラバスのPDFを「大分類 → 中分類 → キーワード」の階層を持つJSONに変換させる（このJSONが以降すべての工程の元データになる）
- P1〜P4 を「全章ぶん、章ごとに1ファイルで保存」と指示して一括で回す。問題はJSONやCSVで保存させると、あとから並べ替えや再利用がしやすい
- シラバスが改訂されたら、JSONを作り直して差分の章だけ再生成できる

## 共通の使い方（記事にも載せる）

- 手元に用意するもの: 資格試験のシラバス（公式サイトで公開されているPDF）と、上のどれかの道具
- 出力は、テンプレートのチェックリストで確かめてから次に進みます

| 工程 | プロンプト | 入力 | 出力 |
| --- | --- | --- | --- |
| 1 | P1 章立て | シラバス | 6〜8章の章立てと時間配分 |
| 2 | P2 用語の精選 | P1の1章分＋シラバスの該当部分 | 章で扱う用語リスト |
| 3 | P3 テキスト化 | P2の用語リスト | 章の学習テキスト |
| 4 | P4 問題作成 | P3のテキスト | 章末の小テスト（と診断・総復習） |
| 5 | P5 スケジュール | P1の章立て＋自分の条件 | 日割りの学習計画 |

工程2〜4は、章の数だけ繰り返します。

## P1 シラバスを章立てに組み直す

```
あなたは資格試験の学習カリキュラムを設計する専門家です。
添付（または下に貼り付けた）{資格名}のシラバスをもとに、**20時間で基礎の全体像をつかむコース**の章立てを作ってください。

## 条件
- 章は**6〜8章**。シラバスの区分の順番ではなく、学ぶ人が「いま何を学んでいるか」が分かる**ジャンル別**にまとめる
- 各章が受け持つシラバスの項目（中分類）を明記する。**すべての項目をどこかの章に1回だけ**割り当てる
- 章ごとの学習時間を決める。合計は**18時間ちょうど**（別に診断0.5時間・総復習1.5時間を取るため）
- 時間配分は、出題比率が分かればそれを優先し、分からなければシラバスの項目数の比で決める
- シラバスに書かれていない内容は追加しない

## 出力形式
1. 章立ての表（章番号／章タイトル／ジャンル／受け持つシラバス項目／学習時間）
2. 時間配分の根拠を2〜3行
3. どの章にも入れにくかった項目があれば、その項目名と理由
```

## P2 章ごとに用語を4〜5割に絞る

```
次は、下の章立てのうち**第{N}章「{章タイトル}」**だけを扱います。

## 第{N}章の情報
{P1の出力から、この章の行をコピーして貼る}

## この章が受け持つシラバスの用語
{シラバスから、該当する中分類のキーワードをコピーして貼る}

## お願い
上の用語を、**20時間コースで扱う用語**に絞り込んでください。

## 条件
- 残すのは全体の**4〜5割**
- 残す基準は次の3つ。どれに当てはまるかを用語ごとに書く
  - A: 過去に出題された実績がある、または出題されやすい
  - B: 他の用語を理解する土台になる
  - C: 最近の改訂で追加された・注目されている
- 用語の表記は**シラバスの原文どおり**にする（言い換えない）
- 外した用語も一覧にして、外した理由を一言ずつ書く

## 出力形式
1. 残す用語の表（用語／基準A・B・C／一言の説明）
2. 外した用語の一覧と理由
3. 用語を3〜5個のまとまり（節）に分ける案
```

## P3 学習テキストを書く

```
第{N}章の学習テキストを書いてください。

## 使う用語と節の分け方
{P2の出力のうち、残す用語の表と節の案を貼る}

## 書き方
- 冒頭に「この章で学ぶこと」を3〜5行で書く
- 各節は「要点の説明（**10〜20行**）→ 扱う用語のリスト」の順にする
- 用語は初めて出てきたところで、たとえや身近な例で言い換える
- 似た用語は「AはBと違って〜」のように**対比**で説明する
- 用語の表記はシラバスの原文どおりにする
- **シラバスに書かれていない話題は入れない**。自信のない数字・年号・固有名詞には「（要確認）」と付ける
- 最後に「この章のまとめ」を2文で書く（要約と、次の章「{次の章タイトル}」の一言紹介）

## 読む人
{例: ITの仕事をしたことがない社会人。専門用語は初めて見る}
```

## P4 章末の小テストを作る

```
下の学習テキストの内容から、章末の小テストを作ってください。

## 学習テキスト
{P3の出力を貼る}

## 条件
- **4択問題を4問**。本番の{資格名}の出題形式に近づける
- 正解は必ず1つだけにする
- 正解の位置（ア〜エ）が偏らないようにする
- 各問に解説を付ける。解説では「なぜ正解か」に加えて「他の選択肢がなぜ違うか」も書く
- 各問が、テキストのどの節の内容かを書く（間違えたときに戻る場所）
- テキストに書かれていない知識が必要な問題は作らない

## 出力形式
問題文／選択肢ア〜エ／正解／解説／対応する節
```

**診断テストと総復習を作るとき**は、全章のテキストを作り終えたあとに、上の条件のうち「4問」を次のように差し替えます。

- 診断テスト: 「各章から2〜3問、合計{章数×2〜3}問。章ごとの難しさを揃える」
- 総復習: 「各章から2〜3問、合計20問。章末の小テストと同じ問題を半分程度まで含めてよい」

## P5 20時間を日割りのスケジュールにする

```
下の章立てをもとに、学習スケジュールを作ってください。

## 章立て
{P1の出力の章立て表を貼る}

## 私の条件
- 勉強を始める日: {例: 11月1日}
- 試験日: {例: 12月14日}
- 使える時間: {例: 平日は30分、土日は2時間ずつ}
- 苦手そうな分野: {例: 数学・統計}

## 作り方
- 最初に**診断テスト（30分）**、最後に**総復習（1時間30分）**を入れる
- 各章は「読む → 章末の小テストを解く → 間違えた節を読み直す」の順で進める。**読むだけの日を作らない**
- 苦手な分野の章には、復習の時間を少し多めに取る
- 試験日の前に、模擬試験を解く日と予備日を入れる
- 1日の時間が条件を超えないようにする

## 出力形式
日付／曜日／やること／時間 の表。最後に合計時間を書く
```

## P6 問題集をExcelや文書ファイルにする

```
ここまでに作った問題を、**{Excelで使えるCSV／印刷用の文書ファイル}**にまとめてください。

## 問題
{P4の出力を、全章ぶん貼る（またはプロジェクト内のファイルを指定する）}

## CSVの場合
- 列は次の順にする: 章番号, 節, 問題文, 選択肢ア, 選択肢イ, 選択肢ウ, 選択肢エ, 正解, 解説
- 1問を1行にする。文中の改行は入れない
- 文字コードはUTF-8にする

## 文書ファイルの場合
- 章ごとに見出しを付け、問題と選択肢を並べる
- 正解と解説は、**各章の最後にまとめて**載せる（解きながら答えが目に入らないように）
```

- ファイルを直接作れない環境では、CSVの中身をテキストで出させて、メモ帳に貼って `.csv` で保存すればExcelで開ける
- CSVはそのまま暗記カードアプリ（Ankiなど）への取り込みにも使える
