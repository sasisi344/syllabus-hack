## 4. 読み取れる方針

1. **モデル名・バージョン名は大きく削減**: 旧第2章の「GPT-1〜GPT-5、GPT-4o、o1/o3/o4、Sora、Gemini、Claude、Copilot」などの語は、新シラバスのキーワード欄にない。ただし学習項目には「GPTモデルの進化（GPT-4〜GPT-6 Astra）」「Gemini（Google）」「Claude（Anthropic）」「Copilot（Microsoft）」「Operator / Codex / Image Generation」が残る。**出題は項目レベルで残る前提**で、バージョン番号の暗記問題は重要度を下げる。
2. **旧第4章の「詐欺・サイバー攻撃の分類」（スミッシング・ヴィッシング・ベイト・プレテキスト等）、「AI社会原則の3つの理念」「AI開発者・提供者・利用者の区分」は新キーワード欄から消えた**。代わりに「AI事業者ガイドライン」の10の共通指針・ELSI・シャドーAI・検証レベル・個人情報保護法・著作権の語が入る。
3. **旧第5章の「文章タスクの例（校正・要約・箇条書き変換・翻訳・議事録等）」は、新第5章で「業務別の活用」に再編**。プロンプトの基本構成要素（Instruction/Context/Input Data/Output Indicator）は新キーワード欄になく、学習項目「プロンプトの基本構成要素」として残る。
4. **新規が最も厚い領域**: エージェント（コンテキストエンジニアリング・MCP・A2A・Agent Skills・ハーネスエンジニアリング・プロンプトインジェクション・最小権限・Eval）、ガバナンス（アジャイル・ガバナンス・SLA・ISMS・SOC 2・SSO）、法（AI法・AI基本計画・EU AI Act・G7広島AIプロセス・不正競争防止法・個人情報保護法の用語）。
5. 新シラバスの語のうち**法令・ガイドラインに依存するもの（AI法・AI事業者ガイドライン・個人情報保護法・著作権法・EU AI Act）は、作問時に一次情報で裏取り**する（`genai-pass-task.md` §3 G-3）。
