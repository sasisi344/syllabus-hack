## 3. 精選の基準（Tier1・IP/G検定コースを踏襲）

1. **新シラバスで新規・拡充された語を優先する**（差分ファイル §2。356語）。旧版と共通する土台の語は、短く確認するにとどめる
2. **本文は、試験の暗記より、判断を中心にする**。第4章のリスク項目は、「この場面で入力してよいか」「この出力をどこまで確かめるか」の判断を、事例（`genai-risk-cases-research.md`）で示す
3. **個別のバージョン名・サービス名は精選する**。新シラバスのキーワード欄にない語（GPT-4o・Sora・BERT 等）は、代表例にとどめる。ただし、学習項目に残る語（GPT-1〜GPT-3.5の歴史、Gemini・Claude・Copilot の特徴、Operator / Codex / Image Generation）は扱う
4. **法令・ガイドライン（個人情報保護法・著作権法・不正競争防止法・AI法・AI事業者ガイドライン・EU AI Act）は、一次情報で確認して書く**。本文に「2026年10月時点」を付ける（`genai-terms-db` の `candidate` 3語は、筆者の確認までは断定しない。AI事業者ガイドラインは第1.2版が令和8年3月31日公表と総務省ページで確認済み）
5. **「一般的な解説」でも、公式テキストの文章を言い換えない**。シラバスの学習目標・学習項目から、自分の言葉で書く
6. 各節の用語は、**1節あたり3語まで**を新しく導入し、日常の例から入って正式な用語へ進む（`post_writer.md` Step 0-4）
7. **具体的な残す語・削る語**は、本文執筆の着手時に、節ごとに決める
