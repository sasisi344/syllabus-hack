# 生成AIパスポート クイズ棚卸し・ギャップ分析（2027年2月試験〜の新シラバス対応）

> 対象: `src/data/quiz/genai-passport/genai-knowledge.json`（236問、旧シラバス分類）。新シラバス（`src/data/master/syllabus-genai-pass-2027.json`）との突き合わせ。タスクは `genai-pass-task.md` G-1〜G-3。
> **データの切替は2026-11-01以降**（旧シラバスの受験者が10月試験を終えるまで、旧データを残す）。本ファイルは、切替前の下調べ。

## 0. 方法と限界

- **機械的な突き合わせ**: 各問の `keyword` を、新シラバスのキーワード・学習項目（「/」で分割）・中項目名と、表記ゆれを吸収して照合した（括弧内の別名、全角半角、空白）。
- **手動の補正**: 表記が変わった語（例: 名誉棄損→名誉毀損、AI新法→AI法）、新では項目として吸収された語（例: Operator、GPT-1〜3.5）、個別タスク（例: 数字の変換）は、`keyword` ごとに手で割り当てた。
- **これは「語の照合」であり、設問の正誤や解説の質を検証したものではない**。区分Aでも、解説が旧シラバスの文脈のままの問題がありうる。切替時に、区分A・Bを1問ずつ目視する。
- 新シラバスの語がない問題（区分C）が即「使えない」ではない。新シラバスの範囲外でも、学習の補助になる内容がある。ただし、**新シラバス対応を名乗る問題集には入れない**。

区分の定義:

| 区分 | 意味 | 扱い |
| --- | --- | --- |
| A | キーワードが新シラバスにそのまま残る | 新分類へ付け替えて転用。解説の見直しは目視で |
| B | 語が変わった、項目に吸収された、バージョン名・サービス名を含む | 設問・選択肢を書き直してから転用 |
| C | 新シラバスに該当語がない | 新分類では使わない（または「旧シラバスの内容」として別枠） |

## 6. 品質の気づき（切替時に直す）

- 設問に Markdown の `**太字**` が入った問題が 8 問ある（例: 「画像生成AIで、現在実現**できない**ことはどれ？」）。クイズアプリの表示で `**` がそのまま出ないか、実機で確認する。
- `keyword` が重複する問題がある（1種）。同じ論点を別の言い方で問うているか、重複かを、切替時に確認する。
- `id` が `genai-{タイムスタンプ}` 形式で、新分類の規約（`.agents/quiz_data_rules.md`）と合うかは未確認。切替時に、規約に合わせて採番し直すかを決める。
- `syllabusRef` が全236問に付いている（例: `4-1`）が、**旧シラバスの中項目番号**であり、新シラバスの番号とは意味が違う（旧4-1＝インターネットを適切に利用するスキル／新4-1＝利用者の基本マインドセット、旧5-4＝テキスト生成AIのビジネス応用／新5-4＝クリエイティブ制作での活用）。切替時は、新番号へ付け替えて、取り違えを防ぐ。
