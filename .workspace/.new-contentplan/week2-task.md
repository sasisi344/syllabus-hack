# Week2タスク（9/13〜9/19）: パイロットカリキュラム制作

> 全体像は [`new-content-plan.md`](./new-content-plan.md) を参照。前提: Week1で確定した「Tier1/Tier2二層カリキュラム（[`ip-course/ip-course-curriculum.md`](./ip-course/ip-course-curriculum.md)）」「`syllabus-ip-2027.json`」を使用する（[`week1-task.md`](./week1-task.md)）。
>
> **2026-09-07更新**: 「全819語を20hでアウトプットするのは非現実的」という考察の結果、Tier1（無料20h・精選版）の章立ては8章に確定済み（[`ip-course-curriculum.md`](./ip-course/ip-course-curriculum.md) §3-2）。本Weekのタスクは「章立てを決める」から「決まった8章に用語を精選して流し込む」に変わった。

## このWeekのゴール

ITパスポート20hoursパイロット＝**Tier1**（無料・入口テキスト）の中身（診断テスト・カリキュラムマップ・章立て本文・章末チェック）を、Web実装前のコンテンツとして一式作り切る。Tier2（有料note・合格テキスト）の本文制作は本Weekのスコープ外（着手時期は判断待ち、`new-content-plan.md` 参照）。

## タスク

- [ ] **Tier1各章の用語精選**（[`ip-course-curriculum.md`](./ip-course/ip-course-curriculum.md) §3-3の基準に従う）: 各章の元語数（155/144/70/29/110/64/90/157語）から高価値な用語を約4割に絞り込む。基準: ①既存theory記事がある用語 ②現行v6.5にもあった用語 ③生成AI・データマネジメント等の新設分野の代表語
- [ ] ITパスポート診断テスト（10問前後）を作成
  - Tier1の8ジャンル（ビジネス基礎／経営戦略・ツール活用／DXの考え方／サービス・PM／PC・システム基礎／ネットワーク・DB／データとAI／セキュリティと倫理）でサブスキルを分解
  - 苦手分野に後続カリキュラムの時間を厚く配分できる設問設計にする
- [ ] カリキュラムマップの文言修正（[`ip-course-curriculum.md`](./ip-course/ip-course-curriculum.md) §3-4）: 「標準（20時間）＝未経験〜非IT職向けの完全ロードマップ」という誤解を招く表記を、「IT経験者の総復習／未経験者には入口」という正確な位置づけに修正
- [ ] 8章の本文執筆
  - 既存 `method/itp-hub` 系記事・`it-passport-quiz` の資産を棚卸しして転用可能な部分を特定し、ゼロから書き起こす範囲を最小化する（ネットワーク・DB・セキュリティ・PC用語系は流用度が高い、DXの考え方・情報倫理は新規執筆が必要）
- [ ] 章末理解度チェック問題（選択式3〜4問×章、最終章は総合復習）を作成

## 次Weekへの引き継ぎ

- 完成した診断テスト・カリキュラムマップ・8章分の本文原稿・章末チェック問題（Tier1一式） → Week3のAstro実装で流し込む素材一式
- Tier2（有料note）の制作着手可否・時期の判断結果 → 着手する場合はWeek3以降のタスクに追加
