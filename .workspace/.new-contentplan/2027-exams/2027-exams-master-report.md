## 2. 横断的な発見

### 2-1. 中分類ID・名称は試験区分をまたいで共有されている

IP・SC・DM・PD-M・PD-Sいずれの構造化データも、同じ中分類（例: 中分類2「経営戦略・デジタル戦略」、中分類17「データベース」、中分類24「情報セキュリティマネジメント」）を複数の試験が共有している。**IPAは2027年制度で「共通の知識体系カタログ」を作り、試験区分ごとに深さ・切り口を変えて出題する設計**にしたと解釈できる。

これはシラバスハックにとって好都合で、**1つの中分類に対して「IP版（浅い）→ 他試験版（深い）」という難易度階段のコンテンツシリーズを作りやすい**（実例: 中分類8「データマネジメント」はIP13語→DM103語で8倍の深掘り）。

### 2-2. 生成AI関連の新設・深掘りが4試験すべてで確認された

| 試験 | 生成AI関連の新規テーマ |
| --- | --- |
| IP | 生成AI利活用（プロンプトエンジニアリング、ハルシネーション、AI利活用ガイドライン等）が中分類10として独立 |
| SC | プロンプトインジェクション・ジェイルブレイク・モデル窃取などAIシステムへの攻撃、Security for AI/AI for Security（完全新規） |
| DM | AI活用時のデータ利用上の留意事項（科目B技能として独立項目） |
| PD-S | AI駆動開発（バイブコーディング、エージェンティックコーディング、仕様駆動開発） — 現行試験に存在しない完全新規領域 |

→ **「生成AI×資格試験」を軸にするシラバスハックの強みが、2027年制度全体を通じて一段と活きる**。特にSCの「AIセキュリティ」とPD-Sの「AI駆動開発」は、既存資格対策サイトが手薄になりやすい最新技術領域であり、先行して記事化する価値が高い。

### 2-3. 新設試験（DM・PD-M・PD-S）はいずれも「科目B（技能）」を持つ

IPは知識のみ（科目Aのみ）だが、SC・DM・PD-M・PD-Sは知識＋技能の2階建て。技能は「〜する能力／スキル」という記述で、暗記ではなく実務での振る舞い方を問う。これは**コンテンツの作り方が知識試験と技能試験で変わる**ことを意味する（用語解説だけでなく、ケーススタディ・シナリオ演習が必要になる）。

### 2-4. 応用情報・高度試験のHub再編は避けられない

PD-M/PD-Sは応用情報技術者試験＋既存高度試験区分（NW/DB/PM/ST/SA/SM/AU/ES）を大括り再編したもの。現行の `method/ap-hub`・`method/advanced-ipa-hub`・`method/level4-strategy-hub` は、2027年度の新試験開始に向けて構成の見直しが必要になる見込み（[`pd-2027-profile-report.md`](./pd-2027-profile-report.md) §4）。ただし**現行試験は2026年度まで続くため、今すぐの改修は不要**。

## 5. コンテンツ企画の優先順位（提案）

今月のロードマップ（[`../new-content-plan.md`](../new-content-plan.md)）はITパスポート20hoursコース（Tier1）とサイト新構成の実装が最優先で、これは変更しない。その前提の上で、2027年シラバス関連コンテンツの優先順位を提案する。

| 優先度 | 施策 | 理由 |
| --- | --- | --- |
| **今月中（trend記事レベル）** | 「IPA 2027年試験制度改訂」trend記事1本（既存タスク、[`week4-task.md`](../week4-task.md)） | 制度変更の告知は早いほど検索優位。IP・SC・DM・PD全体を俯瞰する記事にできる |
| 来月以降・優先度高 | SC関連method記事: 「生成AI時代のセキュリティ脅威」系（プロンプトインジェクション等） | 競合が薄い最新技術領域。`method/advanced-ipa-hub`からの導線あり |
| 来月以降・優先度中 | DM「データマネジメント試験とは」trend記事＋`itp-hub`からの導線 | 新設試験の早期認知獲得。ITパスポート合格者の次のステップとして自然 |
| 来月以降・優先度中 | PD-S「AI駆動開発」method記事（バイブコーディング等） | 現行試験に存在しない独自領域。生成AI軸との親和性が高い |
| 半年〜1年後 | DM・PD-M・PD-SのHub化・examId正式登録 | 現行試験終了（2026年度末）・新試験開始（2027年度）を見てから。時期尚早に作ると検索意図とのズレが大きい |
