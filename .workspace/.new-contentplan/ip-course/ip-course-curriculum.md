# ITパスポート 学習テキスト 二層カリキュラム（2027年シラバスベース）

> **2026-09-07 方針転換**: 当初この単一20時間コース（旧設計・v6.5ベース）は「ユーザー承認待ち」として確定させる予定だったが、「20時間で1,171語すべてをアウトプットできる学習は現実的か」という考察の結果、**単一コースではなく二層構成**に設計を変更した。あわせて土台となるシラバスも現行v6.5ではなく**2027年新シラバス（案）**に切り替える。旧設計は [Appendix A](#appendix-a-v65ベース初期設計アーカイブ) にアーカイブし、以下が新しい正本。

## 0. 決定事項（2026-09-07）

1. **学習テキストを2種類に分ける**（詳細な理由は [`../20hours学習法の基本理念.md`](../20hours学習法の基本理念.md) 「20時間学習法の射程」を参照）
   - **Tier 1（無料）「知識体系への入口テキスト」**: 20時間・カウフマンの20時間学習法（＝スキルを分解し価値の高い部分に絞ることで到達可能にする）を正しく適用した精選版。全用語は網羅しない
   - **Tier 2（有料note）「合格テキスト」**: シラバス全体を網羅する、市販の分厚い合格対策本相当のテキスト。IPAが示す未経験者向け学習時間（50〜80時間）に見合うボリューム
2. **土台となるシラバスは2027年版**（`src/data/master/syllabus-ip-2027.json`、Ver.0.1案・6大分類26中分類819語）に切り替える。現行v6.5（3区分23中分類1,171語）ベースの初期設計は取り下げ、参考資料として保持する
3. **Tier1とTier2は構成そのものが異なる**（用語を間引くか網羅するかだけの差ではない）。詳細は §3・§4
4. 「20時間コースは合格を保証しない」という既存の注意書き（§本ファイル旧版）は**Tier1に対する注意書きとして維持**する。Tier2は「合格テキスト」を名乗る以上、より踏み込んだ完成度が要求される

## 1. なぜ二層構成にするのか（考察の要旨）

- 現行シラバス1,171語 ÷ 実学習時間18h（診断・総復習を除く）＝**時速65語**。用語習得の現実的なペース（時速15〜20語程度）の3〜5倍のオーバーペースであり、「学ぶ」ではなく「辞書の高速斜め読み」に近い密度だった
- サイト自身の既存記事（`method/itp-hub` FAQ）がすでに「IT経験者20〜40時間、未経験者50〜80時間」という学習時間の目安を公開している。20時間は**経験者の下限**にしか届かず、未経験者の目安の**25〜40%**にすぎない
- ジョシュ・カウフマンの20時間学習法は「20時間で完全習得できる」という理論ではなく、「スキルを分解し、価値の高い部分に絞れば20時間で"人前に出せる最低限"に到達できる」という理論（ウクレレの例＝プロ演奏ではなく簡単な曲を人前で弾ける程度）。**全知識を20時間でアウトプットさせようとする設計は、この理論の誤用だった**
- 結論: IT経験者には20時間コース（Tier1）だけで合格ラインに届く可能性があるが、未経験者にとっては「入口」に過ぎない。両者を同じ商品として扱わず、**Tier1（無料・入口）とTier2（有料・完全版）に分離**することで、それぞれの対象読者に正直な期待値を提示できる

### 3-3. 精選（キュレーション）の基準

Tier1は819語のうち約4割（推定300〜350語）を選ぶ想定。基準は優先度の高い順に:

1. 既存theory記事がすでにある用語（約75本のtheory記事は過去のKWリサーチ・SEO実績で選ばれた「読者需要の高い用語」であり、高価値の代理指標として使える）
2. 現行v6.5でも出題されていた用語（新旧シラバスの重複語＝出題実績のある可能性が高い）
3. 生成AI・データマネジメントなど、2027年シラバスで新設・強化された分野の代表語（トレンド性が高くサイトの差別化軸に合致）
4. 上記に当てはまらない用語（型番・製品名の羅列、極めて専門的な法規の細目など）は精選から外し、Tier2に譲る

具体的な用語選定（節ごとの割り当て）は次工程（Week2相当）で行う。旧v6.5ベースの節構成・theory記事対応表（[Appendix A](#appendix-a-v65ベース初期設計アーカイブ)）はネットワーク・データベース・セキュリティ・PC用語などシラバス変更の影響が小さい分野でそのまま再利用できる見込み。

### 3-4. カリキュラムマップ・診断テストの位置づけ

- 診断テスト10問・カリキュラムマップ3パターン（標準/実務者/直前）の仕組み自体は維持するが、**「標準（20時間）」パターンの対象表記を修正する**: 旧版は「未経験〜非IT職。旗艦」としていたが、これは正確ではない。正しくは「IT経験者には総復習として機能しうるが、未経験者には知識体系への入口であり、単体で合格を目指すレベルではない」と明記する
- 未経験者向けには、Tier1完走後に**Tier2（有料note）または追加の自己学習で合計50〜80時間相当に到達する**ことを前提としたロードマップ表示を追加する（例: 「Tier1（20h）→ Tier2（+30〜60h）→ CBT演習 → 受験」の全体像を示す）
