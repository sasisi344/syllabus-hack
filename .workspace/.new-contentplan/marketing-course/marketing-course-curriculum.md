# マーケティング入門 20時間コース 構想

> 20時間コースの次の実装対象。資格コースではなく、`ai-work`（生成AI実務練習コース）と同じ**非資格の基礎＋練習コース**として作る。
> 共通仕様は [`../20hours-course-template.md`](../20hours-course-template.md)、非資格コースの前例は [`../archive/ai-work-course/ai-work-course-task.md`](../archive/ai-work-course/ai-work-course-task.md)。

## 0. 前提と方針

### 想定読者

**経済学・商学を専攻していない大学生が、新卒で入社する前にマーケティングについて押さえておくべきこと**。

- 配属先がマーケ職とは限らない（営業・企画・広報・EC担当・総合職）。どの部署でも「会議でマーケの言葉が出たときに置いていかれない」「上司の指示の意図がわかる」水準を目標にする
- 筆者自身も学習者。「隣の席コメント」（CLAUDE.md「学習体験の共有ルール」）を最初から前提に設計する

### 射程（やること／やらないこと）

| やる（基礎＋仮の実践） | やらない（卒業後の発展） |
| --- | --- |
| 顧客・価値・ニーズの考え方、3C/SWOT、STP、4P/4C、購買行動モデル | MBAレベルの競争戦略・ブランド資産論の理論 |
| 購買心理の代表的なパターン（社会的証明・希少性・返報性・アンカリング・損失回避など）と、文章で読ませる・買ってもらう型（AIDA・PASONA・ベネフィット訴求・見出し） | 行動経済学・消費者心理学の学術的な深掘り（実験の詳細・理論の比較） |
| 店頭・営業・BtoBなど「リアル」の売り方と現場の数字 | |
| SEO・広告・SNS・メールなど Web の集客チャネルの全体像 | 確率・統計モデルでの需要予測（『確率思考の戦略論』の領域） |
| KPI・ファネル・GA4の読み方・A/Bテストの考え方 | 広告運用の入札・タグ実装などの実務オペレーション |
| 景品表示法・ステマ規制・個人情報の「新人がやらかさない」最低限 | 法務の詳細解釈 |
| 架空の商品でマーケティングプランを1枚にまとめる練習 | 実際の予算を使った出稿 |

### 性質の違う3つのパート

ユーザー指摘のとおり、「リアルなマーケティング手法」と「Webマーケティング」は性質が違うので、パートで分ける。土台の理論は共通なので先に置く。

| パート | 性質 | 章 | 学び方 |
| --- | --- | --- | --- |
| A. 基礎理論 | 考え方・フレームワーク。どの業界・部署でも共通 | 第1〜4章 | 読む→フレームに当てはめる練習→章末チェック |
| B. リアルのマーケティング | 店頭・営業・BtoB・販促。人と現場が介在する。数字は「売上＝客数×客単価」の世界 | 第5章 | 現場の事例を分解する練習 |
| C. Webマーケティング | 集客チャネルと計測・改善。数字が細かく取れ、検証サイクルが速い | 第6〜7章 | GA4デモアカウントで実データを見る練習 |
| 総合演習（仮の実践） | A〜Cを1つの商品で通す | 第8章 | 架空商品のマーケティングプランを作り、AIをレビュアーにして直す |

### 学習者を「知識×経験」の2軸で分ける（2026-10-27追加）

ユーザーの考察: 中学生でもマーケティングの原理を知らずにSNSを伸ばせている例がある。そうした人は生まれつき知識を持っているのではなく、**実践から自分なりの理論を組み立てている**。だから、体系的な知識があるかどうか、実践経験があるかどうかで学習の方向は変わる。

この考えは、経験→振り返り→概念化→試行を回す「経験学習モデル」（コルブ）とも合う。SNSが伸びている人は、①自分自身がその媒体の利用者なので、狙う相手の感覚を持っている（西口一希のいう「N1」を自分で持っている状態）②投稿ごとに反応がすぐ返るので、試行と振り返りのサイクルが速い（事実上のA/Bテスト）。

一方で、経験だけで組み立てた理論には弱点もある。どの層に向けて語るかで、学ぶ目的が変わる。

| | 実践経験なし | 実践経験あり（SNS運用・フリマ・模擬店・バイトの販売・サークル新歓など） |
| --- | --- | --- |
| **体系知識なし** | **体験ルート**: 小さく「やってみる」→理論で名前をつける、を全章で往復。第1章から順に進める | **言語化ルート**: 自分の経験を先に書き出し、理論で「なぜうまくいったか」を説明できるようにする。学ぶ目的は**再現性と転用**（自分が客ではない商品・相手に応用する、上司やチームに説明する、うまくいかなかった時に原因を切り分ける）。Webパート（6・7章）→基礎理論（1〜4章）→5章→8章の順を推奨 |
| **体系知識あり**（授業・本で学んだ） | **実践ルート**: 節は読み飛ばし、各章の通し課題とGA4デモアカウントの練習から入る。「知っている」と「使える」の差を埋めることが目的 | **演習ルート**: 第8章のプラン作成から入り、詰まった章だけ戻る |

- 経験者向けの注意: 自分の成功体験は「自分と似た相手」にしか通用しないことがある。また、うまくいった例だけを見て一般化する生存者バイアスに気をつける。この2点は第2章（STP）と第7章（測って直す）で扱う
- 「実践経験」の範囲は広くとる。大学生のフリマアプリ出品・学園祭の模擬店・アルバイトの接客販売・サークルの新歓も、立派なマーケティングの実践として扱う（経験者が自分を「未経験」と思い込まないようにする）

### 学生時代の経験ケース（2026-10-27追加）

ユーザーの考察: 学生時代の経験をマーケティングとして捉え直すと、**理論が本当なのかを想像しやすい**。架空の会社（通し課題）だけでは「そういうものか」で終わるが、自分がやったこと・見たことに当てはめると、理論の当たり外れを自分の記憶で確かめられる。

そこで各章の「まずやってみる」を、**学生時代によくある場面**から始める。AIが書くのは三人称の「よくある場面」までで、一人称の体験談は書かない（創作禁止ルール）。

| 章 | 学生時代の場面（よくある例） | 確かめる理論 |
| --- | --- | --- |
| 1 | フリマアプリで、似た服なのに片方だけ売れた | ベネフィット・価値の伝え方 |
| 2 | サークル新歓で「自分たちが楽しいこと」を全力で伝えたのに、新入生が集まらなかった | ターゲット＝自分の罠、セグメンテーション |
| 3 | 学園祭の模擬店。行列のある店にさらに人が並ぶ／「残り10個」で急に売れる／同じ内容でも告知文で反応が違う | 社会的証明・希少性・文章の型 |
| 4 | バイト先のカフェで、セットメニューの真ん中の値段が一番売れる | 価格戦略・アンカリング・4P |
| 5 | アルバイトの接客販売で、声かけ1つで客単価が変わる | 客数×客単価、店頭の施策 |
| 6 | 推し活の布教／趣味のSNSアカウント運用 | チャネル・アーンドメディア・口コミ |
| 7 | 自分のSNSのインサイト（表示回数・保存数）を見て投稿を変える | ファネル・KPI・測って直す |
| 8 | 上記を踏まえて青葉園のプランを作る | 総合 |

### 筆者の体験（コースの軸になる失敗談）

2026-10-27にユーザー（筆者）がチャットで語った内容の要旨。**callout の文面は筆者が書く**（AIは下記を要約として保持するだけで、一人称の文章に起こさない）。

- 失敗: 自分自身が欲しいと思ったものを紹介することが最良だと思っていた。しかしこの方法は、自分と同じ価値観の人にしか届かず、大多数へ売るためのマーケティングとは違っていた
- 修正: 購買心理を学ぶことで、SNSを伸ばせるようになり、文章で物を買ってもらったり読んでもらったりできるようになる
- 学び: 理論を知れば応用に活かせる。なによりパターンで攻略できる

コースでの使い方:

- **第2章（STP）の山場に置く**: 「自分＝ターゲット」は、前節の「SNSを伸ばせる人は自分がN1」の裏返し。自分と同じ層には強いが、それ以外の層には届かない。この失敗談を `[!exp]` で置き、本文はその直後に「自分以外のセグメントをどう想像するか（ペルソナ、インタビュー、N1を複数持つ）」を解説する
- **第3章（購買心理と文章）の導入につなぐ**: 「自分の好み」の代わりに「人が買う・読むときの共通パターン」を持てば、価値観の違う相手にも届けられる、という流れ
- 下書きでは該当箇所に `<!-- LEARNER_NOTE: 候補=自分が欲しいものを紹介すれば売れると思っていた失敗 / 種類=exp / 筆者の実体験で記入 -->` を置き、筆者が記入する

### 通し課題（全章で同じ架空の会社を使う）

章ごとに別の例を出すと「フレームを覚えた」で終わりやすい。全章を通して**1社の架空ケース**を育て、第8章でプランとして完成させる。

- 案: 創業60年の地方の茶舗「（架空）青葉園」が、20〜30代向けに新商品「水出し緑茶のティーバッグ」を出す。売り場は本店・駅ビルのポップアップ（リアル）と自社EC・Instagram（Web）
- この題材を推す理由: ①リアルとWebの両方の売り場がある ②BtoC で大学生にも想像しやすい ③老舗×若年層で STP・ポジショニングの論点が立つ ④価格（ペットボトル茶との比較）が考えやすい
- 素材はすべて架空データ（売上表・アンケート結果・ECのアクセス数・店頭POPの写真代わりの文章など）。ai-work と同じく、必要な章だけZIP配布を検討

### 章の型

資格コース（節＋章末チェック）と ai-work（実例→練習→ルーブリック）の中間にする。

理論を先に読ませず、**実践→理論の順**で組む（§0「知識×経験」の考察を、全ルート共通の章の型にも反映する）。

1. この章で学ぶこと＋注意書き（圧縮版）
2. **まずやってみる（5〜10分）**: 学生時代の場面（§0の表）を読み、「なぜそうなったか」を理論を知らないまま考える。経験者は「自分の経験でいうと何にあたるか」を書き出す欄を使う
3. 節（3〜4）: 理論で名前をつける。要点の要約。構造があるものは Mermaid 図（例: 3C の関係、ファネル、KPIツリー）
4. **振り返り**: 2で書いた自分の答え・経験を、節の理論で見直す（どこが合っていて、何が抜けていたか）
5. **通し課題**: 青葉園の素材 → ワークシート（穴埋め）→ 自分で書く → 答え合わせの観点（ルーブリック）と解答例
6. AIで学ぶ: プロンプト1〜2本（AIを「先輩マーケター役のレビュアー」にする。経験者向けに「自分の経験を話して、どの理論にあたるか整理してもらう」プロンプトも置く。コードフェンス内は Markdown 太字）
7. 章末チェック（3〜4問）
8. この章のまとめ／次章リンク

### 注意書き

資格コースの「合格を保証しない」ではなく、ai-work と同様に差し替える。

- 案: 「本コースはマーケティングの基礎と考え方を身につけるための入門教材です。業界・会社によって用語の使い方や進め方は異なるため、配属後は職場のやり方を優先してください」
