2. **20時間の内訳**（見出し「20時間で生成AIパスポートの全体像をつかむ」の下）

## 診断の作り方（20問）

- 章ごとの問題数: 第1・6・7・8章は3問、第2〜5章は2問（計20問。重い章を厚くする。どの章も2問以上あるので章ごとの判定ができる）
- ID は `genai-pass-course-diag-{n}`（1〜20、章の順）
- 形式は章末チェックと同じ（`id`・`chapterOrder`・`text`・`choices`（ア〜エ）・`correctLabel`）
- **章末チェック（`course-ch1〜8.json`）と同じ問題・同じ問い方を使わない**。診断は章を読む前に解くので、章末の答えを先に見せない
- その章の中心の論点を問う（細かい語の暗記ではなく、「この章を読めば答えられる」基本）。各章のうち少なくとも1問は場面を示す問題にする
- 本文に書いていないことを問わない。正解と誤答の根拠になる本文の節を、報告書の問題の行に書く

## 総復習の作り方（20問）

- 章ごとの問題数: 第1・6・7・8章は3問、第2〜5章は2問（計20問）
- ID は新しく作る問題を `genai-pass-course-review-{n}`。章末チェックの問題を使うときは、テンプレート §4 のとおり**元の ID のまま**入れる
- 章末チェックからの再出題は全体の半分（10問）まで。残りは新しく作る
- 診断の問題とは重ねない
- 新しく作る問題は、2つの章をまたぐ問いを3問以上入れる（例: 第4章の RAG と第6章のハルシネーション対策、第5章のエージェントの権限と第7章のガバナンス）。`chapterOrder` は主に問う章にする

## 診断・総復習に共通の基準

- 正解の位置はア〜エに散らす（ファイルごとに偏りを数えて報告書に書く）
- **選択肢の長さをそろえる**。正解だけが長く留保つきで、誤答が「不要」「必ず」などの言い切りばかりだと、読まずに正解が分かる（第5・6章の検収での指摘。第7・8章では直っていた。同じ水準を保つ）
- 各問に、本文を読んでいないと選びがちな紛らわしい誤答を1つ以上入れる
- 法令・ガイドラインの問題は、章の本文に書いた事実と時点の範囲だけで作る
- 製品の料金・版・性能の数値は問わない
- 公式テキスト（翔泳社）・公式の問題の文章を写さない
- 設問・選択肢に `**` を使わない
