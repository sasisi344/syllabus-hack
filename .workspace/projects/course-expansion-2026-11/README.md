## 4. 新しいコースの章の品質の基準

テンプレートの章ページの構成（§3・§3-1）に加えて、指示書の完了条件に入れる。

- **出典**: シラバスの該当項目（大・中項目の番号）を章の冒頭に書く。法令・ガイドライン・統計は一次情報にリンクし、「2026年〇月時点」を付ける
- **図**: 仕組み・流れ・分類を説明する節に Mermaid を1章1〜2枚
- **判断の練習**: 用語の説明で終わらせず、「この場面ならどれか」を問う例題を各節に1つ
- **AIで学ぶ**: プロンプト（コードフェンス内の強調は `**太字**`）。実行結果は作らず `AI_EXAMPLE` マーカー（`../rewrite-2026-11/README.md` §2-2）
- **筆者の体験**: Codex は書かない。`LEARNER_NOTE` の候補を1章2〜4個まで置く（筆者が `course-seat-notes.md` の流れで記入）。生成AIパスポートは筆者が未受験なので、候補は「わかりにくさ」（think）に限る
- **転載しない**: 公式テキスト・過去問の文章は使わない。問題はシラバスの学習目標から自作（`.agents/quiz_data_rules.md`）
- マーケティング基礎講座は資格コースと章の型が違う（実践→理論→振り返り、通し課題、ルーブリック）。`marketing-course-curriculum.md` §1「章の型」に従う

## 5. 既存コースの全面リライトの基準（T-18・T-19）

既存の8コース68章は、テンプレートの後からの改訂（2026-10-17 の診断ルーティング、10-19 の隣の席コメント）が入っておらず、出典と図もほとんどない。2026-10-31 時点で筆者の callout は0件なので、構成から書き直してよい。

### 5-1. 章ごとにやること（Codex）

1. **シラバスとの対応を確かめる**: 章が担当する中分類（コースTOPの対応表）と、2027年シラバスの改訂（`.workspace/.new-contentplan/2027-exams/` の差分レポート）を照らし、抜け・古い記述（午前/午後 → 科目A/B など）を直す
2. **章の型をそろえる**: テンプレート §3・§3-1（この章で学ぶこと → 節 → AIで学ぶ → 章末チェック → この章のまとめ）。各章の冒頭に「**まず解いてみる**」（章末チェックと別の1〜2問。答えは節の中で回収する）を置き、読む前に解く流れにする（テンプレート §1「読む時間より解く時間を厚く」）
3. **この章でしか得られない判断材料を足す**: §4 の出典・図・判断の練習・AI_EXAMPLE。用語の羅列になっている節は、「試験でどう問われるか」「どこで間違えやすいか」の観点で書き直す
4. **つながり**: 章の内容に対応する公開中の記事（theory・method）へリンクし、公開停止・統合した記事へのリンクを外す
5. **LEARNER_NOTE の候補**: 1章2〜4個。体験（exp）の候補は筆者に受験・学習の記録がある資格だけ（`src/data/author-exam-status.ts`。ip は合格済み）。ほかは think（わかりにくさ）の候補

### 5-2. コースTOPと問題（Codex）

- コースTOP（`index.mdx`）: テンプレート §2 の構成、§0 の注意書き、診断ルーティングの説明（§1-1）。シラバスの版（2027年シラバスかどうか）を冒頭に明記

- 章末チェック・総復習の問題は、本文を書き直した内容と合っているかを確かめ、合わない問題を直す
