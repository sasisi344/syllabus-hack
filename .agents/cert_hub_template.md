# 資格Hub記事テンプレート

`.workspace/.task/TODO.md` の「資格クエリ拡張施策」で新規資格を追加する際は、本テンプレートに従って構成する。
実例: `src/data/post/method/biru-kanri-hub/index.md`、`src/data/post/method/doboku-sekou-hub/index.md`

---

## 1. 適用条件

- カテゴリ: `method`
- フレームワーク: BEAF ベース（他資格・他手法との比較優位 + 合格後のキャリアBenefit）
- 対象: 単一資格（級ありの場合も含む）または複数資格のクラスター

## 2. 読者セグメントの決め方

すべての資格Hubは、読者を以下の2セグメントに分けて両方に応える。

| セグメント | 定義 | クラスター/級ありの場合の対応 |
|---|---|---|
| A: これから勉強する人 | 未経験・異業種から挑戦する読者 | 受験資格なし／下位級（例: 2級）を担当 |
| B: 現場経験者 | すでに現場で働き、知識はあるがキャリアアップしたい読者 | 受験資格に実務経験が必要／上位級（例: 1級）を担当 |

**セグメント分けの軸を資格制度の中から見つける**のが鍵。具体例:

- 複数資格クラスター（ビル管理クラスター等）→ 受験資格の有無（実務経験必須 vs 誰でも受験可）で資格そのものを割り振る
- 級がある資格（土木施工管理技士等）→ 下位級＝セグメントA、上位級＝セグメントBに割り振る
- 単一資格・級なし → 「未経験からの学習順序」と「実務知識を試験用語に翻訳する」で内容を分ける

## 3. セクション構成（標準順）

1. **結論先出し**（本文冒頭2〜3行）: 記事を読むと何が分かる/できるようになるかを一文で明示
2. `## 合格までの勉強時間`
   - 比較表（資格/級ごとの受験資格・必要勉強時間）
   - `### AI活用で「専任講師を月額20ドルで雇う」感覚`
     - その資格特有の「詰まりポイント」を2〜3個、具体的に列挙する（汎用的な説明にしない）
3. **資格（群）の関係性・全体像の解説**（クラスターなら「○○クラスターとは何か」、級ありなら「1級・2級の違いとは」）
4. **比較表**（試験制度・出題形式・合格率・科目構成など）
5. **各資格/各検定の詳細**（H3で個別解説）
6. `## AIを専任講師にする学習プラン`
   - `### これから勉強する人向け`: ゼロから合格までのロードマップ作成プロンプト
   - `### 現場経験者向け`: 実務知識を前提にした弱点特定・添削プロンプト
7. **キャリア戦略**（資格の組み合わせ・資格手当・職務上の意味）
8. `## まとめ`（3原則 + 締めの一文）

## 4. AIプロンプト設計の原則

`post_writer.md` の AI Learning Philosophy（対話理解型）に従い、以下のいずれかの型でプロンプトを作る。

- **セグメントA向け**: 「スケジュールを作って」ではなく「スケジュールとその設計理由を説明させる」
  - 条件（知識レベル・試験日・1日の学習時間・苦手分野）を具体的に与える
  - AIに理由を説明させることで、進捗が遅れたときに自分で計画を調整できるようにする
- **セグメントB向け**: 「問題を作らせる」のではなく「自分の知識・経験を試験向けに翻訳・添削させる」
  - 実務知識を前提に、知らない部分・試験特有の数値・表現のギャップだけを特定させる
  - 記述式試験（施工経験記述等）がある資格では、AIを「模範解答を書く講師」ではなく「自分の経験を編集する添削者」として使うプロンプトが最も差別化になる

## 5. フロントマター規約

```yaml
category: 'method'
tags: ['資格名1', '（資格名2/関連分野）', '関連キーワード', '生成AI', 'ロードマップ'] # 3-5個
persona: '両セグメントを包含する一文（例: ○○への転職希望者、または実務経験を活かして上位資格を取りたい社会人）'
knowledge:
  examId: '資格・クラスターのkebab-caseスラッグ'
  type: 'method'
  difficulty: 'intermediate' # クラスター/級ありはintermediateを基本値とする
```

## 6. カバー画像

`image_rules.md` のスタイル仕様に従い、資格を象徴するアイコン2〜3個の組み合わせ（例: 建物+鍵+ギア、ヘルメット+図面+クレーン）を `minimalist pictogram, flat design, white icon on dark navy solid background` で生成する。
