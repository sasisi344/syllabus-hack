結論：生成AIは、ツールを渡されただけでは、業務に定着しません。必要なのは、議事録・問い合わせ対応・Excelのような、<strong>成果物が決まった具体的な場面で、繰り返し練習すること</strong>です。
このコースは、そのための全8章・合計約18時間の実務練習コースです。このページ1枚で、学ぶ内容とサンプルファイルの有無が分かります。

## このコースは何か

生成AIのチャットに、思いつきで質問するだけでは、仕事の力は上がりません。
このコースでは、<strong>実際の職場で起こる課題を、AIを使って解決しきる練習</strong>をします。

対象は、次のような人です。

- 生成AIは触ったことがあるが、仕事のどこに使えばよいか分からない人
- 使っているが、出力がばらつき、内容が正しいかの確認にも不安がある人
- 資格の勉強で得た知識を、実務の成果物に変える練習をしたい人

特徴は、次の3つです。

- <strong>1章が、1つのユースケース</strong>：議事録、問い合わせ対応、Excelなど、成果物が決まった場面ごとに、章を分けています
- 「実例を見る → 自分でプロンプトを設計する → 答え合わせをする」の流れ：投げる前に設計する力を鍛えます
- AIの典型的な失敗を、ワナとして仕込んだ素材で練習：担当者や期限を勝手に補う、未確定のことを断定する、存在しない出典を作る、といった失敗を、自分で見抜く練習をします

全章に共通する土台は、プロンプトの設計の5要素です。

- 目的：誰に・何のために・何を作るか
- 入力：AIに渡す素材は何か
- 制約：やってはいけないこと・守るルール
- 出力形式：表・箇条書き・文字数など
- 検証：出力が正しいか、何と突き合わせるか

## なぜ、ユースケース別に練習するのか

ZDNET Japan（Yahoo!ニュース配信）の記事によると、Thomson Reutersが複数分野のプロフェッショナル1,800人を対象にした「2026 Future of Professionals Report」で、従業員の91%が、自社はAIがもたらす価値を十分に引き出せていないと回答しています。
[記事](https://news.yahoo.co.jp/articles/e9ce9ec6bddc95402dd8b377cb0274711ec33e7e)では、その理由の1つとして、明確な成果を想定せずに、ツールだけを従業員に渡す「ツールの大量導入」が挙げられています。
うまくいっている企業は、ユースケースをかなり具体的に定めている、という指摘もあります。

チャットと対話するだけの練習は、この「ツールだけを渡された」状態と同じです。
そこで、このコースでは、<strong>どの問題にも、素材と成果物と、答え合わせの基準（ルーブリック）</strong>を付けました。

## 各章の流れ

どの章も、同じ型で進みます。

- ユースケース：職場のどんな場面で起きるか
- 実例：1つの課題を、最後まで解いてみせる（悪い指示 → 失敗 → 改善したプロンプト → 人が確認した点）
- 練習問題（4問）：素材を読み、5要素を自分で埋めて、AIに頼み、ルーブリックで自己採点し、解説を読む
- 設計の確認問題：選択式で、理解を確かめる
- 自分の職場に置き換える：章の型を、自分の仕事に当てはめる

問題は、同じ場面で、条件を厳しくしながら繰り返します。
素材が整っている問題から、素材が曖昧な問題、制約が厳しい問題、AIの誤りを見抜く問題へと進みます。

### 第1章 議事録・会議メモの整理

雑談や曖昧な発言が混ざった走り書きを、共有できる議事録に整えます。
AIが、メモにない担当者や期限を勝手に補ってしまう失敗を、防ぐ練習が中心です。
社外向けの制約つきの議事録や、AIが書いた議事録の誤り探しも、練習します。

### 第2章 問い合わせ対応・FAQ作成

顧客のメールへの返信案を、AIと作ります。
怒っている顧客への返信で、未確定の返金や納期を約束してしまう失敗を、社内ルールを制約にして防ぎます。
毎回の長い依頼を短くするために、社内規定をAIに登録する方法も、この章で体験します。

### 第3章 資料・企画書の作成

提案書を、構成案から本文へと、段階に分けて作ります。
素材にない数字や事例をAIに作らせない書き方、比較表、Mermaid記法の図、読み手（課長・役員）に合わせた書き分けを練習します。

### 第4章 調査・情報収集とファクトチェック

手元の資料を渡して、資料の範囲内で答えさせる基本形を学びます。
資料同士の食い違いの整理、資料にないことを「資料にない」と答えさせる書き方、AIが挙げた出典を人が確認する手順を練習します。

### 第5章 Excel・スプレッドシート業務

列構成とサンプル行、期待する結果を渡して、数式を作ってもらいます。
営業課の売上データを使い、条件つきの合計、取引先名の表記ゆれの統一、担当者別の前月比、AIが出した数式の誤りの検算を練習します。
シートの設計を先にAIと決める方法や、入力の自動化の考え方も紹介します。

### 第6章 コード・簡易ツールの作成

業務用の簡単なツール（Google Apps Scriptなど）を、AIと作ります。
コードを書かせる前に仕様を固める進め方、エラーの伝え方、他人が書いたコードを実行前にレビューする方法を練習します。
この章は、自分のパソコンで、プログラムを動かして確かめられる人が対象です。初めての方は、先に[事前準備編のコラム](/method/ai-programming-prep/)から始めてください。

### 第7章 運用（ログ解析・障害報告・手順書）

サーバーのログから、障害の経緯を整理し、報告書のたたき台を作ります。
事実と仮説を分ける、根拠の行番号を付けさせる、顧客向けと社内向けに書き分ける、手順書の抜けを見抜く、といった練習をします。

### 第8章 仕組み化（総合演習）

営業課長の日報から週報を作る仕組みを題材に、業務を工程に分けます。
AIに任せる部分と、人が判断する部分を分け、プロンプトをテンプレートにし、AIによる採点の限界を知り、職場のAI利用ガイドを作る、総合演習です。

## サンプルファイルについて

素材の量が多い章には、練習用のサンプルファイルを用意しています。
いずれも架空のデータで、ZIPファイルにまとめてあります。

| 章 | 入っているもの |
| --- | --- |
| 第5章 | 営業課の9月の売上を入れたExcelファイル（売上明細と、担当者別の前月比の2シート） |
| 第7章 | 3台のサーバーのログ、バックアップの実行ログ・使用量の記録・設定ファイルなど（異常のある行番号は、章の「答え合わせ用」に掲載） |
| 第8章 | 営業課の日報25本、課長の月間目標、週報のひな形、価格表、見積依頼4件（メール・FAX・電話メモ） |

第1〜4章は、素材が短い文章なので、本文に掲載しています。コピーして、AIに貼り付けて使います。
第6章は、コードが中心のため、サンプルファイルはありません。

サンプルファイルは、<strong>必要な人だけ</strong>ダウンロードしてください。
本文に、ファイルの抜粋も載せているので、ダウンロードしなくても、流れは追えます。

## 手元のデータで練習してもよい

もし、手元に、やってみたいデータがあるなら、サンプルの代わりに、それを使って練習してかまいません。
むしろ、その方が、仕事にすぐ役立ちます。

| 章 | 手元のデータの例 |
| --- | --- |
| 第1章 | 自分が参加した会議の走り書き |
| 第2章 | 過去の問い合わせ（顧客名や注文番号は伏せる）と、自分の部署の対応ルール |
| 第3章 | 提案したい内容のメモ、比べたいツールの仕様メモ |
| 第4章 | 手元の資料2〜3個（社内アンケート、公的機関の資料の抜粋など） |
| 第5章 | 自社の売上や経費の表の5〜10行（氏名・金額はダミーに置き換える） |
| 第6章 | 自分が繰り返している、手作業の業務 |
| 第7章 | 実際のログ（識別できる情報は伏せ、期間とレベルで絞る）や、手順のメモ |
| 第8章 | 毎週・毎月繰り返している、定型の業務 |

自分のデータで練習するときは、次の点に気をつけてください。

- <strong>機密や個人情報は、AIに貼る前に伏せる</strong>：氏名、社名、金額、IPアドレスなどをダミーにします。社内のAI利用ルールも確認します
- 答え合わせのために、小さくする：5〜10行程度に絞り、AIに頼む前に、自分で先に答えを出しておきます
- ルーブリックを、自分で作る：各章のルーブリックを参考に、「補っていないか」「根拠が付いているか」など、5項目ほどの基準を作ります
- 各章の最後にある「自分の職場に置き換える」は、まさにこの練習です

## おすすめの進め方

各章は、独立して読めます。ただし、第1章の5要素は、全章の土台です。
迷ったら、次のように進めてください。

- はじめての方：第1章 → 第2章 → 第3章の順に進み、5要素に慣れる
- 表計算の業務が多い方：第1章のあとに、第5章へ
- エンジニアや、システム運用の方：第1章のあとに、第6章 → 第7章へ（第6章の前提を確認）
- 管理職や、業務の見直しをしたい方：第8章の実例（日報から週報）を読むだけでも、仕組み化の全体像がつかめます

最後の第8章は、第1〜7章の型を使う総合演習です。
すべてをやり切ると、合計約18時間です。1日1章のペースなら、8日で終わります。

## 使うAIについて

ChatGPT、Claude、Geminiなど、普段使っているチャット型のAIで練習できます。
第5・7・8章では、ファイルを添付できるAIが便利ですが、内容を貼り付ける方法でも進められます。

毎回の依頼が長くなってきたら、制約を、AIに登録して短くする方法があります。
[生成AIに社内ルールを覚えさせるスキル設定のやり方](/method/ai-skill-rules-setup/)で、ChatGPT・Claude・Geminiの手順を解説しています。

## 注意

- このコースは、実務練習用の教材です。AIの出力は、必ず人が検証してください
- サンプルファイルの会社名・人物・数字は、すべて架空です
- 実際の業務で使うときは、社内のAI利用ルールに従い、機密や個人情報を、そのまま入力しないでください

## まとめ

- 生成AIを仕事に定着させるには、成果物が決まった、具体的な場面での練習が必要
- このコースは、全8章（合計約18時間）。1章が1ユースケースで、どの問題にも、素材・成果物・答え合わせの基準がある
