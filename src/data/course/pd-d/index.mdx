PD-Dは、プロフェッショナルデジタルスキル試験（仮称）の3区分のうち、データ・AIを扱う区分です。データスチュワード・データアーキテクト・データエンジニアなどが、管理方針やデータ設計、分析・AI活用の案を作り、実行を支えるための判断を学びます。

マネジメントを学ぶ[PD-Mコース](/course/pd-m/)、システムを学ぶ[PD-Sコース](/course/pd-s/)と比べ、このコースでは「信頼できるデータをどう整え、分析やAIへどう渡すか」を中心にします。DB・分析・AIの一部を経験し、隣の領域まで体系的につなぎたい方にも向いています。

<strong>20時間で目指すのは、全体像と自分の重点分野をつかむこと</strong>です。データ管理・品質・基盤・統計・SQL・AIを8章で結び、「この条件ならどの設計・手法を選ぶか」「何を確認してから進めるか」を説明する練習をします。

本コースは20時間で基礎知識を身につけるための学習教材であり、合格を保証するものではありません。仕上げには受験時点のシラバスに対応した詳しい教材を併用し、問題演習と実装・検証を続けてください。

対象は科目A-2（専門知識）と科目B（技能）の基礎です。[IPA「新試験制度のシラバス案について」](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)に掲載されたPD-Dシラバス案Ver.0.1（2026年10月30日公開）を基にしています（2026年11月時点）。案は変更される可能性があり、全用語・全技能を網羅する教材ではありません。

## 診断の後の進め方

まず診断結果のルートに沿って、読む範囲と練習の順序を決めます。診断は各章の一部を測るもので、本試験の得点や合否を予測するものではありません。

| 全体正答率 | 入口ルート | 最初にすること |
|---|---|---|
| 80%以上（13〜16問正解） | 演習 | 第8章のケースで案と理由を書く → 診断・ケースで迷った章を補う → 総復習。全問正解でも、別の場面と広い範囲の問題で確認する |
| 40〜79%（7〜12問正解） | 重点 | 重点章を正答率の低い順に学ぶ。得意な章は章末チェックで確かめ、間違えた節を読む |
| 40%未満（0〜6問正解） | 基礎 | 第1章から順に「読む→判断の練習→章末チェック→誤答した節」を往復する |

PD-Dのサイト内模擬試験アプリはありません。結果画面の演習ルートを選んだ方は、第8章を入口にして、完走後は下の「完走したら」で案内する公式資料へ進んでください。

得意な章でも、章末チェックの正解の理由を説明できなければ本文へ戻ります。読むだけで終えず、条件が変われば別案を選ぶ理由まで書いてみましょう。

## 実務経験に合わせた学習パターン

診断が示すのは知識の現在地です。次の4パターンは、実務経験から時間を配分するための表として使います。未経験の方は標準を選び、経験者も診断で示された重点章は省きません。

| パターン | 対象 | 目安時間 | 進め方 |
|---|---|---:|---|
| 標準 | データ・AIの実務が初めて | 20時間 | 診断 → 第1〜8章 → 総復習 |
| データエンジニア・DB経験者 | DB・データ基盤の実務がある | 12時間 | 診断 → 第1・2・4・7章 → 第8章 → 総復習 |
| 分析者 | 集計・分析・BIの実務がある | 12時間 | 診断 → 第1・2・3・5・7章 → 第8章 → 総復習 |
| AI実務者 | 機械学習・生成AIの開発や導入の実務がある | 12時間 | 診断 → 第1〜5章 → 第8章 → 総復習 |

12時間は、既知の節を省いて問題と見直しを中心に進める目安です。表に挙げた章を、次の章一覧の標準時間で全て読むと12時間を超えます。省く章も章末チェックで確認し、知識の抜けがあれば時間を追加してください。

## 完走したら

ここからは実戦演習・発展学習のフェーズです。本コースは基礎学習用であり、完走や全問正解が合格を保証するものではありません。

第8章で自分の案と根拠を書く → このページの総復習 → IPAの科目Bサンプル問題、の順に進みましょう。[IPA「新試験制度のサンプル問題について」](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260622.html)には、PD（データ・AI）試験（仮称）の科目Bサンプル問題が2026年10月30日に掲載されています（2026年11月時点）。

サンプル問題は、実際の試験と同じ作成・チェックの過程を経たものではありません。掲載ページには解答・解説の案内がないため、サイト内の自作問題と同じ答え合わせができるものと考えず、公式の追加案内も確認してください。

不足を補う教材は、目的に応じて選びます。

- データ管理の基礎や品質・メタデータの語が難しいときは、[DMコース](/course/dm/)で土台を補います。
- 第3章のクラウド、第5章のDBの共通知識は、[PD-Sコース](/course/pd-s/)で仕組みを補います。
- 第6章の機械学習・ディープラーニングの理論と、第7章の倫理は、[G検定コース](/course/g-kentei/)へ進みます。
- 第7章のRAG・AIエージェント・MCPの語を補うには、[生成AIパスポートコース](/course/genai-pass/)も使えます。

受験に向けては、受験時点のシラバス・公式案内と詳しい教材を照合し、未学習の範囲を追加してください。新試験の区分と対策の入口は、[2027年度IPA新試験の対策一覧](/method/ipa-2027-new-exam-hub/)で確認できます。
