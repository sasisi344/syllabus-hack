## この章で学ぶこと

第1章で見た「AIレベルの4分類」のうち、レベル3にあたる<strong>機械学習</strong>を体系立てて学ぶ章です。機械学習は、正解データの有無によって<strong>教師あり学習</strong>・<strong>教師なし学習</strong>・<strong>強化学習</strong>の3つに大別されます。それぞれ「何を入力し、何を出力させるか」という枠組みが異なるため、個別の手法を覚える前に、この3分類のどれに属するかを常に意識すると整理しやすくなります。最後に、作ったモデルが本当に使えるのかを判定する<strong>モデルの選択・評価</strong>を学び、次章以降のディープラーニングにも共通する土台を固めます。既存theory記事「[教師あり学習・教師なし学習の基礎](/theory/ml-supervised-unsupervised/)」もあわせて参照すると理解が深まります。

## 教師あり学習

<strong>教師あり学習</strong>は、入力データ（特徴量）と正解（教師データ）のペアを与えて学習させる方式です。出力が連続値を予測する<strong>回帰問題</strong>と、カテゴリを予測する<strong>分類問題</strong>（3クラス以上を扱う場合は<strong>多クラス分類</strong>）に大別されます。

回帰の基本形が<strong>線形回帰</strong>で、説明変数が1つなら<strong>単回帰分析</strong>、複数なら<strong>重回帰分析</strong>と呼びます。分類でよく使われるのが、出力を0〜1の確率に変換して分類する<strong>ロジスティック回帰</strong>（名前に「回帰」とありますが分類手法です）、Yes/Noの分岐を繰り返して予測する<strong>決定木</strong>です。境界線（超平面）とデータ点の間の距離である<strong>マージン</strong>を最大化するように分類境界を引く<strong>サポートベクターマシン(SVM)</strong>も代表的な手法で、この<strong>マージン最大化</strong>の考え方により、未知データへの汎化性能が高いという特徴があります。データを高次元空間に写像することで、直線では分けられない複雑な境界も扱えるようにする工夫が<strong>カーネル</strong>で、その計算を効率化する仕組みが<strong>カーネルトリック</strong>です。時系列データに特化した回帰モデルとして、過去の自分自身の値から将来を予測する<strong>自己回帰モデル(ARモデル)</strong>、複数の時系列を同時に扱う<strong>ベクトル自己回帰モデル(VARモデル)</strong>も押さえておきましょう。

複数のモデルを組み合わせて精度を高める考え方を<strong>アンサンブル学習</strong>と呼び、2つの代表的なアプローチがあります。元データから重複を許してランダムに複数のデータセットを作る<strong>ブートストラップサンプリング</strong>を使い、複数のモデルを並列に学習させて多数決や平均を取る<strong>バギング</strong>（<strong>ランダムフォレスト</strong>はバギングに決定木を組み合わせた代表例）。もう1つは、前のモデルが間違えたデータを重点的に学習する次のモデルを順番に作っていく<strong>ブースティング</strong>で、その代表的な実装が<strong>勾配ブースティング</strong>です。バギングは「並列に作って多数決」、ブースティングは「直列に作って弱点を補強」という対比で覚えると区別しやすくなります。

**扱う用語（精選・18語）**

- 回帰問題／分類問題／多クラス分類
- 線形回帰／単回帰分析／重回帰分析／ロジスティック回帰／決定木
- サポートベクターマシン(SVM)／マージン最大化／カーネル／カーネルトリック
- 自己回帰モデル(ARモデル)／ベクトル自己回帰モデル(VARモデル)
- アンサンブル学習／バギング／ブートストラップサンプリング／ランダムフォレスト／ブースティング／勾配ブースティング

## 教師なし学習

<strong>教師なし学習</strong>は正解データを使わず、入力データ（特徴量）そのものが持つ構造やパターンを見つけ出す学習方式です。代表的なタスクが、似た性質のデータをグループ（クラスタ）にまとめる<strong>クラスタリング</strong>です。各データを最も近い中心点に割り当てる操作を繰り返す<strong>k-means法</strong>、クラスタ同士の併合を繰り返して階層構造を作る<strong>ウォード法</strong>があり、後者の結果は樹形図である<strong>デンドログラム(樹形図)</strong>として可視化されます。

データの特徴量の数（次元）を減らしつつ、重要な情報をできるだけ保持する処理が<strong>次元削減</strong>です。データのばらつき（分散）が最大になる方向を新しい軸として抽出する<strong>主成分分析(PCA)</strong>、行列を複数の行列の積に分解することで次元削減や特徴抽出を行う<strong>特異値分解(SVD)</strong>が代表的です。高次元データを2次元・3次元に落とし込み、可視化に特化した手法が<strong>t-SNE</strong>、データ間の距離関係をできるだけ保ったまま低次元に配置する<strong>多次元尺度構成法(MDS)</strong>もあわせて覚えておきましょう。文書集合から話題（トピック）の構成比を推定する<strong>潜在的ディリクレ配分法(LDA)</strong>は、<strong>トピックモデル</strong>の代表的な手法として自然言語処理（第5章）にもつながります。

教師なし学習はレコメンデーション（おすすめ）システムの基盤技術としても使われます。似た趣味嗜好を持つ他のユーザーの行動履歴から推薦する<strong>協調フィルタリング</strong>、アイテム自体の特徴（ジャンル・属性など）に基づいて推薦する<strong>コンテンツベースフィルタリング</strong>があり、新規ユーザー・新規商品のようにデータの蓄積がなく推薦精度が出せない<strong>コールドスタート問題</strong>は協調フィルタリングの代表的な弱点として出題されます。

**扱う用語（精選・14語）**

- クラスタリング／k-means法／ウォード法／デンドログラム(樹形図)
- 次元削減／主成分分析(PCA)／特異値分解(SVD)／t-SNE／多次元尺度構成法(MDS)
- 潜在的ディリクレ配分法(LDA)／トピックモデル
- 協調フィルタリング／コンテンツベースフィルタリング／コールドスタート問題

## 強化学習

<strong>強化学習</strong>は、教師あり学習・教師なし学習とは異なり、正解データも構造もない代わりに、行動の結果として得られる<strong>報酬</strong>を手がかりに、試行錯誤しながら最適な行動方針を学びます。ゲームAIやロボット制御のように「今の一手が将来の結果にどう影響するか」を扱う問題に適した枠組みで、その数学的な土台が<strong>マルコフ決定過程</strong>（現在の状態だけで次の行動を決定でき、過去の履歴に依存しないという前提）です。

強化学習のアプローチは大きく2つに分かれます。1つは、ある状態や行動がどれだけ価値を持つかを見積もる<strong>価値関数の学習</strong>です。ある状態そのものの価値を表す<strong>状態価値関数</strong>、ある状態である行動を取ったときの価値を表す<strong>行動価値関数</strong>を推定し、価値が最大になる行動を選びます。代表的な手法が<strong>Q学習</strong>（行動価値関数=Q値を、実際には選ばなかった最善の行動を仮定して更新する）と<strong>SARSA</strong>（実際に選んだ行動をもとに更新する）で、両者は「学習に使う行動が理論上の最善手か、実際に取った手か」という違いで対比されます。もう1つのアプローチが、行動の選び方そのもの（方策）を直接改善していく<strong>方策の学習</strong>です。<strong>方策勾配法</strong>はその基本形で、報酬が高かった行動の確率を直接引き上げる<strong>REINFORCE</strong>、価値関数（Critic）を使って方策（Actor）の学習を安定させる<strong>Actor-Critic</strong>が代表例です（深層強化学習への発展は第6章で扱います）。

行動を選ぶ際には、今知っている中で一番良さそうな行動ばかり選ぶと、実はもっと良い行動を見逃してしまう可能性があります。既知の最良手を選ぶ「活用」と、未知の可能性を試す「探索」のバランスを取る代表的な方策が、一定確率でランダムな行動を試す<strong>ε-greedy方策</strong>、不確実性が高い（まだ試行回数が少ない）行動を優先的に試す<strong>UCB方策</strong>です。このように行動の選択肢を「腕」に見立てて探索と活用のバランスを最適化する問題設定を<strong>バンディットアルゴリズム</strong>と呼びます。将来の報酬を現在の価値にどれだけ割り引いて評価するかを表すパラメータが<strong>割引率</strong>で、1に近いほど将来の報酬を重視します。

**扱う用語（精選・12語）**

- マルコフ決定過程／状態価値関数／行動価値関数
- Q学習／SARSA／方策勾配法／REINFORCE／Actor-Critic
- ε-greedy方策／UCB方策／バンディットアルゴリズム／割引率

## モデルの選択・評価

学習させたモデルが、訓練に使ったデータだけでなく未知のデータにもきちんと通用するかを見極めるのが<strong>モデルの選択・評価</strong>です。訓練データに対する誤差がいくら小さくても、未知データへの対応力である<strong>汎化性能</strong>が低ければ実用にはなりません。訓練データに過剰に適合してしまい汎化性能が落ちる現象を<strong>過学習</strong>と呼びます。

汎化性能を正しく見積もるための検証方法として、データを訓練用と検証用に1回だけ分割する<strong>ホールドアウト検証</strong>、データをいくつかに分割し、検証用を入れ替えながら複数回評価して平均を取る<strong>交差検証</strong>（分割数をk個にするものを<strong>k-分割交差検証</strong>と呼ぶ）があります。データ量が少ない場合は、1回だけの評価より交差検証の方が信頼できる推定になります。

分類モデルの評価では、予測結果と実際の正解を「陽性・陰性」で突き合わせた表である<strong>混同行列</strong>が基本になります。実際に陽性で陽性と予測できたものが<strong>真陽性</strong>、実際は陰性なのに陽性と誤って予測したものが<strong>偽陽性</strong>、逆に実際は陽性なのに陰性と予測してしまったものが<strong>偽陰性</strong>、実際に陰性で陰性と正しく予測できたものが<strong>真陰性</strong>です。この4つの数値から、全体のうちどれだけ正しく予測できたかを表す<strong>正解率</strong>、陽性と予測したもののうち実際に陽性だった割合である<strong>適合率</strong>、実際に陽性だったもののうちどれだけ正しく陽性と予測できたかを表す<strong>再現率</strong>、両者のバランスを取った<strong>F値</strong>が計算されます。分類の判定しきい値を変化させたときの性能変化を可視化する<strong>ROC曲線</strong>と、その曲線の下側の面積で総合性能を1つの数値にした<strong>AUC</strong>もあわせて押さえておきましょう。

回帰モデルの評価では、予測値と実際の値の差（誤差）をどう集計するかで指標が変わります。誤差を2乗して平均した<strong>平均二乗誤差(MSE)</strong>、その平方根を取り元の単位に戻した<strong>二乗平均平方根誤差(RMSE)</strong>、誤差の絶対値を平均した<strong>平均絶対値誤差(MAE)</strong>が代表的です。MSE・RMSEは大きな誤差ほど強く罰するのに対し、MAEは誤差の大きさに関わらず均等に評価する、という違いがあります。モデル選択の指針としては、モデルの複雑さと当てはまりの良さのバランスを情報量として評価する<strong>赤池情報量規準(AIC)</strong>・<strong>ベイズ情報量規準(BIC)</strong>があり、いずれも「同じ精度なら、より単純なモデルを選ぶべきだ」という<strong>オッカムの剃刀</strong>の考え方を数式に落とし込んだものと理解すると覚えやすくなります。

**扱う用語（精選・18語）**

- 汎化性能／過学習
- ホールドアウト検証／交差検証／k-分割交差検証
- 混同行列／真陽性・偽陽性・偽陰性・真陰性／正解率・適合率・再現率・F値／ROC曲線・AUC
- 平均二乗誤差(MSE)／二乗平均平方根誤差(RMSE)／平均絶対値誤差(MAE)
- 赤池情報量規準(AIC)／ベイズ情報量規準(BIC)／オッカムの剃刀

## この章のまとめ

この章では、機械学習を教師あり学習・教師なし学習・強化学習の3分類で整理し、回帰・分類・クラスタリング・次元削減といった代表的な手法、そしてモデルの汎化性能をどう検証・評価するかを学びました。ここで押さえた評価指標（混同行列・交差検証など）は、次章以降のディープラーニングのモデルを評価する際にもそのまま使う土台知識です。

次章では、機械学習の中でも<strong>ディープラーニング</strong>がどのような理論的な仕組みで学習を進めるのか——活性化関数・誤差関数・最適化手法といった構成要素を学びます。→ [第3章 ディープラーニングの理論基盤](/course/g-kentei/03-deep-learning-theory/)
