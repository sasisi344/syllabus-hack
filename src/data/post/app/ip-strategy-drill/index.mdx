## ストラテジ系を集中して確かめるドリル

ITパスポートの100問のうち、ストラテジ系はおよそ35問です。企業活動、法務、経営戦略、ビジネスで使われる技術と、範囲がとても広い分野です。

ITの勉強をしてきた人ほど、ストラテジ系で点を落としがちです。会計や法律、マーケティングの用語は、ITの知識だけでは答えられないからです。

このドリルは、ストラテジ系の問題だけを集めて、苦手な中分類を見つけ、繰り返し確かめるためのものです。

### 問題は現行シラバスVer.6.5に沿っている

収録している101問は、いずれも現行のITパスポートのシラバス（Ver.6.5）に載っている用語をもとに作っています。中分類ごとの問題数は次のとおりです。

| 中分類 | 問題数 | 主な用語の例 |
| --- | --- | --- |
| 企業活動 | 33問 | 営業利益、回帰分析、相関と因果、DE&I、MVV |
| ビジネスインダストリ | 26問 | IoT、デジタルツイン、サブスクリプション、AIアシスタント |
| 経営戦略マネジメント | 20問 | PPM、RFM分析、オムニチャネル、カニバリゼーション |
| 法務 | 10問 | 商標法、マイナンバー、トロッコ問題、アルゴリズムのバイアス |
| システム戦略 | 8問 | EA、BPMN、クラウドコンピューティング |
| 技術戦略マネジメント | 3問 | リーンスタートアップ、ハッカソン |
| システム企画 | 1問 | 利用者の要求の調査 |

AIの倫理（トロッコ問題、AIサービスの責任論など）や、データ分析（散布図行列、統計的バイアスなど）といった、シラバスの改訂で加わった用語も含めています。

実際の試験では、企業活動・法務・経営戦略マネジメントからの出題が多めです。問題数の少ない中分類は、過去問やシラバスの用語一覧で補ってください。

### 間違えた問題ほど出やすくなる

出題する問題は、これまでの解答の記録をもとに選びます。

- まだ解いていない問題は、やや出やすい
- 一度でも間違えた問題は、いちばん出やすい。間違えた回数が多いほど、さらに出やすくなる
- すべて正解している問題は、出にくくなるが、ゼロにはならない

繰り返すほど、自分が間違えた問題を中心に出題されるようになります。

### 使い方

1. 30問、40問、50問のいずれかを選んで始める
2. 解答するとすぐに、正誤と解説が表示される
3. 終わったら、中分類ごとの正答率を確かめる
4. 「もう一度挑戦」で、間違えた問題が多く入った新しいセットを解く

> 💡 解答の記録はブラウザに保存されます。同じブラウザなら、続きから繰り返し演習できます。

### 向いている学習デバイス

ストラテジ系の長文設問は、PCまたはタブレット横置きで読むと負荷が下がりやすい。スキマ演習はスマホでも可能だが、メニュー設計は [ITパスポートのスマホ勉強法｜スキマ時間の長さで変えるアプリとAIの使い方](/method/smartphone-study-guide/) を参照。模試の通しは [PC学習の強みは「自分で調べに行ける」こと](/method/pc-study-setup-guide/) に寄せると本番感覚に近づきやすい。全体の整理は [スマホ・タブレット・PCをどう使い分ける？IT資格学習の最適デバイス戦略](/method/multi-device-cert-study/) にまとめている。

## 2027年度からのシラバス案で、ストラテジ系はどうなるか

IPAは、2027年度からの新しい試験制度に向けて、ITパスポートのシラバス案（Ver.0.1）を公開しています。案の段階なので、今後変わる可能性があります。

シラバス案では、今の「ストラテジ系・マネジメント系・テクノロジ系」という3つの分け方がなくなり、ビジネス変革、データ・AIの利活用、組織活動、デジタル技術、セキュリティ、倫理・コンプライアンスといった大分類に組み替えられています。

### 今のストラテジ系の中分類は、どこへ移るか

シラバス案の中分類の名前から見た、おおよその移り先は次のとおりです。正式な対応表が公開されているわけではないので、目安として見てください。

| 今の中分類 | シラバス案での主な移り先（目安） |
| --- | --- |
| 企業活動 | 組織活動（経営・組織論）、データ・AIの利活用（データ分析） |
| 法務 | 倫理・コンプライアンス（ビジネス関連法規、プライバシー関連法規など） |
| 経営戦略マネジメント | ビジネス変革（経営戦略・デジタル戦略） |
| 技術戦略マネジメント | ビジネス変革（ビジネス変革の方法論） |
| ビジネスインダストリ | ビジネス変革、デジタル技術（デジタルサービス・デジタルツール） |
| システム戦略・システム企画 | ビジネス変革（ビジネスモデル・ビジネスプロセス） |

このドリルに収録した用語のうち、およそ半分は、シラバス案の用語例には同じ言葉では見当たりません。一方で、データの分析やAIの倫理、DXの考え方は、シラバス案でむしろ厚く扱われています。

### 今から勉強する人は、どうすればいいか

| 受験の時期 | 学ぶもの |
| --- | --- |
| 2026年度中に受ける | 現行のVer.6.5。このドリルと過去問で、そのまま対策できる |
| 2027年度以降に受ける | Ver.6.5で基礎を固め、データ・AIの利活用と倫理・コンプライアンスを少し厚めにしておく |

経営や会計、法律の基本は、分類が組み替わっても考え方は変わりません。このドリルで身につけた知識は、新しい制度でも土台になります。

新しい制度の全体像は、[ITパスポート模擬試験シミュレーター](/app/it-passport-quiz/)の「2027年の新制度で、ITパスポートはどう変わるか」で整理しています。2027年のシラバス案をもとに組み立てた[ITパスポート 20時間コース](/course/ip/)もあわせて使ってください。

## 間違えた問題は、AIに「なぜ」を聞く

ストラテジ系の用語は、仕事の場面に置き換えると覚えやすくなります。間違えた問題は、生成AIに次のように聞いてみてください。

```text
ITパスポートのストラテジ系の問題で、「**[用語名]**」を間違えました。
1. この用語の意味を、会社員の日常業務の例えで説明してください
2. 試験で混同しやすい用語との違いを教えてください
3. 2027年度からのシラバス案では、どの分野で扱われそうかも教えてください
```

AIの説明には誤りが混ざることがあります。用語の定義で迷ったら、シラバスやIPAの公開問題の解説で確かめてください。
