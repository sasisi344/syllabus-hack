G検定の用語は分かるのに、時間内に選べるかが不安。短い模擬試験では、正解数だけでなく「考え続けた問題」と「知らなかった問題」を分けて記録すると、次の対策を選べます。

下のアプリは30問・20分の短縮練習です。本試験との差を確認したうえで、結果の読み方と復習先を整理します。

## 本試験と30問練習は、同じものではない

2026年11月時点のJDLAの案内では、G検定は145問程度で、オンライン試験100分、会場試験120分です。[JDLA「G検定とは」](https://www.jdla.org/certificate/general/)

このアプリは30問・20分なので、単純計算では1問40秒です。オンライン本試験の約41秒に近い練習になりますが、問題の長さ・分野配分・試験全体の負荷まで同じではありません。

| 比較する点 | このアプリ |
| --- | --- |
| 問題数と時間 | 固定の30問を順番を変えて出題、20分 |
| 収録分野 | AIの歴史6問、機械学習6問、深層学習の基礎8問、応用6問、法律・倫理・社会実装4問 |
| 回答の変更 | 採点前なら前後へ移動して選び直せる |
| 採点 | 最後の採点、途中採点、時間切れによる自動採点 |
| 結果 | 全体の正答率、分野別の表示、誤答・未回答の解説 |

収録問題は当サイトの練習用です。30問の正答率を合格可能性に換算したり、シラバス全項目を確認できたと判断したりしないでください。

## 回答してから採点するまでの使い方

「模擬試験を開始する」を押すとタイマーが動きます。選択肢を押したあと「次の問題」で進み、必要なら「前の問題」で戻って回答を変更できます。

途中で終える場合は「全問終わったので今すぐ採点する」を押します。このボタンは未回答が残っていても採点するので、全30問を解きたい場合は回答済みの数を確認してから押してください。

時間切れでも採点される設計です。残り1分以内はタイマーの表示が変わりますが、この30問を覚えた後は速さだけを追わず、解答理由を説明する練習へ移ります。

## 分野別表示は、未回答の数と一緒に読む

全体の正答率は30問を分母に計算されます。一方、分野別の欄は<strong>その分野の正解数／回答した数</strong>です。未回答が多いと、分野別の見た目だけでは弱点が分かりません。

| 結果の状態 | 次にすること |
| --- | --- |
| 未回答が多く、解いた問題は合っている | どの問題に時間を使ったかをメモし、止まった理由を確認する |
| 最後まで回答したが特定分野で間違える | 誤った選択肢と正解の違いを、その分野の教材で確認する |
| 同じ問題の再挑戦だけ速くなる | 正解の番号を覚えていないか、他の選択肢の誤りを説明する |

採点後は、誤答と未回答の問題に解説と「AIで復習」のリンクが表示されます。外部のGeminiへ質問する補助機能であり、アプリ内でAIが合否を判定するものではありません。

## 20分のあとに戻る場所を決める

知識不足なら用語へ、時間不足なら止まった判断へ戻ります。今回の問題を暗記して満点にするより、迷いの原因を1つ解消することを目標にしてください。

分野を学び直すなら[G検定20時間コース](/course/g-kentei/)、受験全体の進め方は[G検定の学習ハブ](/method/g-kentei-hub/)で確認できます。筆者はG検定を未受験で、分析実務で使う知識を足場に内容を整理しています。
