## 分野を決めて解くドリル

ITパスポートの試験は、ストラテジ系・マネジメント系・テクノロジ系の3つの分野から出題されます。

合格には総合評価点だけでなく、<strong>各分野で300点以上</strong>（1,000点満点）が必要です。得意な分野で点を稼いでも、1つの分野が基準に届かないと合格にならない仕組みです。

このドリルは、3つの分野を1ページに集めて、分野ごとに切り替えて解けるようにしたものです。通しの模擬試験で点が足りなかった分野を、ここで集中して確かめられます。

### 3つの分野の配分

| 分野 | 出題の目安 | 主な内容 | 収録問題数 |
| --- | --- | --- | --- |
| ストラテジ系 | 約35問 | 企業活動、法務、経営戦略、システム戦略 | 101問 |
| マネジメント系 | 約20問 | プロジェクト管理、サービスマネジメント、システム開発、監査 | 81問 |
| テクノロジ系 | 約45問 | セキュリティ、ネットワーク、基礎理論、ハードウェア | 101問 |

ITの勉強をしてきた人ほど、ストラテジ系で点を落としがちです。会計や法律、マーケティングの用語は、ITの知識だけでは答えられないからです。

逆に、IT未経験の人はテクノロジ系の用語につまずきやすく、出題数がいちばん多い分野だけに、ここでの取りこぼしが響きます。

どの分野から始めるか迷うときは、過去問や模擬試験で分野別の正答率を確かめてから決めてください。

## 分野ごとの収録内容

### ストラテジ系（101問）

ストラテジ系の問題は、現行シラバス（Ver.6.5）に載っている用語をもとに作っています。中分類ごとの問題数は次のとおりです。

| 中分類 | 問題数 | 主な用語の例 |
| --- | --- | --- |
| 企業活動 | 33問 | 営業利益、回帰分析、相関と因果、DE&I、MVV |
| ビジネスインダストリ | 26問 | IoT、デジタルツイン、サブスクリプション、AIアシスタント |
| 経営戦略マネジメント | 20問 | PPM、RFM分析、オムニチャネル、カニバリゼーション |
| 法務 | 10問 | 商標法、マイナンバー、トロッコ問題、アルゴリズムのバイアス |
| システム戦略 | 8問 | EA、BPMN、クラウドコンピューティング |
| 技術戦略マネジメント | 3問 | リーンスタートアップ、ハッカソン |
| システム企画 | 1問 | 利用者の要求の調査 |

AIの倫理（トロッコ問題、AIサービスの責任論など）や、データ分析（散布図行列、統計的バイアスなど）といった、シラバスの改訂で加わった用語も含めています。

実際の試験では、企業活動・法務・経営戦略マネジメントからの出題が多めです。問題数の少ない中分類は、過去問やシラバスの用語一覧で補ってください。

### マネジメント系（81問）

プロジェクトをどう進めるか、運用をどう安定させるかといった、ITを活用するビジネスパーソン全員に関わる分野です。

| 中分類 | 問題数 |
| --- | --- |
| サービスマネジメント | 26問 |
| システム開発技術 | 17問 |
| ソフトウェア開発管理技術 | 16問 |
| システム監査 | 12問 |
| プロジェクトマネジメント | 10問 |

問題数がもっとも多いサービスマネジメントは、インシデント管理や問題管理など、似た名前の用語が並びます。用語の違いを区別できるかが、この分野の分かれ目です。

### テクノロジ系（101問）

試験でいちばん出題数が多く、理系の基礎理論から最新のセキュリティまでを含む、広い分野です。

| 中分類 | 問題数 |
| --- | --- |
| セキュリティ | 35問 |
| ネットワーク | 31問 |
| 基礎理論 | 6問 |
| マルチメディア | 6問 |
| データベース | 5問 |
| その他（ハードウェア、ソフトウェア、ヒューマンインタフェースなど） | 18問 |

セキュリティとネットワークで全体の3分の2近くを占めます。この2つの中分類は、時間をかけて繰り返す価値があります。

### 間違えた問題ほど出やすくなる

出題する問題は、これまでの解答の記録をもとに選びます。

- まだ解いていない問題は、やや出やすい
- 一度でも間違えた問題は、いちばん出やすい。間違えた回数が多いほど、さらに出やすくなる
- すべて正解している問題は、出にくくなるが、ゼロにはならない

繰り返すほど、自分が間違えた問題を中心に出題されるようになります。解答の記録は分野ごとに保存されるので、分野を切り替えても、それぞれの続きから解けます。

### 使い方

1. 解く分野を選ぶ
2. 30問、40問、50問のいずれかを選んで始める
3. 解答するとすぐに、正誤と解説が表示される
4. 終わったら、中分類ごとの正答率を確かめる
5. 「もう一度挑戦」で、間違えた問題が多く入った新しいセットを解く

> 💡 解答の記録はブラウザに保存されます。同じブラウザなら、続きから繰り返し演習できます。

### 向いている学習デバイス

長文設問が多い分野は、PCまたはタブレット横置きで読むと負荷が下がりやすいです。スキマ演習はスマホでも可能で、メニューの設計は[ITパスポートのスマホ勉強法｜スキマ時間の長さで変えるアプリとAIの使い方](/method/smartphone-study-guide/)を参照してください。

模試の通しは[PC学習の強みは「自分で調べに行ける」こと](/method/pc-study-setup-guide/)に寄せると本番感覚に近づきやすくなります。全体の整理は[スマホ・タブレット・PC、資格勉強はどれがいい？画面で読んだら紙に書くと覚えられる](/method/multi-device-cert-study/)にまとめています。

## 2027年度からのシラバス案で、分野の分け方はどうなるか

IPAは、2027年度からの新しい試験制度に向けて、ITパスポートのシラバス案（Ver.0.1）を公開しています。案の段階なので、今後変わる可能性があります。

シラバス案では、今の「ストラテジ系・マネジメント系・テクノロジ系」という3つの分け方がなくなり、ビジネス変革、データ・AIの利活用、組織活動、デジタル技術、セキュリティ、倫理・コンプライアンスといった大分類に組み替わります。

このページのドリルは今の3分野で分けているので、2027年度以降に受ける人は、分野の名前ではなく、用語がどこに移るかを意識しておくと役立ちます。

### 今のストラテジ系の中分類は、どこへ移るか

シラバス案の中分類の名前から見た、おおよその移り先は次のとおりです。正式な対応表が公開されているわけではないので、目安として見てください。

| 今の中分類 | シラバス案での主な移り先（目安） |
| --- | --- |
| 企業活動 | 組織活動（経営・組織論）、データ・AIの利活用（データ分析） |
| 法務 | 倫理・コンプライアンス（ビジネス関連法規、プライバシー関連法規など） |
| 経営戦略マネジメント | ビジネス変革（経営戦略・デジタル戦略） |
| 技術戦略マネジメント | ビジネス変革（ビジネス変革の方法論） |
| ビジネスインダストリ | ビジネス変革、デジタル技術（デジタルサービス・デジタルツール） |
| システム戦略・システム企画 | ビジネス変革（ビジネスモデル・ビジネスプロセス） |

ストラテジ系のドリルに収録した用語のうち、およそ半分は、シラバス案の用語例には同じ言葉では見当たりません。一方で、データの分析やAIの倫理、DXの考え方は、シラバス案でむしろ厚く扱われています。

### 今から勉強する人は、どうすればいいか

| 受験の時期 | 学ぶもの |
| --- | --- |
| 2026年度中に受ける | 現行のVer.6.5。このドリルと過去問で、そのまま対策できる |
| 2027年度以降に受ける | Ver.6.5で基礎を固め、データ・AIの利活用と倫理・コンプライアンスを少し厚めにしておく |

経営や会計、法律の基本は、分類が組み替わっても考え方は変わりません。このドリルで身につけた知識は、新しい制度でも土台になります。

新しい制度の全体像は、[ITパスポート模擬試験シミュレーター](/app/it-passport-quiz/)の「2027年の新制度で、ITパスポートはどう変わるか」で整理しています。2027年のシラバス案をもとに組み立てた[ITパスポート 20時間コース](/course/ip/)もあわせて使ってください。

## 間違えた問題は、AIに「なぜ」を聞く

用語は、仕事の場面に置き換えると覚えやすくなります。間違えた問題は、生成AIに次のように聞いてみてください。

```text
ITパスポートの[ストラテジ系 / マネジメント系 / テクノロジ系]の問題で、「**[用語名]**」を間違えました。
1. この用語の意味を、会社員の日常業務の例えで説明してください
2. 試験で混同しやすい用語との違いを教えてください
3. 2027年度からのシラバス案では、どの分野で扱われそうかも教えてください
```

AIの説明には誤りが混ざることがあります。用語の定義で迷ったら、シラバスやIPAの公開問題の解説で確かめてください。
