仕訳の解説を読むと分かるのに、取引文だけになると借方・貸方で迷う。そのときは、解く速さより先に「どの判断で止まったか」を確認すると、復習する場所を選べます。

このドリルは取引文から四択で仕訳を選ぶ練習です。収録範囲と誤答の見方を押さえ、選択肢なしでも仕訳を書ける状態につなげます。

## このドリルの範囲は5分野・全20問

2026年11月2日時点では、次の5分野を各4問収録しています。当サイトの練習問題であり、日本商工会議所の公式問題や本試験の全範囲を再現した模試ではありません。

| 分野 | このドリルで確認する観点 |
| --- | --- |
| 商品売買 | 仕入・売上と、代金の決済方法を分けて読む |
| 現金・預金 | 現金と預金の増減や振替を捉える |
| 債権・債務 | 売掛金・買掛金などの発生と消滅を区別する |
| 固定資産 | 取得時と、その後の処理を区別する |
| 決算整理 | 当期の収益・費用になる範囲を確認する |

「全問シャッフル」は20問を一度に解く機能ではなく、全分野の問題から10問を選ぶモードです。分野別では、その分野の4問を解きます。

実際の答案の構成は、日本商工会議所が公開する[簿記2・3級サンプル問題](https://www.kentei.ne.jp/bookkeeping/sample)で確認できます。四択で選べたあとに、勘定科目や金額を自分で記入する練習も必要です。

## 間違えた仕訳のどこを直すか

選択肢を押すと正誤と解説が表示され、回答の変更はできません。「次の問題」で進み、セットの最後に結果と誤答を確認します。

| 誤答の状態 | 戻る学習 | 次に確かめること |
| --- | --- | --- |
| 現金か売掛金かなど、科目から迷う | 取引の発生と決済を分けて読む | 今日、現金が動いたかを言えるか |
| 科目は合うが借方・貸方が逆 | 資産・負債・純資産・収益・費用の増減を整理 | 丸暗記せず左右を説明できるか |
| 科目も向きも合うが金額が違う | 取引日・対象期間・差額を計算 | 問題文の数字をすべて使う必要があるか |

たとえば商品を掛けで売った場面では、売上の発生と代金の回収は別の出来事です。「売ったから現金が増えた」と飛ばさず、まだ回収していない金額があるかを読みます。

解答後は選択肢を隠して、借方・貸方・金額を手書きで再現してください。四択では候補が手掛かりになるので、同じ正答でも再現できるかに違いが出ます。

## 解説で止まったときは、AIに理由を聞く

「深掘りプロンプトをコピー」は、問題と自分の回答を含む質問文をコピーする機能です。AIがこのページ内で採点しているわけではありません。

外部AIに貼り付けるときは、「この勘定科目は何の増減か」「なぜ反対側ではないか」を確認します。回答がドリルの解説と食い違う場合は、教材の該当項目に戻り、どちらが正しいかを確かめてから覚えます。

## 正答率より、選択肢なしで書けるかを確認する

同じ20問を繰り返すと、仕訳の理由より選択肢の見た目を覚えることがあります。全問正解したら、取引文だけを見て仕訳を作り、解説で理由を照合する段階へ進みます。
