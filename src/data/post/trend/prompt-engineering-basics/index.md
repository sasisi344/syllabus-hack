## 試験での出題ポイント
ITパスポート試験では、「どのようにプロンプトを構成すれば、より精度の高い回答が得られるか」という具体例を問う問題が出やすいです。これは、単にプロンプトエンジニアリングの用語を覚えるだけでなく、その実践的な応用力を試す意図があります。AIを適切に活用し、業務課題を解決できる人材であるかを評価するためです。

1.  <strong>役割（Role）</strong>: 「あなたはプロのエンジニアです」と役割を与えることは、AIの思考の「視点」を明確にする上で非常に重要です。
    *   <strong>なぜ重要か</strong>: AIは様々な知識を持っていますが、特定の役割を与えることで、その役割に沿った専門性や視点から回答を生成するようになります。これにより、汎用的な回答ではなく、より的確で質の高いアウトプットが期待できます。
    *   <strong>どう試験に出るか</strong>: 「特定の専門家として回答させるためのプロンプトの構成要素として適切なものはどれか」といった形で、役割指定の重要性を問う選択問題が出される可能性があります。
    *   <strong>実務でどう使うか</strong>: 企画書作成時に「あなたはマーケティング担当者です」と指示し、市場調査に基づいた提案をさせるなど、業務における具体的な役割をAIに与えることで、専門的な視点からの支援を得られます。

2.  <strong>文脈（Context）</strong>: 「新入社員向けの資料作成のために」と背景を伝えることで、AIは回答の「目的」や「対象読者」を理解し、適切なトーンや詳細度で情報を生成します。
    *   <strong>なぜ重要か</strong>: AIが回答を生成する際、その情報が「誰に」「何の目的で」使われるのかを知ることで、言葉遣いや情報の粒度を調整できます。これにより、誤解を防ぎ、ユーザーの意図に沿った回答を得やすくなります。
    *   <strong>どう試験に出るか</strong>: 「ある状況下でAIに適切な情報を引き出すためのプロンプトとして、不足している要素はどれか」といった問題で、背景情報の提供の有無が問われることがあります。
    *   <strong>実務でどう使うか</strong>: 会議の議事録作成で「〇月〇日の〇〇会議の議事録です。決定事項と次回のタスクを箇条書きでまとめてください」と、会議の背景と目的を伝えることで、的���な要約を得られます。

3.  <strong>Few-shot</strong>: 数個の「具体例」を提示して、形式を学習させる技術です。AIに望む回答のパターンを直接示すことで、より精度の高い出力を促します。
    *   <strong>なぜ重要か</strong>: AIは与えられた例からパターンを学習する能力に優れています。Few-shotプロンプティングを用いることで、特定のフォーマットやスタイル、あるいは複雑な推論プロセスをAIに効率的に理解させることができます。
    *   <strong>どう試験に出るか</strong>: 「AIに特定の回答形式を学習させるための手法として最も適切なものはどれか」といった形で、Few-shotプロンプティングの概念とその効果を問う問題が出題される可能性があります。
    *   <strong>実務でどう使うか</strong>: 顧客からの問い合わせメールの返信テンプレートをAIに作成させる際、過去の返信例をいくつか提示することで、自社のブランドイメージ��合った丁寧な文面を生成させることができます。

4.  <strong>Chain-of-Thought (CoT)</strong>: 「ステップバイステップで考えて」と指示し、思考過程を出力させる手法です。これにより、AIの推論過程を可視化し、複雑な問題に対する回答の信頼性を高めます。
    *   <strong>なぜ重要か</strong>: 複雑な問題や多段階の論理を必要とするタスクにおいて、AIが最終的な回答に至るまでの思考プロセスを明示させることで、その回答の妥当性を人間が確認できるようになります。誤りがあった場合も、どの段階で誤ったのかを特定しやすくなります。
    *   <strong>どう試験に出るか</strong>: 「AIが複雑な問題を解決する際の論理的な思考過程を確認するためのプロンプトの指示として適切なものはどれか」といった形で、CoTの有効性や目的を問う問題が出ることが考えられます。
    *   <strong>実務でどう使うか</strong>: プロジェクトのスケジュール作成をAIに依頼する際に、「まずタスクを洗い出し、次に依存関係を考慮し、最後に各タスクの所要時間を推定して、全体スケジュールを提案してください」と指示することで、論理的で実行可能な計画を得られます。

### プロンプト例:
> 「ITパスポート試験の『Few-shotプロンプティング』について、小学生でも分かるように例え話を使って説明してください。回答は150文字以内で、最後に応援メッセージを付けてください。」
