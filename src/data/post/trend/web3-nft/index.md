Web3.0という言葉は、数年前ほど「最新」とは言えなくなりました。

けれど、その土台にある<strong>ブロックチェーン</strong>は、いまも試験で目にする用語です。ネットワークの構成を問う場面や、フィンテックなどの金融の話題で登場するからです。

この記事では、ブロックチェーンを中心に、Web3.0・NFT・DAOとの関係を、試験用語として整理します。

## ブロックチェーンは「みんなで持つ記録帳」

ブロックチェーンは、取引の記録を、特定の管理者ではなく、ネットワークに参加する多くのコンピュータで分け合って持つ仕組みです。分散して持つ記録帳なので、<strong>分散型台帳</strong>とも呼ばれます。

仕組みは、次の4つで押さえます。

| 用語 | 内容 |
| --- | --- |
| ブロックとチェーン | 取引の記録をまとめた「ブロック」を、時系列でつなげていく。つなぐときに、前のブロックの内容から計算した値（ハッシュ値）を入れる |
| 改ざんが難しい | 途中のブロックを書き換えると、ハッシュ値が合わなくなり、以降のブロックもすべて書き換える必要が出る |
| P2P（ピア・ツー・ピア） | 中心のサーバーを置かず、参加者同士が直接つながる。クライアントサーバ型と対比される |
| 合意形成（コンセンサス） | 新しいブロックを正しいものと認めるための、参加者のルール |

さらに、条件が満たされたときに自動で実行される契約の仕組みを<strong>スマートコントラクト</strong>と呼びます。

## なぜ試験に出やすいのか

### ネットワークの構成で問われる

ブロックチェーンは、P2Pのネットワークで動きます。クライアントサーバ型のように、中心のサーバーが全体を管理する形とは、考え方が違います。ネットワークの構成を問う問題で、対比される用語として登場します。

### 金融（フィンテック）の話題で問われる

ブロックチェーンは、暗号資産（仮想通貨）の基盤として広まりました。送金や決済など、金融の分野で新しいサービスを生む技術として、フィンテックの話題でも取り上げられます。金融とITの関係は、[金融IT検定とは？](/trend/fintech-it-cert-intro/)でも整理しています。

## Web3.0・NFT・DAOは、ブロックチェーンの応用

ブロックチェーンを土台にした考え方が、Web3.0です。

| 用語 | 内容 |
| --- | --- |
| Web3.0 | 特定の巨大企業に頼らず、ユーザー自身がデータや資産を持ち、ブロックチェーンを使って直接やりとりするインターネットの考え方。Web1.0は情報の閲覧中心、Web2.0はプラットフォームを通じた情報の共有中心とされる |
| NFT（非代替性トークン） | ブロックチェーン上で、デジタルデータの「唯一性」と所有を証明する仕組み。デジタルアートやゲームのアイテムなどに使われる |
| DAO（自律分散型組織） | 特定のリーダーがおらず、スマートコントラクトと参加者の投票で運営される組織 |

試験では、Web2.0との違い（<strong>非中央集権</strong>であること、データの所有権がユーザー側にあること）と、それぞれの用語の意味が問われます。

### 現状の課題も知っておく

Web3.0は期待された一方で、価格の変動が大きいこと、法律やルールの整備が途中であること、使い方が難しいことなどの課題も指摘されています。「新しい仕組み」として紹介されるだけでなく、メリットと課題を両方説明できると、理解が深まります。

## まとめ

- ブロックチェーンは、取引の記録を参加者で分け合って持つ「分散型台帳」で、ブロックをハッシュ値でつなぐことで改ざんを難しくしている
- P2Pのネットワークで動くため、クライアントサーバ型と対比されて問われやすい
- 暗号資産の基盤として、フィンテックなど金融の話題でも登場する
- Web3.0・NFT・DAOは、ブロックチェーンを土台にした考え方で、非中央集権とデータの所有権が試験のポイント
