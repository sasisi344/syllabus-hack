基本情報技術者試験の科目Bに向けて、「まずはPythonを勉強しておけば大丈夫だろう」と考えていないでしょうか。

Pythonは人気が高く、仕事でも使われることの多い言語です。Pythonでプログラムを書いた経験は、科目Bでも必ず役に立ちます。

ただし、科目Bの問題は<strong>擬似言語</strong>という試験用の言語で出題されます。Pythonの感覚のまま読むと、ところどころでつまずきます。

この記事では、Pythonの経験者が擬似言語でつまずく3つの違いを整理したうえで、Pythonを活かしながら、ほかの言語にも通じる考え方を身につける方法を説明します。

## 科目Bは擬似言語で出題される

いまの基本情報技術者試験の科目Bでは、プログラムの問題はすべて<strong>擬似言語</strong>で出題されます。擬似言語は、特定のプログラミング言語に依存しないように作られた、試験用の書き方です。

2022年度までの基本情報の午後試験では、C言語、Java、Python、アセンブラ、表計算から1つを選んで解く形式でした。2023年度からの科目Bで擬似言語に一本化され、どの言語を学んできた人も同じ問題を解くようになりました。

擬似言語の書き方は、変数を宣言し、繰り返しや条件分岐を組み合わせ、配列を添字で操作するという、C言語の流れをくむ手続き型の言語に近いものです。Pythonの便利な書き方に慣れていると、ここで違いを感じます。

## Pythonの経験者がつまずく3つの違い

### 配列の添字が1から始まる

いちばんつまずきやすいのが、配列の添字です。

| 言語 | 配列の先頭 |
| --- | --- |
| Python | `a[0]` |
| 擬似言語 | `array[1]` |

Pythonでは先頭が0番目ですが、擬似言語では<strong>1番目から始まります</strong>。

1つずれるだけと思うかもしれませんが、繰り返しの処理を追いかける（トレースする）ときには大きな違いになります。Pythonの `for i in range(len(a))` の感覚のまま、擬似言語の「iを1から配列の要素数まで1ずつ増やす」を追うと、どこかで参照する位置がずれてしまいます。

### 便利な関数がない

Pythonには、並べ替えの `sort()`、値が含まれているかを調べる `in` など、便利な機能がそろっています。

擬似言語には、こうした機能はありません。並べ替えなら、値を比べて、一時的な変数に退避し、入れ替える処理を、自分で組み立てる必要があります。

試験で問われるのは、便利な関数の使い方ではなく、<strong>処理の仕組みを理解しているか</strong>です。Pythonで `sort()` に任せていた部分を、自分の手で組み立てられるかが問われます。

### 値と参照の違いを意識する

Pythonを使っていると、データがメモリのどこにあるかを意識することはあまりありません。

擬似言語の問題では、配列やデータを手続きに渡したときに、値をコピーして渡しているのか、同じデータを指す参照を渡しているのかで、結果が変わる問題が出ます。「手続きの中で配列を書き換えたら、呼び出し元の配列も変わった」という動きを、理由とともに説明できるかが問われます。

## Pythonだけでも強い。複数の言語に通じると、さらに強い

ここまで読むと、Pythonで勉強するのは遠回りに思えるかもしれません。けれど、そうではありません。

Pythonは、人気があり、仕事で使われることも多い言語です。いまはWebの分野でJavaScriptなどの言語も強いですが、Pythonを使いこなせるだけでも、データ分析やAI、業務の自動化など、活躍できる場面はたくさんあります。

そのうえで、<strong>複数の言語を扱える</strong>と、エンジニアとしての強みはさらに大きくなります。プログラミング言語は、多くがC言語の考え方をもとに作られています。変数、繰り返し、条件分岐、配列、参照といった共通の仕組み、いわば<strong>言語の体系</strong>を身につけていれば、新しい言語に出会っても、書き方の違いを押さえるだけで使えるようになります。

擬似言語の勉強は、Pythonの便利さの裏で動いている共通の仕組みを学ぶ機会になります。科目Bの対策が、そのまま「ほかの言語にも通じる力」を身につける練習になるのです。

## Pythonのコードを擬似言語に書き換えて練習する

Pythonの経験を活かすなら、<strong>自分で書いたPythonのコードを、擬似言語に書き換える</strong>練習がおすすめです。動かして確かめられるPythonと、試験に出る擬似言語を並べて比べることで、違いが頭に入ります。

書き換えは、生成AIに手伝ってもらえます。

```text
以下のPythonのコードを、基本情報技術者試験の科目Bで使われる擬似言語の形に書き換えてください。

条件:
- 配列の添字は1から始まるように直す
- sort や in など、Python特有の機能は使わず、繰り返しと条件分岐で書く
- **書き換える前と後で、どこが変わったか（特に添字と処理の流れ）**を説明する

（ここにPythonのコードを貼る）
```

たとえば、次のバブルソートを書き換えてもらうと、添字の範囲や繰り返しの書き方の違いがよくわかります。

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                tmp = arr[j]
                arr[j] = arr[j + 1]
                arr[j + 1] = tmp
```

書き換えた擬似言語を、紙の上で1行ずつトレースしてみてください。Pythonで動かした結果と同じになるかを確かめると、添字のずれに気づけるようになります。

AIの書き換えには、まれに誤りがあります。擬似言語の書き方は、IPAが公開している試験の資料やサンプル問題で確かめてください。

## まとめ

基本情報技術者試験の科目Bは、擬似言語で出題されます。

- Pythonの経験者がつまずくのは、1から始まる配列の添字、便利な関数がないこと、値と参照の違いの3つ
- 擬似言語は、C言語の流れをくむ手続き型の言語に近い書き方
- Pythonだけでも活躍できる場面は多いが、複数の言語に通じる「言語の体系」を身につけると、エンジニアとしてさらに強い
- 自分のPythonのコードを擬似言語に書き換えて、トレースする練習が効果的

これで、Pythonの経験を活かしながら、科目Bの擬似言語に慣れる進め方がわかったはずです。まずは手元のPythonのコードを1つ、上のプロンプトで擬似言語に書き換えて、紙の上で追いかけてみてください。
