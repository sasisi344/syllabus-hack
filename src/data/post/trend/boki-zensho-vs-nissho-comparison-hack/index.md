「全商簿記は持っているけど、日商簿記ってどう違うの？」

商業高校で簿記を学んだ人が、一度は考える疑問です。「どっちが難しいか」と調べる人も多いのですが、先に言うと、<strong>二つの違いは難しさより、主催している団体と、使い道にあります</strong>。

この記事では、二つの検定の違いを整理して、自分にとってどちらが必要かを考える見方をまとめます。

筆者は日商簿記を未受験です。以下は主催団体の出題範囲をもとにした比較で、合格体験ではありません。

## 違いは主催者と、想定している受験者

| | 全商簿記 | 日商簿記 |
| --- | --- | --- |
| 主催 | 全国商業高等学校協会 | 日本商工会議所 |
| 想定している受験者 | 商業高校などの生徒 | 学生・社会人 |
| 目的 | 高校生に、社会に出るための会計の知識を身につけてもらう | 企業の経理の全般的な知識を証明する |
| 位置づけ | 授業の学習内容に沿った検定 | 国家資格ではないが、企業で広く知られた検定 |

出典: [全商・簿記実務検定試験](https://zensho.or.jp/examination/bookkeeping/)、[日商簿記2級の位置づけ](https://www.kentei.ne.jp/bookkeeping/class2)。対象の整理は受験資格の制限を示すものではありません。

### 全商簿記は授業の過程で受けるもの

全商簿記は、全国商業高等学校協会が主催する検定です。高校の教科書の内容に沿って出題されるため、授業を受けながら、学校単位で受験することが多くなります。

目的は、高校生レベルで、社会に出るために必要な会計の知識を身につけることです。

### 日商簿記は企業の経理の知識を証明するもの

日商簿記は、日本商工会議所が主催する検定です。国家資格ではありませんが、企業の経理に必要な知識を幅広く問うため、採用や人事で参照される機会が多い検定です。

3級・2級は、ネット試験（CBT）で随時受けられる方式があります。2026年10月31日時点の申込方法・休止期間は、[日商簿記の公式案内](https://www.kentei.ne.jp/bookkeeping)で確認してください。

## どちらが難しいかより、必要かどうかで決める

「どちらが難しいか」は、範囲も出題の形も違うため、単純に比べにくい問いです。それよりも、<strong>自分の進路に、どちらが必要か</strong>で考えると決めやすくなります。

| 自分の状況 | 考え方 |
| --- | --- |
| 授業で全商簿記を受けている | 授業の一部なので、まず目の前の全商簿記に取り組む |
| 就職で、履歴書に簿記を書きたい | 取得済みの全商は正式名称・級・部門を記載。求人に日商の指定があれば追加取得を検討 |
| 経理・財務系の仕事に就きたい | 求人の応募条件が日商2級等なら、その指定級の範囲を確認 |
| 大学進学で、資格による加点を使いたい | 志望校の当該年度の募集要項で、検定名・級・部門・取得期限を確認 |

履歴書では「簿記1級」とだけ書かず、主催団体と検定名を区別します。全商1級は会計と原価計算の両部門に合格して取得するため、一部門だけの合格と1級取得を混同しないでください。出典: [全商の級・部門の説明](https://zensho.or.jp/examination/bookkeeping/)。

## 全商簿記の知識は、日商簿記の土台になる

二つの検定は、別物ではなく、同じ簿記の知識を、違う場面で問うものです。全商簿記で学んだ仕訳や帳簿の基礎は、日商簿記でも使えます。

違いが出やすいのは、日商簿記の2級で、商業簿記に加えて工業簿記（原価計算）が出題される点です。全商でも1級で原価計算を扱いますが、級や範囲の組み合わせが違うため、学んだ内容を確認してから進めるのが安全です。全商1級＝日商2級のような公式な換算ではありません。出典: [全商の出題内容](https://zensho.or.jp/examination/bookkeeping/)、[日商2級の商業簿記・工業簿記](https://www.kentei.ne.jp/bookkeeping/class2)。

自分の学習済みの範囲と、日商簿記で追加で学ぶ範囲の差を、生成AIで洗い出せます。

```text
私は商業高校で全商簿記検定（**取得した級を入力**）に合格しました。
授業で学習した内容は次のとおりです。
（学習した内容を箇条書きで入力。例: 仕訳の基礎、商品売買、手形、精算表の作成）

日商簿記（**目標の級を入力**）の公式出題区分表の該当部分は次のとおりです。
（公式の範囲を確認して入力）
この範囲と私の学習済み内容を照合して、次の3点を整理してください。

1. 全商簿記と重複していて、そのまま使える知識
2. 追加で確認する分野（特に工業簿記・原価計算）。不明な範囲は推測せず保留
3. 週ごとの学習スケジュールの案
```

AIの答えは目安です。出題範囲は、日本商工会議所の公式の試験要項で確認してください。

## 在学中は、仕訳の記憶が新しいうちに始める

全商簿記で学んだ仕訳が身体に残っている高校3年生〜大学1年生は、日商簿記に進みやすい時期です。社会人になってから一から学び直すより、効率がよくなります。

工業簿記の原価計算でつまずいたときは、[工業簿記がわからない簿記3級合格者へ](/method/boki-genka-keisan-wakaranai-hack/)を見てください。仕訳の復習から始めたい場合は、記事末尾のハブで学習手順を確認できます。

## まとめ

- 全商簿記は全国商業高等学校協会、日商簿記は日本商工会議所が主催している
- 全商簿記は高校生が社会に出るための会計の知識を、日商簿記は企業の経理の全般的な知識を示す
- 「どちらが難しいか」より、「自分の進路にどちらが必要か」で考える
- 履歴書では主催・検定名・級・部門を区別し、求人や入試の指定があればその条件に合わせる
- 全商簿記の知識は、日商簿記の土台として使える

日商簿記の全体像、ネット試験の特徴、キャリアへの生かし方は、[日商簿記3級・2級 合格ロードマップ](/method/boki-hub/)にまとめています。
