<h2>試験での出題ポイント</h2>
<p>試験では、「GXを加速させるために、ITを具体的にどう活用すべきか」という視点が問われます。IT初学者として、どのような技術がどのように貢���するのかを理解することが重要です。</p>
<ol>
<li><strong>排出データの見える化</strong>: サプライチェーン（Scope 1〜3）全体でのCO2排出量をリアルタイムで計測・管理するITシステムの導入。
<p>なぜ重要か：脱炭素への取り組みは、まず現状を正確に把握することから始まります。自社だけでなく、原材料調達から製品の廃棄に至るまでのサプライチェーン全体（Scope 1:直接排出、Scope 2:電力由来の排出、Scope 3:その他間接排出）の排出量を可視化することで、どこに削減の余地があるかを特定できます。</p>
<p>どう試験に出るか：IoTセンサーで収集したデータをクラウド上で分析し、ダッシュボードで可視化するシステムや、サプライヤーとのデータ連携の重要性などが問われます。Scope 1〜3の概念も理解しておきましょう。</p>
<p>実務でどう使うか：GHG排出量算定・可視化ツールを導入し、サプライヤーに排出データ提供を要請することで、企業全体の排出削減目標設定や進捗管理に役立てます。</p>
</li>
<li><strong>IT自体の省エネ</strong>: データセンターの冷却効率化や、仮想化技術によるサーバー台数削減などの「グリーンIT」。
<p>なぜ重要か：ITサービス自体も大量の電力を消費するため、IT業界自身が環境負荷を低減する責任があります。データセンターの電力消費を抑えることは、直接的なCO2排出削減に繋がります。</p>
<p>どう試験に出るか：データセンターのエネルギー効率を示す指標であるPUE（Power Usage Effectiveness）や、1台の物理サーバー上で複数の仮想サーバーを動かす仮想化技術による省エネ効果が問われることがあります。また、クラウドサービスの活用もグリーンITの一環として評価されます。</p>
<p>実務でどう使うか：高効率な冷却システムを備えたデータセンターを選定したり、オンプレミス（自社運用���のサーバーをクラウドに移行したりすることで、ITインフラの電力消費を大幅に削減できます。</p>
</li>
<li><strong>業務効率化によるGX</strong>: AIによる物流ルートの最適化で、走行距離（燃料消費）を削減すること自体がGXへの貢献となる。
<p>なぜ重要か：ITを活用した業務効率化は、直接的に燃料消費や電力使用量を削減し、結果としてCO2排出量を減らすことができます。これは、DXがGXに貢献する代表的な例です。</p>
<p>どう試験に出るか：AIやIoT、ビッグデータ分析を活用したサプライチェーンの最適化、スマート農業での水や肥料の効率的な利用、スマートシティにおけるエネルギー管理システムなどが問われる可能性があります。</p>
<p>実務でどう使うか：AIを活用して最適な配送ルートを導き出すことで、トラックの走行距離と燃料消費を削減したり、生産ラインの稼働状況をIoTで監視し、無駄な電力消��を抑えたりする取り組みが挙げられます。</p>
</li>
</ol>
