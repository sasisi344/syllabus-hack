旧シラバスの教材で勉強を始めたあとに、「新シラバスが出た」と知って、どこまで学び直しになるのか気になっていませんか。

結論から言うと、章の数は5つのままで、<strong>増えたのは第3章（AIエージェント）と第4章（リスク・倫理・ガバナンス）</strong>です。

この記事では、公式のシラバスPDFを項目まで数えて、旧版から何を足せばよいかを章ごとに整理します。

読み終えるころには、自分の教材を新シラバスに合わせるために、どの章を補えばよいかが判断できるようになります。

## 新シラバスはいつから？受験月で決まる

先に、いつの試験から変わるのかを確認します。

新シラバスは<strong>2027年2月試験から</strong>です。旧シラバスは、2026年10月試験までです（シラバスPDF 9ページ）。

生成AIパスポートは、年5回（2月・4月・6月・8月・10月）の実施で、各回は月初から月末までの1か月間が受験期間です。

| 試験 | 申込期間 | 受験期間 | シラバス |
| --- | --- | --- | --- |
| 2026年10月試験 | 8/1〜9/30 | 2026/10/1〜10/31 | 旧 |
| 2027年2月試験 | 2026/10/1〜2027/1/31 | 2027/2/1〜2/28 | <strong>新</strong> |

2026年10月26日の時点で、10月試験の申込はすでに締め切られています。

これから受ける人は、基本的に新シラバスで受けることになります。

ここまでは日程の話でした。では、章の中身は何が変わったのでしょうか。

## 章立ては5つのまま、中身が組み替わった

公式の改訂資料（シラバスPDF 9ページ）では、章名は次のように変わっています。

| 章 | 旧シラバス（〜2026年10月試験） | 新シラバス（2027年2月〜） |
| --- | --- | --- |
| 1 | AI（人工知能） | AIの基礎と歴史 |
| 2 | 生成AI（ジェネレーティブAI） | 生成AI |
| 3 | 現在の生成AIの動向 | <strong>AIエージェント</strong> |
| 4 | 情報リテラシー・基本理念とAI社会原則 | <strong>生成AIのリスク予防・AI倫理・ガバナンス</strong> |
| 5 | テキスト生成AIのプロンプト制作と実例 | 生成AIの実践と活用事例 |

GUGA（生成AI活用普及協会）は、改訂の主な点として次の3つを挙げています。

- AIエージェントの内容を拡充し、章立てを再編した
- リスク予防・AI倫理・ガバナンスを大幅に拡充した
- 業務別・業種別の活用と、AI出力の評価・検証を加えた

章名を見ると、第3章・第4章・第5章が大きく変わったことが分かります。

ただ、章名だけでは「どのくらい増えたのか」が分かりません。そこで、項目を数えてみます。

## 項目を数えると、増えた場所がはっきりする

シラバスの表には、章ごとに「詳細キーワード」の欄があります。この欄に並ぶ語の数を、旧版と新版で数えました。

| 章 | 旧シラバス | 新シラバス |
| --- | ---: | ---: |
| 第1章 | 42語（AI） | 77語（AIの基礎と歴史） |
| 第2章 | 63語（生成AI） | 81語（生成AI） |
| 第3章 | 24語（現在の生成AIの動向） | 72語（AIエージェント） |
| 第4章 | 61語（情報リテラシー等） | <strong>214語</strong>（リスク予防・AI倫理・ガバナンス） |
| 第5章 | 47語（プロンプト制作） | 68語（実践と活用事例） |
| 合計 | 237語 | 512語 |

これは当サイトの集計です。語は数え方で変わりますし、旧第2章と第3章は中身が組み替えられているため、章ごとの単純な比較はできません。目安として見てください。

それでも、読み取れることが2つあります。

- <strong>第4章が全体の約4割（214語）</strong>を占めています。旧版の第4章（61語）の3.5倍です
- 第3章は、旧版の動向の章（24語）から3倍になり、ほぼすべてが新しい項目です

つまり、新シラバスの重心は「AIの仕組み」から、「AIを安全に使い、組織で管理する」ほうに移りました。

では、旧版の教材に何を足せばよいのでしょうか。章ごとに見ていきます。

## 第1〜2章：土台は残り、仕組みの説明が深くなった

第1章と第2章は、旧版の知識の多くが土台として使えます。足すのは、仕組みの説明です。

第1章では、ニューラルネットワークの項目が厚くなりました。入力層・隠れ層・出力層、損失関数、誤差逆伝播法、勾配降下法といった語が、キーワードに並びます。

また、CNN・RNN・LSTM・VAE・GANといった代表的なモデルを、「識別系AIと生成系AIの違い」で整理する項目が加わっています。

第2章は、生成AIを「技術・学習・生成」の流れで捉える構成に変わりました。

- <strong>学習</strong>：事前学習→ファインチューニング→RLHFの3段階。スケーリング則（モデルを大きくすると性能が上がる経験則）
- <strong>生成</strong>：トークン化、埋め込み（Embedding）、Temperature・Top-p（出力のばらつきを調整する設定）、コンテキストウィンドウ（一度に扱える文章量）
- <strong>モデルの種類</strong>：オンプレミスLLM、オープンソースLLM、画像の来歴情報（C2PA）

一方で、旧版のキーワード欄にあった語のうち、次の語は新シラバスの本文のどこにも出てきません。

- 第1章：弱いAI・強いAI、特徴量、ニューロン・シナプス、2045年問題
- 第2章：BERT・RoBERTaなどのモデル名、ボルツマンマシン、自己回帰モデル、GPT-4o・Sora などの個別のバージョン名

ただし、GPT-1〜GPT-3.5の歴史や、Gemini・Claude・Copilotの特徴は、学習項目としては残っています。

モデルの項目（ChatGPTと主要な生成AIモデルの動向）には、新しく「推論モデルと推論時の計算」が入りました。学習目標にも、生成AIの最新動向を継続的にキャッチアップするための情報収集力が書かれています。

使うモデルは、最新のものを選べば、まず困りません。ただ、推論に時間をかけるモデルと、日常のタスク向けに軽く作られたモデルでは、得意なことも、かかるコストも違います。

<strong>モデルの特徴を、自分の印象ではなく、知識として整理しておく</strong>と、用途に合うモデルを選び分けられます。選び分けは、コストを抑える意味でも重要です。

<strong>旧版の第1〜2章の知識は、そのまま使えます。足りない分は、学習と生成の仕組み、そして主要モデルの特徴の整理です。</strong>

次の第3章は、旧版にほぼ対応するものがありません。

> [!think]
> 個人的にはGPTの歴史を学ぶ必要性は感じないけれど、AIモデルの特徴は主観ではなく知識体系での学び直しが必要になると思う。モデルは使っているなら最新で問題ないけど、より柔軟にするなら推論・思考・日常タスクなどの最適化されたモデルを適時適切に選ぶことがコスト削減にもなるので重要。

## 第3章：AIエージェントは、ほぼ新しい項目

第3章は、旧版の「動向」の一部だったAIエージェントが、独立した章になりました。

AIエージェントとは、LLM（大規模言語モデル）を中心にして、計画を立て、ツールを使い、結果を見てやり直す、というループで複数の手順を進めるしくみです。

新シラバスでは、次の中項目が並びます。

- AIエージェントとは（ワークフロー型と自律型、Human-in-the-Loop）
- RAG（検索拡張生成）：Advanced RAG、Agentic RAG、Graph RAGなどの発展形まで
- AIエージェントの仕組み：タスク分解、記憶、<strong>コンテキストエンジニアリング</strong>
- MCP・Agent Skills と外部連携：A2A（エージェント同士の連携）
- AIエージェントのツールと活用事例：コーディングエージェント、ハーネスエンジニアリング
- AIエージェントのリスク・安全性・評価：<strong>プロンプトインジェクション</strong>、最小権限の原則

この中で、初めて見る人がつまずきやすい語を3つだけ挙げます。

- コンテキストエンジニアリング：AIに渡す情報（指示文・参考資料・やり取りの履歴）全体を設計して管理すること
- MCP（Model Context Protocol）：AIが外部のツールやデータにつながるための共通の取り決め
- プロンプトインジェクション：文書やWebページに紛れ込んだ悪意ある指示で、AIを意図しない動作に誘導する攻撃

旧版の教材にこれらの語がなければ、第3章は丸ごと新しく学ぶことになります。

AIエージェントは、新しい分野のため、資料やサービスによって説明が揺れやすい領域です。シラバスの語を軸に、定義を揃えておくと、後から情報を足しても混乱しにくくなります。

では、最も増えた第4章はどうでしょうか。

> [!think]
> AIエージェントは理論がぶれやすいので知識として備えておくと心強い。

## 第4章：増えた分の大半は「リスクとルール」

第4章は9つの中項目になり、新シラバスで最も項目が多い章です。

<strong>シャドーAI</strong>は、会社が承認していないAIツールや個人アカウントを、業務で使ってしまうことです。情報漏えいの原因になるため、会社と従業員がそれぞれ守るルールが問われます。

<strong>検証レベル</strong>は、AIの出力をどこまで確認するかを、用途と影響度に応じて変える考え方です。社内の連絡メモと、社外に公開する資料では、確認の深さが違います。

<strong>AI事業者ガイドライン</strong>は、AIを扱う事業者向けの指針で、人間中心・安全性・公平性・プライバシー保護・セキュリティ確保・透明性・アカウンタビリティ・教育リテラシー・公正競争確保・イノベーションの10の共通指針が、キーワードに入っています。

中項目の名前だけを並べると、次のとおりです。

- 生成AI利用者の基本マインドセット（AIを使わない判断を含む）
- 生成AIの代表的リスク
- シャドーAIと企業コンプライアンス
- AI出力の評価と検証
- 個人情報・プライバシー・秘密保持（個人情報保護法、営業秘密）
- 著作権・知的財産・生成物の権利
- AI倫理とAI事業者ガイドライン（ELSI）
- AIガバナンスと社内ガイドライン
- AI法・国際ルール・AI安全保障（AI法、G7広島AIプロセス、EU AI Act）

旧版にあった、フィッシングやスミッシングなどの詐欺の種類の細かい分類は、新シラバスでは中心から外れました。

代わりに、法律・ガイドライン・社内ルールの項目が大きく増えています。<strong>丸暗記ではなく、「この場面で入力してよいか」を判断する力</strong>が問われる構成です。

増えた項目は、リテラシーとセキュリティの部分が多くを占めます。その土台にあるのが、<strong>生成AIに入力した情報は、サービスを提供する会社に送られている</strong>という意識です。

会社の機密にあたるデータを、承認されていないクラウドサービスに入れるのは避けるべきです。便利だからと何でも処理させると、入力した情報が学習に使われ、他の情報と結びついて出力されうることを、個人情報保護委員会も注意喚起しています。

実際に起きた事例は、[生成AIのリスクを実例で整理した記事](/trend/genai-risk-cases-explained/)にまとめています。

最後の第5章は、旧版からの変化が比較的おだやかです。

> [!think]
> 増えた項目で多いのはリテラシーとセキュリティの部分。2026年は漏えいが多くAIツールによる攻撃も対象になっているが、生成AIを利用するうえで「相手の会社にデータを送っている」ことを念頭にしなければならない。特に会社の機密にあたるデータをクラウドサービスで使うのは言語道断だし、便利だからとなんでも処理させると、後から学習された自社データがよそから参照されるなんてケースもある。

## 第5章：プロンプトから「業務別の活用」へ

第5章は、プロンプトの基本（Zero-Shot、Few-Shot、Chain-of-Thought）を残したうえで、活用の場面ごとに分かれました。

文書作成、企画・マーケティング、クリエイティブ制作、データ分析、開発・業務自動化、業種別の活用の6つです。

旧版では、文章の校正・要約・翻訳など、個別のタスクがキーワードとして並んでいました。新シラバスは、それらを「文書作成・コミュニケーション業務での活用」にまとめています。

各場面で、リスクと確認の観点が加わった点が新しいところです。

ここまでで、章ごとの変化が分かりました。旧版の教材をどう使うか、まとめて判断してみます。

## 旧版の教材は、どこまで使えるか

当サイトの見立てを、表にまとめます。キーワードの増減と、学習項目の有無から判断したもので、公式の見解ではありません。

| 章 | 旧版の教材での対応 | 補うもの |
| --- | --- | --- |
| 第1章 | ほぼ使える | ニューラルネットワークの学習の仕組み、識別系AIと生成系AI |
| 第2章 | 土台は使える | 学習の3段階、トークン化と生成パラメータ、オンプレ・OSS LLM |
| 第3章 | <strong>ほぼ使えない</strong> | 章ごと新しく学ぶ（エージェント、RAGの発展形、MCP、リスク） |
| 第4章 | <strong>大きく不足</strong> | シャドーAI、検証レベル、個人情報・著作権、ガバナンス、AI法 |
| 第5章 | 半分は使える | 業務別の活用と、場面ごとのリスク・確認の観点 |

旧版の問題集も同じで、第3章・第4章に当たる問題は、新シラバスの範囲を十分に扱えていない可能性があります。

また、<strong>法律・ガイドラインに関する項目は、改訂が早い</strong>ので、教材の発行時期を必ず確認してください。

では、教材は何を選べばよいのでしょうか。

## 公式テキストは、受験月で選ぶ

公式テキストは、受験する月で選ぶ形です。

| 受験月 | 選ぶテキスト |
| --- | --- |
| 2026年10月試験 | 現行版（第4版） |
| 2027年2月試験以降 | 改訂版『AXリテラシー教科書 生成AIパスポート 公式テキスト 2027年試験シラバス対応』 |

改訂版は、翔泳社から発行され、価格は2,090円（税込）です。予約販売は2026年10月1日に始まり、<strong>発送は2026年11月24日から</strong>順次です。

現行版と改訂版の交換・返品はできません。また、受験申込時のセット購入もできなくなり、別途購入する形です。

改訂版が届くのは11月24日以降なので、それまでの期間は、シラバスのPDF（公式サイトで無料公開）を使って学習を始められます。

最後に、旧版の教材とシラバスの差を、AIで確認する方法を紹介します。

## 手元の教材の抜けを、AIで見つける

シラバスのPDFと、自分の教材の目次を使えば、足りない項目をAIに洗い出してもらえます。

NotebookLMなどに、公式のシラバスPDFを資料として入れて、次のように聞いてみてください。

```text
このPDFは、生成AIパスポートの2027年2月試験から適用されるシラバスです。

私は、旧シラバスの教材（目次を下に貼ります）で勉強しています。

1. 新シラバスの**第3章と第4章**の中項目それぞれについて、私の目次に対応する項目があるかを表にしてください
2. 対応がない中項目は、**学習目標**を、初学者向けのやさしい言葉で説明してください
3. 私が先に学ぶべき中項目を、3つだけ選び、理由を添えてください

【私の教材の目次】
（ここに目次を貼る）
```

AIの答えは、必ずシラバスの本文と照らし合わせてください。AIは、表の対応を取り違えることがあります。

## まとめ

冒頭の疑問に戻ります。旧版の教材で学び始めた人の学び直しは、<strong>第3章のAIエージェントと、第4章のリスク・倫理・ガバナンス</strong>に集中します。

整理すると、次のようになります。

- 新シラバスは2027年2月試験から。旧シラバスは2026年10月試験までで、その申込はすでに締め切られている
- 章は5つのまま。キーワード欄の語は旧237語から新512語に増え、第4章が約4割を占める
- 旧版の第1〜2章は土台として使える。第3章はほぼ新規、第4章は大きく増えた
- 公式テキストは、2027年2月以降に受けるなら改訂版（11月24日から発送）
