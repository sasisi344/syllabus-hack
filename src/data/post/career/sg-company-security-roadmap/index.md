「うちの会社で、セキュリティのことを本当にわかっている人は誰だろう」と考えたとき、すぐに名前が浮かぶでしょうか。

2026年9月前後には、大きな情報漏えいのニュースが続きました。利用者の多いサービスで不正アクセスの公表が相次ぎ、IT企業に限らず、多くの会社が「自社は大丈夫か」と考え始めています。

ただ、分かれ目は高価なセキュリティ製品を入れることではありません。<strong>ソフトウェアを最新に保つといった基本の運用を、当たり前に回せる人が社内にいるかどうか</strong>です。

この記事では、最近の情報漏えいから見える課題を整理したうえで、そうした人材を育てるために、情報セキュリティマネジメント試験（SG）の取得を会社が補助すべき理由と、その進め方を紹介します。経営層の方にも、経営層に提案したい担当者の方にも読んでいただける内容です。

## 2026年9月の情報漏えいから見える課題

2026年9月前後に公表された情報漏えいの中には、原因として次のようなものが挙げられた事案がありました。

- VPNの脆弱性を突いた侵入
- 修正プログラムを適用する前に、ツールの脆弱性を突かれた不正アクセス
- Webシステムの一部にあった脆弱性を起点にした侵入

（出典：[【号外】【2026年9月】相次ぐ不正アクセス・情報漏えい まとめ16選｜サイバーセキュリティラボ](https://www.gate02.ne.jp/lab/security-article/incident-news-summary-202609-extra-edition/)。原因は各社の公表時点のもので、続報で変わることがあります）

どれも、高度で特殊な攻撃というより、<strong>知られている弱点が、修正される前に突かれた</strong>という点で共通しています。

### 基本の運用を回し続けるのは、人の仕事

ソフトウェアの更新や修正プログラムの適用は、セキュリティの基本中の基本です。それでも抜けが起きるのは、多くの会社で、次のような事情があるからです。

- セキュリティを専門に見る人が足りず、ほかの仕事と兼務している
- どのサーバーやツールが、どの版で動いているかを把握しきれていない
- 「今は動いているから」と、更新が後回しになる

セキュリティをいかに強固にするかも大事ですが、その前に、<strong>システムの裏側を最新の状態に保つという意識</strong>が欠かせません。そして、その意識を持って運用を回すのは、結局は人です。

では、その人材をどう育てればいいのでしょうか。

## SGは、セキュリティを学ぶ入口として取り組みやすい

情報セキュリティマネジメント試験（SG）は、IPAが実施する国家試験です。ITの専門職ではなく、ITを使う側の部門で情報セキュリティを管理する人を対象にしています。

IPAの試験の中では、比較的取りやすい試験です。技術者向けの基本情報技術者などと比べると、プログラミングの知識は問われず、組織として情報を守るための考え方が中心になります。

| SGで学ぶこと | 会社の運用とのつながり |
| --- | --- |
| 脅威と脆弱性 | どんな弱点が、どう狙われるのかがわかる |
| 脆弱性管理（OSの更新、修正プログラムの適用など） | 更新を後回しにする危うさを理解できる |
| リスクマネジメント | 守るべき情報と、対策の優先順位を決められる |
| インシデント対応 | 事故が起きたときの初動を知っている |
| 委託先の管理、関連する法律 | 取引先やクラウドサービスに情報を預けるときの注意がわかる |

### 合格しなくても、学ぶ過程に価値がある

セキュリティやITに興味がない社員にとって、SGの勉強は楽しいものではないかもしれません。用語も多く、正直に言えば苦痛に感じる人もいるでしょう。

それでも、会社にとって大事なのは、合格という結果だけではありません。<strong>勉強の過程で、セキュリティの知識に一度触れたこと</strong>そのものに価値があります。

「修正プログラムは、なぜすぐに当てる必要があるのか」「不審なメールは、なぜ開いてはいけないのか」。理由を一度学んだ社員は、日々の行動が変わります。たとえ不合格でも、その知識は社内に残ります。

では、会社としてどう後押しすればいいのでしょうか。

## 会社がSGの取得を補助すべき理由

社員が自分のお金と時間で勉強するのを待っているだけでは、学ぶ人は増えません。会社が補助を出し、リスキリングを積極的に促すことで、はじめて社内にセキュリティを理解する人が増えていきます。

| 補助の例 | ねらい |
| --- | --- |
| 受験料の補助 | 受けてみようと思う人を増やす |
| テキスト代や学習サービスの費用の補助 | 勉強を始めるハードルを下げる |
| 勤務時間の一部を学習に充てる | 忙しい部署の人も学べるようにする |
| 合格時の報奨金や資格手当 | 学んだことを評価し、続ける動機をつくる |

受験料の補助は、合格・不合格にかかわらず出すのがおすすめです。合格したときだけ補助する形にすると、受ける前から尻込みする人が増えます。学ぶ過程に価値があると考えるなら、受けてみること自体を後押しします。

情報漏えいが起きたときの損失は、顧客への対応、システムの調査と復旧、会社の信用の低下と、受験料の補助とは比べものにならない大きさになります。社員の学びに投資することは、会社の将来を守る投資です。

### 社内での進め方

| 段階 | 対象 | やること |
| --- | --- | --- |
| 最初の半年 | 情報システム担当・総務 | まず旗振り役が取得し、社内の更新状況やルールを見直す |
| 次の1年 | 各部署の管理職 | 部署ごとの情報管理を、自分ごととして考えられる人を増やす |
| その後 | 希望する全社員 | 受験料の補助を全社員に広げ、勉強会や社内研修に組み込む |

旗振り役がSGで学んだことをもとに、「社内のソフトウェアは、どれも最新の状態か」を一度棚卸しするだけでも、目に見える成果になります。

## 経営層に提案するときの伝え方

担当者の立場から、経営層に補助を提案する場合は、生成AIで提案の骨子をまとめると話が通りやすくなります。

```text
社員の情報セキュリティマネジメント試験（SG）の取得を、会社として補助する提案をしたいです。

- 会社の規模と業種：**〇〇**
- 今の課題：**ソフトウェアの更新状況を把握できている人がいない**
- 提案したい補助：**受験料とテキスト代の補助、合否にかかわらず**

経営層向けに、
1. 最近の情報漏えいの傾向から見た、自社のリスク
2. 補助にかかる費用と、事故が起きた場合の損失の比べ方
3. 最初の半年で出せる、目に見える成果
を、A4で1枚にまとめられる形で整理してください。
```

AIがまとめた内容は、自社の実情に合わせて書き直してください。費用の数字や試験の条件は、IPAの公式サイトなどで確かめましょう。

## まとめ

2026年9月前後の情報漏えいでは、知られている弱点が、修正される前に突かれた事案がありました。強固な対策の前に、ソフトウェアを最新に保つという基本の運用を回せる人が要ります。

- SGは、IPAの試験の中では比較的取りやすく、組織として情報を守る考え方を学べる
- 合格しなくても、セキュリティの知識を学んだ過程に価値がある
- 会社が受験料などを補助し、合否にかかわらず学ぶことを後押しする
- 旗振り役から始め、管理職、全社員へと広げる

これで、SGの取得を補助することが、なぜ会社の将来にとって強みになるのかを、経営層に説明できるはずです。

SGの試験内容と学び方は、[情報セキュリティマネジメント試験（SG） 合格ロードマップ](/method/sg-hub/)にまとめています。バックオフィスの社員が社内で教える側に回る道筋は、[バックオフィス職がSGで年収を上げる道筋](/career/backoffice-sg-career-hack/)も参考にしてください。
