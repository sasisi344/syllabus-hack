仕事のあとに確保できるのは1日60分くらい。

その時間で、どの資格なら取れるのかを知りたいのではないだろうか。

ただ「1日60分」だけでは答えが出ない。

<strong>分かれ目は、何ヶ月で合格したいかという期間</strong>だ。

この記事では、3ヶ月・6ヶ月・1年の3つの期間に分けて人気資格を並べる。

読み終えたときに、自分の期間で届く資格と、その次に狙う資格を判断できるようにする。

## 1日60分は期間で何時間になるか

まず、1日60分を期間ごとの合計時間に直しておく。

| 期間 | 合計の勉強時間（目安） |
| :--- | :--- |
| 3ヶ月 | 約90時間 |
| 6ヶ月 | 約180時間 |
| 1年 | 約365時間 |

資格の難しさは、合格までに必要とされる勉強時間（標準学習時間）で比べられる。

この合計時間と標準学習時間を並べると、どの期間でどの資格に届くかが見えてくる。

では、人気資格の標準学習時間はどのくらいなのだろうか。

## 期間ごとに届く資格の早見表

初学者が1日60分を続けた場合の目安だ。

FPと簿記は、3級と2級で必要な時間が大きく違うため分けて並べている。

| 資格名 | 標準学習時間 | 3ヶ月（約90h） | 6ヶ月（約180h） | 1年（約365h） |
| :--- | :--- | :--- | :--- | :--- |
| FP3級 | 80〜150時間 | 届く | 余裕あり | 余裕あり |
| 簿記3級 | 100〜150時間 | ぎりぎり | 届く | 余裕あり |
| FP2級 | 3級取得後100〜150時間 | 3級取得後ならぎりぎり | 届く | 余裕あり |
| 簿記2級 | 300〜500時間 | 届かない | 届かない | 下限に届く |
| 宅建 | 300〜400時間 | 届かない | 届かない | 足りないとされる |
| 行政書士 | 600〜1,000時間 | 届かない | 届かない | 届かない |
| 社労士 | 800〜1,000時間 | 届かない | 届かない | 届かない |

1日60分で現実的に狙えるのは、<strong>FPと簿記の3級・2級</strong>になる。

3ヶ月なら3級、6ヶ月ならFP2級まで、1年あれば簿記2級が射程に入る。

宅建・行政書士・社労士は、1年続けても時間が足りないとされる資格だ。

ただし、これは「ゼロから学ぶ人」の目安にすぎない。

すでに持っている教養や仕事の経験によって、必要な時間は変わってくる。

## FPと簿記は3級と2級で考える

FPと簿記は、3級から2級へ段階的に進めるのが無理のないルートだ。

3級で全体の地図をつかんでおくと、2級の学習時間を短くできる。

### FP3級・FP2級（ファイナンシャル・プランナー）

FPは、保険・金融・税金・ライフプランなど、個人のお金に関する知識を問う資格だ。

3級は3ヶ月で届く範囲にある。

FP3級を取ったあとなら、2級も3ヶ月〜6ヶ月で手が届く。

初学者がいきなり2級を狙うと、計算問題や税制の仕組みでつまずきやすい。

<strong>FPの強みは、取得後すぐに生活で使える知識が多いこと</strong>だ。

保険の見直し、住宅ローンの比較、税制の基本などがそのまま役立つ。

### 簿記3級・簿記2級

簿記は、会社のお金の動きを記録するルール（仕訳）を学ぶ資格だ。

3級は100〜150時間なので、3ヶ月だとぎりぎり、6ヶ月あれば届く。

2級は工業簿記や連結会計が加わり、300〜500時間が必要とされる。

1日60分なら、<strong>3級から始めて1年かけて2級まで進む</strong>のが現実的な計画になる。

レジ締めや経理の経験がある人、確定申告をしたことがある人は入りやすい。

CBT試験（ネット試験）なら自分の仕上がりに合わせて受験日を選べるのも、1日60分の学習と相性がいい。

では、1年でも足りないとされる資格は、最初から選ばないほうがいいのだろうか。

## 宅建・行政書士・社労士は1年でも足りないとされる

宅建は300〜400時間、行政書士は600〜1,000時間、社労士は800〜1,000時間が目安とされる。

1日60分を1年続けても365時間なので、宅建でも余裕はなく、行政書士・社労士は半分にも届かない。

一方で、<strong>もともとの教養や、その業種に近い仕事をしているかで可能性は変わる</strong>。

たとえば、不動産業界で働いている人なら、宅建業法の内容を仕事で目にしている。

人事・労務の担当者なら、社労士の労働基準法や社会保険の知識が日々の業務とつながっている。

法律の文章を読み慣れている人も、条文を読み解く時間を短くできる。

こうした下地がある人にとって、1日60分×1年の可能性はゼロではない。

下地がない場合は、1日2〜3時間を確保するか、2〜3年の計画で考えるほうが現実的だ。

## 期間より大事な勉強を始めるきっかけ

ここまで期間と時間で比べてきたが、資格選びはそれだけでは決まらない。

勉強を続ける原動力になるのは、次のような理由だ。

- 将来のキャリアを伸ばしたい
- 給料を上げたい
- 管理職になりたい
- シンプルに興味がある

中でも、<strong>きっかけになりやすいのは「必要だから」</strong>だ。

仕事で必要になった、生活で必要になったという場面は、学ぶ理由がはっきりしている。

だから、表で届く資格を選ぶよりも、学びたい興味が向いたときに始めるのがいちばんいい。

そのうえで、期間と時間の早見表を「どのくらいの計画になるか」の見積もりに使ってほしい。

## AIで1日60分の密度を上げる

1日60分の学習では、わからない箇所で止まっている時間がいちばんもったいない。

AIを家庭教師として使えば、その場で疑問を解消できる。

- 法律の条文を「具体例を使って説明して」と頼む
- 計算問題で詰まった箇所を「ステップごとに解説して」と頼む
- その日学んだ内容を自分の言葉で説明し、「理解の穴を指摘して」と頼む

<strong>苦手な概念をAIに言語化してもらい、自分の言葉で返す往復</strong>が理解を定着させる。

テキストを読んだだけで理解した気になるより、確かめながら進むほうが記憶に残る。

3ヶ月ならFP3級・簿記3級、6ヶ月ならFP2級まで、1年あれば簿記2級が射程に入る。

宅建・行政書士・社労士は1年でも足りないとされるが、近い仕事や教養があれば可能性はゼロではない。
