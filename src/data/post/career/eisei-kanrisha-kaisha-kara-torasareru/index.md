会社から「衛生管理者を取って」と言われても、受験だけなのか、合格後に仕事が増えるのかが分からないと、準備に入れません。

判断の分かれ目は、会社が必要としているのが「選任する後任」なのか「将来の資格保有者」なのかです。法律と社内制度を分け、受験前に確認する条件を整理します。

筆者は衛生管理者試験を受験していません。以下は公式情報をもとにした制度と確認項目の整理です。

## 会社から取らされる背景は、事業場の選任義務から確認する

衛生管理者は、常時50人以上の労働者を使用する事業場で選任が必要です。50〜200人なら1人、200人超〜500人なら2人が必要で、選任事由の発生から14日以内の選任と、遅滞ない届出が求められます（2026年10月時点）。[厚生労働省の選任要件](https://anzeninfo.mhlw.go.jp/yougo/yougo33_1.html)

人数を見る単位は会社全体ではなく<strong>事業場</strong>です。会社全体の従業員数だけで、自分の勤務先に選任義務があると判断しないでください。

ただし、事業者の選任義務から「あなた個人が必ず試験を受ける義務がある」とは言えません。後任の確保、複数人の育成、社内の昇格要件など、指名の理由は人事に確認する必要があります。

取得指示だけで管理職候補と評価されたとも断定できません。次は、何の免許が必要かを確かめます。

## 第一種か第二種かは、選任先の業種で決める

製造業・建設業・運送業・医療業・清掃業などでは、第二種衛生管理者免許だけでは選任できません。それら以外の業種では第二種も選任資格に含まれます（2026年10月時点）。[厚生労働省の業種別一覧](https://anzeninfo.mhlw.go.jp/yougo/yougo33_1.html)

| 会社への確認で分かった条件 | 次に決めること |
| --- | --- |
| 製造業など、第二種では選任できない事業場の後任 | 第一種等の必要な免許区分を確認する |
| 第二種で選任できる事業場の後任 | 第二種で足りるか、会社が第一種を求めるかを確認する |
| 将来の異動先が決まっていない | 想定する配属先と必要区分を人事に聞く |
| 資格保有だけが目的 | 選任予定の有無と、保有者として求められる役割を聞く |

「第一種のほうが上だから」という理由だけで決めると、会社の指示と申込区分が食い違うことがあります。申込前に区分を文面で確認しましょう。

## 受験資格の証明と、選任後の仕事を先に確かめる

受験資格には学歴に応じた労働衛生の実務経験などの要件があり、事業者証明書が必要になる場合があります。勤続年数だけで自己判断せず、該当する要件と担当してきた業務を照合してください。[安全衛生技術試験協会の衛生管理者試験案内](https://www.exam.or.jp/introduction/h_shokai502/)

資格を取った後に選任される場合、少なくとも毎週1回の作業場巡視などの職務があります。名義だけを置く仕事として引き受けるのではなく、通常業務との配分を確認する必要があります。[厚生労働省の職務説明](https://anzeninfo.mhlw.go.jp/yougo/yougo33_1.html)

上司には次のように尋ねると、試験と仕事の条件を分けて話せます。

- 「取得の目的は欠員補充ですか。いつからどの事業場で選任する予定ですか」
- 「受験資格の実務経験は、どの業務を誰が証明しますか」
- 「受験料・教材費・交通費・再受験費用は、どこまで会社負担ですか」
- 「受験日と勉強時間の扱い、合格後の巡視時間と手当は、どの規程にありますか」

返答が曖昧なら、先に自費で申し込まず、社内申請の承認を待つほうが条件を整理できます。

## 断りたいときは、引き受けられない条件を具体化する

断れるかは、労働契約、就業規則、指示の内容や事情によって変わります。この記事では個別の業務命令の有効性を判断できません。

| 困っている条件 | 相談の焦点 |
| --- | --- |
| 受験資格を満たしていない可能性がある | 経験の証明を確認し、受験時期の変更を相談する |
| 仕事と家庭の事情で期限に間に合わない | 学習時間の確保、期限の延長、別の候補者を相談する |
| 選任後の仕事を通常業務に上乗せされる | 職務分担と巡視の時間を調整する |
| 費用負担や指示の妥当性で合意できない | 規程と指示の記録を持って外部窓口に相談する |

社内で解決しない労働条件の疑問は、厚生労働省の[総合労働相談コーナー](https://www.mhlw.go.jp/general/seido/chihou/kaiketu/soudan.html)で相談先を確認できます。

## まとめ

衛生管理者を会社から取らされるときは、選任先・必要な免許・受験資格・費用と時間・選任後の仕事を確認してください。

会社の選任義務と自分への指示の条件を分ければ、「取得するか」だけでなく、「どの条件を調整してから受験するか」を具体的に相談できます。
