銀行から年金アドバイザー3級を勧められたとき、「昇格に必須なのか」「FPを先に取るほうがよいのか」で迷うことがあります。

判断する軸は、資格の知名度よりも、勤務先の規程と今の担当業務です。この記事では、受験前に確認する条件と、試験範囲がどの仕事につながるかを整理します。

筆者は年金アドバイザー試験を受験していません。試験形式は公式案内に基づき、社内制度については確認のための観点を示しています。

## 年金アドバイザー3級は銀行員共通の昇格要件ではない

銀行業務検定の合格と、自分の銀行での昇格認定は別です。試験団体の案内だけでは、勤務先が必須・推奨・加点のどれに位置づけているかは分かりません。

社内の資格一覧に名前があっても、「昇格の応募条件」なのか「研修の推奨資格」なのかで優先度は変わります。次の4点を人事・研修担当に確認してください。

| 確認項目 | 必要性の判断に使う理由 |
| --- | --- |
| 必須・加点・推奨のどれか | 未取得だと応募できないのか、他の実績で補えるのかが違う |
| 何級以上が対象か | 4級の取得では3級の要件を満たさない可能性がある |
| 合格・証明書提出の期限 | 受験日が間に合っても社内申請に間に合わないことがある |
| CBTと全国一斉試験の社内での扱い | 試験名・方式・結果の提出方法を取り違えないため |

「銀行員なら取るもの」と考える前に、この表の空欄を埋めると、今期に受ける理由が明確になります。

## 試験範囲は、年金相談のどの場面につながるか

CBT年金アドバイザー3級は、基本知識30問と、技能・応用10事例20問で構成されます。社会保険制度、年金の給付や支給要件、企業年金・個人年金、裁定請求等の手続きが出題範囲に含まれます（2026年10月時点）。[試験実施団体のCBT案内](https://www.kenteishiken.gr.jp/upfiles/pdf/4961.pdf)

学習と業務のつながりは、次のように考えると具体的です。以下は業務を整理するための例で、個別の顧客に支給額を確定する手順ではありません。

| 学ぶ範囲 | 窓口・渉外での確認場面の例 | 学習後にも確認が必要なもの |
| --- | --- | --- |
| 公的年金の仕組み | 顧客の加入歴や相談したい給付を整理する | 本人の記録と最新の制度 |
| 支給要件 | 老齢・障害・遺族のどの相談かを切り分ける | 個別の支給可否に関する公的窓口の判断 |
| 企業年金・個人年金 | 公的年金と別の制度を混同しないよう説明する | 加入先の規約や契約 |
| 請求等の手続き | 書類や相談先を確認する | 日本年金機構等が示す最新の手続き |

試験合格は個別相談の結論を保証しません。顧客に説明する内容は、勤務先の業務手順と[日本年金機構の公式案内](https://www.nenkin.go.jp/)で確認する必要があります。

## 年金アドバイザー3級とFP、どちらを先にするか

FPはライフプランニング、金融資産運用、不動産、相続なども扱うため、年金に対象を絞った検定とは学習目的が異なります。[日本FP協会の試験範囲](https://www.jafp.or.jp/exam/)

| 自分の条件 | 先にすること |
| --- | --- |
| 3級が今期の昇格応募の必須要件 | 社内期限に合わせて3級の受験を組む |
| 指定資格はなく、年金相談の基礎を整理したい | 年金アドバイザー3級の範囲を確認する |
| 税・不動産・保険も含めた相談力を広げたい | FPの範囲と勤務先の推奨級を確認する |
| すでにFPを持っている | 年金分野の事例問題を確認し、不足と社内評価から追加取得を決める |

社内要件があるなら、それを優先します。要件がないなら、現在の担当で答えに困る相談が年金に集中しているかが判断材料です。FP全体の取得ルートは[FPの学習ガイド](/method/fp-hub/)で確認できます。

## CBTで受けるなら、形式と社内提出日から逆算する

2026年10月時点のCBT個人申込案内では、受験資格は制限なし、五答択一式50問・120分、合格基準は100点満点中60点以上です。試験終了後に即時判定され、合格証書は翌日以降にマイページからダウンロードする案内です。[受験運営会社の公式ページ](https://cbt-s.com/examinee/examination/khk-nenkin03.html)

全国一斉試験とCBTでは、申込窓口や日程、試験時間等の案内を混ぜないようにしてください。上記はCBTの説明です。受験料や予約可能日は、受ける方式の現行案内で確認します。

学習を始める前に、次の3つをそろえます。

- 受ける方式に対応した公式の出題範囲と、適用法令の案内
- 受験時点に対応する教材と、改正・訂正情報
- 社内の合格証提出期限と、再受験を検討できる日程の余裕

必要時間は、銀行勤務という属性だけでは決まりません。まず教材の基本知識と事例問題を解き、誤答を「制度の区別」「条件の読み落とし」「計算」に分けてから計画を立てましょう。

## まとめ

年金アドバイザー3級を銀行員が優先するかは、社内の昇格要件と、担当する相談の範囲で決まります。

まず資格規程の必須・加点・推奨を確認し、必要級・試験方式・提出期限をそろえてください。規程上の必須でなければ、年金に絞るかFPで範囲を広げるかを、現在の業務から選べます。
