資格試験の勉強用に、スマホアプリや問題集を探していて、「もう少しこうだったら使いやすいのに」と感じたことはないでしょうか。

ITパスポートなどのIPAの試験や、書店で見かける合格テキストには、スマホで使えるアプリ版もあります。けれど、出題の順番や画面の見やすさ、解く時間の長さが、自分の生活に合うとは限りません。

そこで選択肢になるのが、<strong>AIと会話しながら、自分で使うアプリを自分で作る</strong>ことです。

ただし、分かれ目はアプリのコードをAIに書いてもらうことではありません。<strong>作ったアプリを、実際に動く状態まで持っていけるかどうか</strong>です。

この記事では、バイブコーディングで資格試験の問題集アプリを作る手順と、動かすまでにぶつかる壁、そしてその経験をポートフォリオとして残す方法を紹介します。

## バイブコーディングとは

バイブコーディング（Vibe Coding）は、コードを自分で一行ずつ書くのではなく、AIに「こんなものを作りたい」と言葉で伝え、AIが書いたコードを動かしながら完成に近づけていく作り方です。

プログラミングの経験がなくても、作りたいものを言葉で説明できれば、始めることができます。資格試験の勉強に使うなら、たとえば次のようなものが作れます。

| 作れるものの例 | 内容 |
| --- | --- |
| 問題集アプリ | 自分で集めた問題を、ランダムに出題して正誤を記録する |
| CBT形式の演習アプリ | 制限時間つきで解き、見直しの印をつけ、最後に採点する |
| 用語カード | 覚えたい用語をめくって確かめ、覚えていないものを繰り返す |
| 学習記録 | 毎日の勉強時間や正答率を記録し、グラフで見る |

### 市販のアプリを買うより、自分の生活に合わせられる

自分で作る良さは、自分の生活に合わせて形を決められることです。

- 通勤の5分で解けるように、1回3問だけ出す
- 間違えた問題だけを、翌日にもう一度出す
- 夜は画面を暗くして、文字を大きくする

市販のアプリでは変えられない細かいところまで、自分で決められます。

では、実際にどう作っていけばいいのでしょうか。

## 問題集アプリを作る手順

### 作りたいものを、言葉で決める

いきなりAIに「アプリを作って」と頼むと、思ったものとは違うものができがちです。まず、次のことを自分で決めて書き出します。

- 誰が、いつ、どこで使うか（例：自分が、通勤中に、スマホで）
- どんな機能があればいいか（例：ランダム出題、正誤の記録、間違えた問題の復習）
- どこにデータを保存するか（例：スマホのブラウザの中）

### 問題のデータを用意する

アプリの中身になる問題は、自分で用意します。

- 自分で作った問題や、勉強中にまとめた用語
- 試験を実施する団体が公開しているシラバスの用語

市販のテキストや問題集の問題を、そのままアプリに入れて人に配ったり公開したりすることはできません。公開されている過去問題を使う場合も、実施団体のサイトで利用の条件を確かめてください。自分の勉強のためだけに使う場合でも、出典はメモしておきましょう。

### AIに頼んで、少しずつ作る

作りたいものが決まったら、AIに伝えます。ChatGPTやClaude、Geminiのチャットでも、AIを組み込んだコードエディターでもかまいません。

```text
資格試験の勉強に使う、問題集のWebアプリを作りたいです。
私はプログラミングの経験がありません。

- 使う場面：通勤中に、スマホのブラウザで使う
- 機能：
  1. 問題をランダムに**1回3問**出す
  2. 選択肢を選ぶと、正誤と解説を表示する
  3. 間違えた問題を記録し、次回は優先して出す
- 問題のデータは、別のファイル（JSON）にまとめて、あとから追加できるようにしたい

まずは、**1つのHTMLファイルで動く最小の形**で作ってください。
動かし方も、初心者にわかるように手順で説明してください。
```

最初から全部の機能を入れようとせず、「動く最小の形」から始めるのがポイントです。動いたら、機能を1つずつ足していきます。

## 実際に動かすのは、思ったより難しい

生成AIを使えば、アプリは簡単に作れると思われがちです。確かに、コードはすぐに出てきます。けれど、それを実際に動かし、毎日使える状態にするのは、思っていたよりずっと難しいものです。

作ってみると、たとえば次のような壁にぶつかります。

| ぶつかりやすい壁 | 例 |
| --- | --- |
| 動かし方がわからない | ファイルをどこに置き、どう開けばいいのかわからない |
| エラーが出る | 画面が真っ白になる。エラーの文章の意味がわからない |
| データが消える | ブラウザを閉じたら、記録が消えてしまう |
| スマホで崩れる | PCではきれいなのに、スマホでは文字がはみ出す |
| 公開できない | 自分のPCでしか動かず、スマホから開けない |

1つ作ってみると、「AIがコードを書いてくれること」と「アプリが完成すること」の間に、大きな距離があることがわかります。

### 壁は、AIに聞きながら越える

壁にぶつかったら、その状況をそのままAIに伝えます。

```text
さきほどの問題集アプリを動かしたところ、次のようになりました。
- やったこと：**HTMLファイルをダブルクリックして開いた**
- 起きたこと：**画面が真っ白で、何も表示されない**
- ブラウザの開発者ツールに出ていたエラー：（エラーの文章を貼る）

原因として考えられることと、確かめる手順を、1つずつ教えてください。
```

何をして、何が起きて、どんなエラーが出たか。この3つを伝える習慣がつくと、AIからの答えの精度が上がります。

## 作った経験は、PCの困りごとを解決する力になる

アプリを1つ動かすまでの間に、ファイルの置き場所、ブラウザの仕組み、エラーの読み方、データの保存のされ方といった、PCの基本に何度も向き合うことになります。

その経験は、アプリ作りだけに役立つものではありません。仕事でPCやツールのトラブルに出会ったときにも、「何をして、何が起きたか」を整理し、AIに聞きながら自分で解決する力になります。エンジニアではない人にとって、この力は大きな強みです。

### ポートフォリオとして残す

作ったアプリは、ポートフォリオとして残しておきましょう。

- コードをGitHubなどに保存し、変更の履歴を残す
- 「何のために作ったか」「どんな機能があるか」「どこでつまずき、どう解決したか」を短い説明文にまとめる
- 公開できる形にしたら、画面の写真や、実際に使えるURLも添える

資格の合格証は「知識があること」を示しますが、自分で作って動かしたアプリは「知識を使って、形にできること」を示します。転職や社内の新しい仕事に手を挙げるとき、話せる実績になります。

### AIにポートフォリオの説明文を整えてもらう

```text
資格試験の勉強用に、自分で問題集アプリを作りました。
- 作った理由：**〇〇**
- 主な機能：**〇〇**
- つまずいたことと解決の仕方：**〇〇**

この内容をもとに、ポートフォリオに載せる300字程度の説明文を作ってください。
技術の名前を並べるより、何に困って、どう解決したかが伝わるようにしてください。
```

## まとめ

バイブコーディングを使えば、資格試験の問題集やCBT形式の演習アプリを、自分の生活に合わせて自分で作れます。

- 作りたいものを言葉で決め、問題のデータは自分で用意する。市販の教材の問題を勝手に使わない
- 「動く最小の形」から作り、機能を1つずつ足す
- 実際に動かすまでには壁がある。何をして、何が起きたかをAIに伝えて越える
- 作って動かした経験は、PCの困りごとをAIで解決する力になり、ポートフォリオとして残せる

これで、市販のアプリを探す代わりに、自分で使うアプリを自分で作り、その経験を将来の強みとして残す道筋が見えたはずです。
