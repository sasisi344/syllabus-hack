問題集を買う余裕がなくても、資格の勉強は始められます。

ITパスポートは、出題範囲を示す<strong>公式シラバス</strong>も、<strong>過去問</strong>も、IPAが無料で公開しています。この2つをNotebookLMに読み込ませれば、自分専用の問題集を無料で作れます。

さらに、作った問題を印刷して手書きで解く方法や、テキストファイルから出題アプリを作る方法まで進めれば、市販の問題集に近い練習ができます。

この記事では、その手順をITパスポートで試します。読み終えたときに、シラバスを読ませて問題集を作り、自分に合う形で解く方法を選べるようにします。

なお、NotebookLMは2026年7月に「Gemini Notebook」へ名称変更されました。同じサービスで、ノートブックの移行は不要です。この記事では「NotebookLM」と表記します。機能全体は、[NotebookLM資格試験活用ガイド](/method/notebooklm-features-guide/)にまとめています。

## ITパスポート以外の資格にも使える

この方法の土台は、「ITパスポート」ではなく、<strong>公式のシラバスを資料として読み込ませる</strong>ことです。

シラバスや出題範囲が公開されている試験なら、同じ手順で問題集を作れます。

| 試験 | 公開されている資料 |
| --- | --- |
| ITパスポート、基本情報技術者、応用情報技術者 | シラバス、過去問題（IPA） |
| 情報セキュリティマネジメント | シラバス、過去問題（IPA） |
| 民間の資格 | 公式サイトの出題範囲、サンプル問題（試験により異なる） |

この記事の手順は、ITパスポートの用語やプロンプトを使って説明します。他の資格では、シラバスと用語を、自分が受ける試験のものに置き換えてください。

## 合格までの勉強時間

ITパスポートの学習時間の目安は、前提知識によって次のように変わります。

| 学習前の状態 | 目安時間 |
|---|:---:|
| ITの経験がほぼない（未経験） | 50〜80時間 |
| 仕事でパソコンやシステムを日常的に使っている | 20〜40時間 |
| 基本情報技術者などの関連資格を持っている | 10〜20時間 |

（当サイトの[ITパスポート 合格ロードマップ](/method/itp-hub/)と同じ目安です。個人差があります）

### AI活用で専任講師を月額20ドルで雇う感覚

ITパスポートで多くの人が止まるのは、次の3か所です。

- ストラテジ系で、SWOT分析やROIなど、実務で見たことのない経営用語が「記号」にしか見えない
- テクノロジ系で、稼働率や2進数の計算の「なぜそうなるか」が分からない
- セキュリティ系で、攻撃名が似ていて区別がつかない

NotebookLMなら、分からない瞬間に、何度同じ質問をしても怒られません。<strong>深夜でも休憩の5分でも質問できる</strong>ので、専任の講師を月額20ドル程度で雇う感覚です。

ただし、勉強時間そのものが半分になるわけではありません。減らせるのは「詰まって止まる時間」です。

## 最初に用意するもの：ソース3点とノートブック分け

用意するソースは、次の3点です。

1. <strong>公式シラバス</strong>：IPAのサイトから最新版のPDFを入手する
2. <strong>過去問題</strong>：IPAが公開している過去問題のPDF（個人の学習用）
3. <strong>ミスノート</strong>：自分が間違えた問題と、その理由を書いたメモ（作り方は[ミスノートの記事](/method/miss-note-db/)）

参考書の全文をアップロードするのは、著作権上の問題があるため避けてください。使うなら、自分の言葉でまとめた要約やメモにします。

ITパスポートは、総合で600点以上に加えて、各分野で30%以上の得点が必要です。そのため、ノートブックを<strong>分野ごと</strong>に3つ作ると、苦手分野だけを集中して回せます。

| ノートブック | 入れるソース |
|---|---|
| ストラテジ系 | シラバスのストラテジ系部分、該当分野の過去問 |
| マネジメント系 | シラバスのマネジメント系部分、該当分野の過去問 |
| テクノロジ系 | シラバスのテクノロジ系部分、該当分野の過去問 |

PDFが読み込みにくいときは、[シラバスPDFを使いやすいテキストにする方法](/method/notebooklm-features-guide/)を使うと、読み込み精度が上がります。

## 用語を自分の仕事や生活に置き換える

問題を作る前に、<strong>用語を自分の言葉で理解すること</strong>から始めます。

ITパスポートは、実務経験のない用語ほど暗記が苦しくなります。まず、自分の属性を伝えます。

```text
私は**不動産営業をしている30代の社会人**です。
ITパスポートの勉強を始めたばかりで、IT知識はほぼゼロです。
以降の説明では、不動産営業の日常業務を例えに使ってください。
```

次に、苦手な用語を一つずつ翻訳してもらいます。

```text
シラバスにある「**CRM（顧客関係管理）**」を、
私の営業活動（問い合わせ対応・内見の記録・成約管理）に例えて説明してください。
**シラバスの定義から外れない範囲**で、具体例を2つ挙げてください。
```

経営の言葉は、自分の仕事に置き換えた瞬間に意味が通るものが多いです。

理解できたら、自分の言葉で説明して、AIに穴を指摘してもらいます。

```text
「**ファイアウォール**」と「**WAF**」の違いを、これから私が自分の言葉で説明します。
シラバスの記述と照らして、**間違っている点・抜けている点**だけを指摘してください。
正解の説明を先に出さず、私が直すまで待ってください。
```

## 自分専用の問題集を作る

ここから、問題集を作ります。ポイントは、問題を<strong>テキストの決まった形式</strong>で出力させることです。形式がそろっていれば、印刷にも、記入式にも、アプリ化にも使い回せます。

ノートブックを切り替えて、分野ごとに頼みます。

```text
このノートの資料をもとに、**マネジメント系**の4択問題を**10問**作ってください。
プロジェクト管理・サービスマネジメント・システム監査のうち、
**私が間違えた分野を中心に**してください。

出力は、次の形式にそろえてください。
## 問題番号
**問題文**
ア: 選択肢
イ: 選択肢
ウ: 選択肢
エ: 選択肢
**正解**: （ア〜エ）
**解説**: （根拠となるシラバスの該当箇所を示す）

問題と選択肢を先に10問分すべて出し、**正解と解説は最後にまとめて**表示してください。
```

計算問題を入れたいときは、条件を足します。

```text
**稼働率・2進数・確率**の計算問題を3問含めてください。
計算問題の解説には、**途中式を省かず**書いてください。
```

量を一気に求めるより、<strong>10問ずつ作って、毎回ミスノートに反映する</strong>ほうが身につきます。

### 生成AIの分野は、シラバスをもとに作らせる

シラバスの改訂で、ハルシネーションやプロンプト、生成AIと著作権のリスクといった用語が加わっています。新しい分野なので、市販のテキストの解説が少なく、独学ではつまずきやすいところです。

NotebookLMはシラバスをソースにしているので、生成AIの項目だけに絞って問題を作れます。

```text
このノートのシラバスにある、**生成AIに関わる用語**だけを使って、4択問題を**5問**作ってください。
用語の意味を問う問題を2問、
「この業務の場面では、どの使い方が適切か」を問う**ケース問題を3問**にしてください。
```

AIで作った問題は、本番の問題とは違います。IPAが公開している過去問やサンプル問題で、実際の問われ方も確かめてください。

## 作った問題集を、どう解くか

作った問題集は、3つの方法で解けます。自分の環境と好みで選んでください。

| 方法 | 向いている人 | 準備 |
| --- | --- | --- |
| 印刷して手書きで解く | 画面を見るだけだと覚えにくい人 | プリンターか、コンビニのプリント |
| テキストファイルに記入する | 印刷したくない人、パソコンで済ませたい人 | メモ帳やエディタ |
| 出題アプリにして解く | 繰り返し、ランダムに解きたい人 | ChatGPTなどにアプリを作ってもらう |

### 印刷して、手書きで解く

アウトプットとして、おすすめしたいのは<strong>印刷して手書きで答えを書く</strong>方法です。

画面で選択肢を眺めるだけよりも、手を動かして答えを書くほうが、「思い出す」作業になりやすくなります。画面で読んだら紙に書くと覚えやすい理由は、[スマホ・タブレット・PC、資格勉強はどれがいい？](/method/multi-device-cert-study/)でも整理しています。

手順はこうです。

1. 問題を「正解と解説なし」の形で、テキストに書き出す
2. 印刷して、答えを手書きする
3. 最後に、正解と解説を見ながら答え合わせをする
4. 間違えた問題を、ミスノートに書き写す

### テキストファイルに記入式で解く

印刷しない場合は、問題のテキストファイルに、自分の答えを直接書き込みます。

```text
## 問題3
**問題文**
（略）
**自分の答え**: イ
**そう考えた理由**: （略）
```

答えを書き込んだファイルを、ChatGPTなどに読み込ませれば、正誤の判定と、考え方の指摘もしてもらえます。

### テキストから、CBT風の出題アプリを作る

問題がテキストの決まった形式になっていれば、ChatGPTなどに頼んで、<strong>ブラウザで動く出題アプリ</strong>を作れます。

```text
添付のテキストファイルは、4択問題の一覧です。
このファイルを読み込み、ブラウザで開くだけで動く、1つのHTMLファイルを作ってください。

- 問題をランダムな順で1問ずつ表示する
- 選択肢を選ぶと、正解と解説を表示する
- 間違えた問題は、あとで再び出題する
- 最後に正答率を表示する
- 外部のライブラリは使わない
```

問題のファイルを差し替えれば、他の分野や他の資格にも使えます。アプリが作れるようになると、スクリプトで問題を出題することもできるようになります。

なお、AIが作ったアプリは、不具合があることがあります。動作を確かめてから使ってください。

## 間違えた問題から類題を作る

過去問や出題で間違えたら、その問題をミスノートに書き、類題を出してもらいます。

```text
ミスノートの「**稼働率の計算を間違えた**」という項目をもとに、
**同じ考え方で解ける類題**を3問作ってください。
数字と場面は変えてください。
最初の1問は、考え方のヒントを先に出してください。
```

間違えた選択肢まで掘り下げる方法は、[逆転学習法の記事](/method/miss-note-db/)も参考になります。

## ハルシネーション対策：AIの答えをそのまま信じない

NotebookLMは、資料の範囲内で答える設計ですが、<strong>間違いが混じる可能性はゼロではありません</strong>。試験勉強では、次の4点を習慣にしてください。

1. <strong>引用元を開いて確認する</strong>：解説に付く引用番号から、元の資料の該当箇所を見る
2. <strong>計算は自分で再計算する</strong>：稼働率や2進数は、AIの数字を信じずに検算する
3. <strong>怪しいときは公式の過去問と照合する</strong>：IPA公開の過去問と答えが合うか確かめる
4. <strong>資料にない内容は「推測」と考える</strong>：シラバスに載っていない説明が出たら、公式資料を確認する

AIが作る問題は、あくまで練習用です。<strong>本番の出題形式に慣れるためには、必ずIPA公開の過去問を、時間を計って解いてください</strong>。

## 1日の回し方

ひとつの流れにすると、次のようになります。

| 場面 | やること | 目安 |
|---|---|:---:|
| 通勤中 | 音声オーバービューで、苦手分野を聞き流す | 15分 |
| 机で | 用語を自分の仕事に置き換えて理解する | 20分 |
| 机で | 作った問題を10問、手書きか出題アプリで解く | 20分 |
| 仕上げ | 間違えた問題をミスノートに追記する | 5分 |

週に1回は、IPA公開の過去問を本番と同じ時間で解いて、足切りに当たる分野がないかを確認します。

## NotebookLMだけでは足りない部分

NotebookLMは強力ですが、次の点には別のツールを使います。

- <strong>本番形式の模擬試験</strong>：CBTの画面と時間配分に慣れるため、[ITパスポート模擬試験シミュレーター](/app/it-passport-quiz/)などを使う
- <strong>時間がないときの優先順位</strong>：試験直前は、[全力捨て問戦略](/method/ip-discard-strategy/)で、得点源を絞る
- <strong>全体像の把握</strong>：最初に20時間で全体をつかむなら、無料の[ITパスポート20時間コース](/course/ip/)が向いている

ChatGPTやGeminiを含めた全体の進め方は、[ITパスポートAI学習のガイド](/method/chatgpt-itpassport-ai-complete-guide/)にまとめています。

## よくある質問

<strong>Q: 問題集の自作は無料でできますか？</strong>

無料プランでも、ソースの読み込み・チャット・問題の作成が使えます。1科目分の学習なら、無料枠で回せます。上限は変わることがあるため、公式ヘルプで確認してください。

<strong>Q: 過去問のPDFをアップロードしても大丈夫ですか？</strong>

IPAが公開している過去問題を、個人の学習のために使う前提です。参考書の全文など、許諾のないものは避けてください。

<strong>Q: AIが作った問題の答えは信用できますか？</strong>

そのままは信用せず、引用元と公式の過去問で確認してください。計算問題は自分で検算します。

<strong>Q: ITパスポート以外の資格でも使えますか？</strong>

公式のシラバスや出題範囲が公開されている試験なら、同じ手順で使えます。

## まとめ

シラバスと過去問があれば、問題集を買わなくても、自分専用の問題集を無料で作れます。

1. 公式シラバス・IPA公開の過去問・ミスノートを、分野別のノートブックに入れる
2. 用語を自分の仕事や生活に置き換えて、理解する
3. 決まった形式のテキストで、問題集を作る
4. 印刷して手書きで解く、記入式にする、出題アプリにする、のどれかで解く
5. 間違いを類題で潰し、引用元と過去問で答えを確認する

今日できる最初の一歩は、IPAのシラバスPDFを入れたノートブックを1つ作り、苦手な分野の問題を10問、テキストで出してもらうことです。
