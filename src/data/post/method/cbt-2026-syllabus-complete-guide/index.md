応用情報技術者試験や高度試験を受けようと調べると、「CBT化」「前期・後期」「2027年度から新試験」と、変更の話がいくつも出てきて、結局いつ何が変わるのか混乱していないでしょうか。

変更は、大きく<strong>2段階</strong>に分かれています。ひとつは、令和8年度（2026年度）からすでに始まっているCBT化。もうひとつは、2027年度から予定されている試験制度そのものの見直しです。

この記事では、この2つを順に整理したうえで、令和8年度の試験を受けるか、2027年度の新しい試験を待つかの判断の考え方を説明します。

試験の情報は、IPA（情報処理推進機構）の公式サイトで更新されます。この記事は2026年10月時点の公表内容をもとにしています。受ける前に、必ず[IPAの試験情報のページ](https://www.ipa.go.jp/shiken/)で最新の情報を確認してください。

## 第1段階：令和8年度からCBT方式になった

令和8年度から、<strong>応用情報技術者試験、高度試験、情報処理安全確保支援士試験</strong>は、テストセンターのパソコンで受けるCBT方式で実施されています。これで、IPAの試験はすべてCBT方式になりました。

| 試験 | 方式 |
| --- | --- |
| ITパスポート試験 | CBT（随時） |
| 情報セキュリティマネジメント試験・基本情報技術者試験 | CBT（随時） |
| 応用情報技術者試験・高度試験・情報処理安全確保支援士試験 | 令和8年度からCBT（前期・後期の期間内に受ける） |

### 前期・後期の年2回、区分ごとに受けられる期が決まっている

これまでの春期・秋期は、<strong>前期・後期</strong>に整理されました。応用情報技術者試験と情報処理安全確保支援士試験は前期・後期の両方で、それ以外の高度試験は、区分によって前期か後期のどちらかで受けます。

| 期 | 主な時期（令和8年度） | 受けられる区分 |
| --- | --- | --- |
| 前期 | 2026年10月〜12月 | 応用情報、情報処理安全確保支援士、ITストラテジスト、システムアーキテクト、ネットワークスペシャリスト、ITサービスマネージャ |
| 後期 | 2027年2月〜3月 | 応用情報、情報処理安全確保支援士、プロジェクトマネージャ、データベーススペシャリスト、エンベデッドシステムスペシャリスト、システム監査技術者 |

申込期間や試験の期間の細かい日付は、[応用情報・高度試験CBTの申込日程と試験期間](/trend/ipa-2026-cbt-schedule-guide/) で区分ごとにまとめています。

### 科目Aと科目Bを、別の期間に受ける

CBT化にあわせて、科目の名前も変わりました。

| これまでの名前 | 令和8年度からの名前 |
| --- | --- |
| 午前I | 科目A-1 |
| 午前II | 科目A-2 |
| 午後I | 科目B-1 |
| 午後II | 科目B-2 |

これまでは1日で午前と午後を続けて受けていましたが、CBTでは<strong>科目A（A-1・A-2）と科目B（B-1・B-2）を、それぞれ決められた期間の中で別の日に</strong>受けます。1日に長時間の試験を受け続ける負担が分かれる一方で、2回テストセンターに行く予定を組む必要があります。

応用情報技術者試験に合格している人などが受けられた午前Iの免除は、科目A-1の免除として続いています。免除の条件は、申込の前に公式の案内で確認してください。

### 論文はキーボードで入力する

CBT化でいちばん影響が大きいのが、<strong>論文や記述をキーボードで入力する</strong>ようになったことです。プロジェクトマネージャ、ITストラテジストなどの論文試験では、2,000字を超える文章を、時間内にパソコンで書き上げる必要があります。

手書きと比べて、書き直しや段落の入れ替えがしやすくなった一方で、問題文に直接線を引いたりメモを書き込んだりできないなど、紙とは違う慣れが必要です。

日本語の入力に慣れていない人は、本番と同じ時間で、論文を通してキーボードで書く練習をしておきましょう。入力の練習の方法は [CBT試験のPC操作が不安な人へ](/method/typing-speed-cbt/) で扱っています。

## 第2段階：2027年度から新しい試験制度へ

IPAは、<strong>2027年度から新しい試験制度に移る予定</strong>としています。公表されている見直し案では、次のように変わります。

| いまの試験 | 2027年度からの予定 |
| --- | --- |
| ITパスポート試験・情報セキュリティマネジメント試験・基本情報技術者試験 | 続く |
| － | データマネジメント試験（仮称）を新設。ITパスポートの次のステップ |
| 応用情報技術者試験・高度試験（情報処理安全確保支援士試験を除く） | まとめ直して、プロフェッショナルデジタルスキル試験（仮称）へ。マネジメント・データ・AI・システムの3区分 |
| 情報処理安全確保支援士試験 | 一部を変更して続く |

つまり、いまの応用情報技術者試験と、情報処理安全確保支援士試験以外の高度試験は、<strong>令和8年度（2026年度）が現行の形で受けられる最後の年度</strong>になる予定です。

新しい試験の詳しい内容や日程は、今後IPAから順に公表されます。見直しの全体像は [2027年からのIPA試験再編まとめ](/trend/ipa-2027-restructuring/) でも扱っています。

### シラバスは「生成AI」を前提にした内容が増えている

現行の試験のシラバス（出題範囲）にも、生成AIの仕組みや、使うときのリスク、AIのセキュリティといった内容が加わってきています。新しい試験でも、データとAIを扱う力がより重く問われる見込みです。

古い参考書を使う場合は、シラバスの変更点を確かめ、追加された用語だけを別に学ぶと効率的です。変更点の確かめ方は [シラバス改訂差分から次回の出題を予測するハック](/method/syllabus-diff-hack/) で扱っています。

## 令和8年度に受けるか、2027年度の新試験を待つか

いちばん迷うのが、ここだと思います。目安は次のとおりです。

| 今の状況 | おすすめ |
| --- | --- |
| すでに勉強を進めていて、受けたい区分が令和8年度の前期・後期にある | 令和8年度に受ける。現行の試験の過去問がそのまま使える |
| 応用情報に合格して、高度試験を目指している | 令和8年度のうちに受けると、合格すれば現行の資格として残る。科目A-1の免除も使える |
| これから勉強を始める | いまの区分の知識は新しい試験の土台になるので、勉強は今から始めてよい。受ける時期は、新しい試験の公表を見て決める |

迷ったときの考え方はシンプルです。<strong>勉強した知識は、どちらの試験でも無駄になりません</strong>。新しい試験の範囲の多くは、いまの応用情報と高度試験の知識と重なっています。

新しい試験の内容は、公開されているシラバス案をもとにした無料のコースで先に確かめられます。

- [プロフェッショナルデジタルスキル（マネジメント）試験 20時間コース](/course/pd-m/)
- [プロフェッショナルデジタルスキル（システム）試験 20時間コース](/course/pd-s/)
- [データマネジメント試験 20時間コース](/course/dm/)

区分の選び方は [IPA資格の高難易度対策｜応用情報・高度試験と2027年の新試験の選び方](/method/advanced-ipa-hub/) で整理しています。

## よくある質問

<strong>Q: CBT化で過去問は使えなくなりましたか？</strong>

A: 方式が変わっても、問われる知識は変わりません。過去問は引き続き勉強に使えます。ただし、新しくシラバスに加わった用語は過去問に出てこないことがあるので、変更点は別に確かめてください。

<strong>Q: 論文試験はなくなりましたか？</strong>

A: なくなっていません。手書きからキーボード入力に変わっただけで、論文を書く力が問われる点は同じです。

<strong>Q: 2027年度の新しい試験の日程は決まっていますか？</strong>

A: 2026年10月時点では、IPAは「2027年度から新試験制度に移行予定」としています。詳しい日程や内容は、IPAの公式サイトで公表を確認してください。

## まとめ

IPAの試験の変更は、2段階で進んでいます。

- 令和8年度から、応用情報・高度試験・情報処理安全確保支援士試験はCBT方式。前期・後期に分かれ、科目Aと科目Bを別の期間に受ける。論文はキーボード入力
- 2027年度からは新しい試験制度へ移る予定。応用情報と多くの高度試験は、プロフェッショナルデジタルスキル試験にまとめ直される
- いまの試験に向けた勉強は、新しい試験の土台にもなる

これで、自分が令和8年度に受けるか、新しい試験を待つかを判断できるはずです。まずは受けたい区分が前期と後期のどちらにあるかを、上の表で確かめてみてください。
