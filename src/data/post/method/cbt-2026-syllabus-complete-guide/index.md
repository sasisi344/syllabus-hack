応用情報技術者試験や高度試験を受けようと調べると、「CBT化」「前期・後期」「2027年度から新試験」と、変更の話がいくつも出てきて、結局いつ何が変わるのか混乱していないでしょうか。

変更は、大きく<strong>2段階</strong>に分かれています。ひとつは、令和8年度（2026年度）からすでに始まっているCBT化。もうひとつは、2027年度から予定されている試験制度そのものの見直しです。

この記事では、この2つを順に整理したうえで、令和8年度の試験を受けるか、2027年度の新しい試験を待つかの判断の考え方を説明します。

試験の情報は、IPA（情報処理推進機構）の公式サイトで更新されます。この記事は2026年10月時点の公表内容をもとにしています。受ける前に、必ず[IPAの試験情報のページ](https://www.ipa.go.jp/shiken/)で最新の情報を確認してください。

## 第1段階：令和8年度からCBT方式になった

令和8年度から、<strong>応用情報技術者試験、高度試験、情報処理安全確保支援士試験</strong>は、テストセンターのパソコンで受けるCBT方式で実施されています。通常実施のCBTと、身体等の事情によりCBTで受験できない方向けの特別措置試験は区別してください。[IPAの令和8年度実施案内](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)

| 試験 | 方式 |
| --- | --- |
| ITパスポート試験 | CBT（随時） |
| 情報セキュリティマネジメント試験・基本情報技術者試験 | CBT（随時） |
| 応用情報技術者試験・高度試験・情報処理安全確保支援士試験 | 令和8年度からCBT（前期・後期の期間内に受ける） |

### 前期・後期の年2回、区分ごとに受けられる期が決まっている

これまでの春期・秋期は、<strong>前期・後期</strong>に整理されました。応用情報技術者試験と情報処理安全確保支援士試験は前期・後期の両方で、それ以外の高度試験は、区分によって前期か後期のどちらかで受けます。

| 期 | 主な時期（令和8年度） | 受けられる区分 |
| --- | --- | --- |
| 前期 | 2026年10月〜12月 | 応用情報、情報処理安全確保支援士、ITストラテジスト、システムアーキテクト、ネットワークスペシャリスト、ITサービスマネージャ |
| 後期 | 2027年2月〜3月 | 応用情報、情報処理安全確保支援士、プロジェクトマネージャ、データベーススペシャリスト、エンベデッドシステムスペシャリスト、システム監査技術者 |

上の期間と区分は、2026年10月時点の[IPAの前期・後期の公式日程](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)に基づきます。10月31日時点では、前期の高度試験・支援士の申込受付はすでに終了しています。これから申し込む人は、受けられる期だけでなく受付期限も確認してください。

申込期間や試験の期間の細かい日付は、[応用情報・高度試験CBTの申込日程と試験期間](/trend/ipa-2026-cbt-schedule-guide/) で区分ごとにまとめています。

### 科目Aと科目Bを、別の期間に受ける

CBT化にあわせて、科目の名前も変わりました。

| これまでの名前 | 令和8年度からの名前 |
| --- | --- |
| 応用情報の午前・午後 | 科目A・科目B |
| 高度・支援士の午前I | 科目A-1 |
| 午前II | 科目A-2 |
| 高度試験の午後I | 科目B-1 |
| 高度試験の午後II | 科目B-2 |
| 支援士の午後 | 科目B |

これまでは1日で午前と午後を続けて受けていましたが、CBTでは<strong>科目A（A-1・A-2）と科目B（B-1・B-2）を、それぞれ決められた期間の中で別の日に</strong>受けます。1日に長時間の試験を受け続ける負担が分かれる一方で、2回テストセンターに行く予定を組む必要があります。[IPAの科目別実施期間・科目名称](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)

応用情報技術者試験に合格している人などが受けられた午前Iの免除は、科目A-1の免除として続いています。免除の対象・有効な期間は、申込前に[IPAの一部免除の案内](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)で確認してください。

### 論文はキーボードで入力する

CBT化でいちばん影響が大きいのが、<strong>論文や記述をキーボードで入力する</strong>ようになったことです。プロジェクトマネージャ、ITストラテジストなどの論文試験では、試験時間内に文章を入力する練習が必要です。[IPAのCBT実施方式の説明](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)

手書きと比べて、書き直しや段落の入れ替えがしやすくなった一方で、問題文に直接線を引いたりメモを書き込んだりできないなど、紙とは違う慣れが必要です。画面上のメモ・電卓機能に加え、メモ用紙1枚と筆記用具の配布も案内されています。[IPAの2026年9月17日追記](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)

日本語の入力に慣れていない人は、本番と同じ時間で、論文を通してキーボードで書く練習をしておきましょう。入力の練習の方法は [CBT試験のPC操作が不安な人へ](/method/typing-speed-cbt/) で扱っています。

## 第2段階：2027年度から新しい試験制度へ

IPAは、<strong>2027年度から新しい試験制度に移る予定</strong>としています。公表されている見直し案では、次のように変わります。以下は2026年10月時点の予定で、実施条件の確定とは区別します。[IPAの見直し案](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

| いまの試験 | 2027年度からの予定 |
| --- | --- |
| ITパスポート試験・情報セキュリティマネジメント試験・基本情報技術者試験 | 続く。ただし出題構成・シラバス等に変更予定 |
| － | データマネジメント試験（仮称）を新設。ITパスポートの次のステップ |
| 応用情報技術者試験・高度試験（情報処理安全確保支援士試験を除く） | まとめ直して、プロフェッショナルデジタルスキル試験（仮称）へ。マネジメント／データ・AI／システムの3区分 |
| 情報処理安全確保支援士試験 | 一部を変更して続く |

つまり、いまの応用情報技術者試験と、情報処理安全確保支援士試験以外の高度試験は、<strong>令和8年度（2026年度）が現行の形で受けられる最後の年度</strong>になる予定です。

新しい試験の詳しい内容や日程は、今後IPAから順に公表されます。公表済みの内容は [IPA 試験制度の見直しについて](https://www.ipa.go.jp/shiken/minaoshi/index.html) にまとまっています。見直しの全体像は [2027年からのIPA試験再編まとめ](/trend/ipa-2027-restructuring/) でも扱っています。

### シラバスは「生成AI」を前提にした内容が増えている

現行の試験のシラバス（出題範囲）にも、生成AIの仕組みや、使うときのリスク、AIのセキュリティといった内容が加わってきています。新しい試験でも、データ・AIの利活用を扱う方向です。[IPAの見直しのポイント](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

古い参考書を使う場合は、シラバスの変更点を確かめ、追加された用語だけを別に学ぶと効率的です。変更点の確かめ方は [資格のシラバス更新を見逃さない仕組み作り](/method/syllabus-diff-hack/) で扱っています。

### 応用情報技術者試験のシラバス最新版は、受験年度で分ける

「応用情報 シラバス 最新」を探すときは、現行の応用情報技術者試験と2027年度の再編案を混ぜないことが大切です。2026年度の応用情報はVer.7.2で、2026年1月には法令用語、7月には科目名称の表記が更新されています。[IPAの現行シラバス一覧・変更注記](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

| 受ける対象 | 確認する資料 | 教材との照合 |
| --- | --- | --- |
| 2026年度の応用情報技術者試験 | 現行シラバスVer.7.2と試験要綱 | 教材の版、改訂された法令用語、科目A・Bの表記 |
| 2027年度の新試験を検討 | 新試験制度のシラバスとサンプル問題 | 希望する区分の共通知識・専門知識・技能 |

新制度の資料は[IPAの見直しページ](https://www.ipa.go.jp/shiken/minaoshi/index.html)から辿れます。新試験案は応用情報の単純な改名とは扱わず、希望区分に対応する範囲を確認してください。

### 基本情報技術者試験のシラバス2026と、2027年度案の違い

2026年10月時点、基本情報技術者シラバスの現行版はVer.9.2です。2026年1月の更新では「下請法」から「中小受託取引適正化法」への用語変更が示されています。[IPAの現行版と変更注記](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

2027年度案では科目Aの範囲体系を再整理し、科目Bの技能の細目も確認できます。ただし、用語例が新版に見当たらないことだけで「もう出ない」と判断しないでください。IPAは体系の表記変更と知識・技能の範囲そのものの変更を区別しています。[IPAの一部変更の説明](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

### 情報セキュリティマネジメントのシラバス変更点は、現行と移行案を区別

現行のSGはVer.4.1で、2025年4月に「プロバイダ責任制限法」から「情報流通プラットフォーム対処法」への用語変更が示されています。[IPAの現行版・変更注記](https://www.ipa.go.jp/shiken/syllabus/gaiyou.html)

2027年度案には科目Aの出題範囲体系と科目Bの一部変更が示されています。旧教材は用語例の有無だけで取捨選択せず、新旧の対応と技能の説明まで照合します。[IPAのSG・FEに関する変更案](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

筆者は現行CBTの応用情報・基本情報・SGを受験していません。この節は公式資料に基づく整理です。受験操作や学習上の体験コメントは加えていません。

## 令和8年度に受けるか、2027年度の新試験を待つか

いちばん迷うのが、ここだと思います。目安は次のとおりです。

| 今の状況 | おすすめ |
| --- | --- |
| すでに勉強を進めていて、受けたい区分に申込済み、または受付中 | 令和8年度に受ける。現行の形式に合わせて過去問を使い、現行シラバスの追加・変更点を補う |
| 応用情報に合格して、高度試験を目指している | 令和8年度の受験を検討。免除は合格時期等によるため、個別の有効期間を確認する |
| これから勉強を始める | いまの区分の知識は新しい試験の土台になるので、勉強は今から始めてよい。受ける時期は、新しい試験の公表を見て決める |

基礎知識の学習を続ける一方、受験料を払う判断は、申込可能な日程・社内要件・新制度の範囲をそろえて行いましょう。新旧で全範囲が一致することや、合格・免除が自動で引き継がれることは前提にしません。

新しい試験の内容は、公開されているシラバス案をもとにした無料のコースで先に確かめられます。

- [プロフェッショナルデジタルスキル（マネジメント）試験 20時間コース](/course/pd-m/)
- [プロフェッショナルデジタルスキル（システム）試験 20時間コース](/course/pd-s/)
- [データマネジメント試験 20時間コース](/course/dm/)

区分の選び方は [IPA資格の高難易度対策｜応用情報・高度試験と2027年の新試験の選び方](/method/advanced-ipa-hub/) で整理しています。

## よくある質問

<strong>Q: CBT化で過去問は使えなくなりましたか？</strong>

A: 2026年度のCBT化では、現行区分の過去問を学習に使えます。ただし、2027年度の再編は別の変更なので、過去問だけで新範囲を網羅できるとは限りません。

新しくシラバスに加わった用語は過去問に出てこないことがあるので、変更点は別に確かめてください。

<strong>Q: 論文試験はなくなりましたか？</strong>

A: 2026年度の論文区分はキーボードで入力します。これは2027年度の新試験の出題形式と分けて確認してください。[IPAの現行実施方式](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html)

<strong>Q: 2027年度の新しい試験の日程は決まっていますか？</strong>

A: 2026年10月時点では、IPAは「2027年度から新試験制度に移行予定」としています。詳しい日程や内容は、IPAの公式サイトで公表を確認してください。

## まとめ

IPAの試験の変更は、2段階で進んでいます。

- 令和8年度から、応用情報・高度試験・情報処理安全確保支援士試験はCBT方式。前期・後期に分かれ、科目Aと科目Bを別の期間に受ける。論文はキーボード入力
- 2027年度からは新しい試験制度へ移る予定。応用情報と多くの高度試験は、プロフェッショナルデジタルスキル試験にまとめ直される
- いまの試験に向けた勉強は、新しい試験の土台にもなる

これで、自分が令和8年度に受けるか、新しい試験を待つかを判断できるはずです。まずは受けたい区分が前期と後期のどちらにあるかを、上の表で確かめてみてください。
