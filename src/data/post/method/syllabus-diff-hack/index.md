試験日が近づいてから、シラバスが変わっていたことに気づく。そんな経験がありますか。

資格試験を毎年追いかける人は多くありません。ただ、年に1回しか受けられない高難度の試験は、<strong>1年の間にシラバスや制度が変わる</strong>ことがあります。受験する年の最新の情報を、手間をかけずに知っておくことが大切です。

そこで、更新を自分で探しに行くのをやめて、<strong>更新が自分に届く仕組み</strong>を先に作ります。

この記事では、公式ページのURLの記録から、更新の通知、変更点のAIでの要約までを紹介します。読み終えたときに、自分が受ける試験の更新を自動で知らせる仕組みを、自分で組めるようにします。

## 最初に決めるのは、追いかける試験と情報源

すべての試験を追う必要はありません。追いかけるのは、<strong>これから受ける試験だけ</strong>です。

受験を決めたら、次の情報源を探します。

| 情報源 | 何が分かるか |
| --- | --- |
| 試験の公式ページ | 試験の概要、日程、制度の変更の案内 |
| シラバス（出題範囲）の資料 | 出題される用語と範囲 |
| 公式のお知らせ・ニュース | 試験制度やシラバス改訂の予告 |
| 受験の申込みのページ | 申込み期間、受験料、会場の案内 |

見つけたURLは、<strong>台帳</strong>に記録します。表計算ソフトでも、Markdownのファイルでも構いません。

| 試験 | 資料の種類 | URL | 確認の頻度 | 最後に確認した日 |
| --- | --- | --- | --- | --- |
| （受ける試験名） | シラバス | （公式ページのURL） | 月1回 | 2026-10-25 |
| （受ける試験名） | お知らせ | （公式ページのURL） | 週1回 | 2026-10-25 |

この台帳があるだけで、「どこを見ればよいか」が分かり、確認の抜けが減ります。

## 更新を知らせてもらう3つの方法

台帳の情報源に更新があったとき、通知を受け取る方法は3つあります。手間の少ない順に紹介します。

### 方法1：RSSやメール配信を使う

公式サイトにRSSやメールの配信があれば、まず登録します。更新があると、自動で届きます。

RSSとは、サイトの更新情報を配信する仕組みです。RSSリーダーという無料のアプリに登録すると、複数のサイトの更新をまとめて見られます。

RSSやメール配信の有無は、サイトによって違います。公式ページのお知らせ欄や、フッターを確認してください。

### 方法2：ページの変更を検知するツールを使う

RSSがないページには、ページの変更を検知してくれるサービスやブラウザの拡張機能が使えます。監視したいURLを登録しておくと、内容が変わったときに通知が届きます。

無料で使える範囲は、サービスによって違います。登録の前に、料金と利用条件を確認してください。

### 方法3：自分でスクリプトを書いて、定期的に確認する

もう少し細かく調整したい人は、ページを定期的に取得して、前回と比べるスクリプトを書く方法があります。AIに書いてもらうこともできます。

次は、台帳のURLを取得して、内容が変わったかを調べる例です。

```python
import hashlib
import json
import urllib.request
from pathlib import Path

# 台帳のURLを入れる（公式ページのURLに置き換える）
URLS = {
    "シラバスの案内ページ": "https://example.com/syllabus",
}
STATE = Path("watch_state.json")


def fetch_hash(url):
    # 取得先に負担をかけないよう、実行は1日1回程度にとどめる
    req = urllib.request.Request(url, headers={"User-Agent": "syllabus-watch/1.0 (personal study)"})
    with urllib.request.urlopen(req, timeout=30) as res:
        return hashlib.sha256(res.read()).hexdigest()


state = json.loads(STATE.read_text(encoding="utf-8")) if STATE.exists() else {}
for name, url in URLS.items():
    new_hash = fetch_hash(url)
    if name in state and state[name] != new_hash:
        print(f"更新の可能性があります: {name} {url}")
    state[name] = new_hash
STATE.write_text(json.dumps(state, ensure_ascii=False, indent=2), encoding="utf-8")
```

このスクリプトは、ページ全体が変わったかどうかを見ています。そのため、ページに日付やアクセス数のような常に変わる部分があると、毎回「更新あり」と出てしまいます。その場合は、お知らせの一覧やPDFへのリンクなど、見たい部分だけを取り出して比べるようにします。

スクリプトでページを取得するときは、次のことを守ってください。

- サイトの利用規約と、robots.txtに従う
- 短い間隔で何度もアクセスしない
- 個人の学習のために使い、取得した内容を再配布しない

## 更新を見つけたら、変更点をAIで調べる

シラバスのPDFが更新されたら、前の版との<strong>差分</strong>を調べます。数百ページあるPDFを、人が目で比べるのは大変です。

### NotebookLMに、新旧を並べて聞く

手軽なのは、NotebookLMに新旧のシラバスを両方入れて聞く方法です。

```text
このノートには、前年度のシラバスと今年度のシラバスが入っています。
今年度で、次の3つに当てはまる項目を一覧にしてください。
1. 新しく追加された用語
2. 削除された用語
3. 説明や範囲が変わった用語
それぞれ、根拠になった箇所を、資料から引用して示してください。
```

NotebookLMの基本的な使い方は、[NotebookLM資格試験活用ガイド](/method/notebooklm-features-guide/)にまとめています。

### Pythonで、用語の差を取り出す

資料が多く、自動で処理したい場合は、PDFからテキストを取り出して差を求める方法もあります。

```python
import pypdf


def get_lines(pdf_path):
    reader = pypdf.PdfReader(pdf_path)
    text = ""
    for page in reader.pages:
        text += page.extract_text() or ""
    # 1行ずつの集合にして、新旧を比べやすくする
    return set(text.split("\n"))


old_ver = get_lines("syllabus_old.pdf")
new_ver = get_lines("syllabus_new.pdf")

# 新しい版にだけある行を取り出す
for item in sorted(new_ver - old_ver):
    print(f"新規項目: {item}")
```

行単位で比べるため、改行の位置が変わっただけの部分も「差」として出ます。取り出した結果は、そのまま信じず、AIに渡して整理させます。

```text
次のリストは、旧版と新版のシラバスの差分として取り出した行です。
改行の位置が変わっただけのものは除き、新しく追加された用語と、変更された用語に分けてください。
分類が曖昧なものは「要確認」としてください。
```

PDFからのテキストの取り出しがうまくいかないときは、シラバスの「用語例」の部分だけをコピーして、生成AIに構造化させる方法も使えます。

### 新しい用語を、自分で説明できるか確かめる

差分で見つかった新しい用語は、AIに問題を作らせて、理解を確かめます。

```text
次の用語は、今年度のシラバスで新しく追加されたものです。
1. 小学生にも分かる言葉で、意味を説明してください。
2. 試験の知識問題として出題される場合を想定し、4択問題を1問作ってください。
   正解と、誤りの選択肢が誤りである理由も付けてください。

用語：（ここに差分で見つかった用語）
```

作られた問題と解説は、公式の用語集やテキストで必ず確認してください。AIの問題は、練習の材料であって、実際に出題される問題を予測するものではありません。

## 差分は「出題予測」ではなく、学ぶ範囲の確認

注意したいのは、新しく加わった用語が、必ず出題されるとは限らないことです。

差分から分かるのは、<strong>試験の範囲がどう変わったか</strong>です。自分が過去問で学んだ範囲とのずれを確認し、学ぶ内容に抜けがないかを確かめる目的で使ってください。

シラバスの内容は、必ず公式の資料で確認します。AIの要約は、確認の入口として使います。

## 関連するニュースを取り込む

制度の変更は、公式の案内より先にニュースで知ることもあります。

- <strong>Googleアラート</strong>：試験名や、新しい用語のキーワードを登録すると、関連する新しいページが公開されたときにメールで届く
- <strong>新聞社や出版社のサイト</strong>：個人の発信より、情報源がはっきりしている媒体を優先する

AIは、学習の時点より新しい情報を知らないことがあります。ニュースの記事を見つけたら、記事のURLや本文をAIに渡して、要約してもらいます。

## 仕組みを回す手順

最後に、全体の流れをまとめます。

| ステップ | やること | 頻度 |
| --- | --- | --- |
| 1 | 受ける試験の公式ページのURLを、台帳に記録する | 最初の1回 |
| 2 | RSS、メール配信、変更検知のいずれかで、通知を受け取る | 設定は1回 |
| 3 | 通知が来たら、新旧の資料をNotebookLMなどに入れ、差分を調べる | 更新のたび |
| 4 | 学習計画に、変更点の学習を足す | 更新のたび |

## まとめ

試験の更新は、探しに行くのではなく、届く仕組みを作っておくのが効率的です。

公式ページのURLを台帳に記録し、RSS・変更検知・スクリプトのいずれかで通知を受け取り、差分はAIで整理する。これで、受験する年の最新の範囲を、手間をかけずに押さえられます。

まず今日は、受ける試験の公式ページのURLを2つ、台帳に書き出してみてください。
