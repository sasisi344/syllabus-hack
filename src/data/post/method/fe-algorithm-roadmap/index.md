ITパスポートに合格して、次は基本情報技術者試験。そう思って科目Bの過去問を開いたら、まったく歯が立たなかった、ということはないでしょうか。

基本情報は、ITパスポートの延長だと思って始めると、<strong>一気に難易度が上がったように感じる</strong>試験です。ITパスポートではほとんど出てこなかったプログラミングが、科目Bの中心になるからです。

この記事は、ITパスポートに合格した人や、プログラミングに少し触れたことがある人など、<strong>ITの基礎知識がある人</strong>を前提にしています。そのうえで、科目Bのアルゴリズムをどう進めればいいかを説明します。

## ITパスポート合格者でも難しくなる理由

### 科目Bはアルゴリズムが8割

基本情報技術者試験は、科目Aと科目Bに分かれています。

| 科目 | 内容 |
| --- | --- |
| 科目A | ITの基礎理論、コンピュータ、ネットワーク、データベース、セキュリティ、マネジメント、ストラテジなど幅広い知識 |
| 科目B | 20問のうち、アルゴリズムとプログラミングが16問、情報セキュリティが4問 |

科目Bの<strong>8割はアルゴリズムとプログラミング</strong>です。擬似言語で書かれたプログラムを読み、処理の流れを追って、答えを選びます。

擬似言語は、特定のプログラミング言語に依存せず、処理の手順（アルゴリズム）を書くための記法です。基本情報で問われるのは、ある言語の文法の知識ではなく、<strong>処理の流れを論理的に追い、正しい結果を導く力</strong>だからです。この力は、開発の仕事でコードを読んだり、不具合の原因を探したりするときにそのまま使われます。

### ITパスポートでは出ない内容が中心になる

ふだんからパソコンを使っている人なら、科目Aの問題の一部は、なんとなくの知識でも正解できるかもしれません。ITパスポートで学んだ用語も、科目Aでは役に立ちます。

けれど、プログラミングや、ネットワーク・データベースの深い仕組みは、ITパスポートではほとんど問われなかった内容です。<strong>ITパスポートの知識だけでは、科目Bはほぼ解けません</strong>。ここが、ITパスポート合格者でも「急に難しくなった」と感じる理由です。

まったくの未経験から始める場合は、先に変数・配列・繰り返し・条件分岐といったプログラミングの基本を、入門書などで一通り学んでから、この記事の進め方に入ることをおすすめします。

## 科目Bの進め方

### プログラムを紙の上で追う（トレース）

科目Bの中心になる力は、プログラムを読み、変数の値がどう変わっていくかを<strong>紙の上で追う（トレースする）</strong>力です。

最初は、短いプログラムで、1行ずつ変数の値を表に書き出す練習をします。

| 行 | i | sum |
| --- | --- | --- |
| 開始 | － | 0 |
| 1回目の繰り返し | 1 | 1 |
| 2回目の繰り返し | 2 | 3 |

時間はかかりますが、この練習を積むと、長いプログラムでも、どこで何が起きているかを見失わなくなります。

### 得意な言語があるなら、擬似言語との違いを先に埋める

PythonやJavaScriptなどを書いたことがある人は、文法の考え方はすでに知っています。そのぶん、<strong>擬似言語との違い</strong>でつまずきやすくなります。

代表的なのが、配列の添字です。Pythonなどでは先頭が0番目ですが、擬似言語では1番目から始まります。この違いを知らずにトレースすると、処理が1つずれてしまいます。Pythonとの違いは、[基本情報の科目BはPythonだけで大丈夫？擬似言語でつまずく3つの違い](/trend/fe-pseudo-language-trap/) でくわしく扱っています。

### よく出るアルゴリズムを押さえる

科目Bでは、探索や並べ替えなど、よく出るアルゴリズムがあります。仕組みを先に理解しておくと、初めて見る問題でも、どのアルゴリズムの変形なのかに気づけます。

- 線形探索・二分探索
- バブルソート・選択ソートなどの並べ替え
- スタック・キュー・木などのデータ構造

仕組みは、[線形探索・二分探索・ソート・スタック・キュー・木とは？](/theory/algorithm-search-sort/) で整理しています。

## AIで練習問題と添削を回す

### 擬似言語のトレースを手伝ってもらう

過去問の擬似言語がわからないときは、生成AIに、1行ごとの変数の変化を表にしてもらいます。

```text
以下は基本情報技術者試験の科目Bの擬似言語のプログラムです。
実行したときに、変数の値が1行ごとにどう変わるかを、トレース表にしてください。
配列の添字は1から始まるものとして扱ってください。

最後に、**このプログラムが何をする処理なのか**を1文でまとめてください。

（ここにプログラムを貼る）
```

AIの表をそのまま読むのではなく、まず自分で紙にトレースしてから、AIの表と見比べてください。ずれた所が、自分の弱い所です。

### Pythonに翻訳して、実際に動かしてみる

擬似言語は、実際に実行して確かめることができません。そこで、生成AIにPythonへ書き直してもらい、Google Colabなどの実行環境で動かすと、変数の値の変化を目で確かめられます。入力の数値を変えて、結果がどう変わるかを見ると、処理の流れがつかみやすくなります。

```text
# 指示
以下の基本情報技術者試験「科目B」の擬似言語を、私が理解できるように解説してください。

# 手順
1. このプログラムが何を目的としているかを、現実の例え話で100文字以内で要約する
2. 擬似言語を、そのまま動くPythonコードに書き直す（配列の添字は1始まりに注意）
3. Pythonコードの各行で、変数の中身がどう変わるかを、コメントで補足する
4. ループが3回行われた時点の変数の値を、表にまとめる

# 擬似言語の問題文
（ここに問題を貼る）
```

Pythonは実行できるので、擬似言語だけではできない「動かして確かめる」ことができます。ただし、試験本番では実行できないので、動かして理解したあとは、必ず紙の上で自力でトレースし直してください。紙でのトレースと、実行結果が一致すれば、理解できたと判断できます。

AIは、図や表への整理も手伝ってくれます。処理の流れが入り組んでいるときは、フローチャートにしてもらうと、全体の構造をつかみやすくなります。問題文を写真に撮ってAIに読ませる方法もありますが、読み取りの誤りが出やすいので、変数名や記号が正しいかを確認してください。

### 自分で書いて、添削してもらう

プログラミングの経験がある人は、読むだけでなく、<strong>自分でコードを書く</strong>練習も効果的です。生成AIに問題を出してもらい、自分で書いたコードを添削してもらいます。CursorのようなAIの機能があるエディタを使うと、問題を出してもらう、書く、添削してもらうを、同じ画面の中でくり返せます。

```text
基本情報技術者試験の科目Bで出題されやすい「二分探索」の問題を、Pythonで1問出してください。
穴埋めではなく、関数を一から書く形にしてください。
私がコードを書いたら、正しいかどうかと、改善できる点を教えてください。
**答えのコードは、私が書いたあとまで示さないでください。**
```

自分で書けるようになったアルゴリズムは、擬似言語で出題されても、読むのがぐっと楽になります。

AIの説明やコードには、まれに誤りがあります。気になった所は、過去問の解説やIPAが公開しているサンプル問題で確かめてください。

## まとめ

基本情報技術者試験の科目Bは、ITパスポートに合格した人でも一気に難しく感じる試験です。

- 科目Bの8割はアルゴリズムとプログラミング。ITパスポートでは出ない内容が中心になる
- 中心になる力は、プログラムを紙の上でトレースする力
- 得意な言語がある人は、配列の添字など擬似言語との違いを先に埋める
- AIにトレース表を作ってもらったり、問題を出して添削してもらったりして、練習の回数を増やす

これで、科目Bに向けて何から始めればいいかがわかったはずです。まずは過去問の短いプログラムを1つ選び、変数の値を1行ずつ紙に書き出してみてください。
