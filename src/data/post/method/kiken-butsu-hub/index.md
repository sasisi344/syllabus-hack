危険物取扱者乙種第4類（乙4）は、<strong>日本で最も受験者数が多い国家資格</strong>だ。
年間受験者数は約180万人。ガソリン・軽油・灯油などの引火性液体（第4類危険物）を取り扱う施設では、乙4を持つ危険物取扱者の選任が義務付けられているためだ。

<strong>60〜100時間の学習で合格できる</strong>ため、コストパフォーマンスが非常に高い資格でもある。
資格手当・就職の有利さ・就職先の幅広さを考えると、「最初に取るべき資格」として工場・倉庫・エネルギー業界では筆頭に挙がる。

## 合格までの勉強時間

危険物乙4の標準学習時間は<strong>60〜100時間</strong>だ。
化学の基礎知識がある人なら50時間以下でも合格できる。国家資格の中でトップクラスに学習コストが低い。

| 学習経験 | 目安時間 |
|---|:---:|
| 化学知識なし・完全未経験 | 80〜100時間 |
| 高校化学の基礎知識あり | 50〜70時間 |
| 他の乙種取得済み（科目免除あり） | 15〜25時間 |

### AI活用で専任講師を月額20ドルで雇う感覚

乙4の学習で詰まりやすいのは「基礎物理・化学」だ。
引火点・発火点・燃焼範囲など、テキストには定義だけが並んで「どう理解すればいいか」が書かれていないことが多い。

生成AIを使うと、この壁がなくなる。
<strong>月額20ドル程度で、何度でも質問できる専任の試験講師を雇うようなもの</strong>だ。

- 「引火点と発火点の違いが頭に入らない」→ 日常の例え話でその場で説明してもらえる
- 「ガソリンが危険な理由を化学的に説明して」といったぶしつけな質問でも歓迎される
- 何度同じ質問をしても怒らない
- 通勤・休憩中など自分の空き時間にいつでも使える

60〜100時間のうち「理解が止まって前に進めない時間」をゼロにすることが、AI活用の最大の効果だ。

## 危険物取扱者の種類

危険物取扱者には「甲種」「乙種」「丙種」の3区分がある。

| 区分 | 取り扱える危険物 | 難易度 |
|-----|-------------|:----:|
| 甲種 | 全種類の危険物 | 難（受験資格あり） |
| 乙種（1〜6類） | 取得した類の危険物 | 中 |
| 丙種 | 特定の第4類危険物（ガソリン等） | 易 |

<strong>乙種第4類（乙4）</strong>が最も需要が高い。ガソリン・軽油・灯油・重油など、日常生活に最も近い危険物を取り扱うためだ。

### 第4類危険物の主な物質

| 品名 | 代表例 |
|-----|------|
| 特殊引火物 | ジエチルエーテル、二硫化炭素 |
| 第1石油類 | ガソリン、アセトン |
| 第2石油類 | 軽油、灯油 |
| 第3石油類 | 重油、グリセリン |
| 第4石油類 | ギヤー油、シリンダー油 |
| 動植物油類 | ヤシ油、アマニ油 |

以下の施設では乙4保有者の選任が法律で義務付けられている。

- <strong>ガソリンスタンド</strong>（給油取扱所）
- <strong>石油・化学工場</strong>
- <strong>航空機燃料取扱施設</strong>
- <strong>倉庫・配送センター</strong>（危険物倉庫）
- <strong>発電所・変電所</strong>（重油タンク管理）

「乙4を持っていないとシフトに入れない」というガソリンスタンドが多く、アルバイト・パートでも取得推奨される数少ない資格だ。

### 資格手当の相場

- 月2,000〜5,000円が一般的
- 工場・プラント系では月5,000〜1万円の企業もある
- 甲種取得でさらに手当が増える企業も多い

### 受験資格

乙4の受験に学歴・経験などの要件はない。<strong>誰でも受験できる。</strong>
他の乙種を1つ持っていると「法令」と「基礎物理・化学」が免除になり、試験が短くなる（性消のみ）。

## 試験の全体像

### 試験形式

- 実施：全国各地で月1〜2回程度（都道府県によって異なる）
- 形式：四肢択一、35問
- 試験時間：2時間（法令・基礎物理化学15問+性質消火10問の計35問）

### 出題科目と合格基準

| 科目 | 問題数 | 合格ライン |
|-----|:-----:|:-------:|
| 危険物に関する法令 | 15問 | 60%以上（9問） |
| 基礎的な物理学・化学 | 10問 | 60%以上（6問） |
| 危険物の性質・火災予防・消火方法 | 10問 | 60%以上（6問） |

<strong>3科目すべてで60%以上を取る必要がある。</strong>
1科目でも60%を下回ると不合格になる「足切り制度」がある点に注意が必要だ。

### 合格率

乙4の合格率は約<strong>30〜35%</strong>。
ITパスポート（50%超）より低いが、学習方法が明確なため準備をすれば十分に届く水準だ。

## 最短合格ロードマップ（70時間・2ヶ月プラン）

### Week 1-2（〜25時間）：法令を先に攻める

法令は暗記が中心で、得点を積みやすい。
貯蔵・取扱の基準、指定数量、免状の種類・申請手続きなど、繰り返し出るテーマが多い。

### Week 3-4（〜20時間）：基礎物理・化学を整理する

燃焼の3要素（可燃物・酸素供給体・点火エネルギー）、引火点・発火点・沸点の違い、消火方法の分類などを整理する。
化学が苦手な場合、AIに例え話で説明させると理解が速い。

### Week 5-6（〜15時間）：性質・消火の各物質を暗記する

第4類の各品名ごとの特性（引火点・燃焼範囲・色・臭い・水への溶け方）を覚える。
量が多いため、比較表を作って丸暗記するより「物質のストーリーで覚える」方が忘れにくい。

### Week 7-8（〜10時間）：過去問反復で弱点を潰す

消防試験研究センターが公表している例題と、市販の過去問集を繰り返す。
足切りされやすい「基礎物理・化学」の得点率を最後に確認すること。

## AI活用法

### 物質の特性暗記をゲーム化する

```
危険物取扱者乙4試験の「性質・消火」科目の練習問題を10問作ってください。

出題範囲:
- 第4類危険物の品名と代表物質
- 各物質の引火点・発火点の大小比較
- 水溶性か非水溶性か
- 適切な消火方法（泡・粉末・二酸化炭素等）

四肢択一で、正解の解説も付けてください。
```

### 化学が苦手な人向けの解説プロンプト

```
高校化学を勉強したことがない人に向けて、危険物乙4試験の「燃焼と消火」を説明してください。

説明してほしい内容:
- 燃焼の3要素とは何か（例え話で）
- 引火点と発火点の違い（日常の例で）
- 消火方法の種類（除去・窒息・冷却・抑制）とそれぞれの具体例

専門用語は最小限にして、中学生でも分かる言葉で説明してください。
```
