## 合格までの勉強時間

危険物乙4の標準学習時間と、1週間で詰め込む場合の内訳を比較する。

| パターン | 目安時間 | 前提 |
|---|:---:|---|
| 標準（余裕を持った学習） | 40〜60時間 | 1〜3ヶ月かけて習得 |
| 1週間集中（平日夜＋休日） | 21〜35時間 | 1日3〜5時間×7日 |
| 業務経験あり（ガソリンスタンド等） | 15〜20時間 | 実務知識で一部を省略可能 |

<strong>合格基準は全科目60%以上</strong>であり、100点を狙う必要はない。この「60%でいい」という試験の性質こそが、1週間集中を可能にする。

### AI活用で専任講師を月額20ドルで雇う感覚

1週間という制約の中で最もやってはいけないのは、<strong>全範囲を均等な密度で勉強してしまうこと</strong>だ。乙4は法令15問・物理化学10問・性質と消火10問という配点構成があり、範囲ごとに「頻出度」に差がある。

- 「この分野は毎年出るのか、たまにしか出ないのか」を聞ける
- 苦手な化学の燃焼理論を、身近な例え（ろうそくの燃え方など）で理解できる
- 深夜に1問だけ疑問が浮かんでも、翌朝まで待たずに解消できる
- 「今日やった範囲で、明日忘れていそうな部分」をAIに診断させて復習リストを作らせられる

生成AIを使えば、<strong>月額20ドル程度で、1週間の詰め込み学習に伴走してくれる専任講師を雇うようなもの</strong>になる。時間を増やす魔法ではなく、<strong>「何を勉強すべきか迷う時間」をゼロにする</strong>ことが、短期集中においては最大の武器になる。

## 1週間プランの全体設計

7日間を「捨てる範囲を決める日」「頻出範囲を固める日」「総仕上げの日」の3フェーズに分ける。

| 日程 | フェーズ | やること |
|---|---|---|
| 1〜2日目 | 全体把握 | AIに出題頻度を診断させ、優先順位表を作る |
| 3〜5日目 | 頻出範囲の反復 | 法令の数値暗記＋物理化学の頻出パターンを問題集で反復 |
| 6日目 | 弱点補強 | 苦手分野だけをAIに再解説させる |
| 7日目 | 総仕上げ | 模擬試験形式で60%ラインを確認 |

<strong>1〜2日目で優先順位を決める作業を飛ばさないこと</strong>が最大のポイントだ。ここを丁寧にやるほど、残り5日間の効率が上がる。

## AIに優先順位を決めさせるプロンプト

危険物乙4のテキストは分厚く見えるが、実際に毎年出題される範囲は限られている。AIに過去の出題傾向を踏まえた優先順位表を作らせる。

```
私は危険物取扱者乙種第4類を1週間後に受験します。
1日に確保できる学習時間は平日3時間・休日5時間です。

以下の3科目について、出題頻度が高く「絶対に落とせない」項目と、
出題頻度が低く「今回は捨ててもよい」項目に仕分けしてください。

- 法令（15問）
- 物理及び化学（10問）
- 危険物の性質並びにその火災予防及び消火の方法（10問）

各科目で「絶対に落とせない項目」を3〜5個、
理由（なぜ頻出とされているか）も添えて挙げてください。
```

この仕分け作業をAIにやらせることで、<strong>1週間という限られた時間を、出題確率の高い範囲に集中投下</strong>できる。

## 苦手な化学範囲をAIで理解する

物理化学は暗記だけで乗り切ろうとすると、応用問題で崩れる。燃焼理論は「なぜそうなるか」を理解しておくと、初見の問題文にも対応できる。

```
危険物取扱者乙4の「燃焼の三要素」について、
化学が苦手な社会人にもわかるように説明してください。

条件:
- 専門用語を使う場合は必ず日常的な例えを添える
- 「燃焼が起きる条件」と「消火の原理（三要素のどれを取り除くか）」を
  セットで説明する
- 最後に、この知識を使って解ける典型的な試験問題のパターンを1つ出す
```

<strong>燃焼の仕組みを理解してから消火方法を学ぶと、「なぜこの消火剤が有効なのか」まで芋づる式に理解できる</strong>。丸暗記より記憶の定着が速い。

## 前日・当日の最終チェック

7日目は新しい知識を入れず、<strong>「解ける」ことを確認する日</strong>にする。

```
危険物乙4の試験を明日受けます。
これまで勉強してきた内容の理解度を確認したいです。

法令・物理化学・性質と消火の各分野から1問ずつ、
本番形式の四肢択一問題を出してください。
私が答えたら、正誤だけでなく「なぜその選択肢が正しいか」も解説してください。
```

前日にAIとこのやり取りを2〜3周行うことで、<strong>「わかったつもり」になっている箇所を試験前に洗い出せる</strong>。

## まとめ

危険物乙4を1週間で合格する3原則：

<strong>1. 全範囲を均等にやらない</strong>
AIに出題頻度を診断させ、頻出範囲に時間を集中投下する。

<strong>2. 化学は暗記でなく理解で乗り切る</strong>
燃焼の仕組みを理解すれば、消火方法まで芋づる式に覚えられる。

<strong>3. 最終日は新しい知識を入れず「解ける」ことを確認する</strong>
AIとの模擬一問一答で、わかったつもりの箇所を試験前に潰す。
