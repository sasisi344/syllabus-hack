間違えた問題をノートに書き写しても、数週間後に見返すと「結局どこが弱いのか」が分からない、という経験はありませんか。

原因は、問題を1問ずつ記録しているだけで、<strong>間違い方の共通点</strong>を見ていないことにあります。

この記事では、Markdownの記入式ノートにミスを記録し、AIにパターンを見つけてもらう手順を紹介します。読み終えたときに、自分のミスを「知識の不足」と「読み違い」などに分けて、次に何を復習するかを決められるようにします。

## 間違いの数より、間違い方の傾向を見る

資格試験は、満点を取る必要がありません。幅広い分野で取りこぼしを減らすほうが、合格に近づきます。

そのためには、「どの問題を間違えたか」だけでなく、<strong>なぜ間違えたか</strong>を分類して、同じ原因のミスをまとめて減らすのが効率的です。

たとえば、同じ「間違い」でも、原因は次のように分かれます。

| 原因の分類 | 例 | 対策 |
| --- | --- | --- |
| 知識不足 | 用語の意味を知らなかった | 用語を調べ直す |
| 用語の混同 | 公開鍵と秘密鍵を逆に覚えていた | 違いを表にまとめる |
| 問題文の読み違い | 「適切でないもの」を「適切なもの」と読んだ | 設問の条件に印をつける |
| 計算ミス | 単位の変換を間違えた | 計算の手順を決める |
| 時間切れ | 最後まで読めなかった | 解く順番を決める |

自分で分類するのは手間がかかります。そこで、AIに手伝ってもらいます。

## Markdownの記入式ノートを作る

ノートは、アプリではなく、パソコンに置いた<strong>1つのMarkdownファイル</strong>で十分です。ローカルのファイルなので、検索しやすく、AIにそのまま渡せます。

間違えた問題ごとに、次の形で記入します。

```text
## 2026-10-25 / セキュリティ / 問題の番号

**問題**
（問題文を短く要約して書く）

**自分の答え**
（選んだ選択肢と、そう考えた理由）

**正解**
（空欄でもよい。AIに判定してもらう）

**なぜ間違えたと思うか**
（自分の考えを書く）
```

ポイントは、「自分の答え」と「そう考えた理由」を必ず書くことです。理由まで書いておくと、AIが<strong>考え方のどこが間違っていたか</strong>を指摘できます。

なお、過去問の問題文は、権利の関係もあるため、全文をそのまま保存せず、要約と問題番号で記録してください。

### クイズアプリの記録から下書きを作る

当サイトのクイズアプリは、回答の記録（問題のIDと正誤）をブラウザに保存しています。ブラウザの開発者ツールで、LocalStorageにある `sh_quiz_` で始まるデータを開くと確認できます。

このデータをAIに渡して、不正解の問題だけを一覧にしてもらえば、ノートの下書きができます。

```text
次のJSONは、クイズアプリの回答履歴です。
isCorrect が false の問題のIDだけを抽出し、
ノートに貼り付けやすいMarkdownの一覧にしてください。
```

## AIに正誤を判定してもらい、パターンを見つける

ノートが数件たまったら、ファイルをAIに渡します。最初の依頼は、記入した内容の確認です。

```text
添付のMarkdownは、私の資格試験の間違いノートです。
1. 各項目について、私の答えと理由が正しいかを判定してください
2. 正しくない場合は、考え方のどこが違っていたかを説明してください
3. 原因を「知識不足・用語の混同・問題文の読み違い・計算ミス・時間切れ」に分類してください
```

数週間ぶんがたまったら、次は傾向を見ます。

```text
添付のノート全体から、私のミスの傾向を分析してください。
原因の分類ごとの件数と、繰り返し間違えている分野を挙げ、
次の1週間で復習すべき内容を3つに絞ってください。
```

AIの分析には誤りが混ざることがあります。用語の意味や解答は、公式のシラバスや解説で必ず確かめてください。

分析の結果は、[NotebookLM](/method/notebooklm-features-guide/)にノートを読み込ませて、自分の間違いだけを教材にする使い方もできます。

## 発展：HTMLのアプリにして、グラフで見る

Markdownのままでも使えますが、件数が増えると見にくくなります。そこで、AIにHTMLのファイルを作らせて、グラフで確認できるようにする方法があります。

```text
添付のMarkdownの間違いノートを読み込み、次の機能を持つ、
1つのHTMLファイルを作ってください。
- 原因の分類ごとの件数を、棒グラフで表示する
- 分野ごとの件数を一覧にする
- 分類や分野で絞り込みができる
外部のライブラリは使わず、ブラウザで開くだけで動くようにしてください。
```

ローカルで動くことを確かめたら、さらに次の使い方に広げられます。

- 他の資格の勉強にも使えるよう、分類や分野を設定で変えられるようにする
- 公開して、同じ勉強をしている人が自由に使えるようにする
- 作ったアプリを、ポートフォリオの成果物として載せる

公開するときは、自分の学習記録や、過去問の問題文を含めないようにしてください。公開するのは、アプリの仕組みだけです。

作ったものの見せ方は、[資格よりポートフォリオは本当？採用側の見方は職種と採用担当のタイプで変わる](/career/portfolio-vs-cert/)でも整理しています。

## まとめ

間違いノートは、書き写すものではなく、<strong>原因を分類して傾向を見るためのデータ</strong>です。

Markdownの記入式にすれば、ローカルのファイルとしてAIに渡せ、正誤の判定とパターンの分析を任せられます。

これで、自分のミスを原因ごとに分けて、次に復習する内容を決められます。まずは今日間違えた問題を1つ、上のひな形で記録してみてください。
