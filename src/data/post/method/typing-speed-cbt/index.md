CBT試験を申し込んだものの、ふだんスマホしか使っていなくて、会場のPCをちゃんと操作できるか不安になっていないでしょうか。

CBT（Computer Based Testing）は、紙ではなくPCの画面で問題を解く試験の方式です。民間の資格には自宅で受けられるオンライン試験もありますが、ITパスポートなどの国家資格の多くは、<strong>指定された会場で、用意されたPCを使って受験</strong>します。

会場のPCは、キーボードとマウスで操作します。スマホのように画面を指で触る操作はできません。

知識は十分なのに、操作でつまずいて時間を失うのはもったいないことです。この記事では、スマホ中心の人がCBT会場でつまずきやすいポイントを整理し、本番までにどこで、何を練習しておけばいいかを紹介します。

## CBT会場のPCはキーボードとマウスで操作する

国家資格のCBTでは、受験者は会場に用意されたPCの前に座り、画面に表示される問題に答えていきます。

選択式の問題なら、主な操作は次のようなものです。

- 選択肢をマウスでクリックして選ぶ
- 長い問題文を、マウスのホイールやスクロールバーで上下に動かす
- 「次へ」「前へ」のボタンや、見直し用のチェックをクリックする

PCに慣れている人には何でもない操作ですが、ふだんスマホだけを使っている人の中には、<strong>マウスの使い方がわからず戸惑う</strong>人もいると聞きます。クリックとダブルクリックの違い、ホイールで画面を動かす感覚は、触ったことがないと意外とわからないものです。

さらに、記述式の問題がある試験や、受付で名前などを入力する場面では、キーボードでの文字入力も必要になります。

つまりCBT試験の対策としては、問題を解く知識に加えて、<strong>PCの操作も練習しておく</strong>必要があるのです。

では、具体的にどんな所でつまずきやすいのでしょうか。

## スマホ派がつまずきやすい3つのポイント

キーボードとマウスでゲームを遊んでいる人なら、操作そのものはほとんど問題ないはずです。つまずきやすいのは、日本語の入力まわりです。

### 日本語入力（IME）の切り替えと変換の戻し方

PCで日本語を入力するときは、<strong>IME</strong>（日本語入力の仕組み）を使います。スマホでは自動で切り替わる「英字」と「日本語」を、PCでは自分で切り替えます。

日本語配列のキーボードには、スマホにはないキーがいくつかあります。

| キー | はたらき |
| --- | --- |
| 半角/全角 | 日本語入力と英字入力を切り替える |
| 変換 | 入力中の文字を漢字などに変換する（スペースキーでも変換できる） |
| 無変換 | 変換せずにひらがな・カタカナを切り替える |
| カタカナ/ひらがな | ローマ字入力とカナ入力の切り替えに関わるキー |

困りやすいのは、うっかり別のキーを押して、入力のモードが変わってしまったときです。たとえば<strong>カナ入力</strong>（キーに書かれたひらがなで直接入力する方式）に切り替わると、「a」を押したつもりが「ち」と入力されてしまいます。

こうしたときに、元に戻す方法を知っていれば慌てずに済みます。

- 変換を間違えたら、確定する前に <strong>Esc</strong> キーで取り消す
- 確定してしまった変換は、<strong>Ctrl＋Z</strong> で取り消すか、Backspaceで消して打ち直す
- 入力中の文字は、F7でカタカナ、F10で半角英数字に変えられる
- カナ入力になってしまったら、IMEのメニュー（画面右下の「あ」や「A」の表示）からローマ字入力に戻す

会場のPCの設定は会場ごとに違うことがあるので、操作に迷ったら試験監督の人に声をかけて構いません。ただ、自分で戻せると時間を失わずに済みます。

### 日本語配列と英字配列で記号の位置が違う

ふだん英字配列（US配列）のキーボードを使っている人も注意が必要です。日本の試験会場のPCは、多くが日本語配列（JIS配列）です。

アルファベットの位置は同じですが、<strong>記号の位置が違います</strong>。

- 英字配列では Shift＋2 で「@」、日本語配列では Shift＋2 で「"」
- 日本語配列では「@」はPの右隣のキー
- 「:」「*」「(」「)」なども位置が変わる

記述式の解答で記号を打つときや、計算式を入力するときに手間取ることがあります。

### ノートPCのタッチパッドとマウスの違い

ふだんノートPCのタッチパッドで操作している人は、会場のデスクトップPCで<strong>マウス</strong>を使うことになります。クリックの感覚や、画面のポインターが動く速さが違うので、最初は少し戸惑うかもしれません。

これらはどれも、一度触っておけば慣れるものばかりです。では、自宅にPCがない場合はどこで練習すればいいのでしょうか。

## 自宅にPCがないならネットカフェや図書館で触っておく

自宅にPCがない人は、試験の前に一度、外でPCを触っておくのがおすすめです。

- <strong>ネットカフェ</strong>: デスクトップPCとマウス、日本語配列のキーボードがそろっていることが多く、会場の環境に近い
- <strong>図書館や公共施設</strong>: 利用者向けのPCを置いている所がある
- <strong>学校や職場</strong>: 学生なら学校のPC室、社会人なら職場のPCで、昼休みなどに少し練習する

練習するときは、次のことを一通り試しておくと安心です。

1. マウスでクリックし、ホイールで長いページを上下に動かす
2. 半角/全角キーで日本語と英字を切り替える
3. 日本語を入力して変換し、Escで取り消す
4. 「@」「:」「(」などの記号を打ってみる

また、受験する試験の公式サイトでCBTの体験版が公開されていれば、それを使うのがいちばんの練習になります。ITパスポートでは、本番と同じ画面で操作を試せる疑似体験ソフトが公開されています。

## 記述式があるならタイピングも練習しておく

選択式の試験なら、マウスの操作ができれば大きな問題はありません。ただ、応用情報技術者試験や高度試験のように記述式・論述式の問題がある試験では、<strong>考えながら文字を打つ速さ</strong>も解答時間に影響します。

### まずは今の速さを測る

無料のタイピング練習サイトで、1分間に何文字打てるかを測っておきます。日本語の文章で測れるサイトを選ぶと、本番に近い数字がわかります。

### 指の位置を決めて、画面を見て打つ

手元のキーを見ながら打っていると、そのたびに考えが止まります。ホームポジション（左手の人差し指をF、右手の人差し指をJに置く基本の位置）から指を離さないと決めて、画面を見ながら打つ練習をします。

最初は遅くなりますが、続けるうちに指が位置を覚えていきます。

### 考えながら打つ練習をする

タイピング練習サイトは、表示された文字を打つだけです。本番では、自分で考えた内容を打つ必要があります。

毎日、その日に勉強した内容を数百文字でまとめてPCに打ち込むと、考えながら打つ練習と復習を同時にできます。

```text
今日勉強した内容を、自分の言葉で300字にまとめて打ち込みました。
内容の誤りと、説明が足りない所があれば**具体的に指摘**してください。
文章の書き方ではなく、内容の正しさを中心に見てください。

（ここにまとめた文章を貼る）
```

## まとめ

国家資格のCBT試験は、会場に用意されたPCを、キーボードとマウスで操作して受けます。

- スマホ中心の人は、マウス操作と日本語入力の切り替えでつまずきやすい
- 変換の取り消し（Esc・Ctrl＋Z）や、日本語配列の記号の位置を知っておくと慌てずに済む
- 自宅にPCがなければ、ネットカフェや図書館で一度触っておく

これで、会場のPCの前に座ったときに、操作で迷う場面を減らせるはずです。試験の日までに一度、デスクトップPCの前に座って、クリックと日本語入力を試してみてください。
