仕事をしながら、ITパスポートをなるべく早く取りたい。

でも、テキストを開くと用語の多さに圧倒されてしまう。

そんな社会人に向けて、この記事では「捨て問」で範囲を絞る戦略を紹介します。

ただし、<strong>何を捨てるかは、教科書ではなくあなたの今の点数で決まります。</strong>

だから最初にやるのは、勉強せずに過去問を1回解くことです。

読み終えたときには、自分が捨ててよい分野と、1週間で取りに行く分野を判断できるようになります。

## 完璧を目指す人ほどITパスポートで挫折する

「全範囲を網羅しようとして、力尽きた…」

そんな声をよく耳にします。

ITパスポートのシラバスには、<strong>IT初学者には馴染みのない専門用語が大量に含まれています。</strong>

一から教科書を読んでいくと、1週間では到底終わりません。

ITパスポートの合格基準は、1,000点満点中 <strong>600点（6割）</strong> です。

満点を目指す必要はなく、100問のうち約40問は間違えても届く計算になります。

では、その40問をどこで落とすかは、どうやって決めればいいのでしょうか。

## 最初の1日は勉強せずに過去問を解く

捨て問を決める前に、<strong>何も勉強しない状態で過去問を100問解いてみてください。</strong>

[模擬試験シミュレーター](/app/it-passport-quiz/)や過去問道場を使えば、時間を測って本番に近い形で解けます。

解き終わったら、次の2つを書き出します。

- 分野別の正答率（ストラテジ系・マネジメント系・テクノロジ系）
- まったく見当がつかなかった問題のテーマ（計算、ネットワーク、法律など）

この結果が、あなた専用の「捨て問リスト」の材料になります。

社会人は、仕事や日常の中ですでに身についている知識が意外と多いものです。

最初から教科書を読むと、その「もう取れている問題」にまで時間を使ってしまいます。

では、勉強しなくても取れている問題には、どんなものが多いのでしょうか。

## 勉強しなくても取れる問題がある

ITパスポートでは、ビジネスの基本に関する問題が多く出題されます。

それに加えて、シラバス改訂で生成AIに関する用語が加わり、AIの出題がそれなりに増えています。

<strong>ビジネスとITのニュースにアンテナを張っている人や、仕事でAIを日常的に使っている人</strong>は、勉強しなくても答えられる問題があるはずです。

たとえば、次のような知識です。

- 生成AIの使い方や注意点（ハルシネーション、情報漏えいのリスク）
- 会社の業務で使うクラウドサービスやセキュリティのルール
- マーケティングや財務など、ニュースでよく見る経営の言葉

過去問で正解できた分野は、仕上げの演習だけで十分です。

逆に、ここで点が取れなかった分野が、1週間で時間を使う候補になります。

では、点が取れなかった分野は、すべて勉強し直すべきなのでしょうか。

## 捨ててよい問題と捨ててはいけない問題

ITパスポートの出題数は、おおむね次の配分です。

| 分野 | 出題数（目安） |
| :--- | :--- |
| ストラテジ系（経営） | 約35問 |
| マネジメント系（管理） | 約20問 |
| テクノロジ系（技術） | 約45問 |

テクノロジ系の中には、「2進数・16進数の計算」「論理演算」「回路の仕組み」など、未経験者が理解するのに時間がかかる分野があります。

これらは <strong>時間をかけても数問分にしかならない、ハイコスト・ローリターンな問題</strong>です。

過去問で手も足も出なかったのがこうした計算問題なら、捨て問の第一候補にしてかまいません。

一方で、<strong>捨ててはいけないのが分野別の基準点</strong>です。

ITパスポートは総合600点に加えて、3分野それぞれで1,000点満点中300点以上が必要です。

テクノロジ系をまるごと捨てると、総合点が届いていても不合格になります。

捨てるのは「計算問題」までにして、テクノロジ系の用語問題は取りに行きましょう。

## 1週間で進める順番

過去問の結果をもとに、残りの6日間を次のように使います。

### Day 1：勉強なしで過去問を解き、捨て問を決める

前の節のとおり、100問を解いて分野別の正答率と苦手なテーマを書き出します。

計算問題で手が止まったなら、その時点で捨て問に入れて構いません。

### Day 2-3：点が取れなかったストラテジ・マネジメント系を自分事にする

ここはビジネス用語が多く、非IT職でも「聞いたことがある」言葉が多い分野です。

過去問で落とした問題のテーマだけを、[AIたとえ話ハック](/method/ip-strategy-ai-hack/)を使って身近な例に置き換えて理解します。

<strong>抽象的な概念は、AIに具体的なたとえ話にしてもらうと記憶に残りやすくなります。</strong>

### Day 4-5：テクノロジ系の用語を過去問で周回する

計算問題は捨てたまま、「Cookie」「ファイアウォール」「公開鍵暗号」など、<strong>単語と意味が1対1で結びつくもの</strong>を過去問道場で周回します。

たとえば「VPN」なら「仮想的な専用線で安全な通信を実現する技術」のように、用語と目的をセットで覚えます。

### Day 6-7：100問シミュレーションで仕上げる

もう一度、模擬試験シミュレーターで時間を測って100問を解きます。

Day 1の点数と比べて、苦手だった分野がどれだけ伸びたかを確認しましょう。

計算問題が出てきたら直感でマークして次に進み、余った時間を見直しに使います。

## 捨てても届く点数の目安

計算問題を捨てた場合の、得点の目安は次のとおりです。

- ストラテジ系：7割
- マネジメント系：7割
- テクノロジ系：6割（用語問題で狙える範囲）

この配分なら、総合で600点を上回り、3分野とも基準点の300点を超えます。

ITパスポートの点数は問題ごとの重みが公開されていない方式（IRT）で計算されるため、正答率から点数をぴったり出すことはできません。

それでも、<strong>どの分野も6〜7割を取る</strong>ことを目安にすれば、合格ラインに届く計画が立てられます。

## ITパスポートは何を証明するための資格か

「捨て問を作るなんて邪道だ」と思うかもしれません。

ただ、ITパスポートは、ITを一から学ぶために始める資格とは限りません。

<strong>ITスキルはあるのに、それを証明するものがない</strong>という社会人の悩みを、手軽に解決できる資格でもあります。

仕事でAIやクラウドを使いこなしている人なら、すでに持っている力を形にするために受ければいいのです。

だからこそ、すでに取れている分野に時間を使わず、足りない部分だけを埋める進め方が合っています。

## まとめ

社会人がITパスポートをなるべく早く取るなら、最初の1日は勉強せずに過去問を解きましょう。

その点数と苦手から、計算問題などの捨て問を決め、点が取れなかった分野に時間を集中させます。

ただし、分野別の基準点（各300点）を割らないように、テクノロジ系の用語問題は取りに行きます。

これで、自分が捨ててよい問題と、1週間で取りに行く問題を判断できるはずです。
