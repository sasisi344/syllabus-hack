2027年度の新IPA試験を目指すとき、区分名の変更だけを見て教材を選ぶと、自分が学びたい仕事と出題範囲がずれることがあります。

勉強法を決める軸は、受ける区分の対象者像と、シラバス・公式サンプルに示された知識の深さです。この記事では、制度案と確定情報を区別し、自分の誤答を使って学習計画を更新する方法を整理します。

2026年10月時点、新制度は2027年度開始予定で、名称・内容は検討中です。[IPA・試験制度の見直し](https://www.ipa.go.jp/shiken/minaoshi/index.html)

## ビジネス体系に合わせた区分の選択

「AI資格が欲しい」だけで決めず、何を扱う仕事を学びたいのかを先に書きます。新制度案では、データマネジメント試験は主にビジネス部門のデータ整備・管理、PD試験はマネジメント、データ・AI、システムの3領域として整理されています。[IPA・見直しの検討状況](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

| 学びたい役割・条件 | 最初に確認する区分 | 選ぶ前に見る箇所 |
| --- | --- | --- |
| IT全般の基礎から学びたい | ITパスポート | 基礎用語を自分の言葉で説明できるか |
| 業務データの品質・管理を学びたい | データマネジメント試験（仮称） | データの取扱いと業務上の判断 |
| 組織の変革・プロジェクトを管理したい | PDのマネジメント領域（仮称） | 対象者像と専門知識 |
| データ基盤やAI活用を支える設計を学びたい | PDのデータ・AI領域（仮称） | 対象者像と専門知識 |
| システムの要件定義・設計・開発を主導したい | PDのシステム領域（仮称） | 対象者像と専門知識 |

この表は選び方の提案で、就職効果や合格の保証ではありません。広い基礎から始める人は[ITパスポートのハブ](/method/itp-hub/)で全体像を確認できます。

区分の候補が決まったら、必要時間の数字より、いま説明できない範囲を調べます。

## 試験区分別 学習時間の目安

新設区分には、学習者の合格実績に基づく標準時間をまだ示せません。本節では合格までの所要時間ではなく、最初に時間を割り当てる順序を示します。

| 現在の理解 | 初回の学習枠で行うこと | 次の枠の配分 |
| --- | --- | --- |
| 用語がほぼ初見 | シラバスの一つの中分類を読み、分からない語を記録する | 用語の意味と具体例に使う |
| 用語は分かるが判断を誤る | サンプルの正答理由と、自分の判断を比較する | 条件の読み取りと概念の使い分けに使う |
| 関連分野を学習済み | 既習範囲と新シラバスの差を確認する | 未学習の項目と誤答が残る範囲に使う |

「週に確保できる時間×残り週数」を先に出し、学習枠の実績で配分を修正します。20時間コースは学習の入口として、基礎なら[ITパスポート](/course/ip/)、データの取扱いなら[データマネジメント](/course/dm/)を使えます。20時間を合格所要時間とは扱いません。

## シラバス・ファーストと生成AIの活用

2026年10月時点の公式公開資料はシラバス案です。用語の一覧だけでなく、「目標とする知識・技能」を読み、何を説明・判断できる必要があるかを確認します。[IPA・新試験制度のシラバス案](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)

シラバスに載っていることと、頻出であることは別です。新設区分の過去問がない段階で、AIに頻出順位を推測させて学習範囲を削ることは避けます。出題形式を知る材料には、[IPAの公式サンプル問題](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260622.html)を使います。

### ツール別の役割分担（調査・添削・スケジュール）

複数のAIを使うこと自体を目標にせず、資料の確認、理解の対話、復習計画の3作業に分けます。普段使う一つのAIから始めて構いません。

| 作業 | AIに渡す材料 | 人が確かめること |
| --- | --- | --- |
| 公式資料の整理 | 区分名・資料名・版・該当箇所 | 新旧制度や案を混ぜていないか |
| 理解の確認 | 自分の説明と教材の根拠 | もっともらしい補足に資料の裏付けがあるか |
| 復習の計画 | 誤答した分野と実際に使えた時間 | 無理なく次の週に実行できるか |

以下は筆者が実行した元の設定メッセージです。複数AIを自動で連携させる指示ではありません。

```text
あなたはIPA試験対策の学習コーチです。
私は新試験制度に向けて学習します。次の役割で支援してください。
- ChatGPT: 類題生成と誤答分析
- Claude: 記述答案の添削
- Gemini: 公式情報の更新確認
毎日の学習計画を「60分版」で提案し、最後に今日の確認問題を3問出してください。
```

### Geminiで実行した結果

この設定メッセージを、Geminiで実行しました（2026年10月）。

60分の計画は、3つの段階に分かれて返ってきました。

| 段階 | 時間 | 内容 |
| --- | --- | --- |
| 公式情報の確認 | 5分 | IPAの公式サイト・試験要綱の変更点をチェック |
| インプットと類題演習 | 35分 | テキストの確認、類題演習、間違えた理由の分析 |
| 記述対策と添削 | 20分 | 記述式の答案を作り、自己採点して直す |

確認問題は次の3問でした（要約）。

> 1. DevSecOpsに関連して、セキュリティを開発の初期から組み込む考え方を何というか
> 2. 部分関数従属をなくし、非キー属性を候補キーに完全関数従属させる正規化は第何正規形か
> 3. クリティカルパス上の作業に資源を追加して、期間を短くする手法を何というか

答えは、1が「シフトレフト（セキュリティ・バイ・デザイン）」、2が「第2正規形」、3が「クラッシング」です。

> [!exp]
> 今回はGeminiで試しました。学習計画を出してもらったら、そのままカレンダーに登録することもできます。

使ってみると、気をつけたい点が2つあります。

1つ目は、役割分担の扱いです。Geminiは「ChatGPT・Claude・Gemini」の役割を、1つの会話の中の3つの段階に置き換えて計画を作りました。1つのAIがほかのAIを呼び出すわけではないので、類題はChatGPT、添削はClaude、と実際に使い分けるなら、それぞれのツールを自分で開きます。

2つ目は、試験区分です。確認問題は応用情報によく出る一般的な内容で、回答の最後に「どの試験区分か」を聞き返されました。最初の設定に「受ける区分：応用情報技術者試験」のように1行足すと、問題の範囲がしぼられます。


## 理論の習得がツール選択の武器になる

たとえばAIが説明したデータ品質の例を、そのまま覚えるだけでは、入力の誤りと分析方法の誤りを区別できないことがあります。自分で「何が問題で、どの対策が対応するか」を説明してから、資料と照合します。

理論を学ぶ目的は、AIの回答の採否を判断することにもあります。「資料に書かれている説明」と「理解のためのたとえ」を分けると、たとえを試験上の定義と取り違えにくくなります。

AIを使う能力がすべての区分で同じ形で採点される、とまでは言えません。学習目標は受ける区分のシラバスに戻して確認してください。

## CBT移行で試験の受け方も変わる

CBT対策では、知識の復習と、画面で問題を読み操作する練習を分けます。新制度の実施方式や開始時期は、2026年度の現行試験の予約条件をそのまま当てはめず、対象年度の発表を確認します。[IPA・制度見直しの案内](https://www.ipa.go.jp/shiken/minaoshi/index.html)

| 困っていること | 優先する準備 |
| --- | --- |
| 正答理由を説明できない | 教材に戻り、判断の根拠を一つずつ確認 |
| 内容は分かるが画面上で読み落とす | 公式の体験画面や操作案内で確認 |
| 会場・予約日が決まらない | 対象年度・区分の公式申込案内を確認 |

## まとめ

新IPA試験の勉強法は、区分の対象者像を選び、シラバス案と公式サンプルで必要な深さを確認し、自分の誤答で時間配分を変える順序で組み立てます。

まず区分名、資料の版、説明できない項目を一つのメモにしてください。AIとの対話は、その項目を自分の言葉で説明し直すために使います。
