「感触は悪くなかったのに落ちた」——消防設備士乙6の不合格でいちばん多いのが、このパターンです。

結論：消防設備士乙6は<strong>合計点で6割取れても、科目ごとに40%未満の分野が一つでもあれば不合格</strong>になる試験です。本記事では、自己採点だけでは見えない足切りの原因を、生成AIに診断させて特定する方法を解説します。

## なぜ「感触は悪くなかった」のに落ちるのか

消防設備士乙6の合格基準は、単純な合計6割ではありません。

1. 筆記試験で<strong>科目ごとに40%以上</strong>、かつ全体で60%以上
2. さらに実技（鑑別）で<strong>60%以上</strong>

乙6の筆記は「法令10問・基礎的知識5問・構造機能15問」の3科目に分かれています。問題数の少ない<strong>「基礎的知識」（5問）は1問の重みが大きく</strong>、法令や構造機能でどれだけ得点していても、基礎的知識で2問しか取れなければ40%未満で不合格になります。

「全体では6割取れていたはずなのに落ちた」という違和感の正体は、ほとんどの場合この<strong>科目別足切り</strong>です。合計点しか見ていない自己採点では、この構造に気づけません。

## 自己採点で見るべき3つの数字

再挑戦の前に、前回の結果を次の3つの視点で見直してください。

- <strong>科目ごとの正答率</strong>：法令・基礎的知識・構造機能それぞれで40%を超えていたか
- <strong>実技（鑑別）の得点率</strong>：5問中何問取れていたか（60%＝3問以上が必要）
- <strong>落とした問題の分野</strong>：同じ分野で複数落としていないか（弱点の偏りの有無）

合格通知や成績通知に科目別の点数が明記されていない場合でも、<strong>自己採点した際に解答用紙の控えがあれば、科目ごとに集計し直す</strong>ことで足切りの有無を推定できます。

## AIに模試結果を診断させる

過去問や模試を解いた後、正誤の記録を生成AIに渡して<strong>足切りリスクの診断</strong>をさせると、弱点科目が数値で可視化されます。

```text
あなたは消防設備士乙6類の学習コーチです。
以下は模試の科目別正答数です。合格基準（科目ごと40%以上・全体60%以上・実技60%以上）に照らして、
足切りのリスクがある科目を診断してください。

# 模試結果
- 法令：10問中7問正解
- 基礎的知識：5問中2問正解
- 構造機能：15問中10問正解
- 実技（鑑別）：5問中3問正解

診断してほしいこと：
1. 各科目が40%の足切りラインを超えているか
2. 最も優先して復習すべき科目はどこか
3. その科目に絞った1週間の復習プランを1つ提案してください
```

この診断を毎回の模試のたびに行うと、<strong>「合計点は伸びているのに、特定の科目だけ足切りラインに達していない」</strong>という自分では気づきにくい傾向が見えてきます。

## 「基礎的知識」で落ちるパターンへの対処

基礎的知識は問題数が少なく、力学・計算問題への苦手意識から後回しにされがちな科目です。しかし1問あたりの重みが最も大きいため、<strong>捨て科目にできない科目No.1</strong>です。

```text
消防設備士乙6の「基礎的知識」分野が苦手です。
力学・計算問題のどこでつまずいているか、
以下の問題の解き方をステップバイステップで教えてください。
数式の意味（なぜこの公式を使うのか）から説明してください。

【問題文をここに貼り付ける】
```

計算問題は「公式を覚える」より「なぜその公式を使うのか」から理解した方が、少ない問題数でも安定して得点できるようになります。

## 実技（鑑別）で落ちている場合

科目別の足切りはクリアしているのに実技で不合格になっている場合は、記述式の解答が<strong>名称は合っているが機能・理由の説明が不足</strong>している可能性があります。この場合は、[鑑別×AI連想学習の攻略法](/method/shobo-setsubi-kanbetsu-ai-hack/)で解答の型そのものを見直すことをおすすめします。

## 「法令」科目で失点している場合

法令は暗記量が多く、数字を丸暗記しただけでは応用問題に対応できません。<strong>数値そのものではなく、その数値が定められている理由</strong>から確認すると定着しやすくなります。

```text
消防設備士乙6の法令問題で、設置基準の数値（延べ面積・階数の条件など）を
覚えても応用問題で間違えてしまいます。
以下の設置基準について、「なぜこの数値なのか」という背景を含めて説明してください。
その上で、似た数値の条件が複数ある場合の見分け方も教えてください。

【設置基準・問題文をここに貼り付ける】
```

### 次回受験に向けたセルフチェックリストを作らせる

再挑戦の前に、前回落とした分野を踏まえたチェックリストを作ってもらうと、直前期の見直しが漏れなく進みます。

```text
消防設備士乙6を一度受験し、以下の科目で足切りに近い点数でした。
再受験に向けて、直前1週間で確認すべきセルフチェックリストを作ってください。

# 前回の弱点科目
- 基礎的知識：40%ギリギリだった
- 実技（鑑別）：3問/5問正解

チェックリストには、各項目を「理解している／怪しい／分からない」の
3段階で自己評価できる形式にしてください。
```

## AIハックポイント

模試を受けるたびに、上記の診断プロンプトへ結果を貼り付けて<strong>科目別の推移を記録</strong>していくと、「前回は基礎的知識が原因だったが、今回は構造機能に弱点が移った」といった変化にも気づけます。合計点だけを見ていては分からない、足切り構造への対応力が身につきます。

## まとめ：合計点ではなく科目別で診断する

消防設備士乙6の不合格は、多くの場合「感触が悪かった」からではなく、<strong>特定の科目が40%の足切りラインに届いていなかった</strong>ことが原因です。自己採点は合計点だけでなく科目ごとに集計し、生成AIに診断させることで、次の学習で何を優先すべきかが明確になります。

全体の学習計画に立ち返りたい場合は、[消防設備士 完全攻略ガイド](/method/shobo-setsubi-hub/)で二重足切り構造からもう一度確認してください。
