情報処理安全確保支援士（SC）の科目Bは自由記述式で、参考書を何周してもサイト側では採点できない。結論から言えば、<strong>AIを「模範解答を書く講師」ではなく「自分の答案を編集する添削者」として使う</strong>と、独学でも実務経験を試験の型に磨き上げられる。本記事では、連続起業家ダン・マーテル氏が提唱する自己学習フレームワーク「[S.E.L.Fループ](/method/self-loop-ai-learning/)」を科目B対策に応用したループと、学習の方向性そのものに迷っている人向けの自己診断プロンプトを紹介する。

## なぜ科目Bは「添削」が効くのか

SCの技能項目は、そのほとんどが「〜について、必要な指導・助言を行い、支援する」という文体で書かれている。つまり科目Bで問われているのは、知識の暗記ではなく<strong>組織のセキュリティ推進を指導・助言する立場としての振る舞い</strong>だ。

ここで陥りやすいのが、AIに「模範解答を書いて」と頼んでしまうことだ。模範解答を読んで満足しても、本番で同じ文章は書けない。実務経験者にとって本当に必要なのは、<strong>自分がすでに持っている実務知識を、採点者に伝わる形に翻訳する練習</strong>であり、それはAIに書かせるのではなく、AIに添削してもらうことでしか身につかない。

## 科目B（記述式）のS.E.L.Fループ

[S.E.L.Fループ](/method/self-loop-ai-learning/)は、①テーマを選ぶ（Select）→②AIで要点を抽出する（Extract）→③自分の状況に当てはめて実践する（Live）→④フィードバックで固める（Forge）という4段階のフレームワークだ。科目B対策では、次のように読み替える。

- <strong>S（Select it）</strong>: [SC 20時間コース第12章](/course/sc/12-practice-casestudy/)の技能31項目、または過去問から、1つのケースを選ぶ
- <strong>E（Extract it）</strong>: AIに、そのケースで採点者が見ているであろう論点を構造化させる
- <strong>L（Live it）</strong>: 論点を見ながら、自分の実務経験を交えて再現答案を実際に書く
- <strong>F（Forge it）</strong>: 書いた答案をAIに添削してもらい、抜け落ちている視点を指摘してもらう

### 論点抽出プロンプト（Select → Extract）

模範解答を先に読んでしまうと、本番でその文章をなぞろうとしてしまう。先に論点だけを構造化してもらい、答案は自分の言葉で書く。

```
あなたは情報処理安全確保支援士（SC）試験、科目B（記述式）の採点者です。

次のケースについて、模範解答は書かずに、採点者が答案のどこを評価するかという「論点」だけを整理してください。

【ケース】
（ここに過去問、または第12章のケーススタディから選んだ場面を貼り付ける）

以下の形式で整理してください。

1. このケースで支援士に求められている役割（指導する相手は誰か、何を判断すべき場面か）
2. 答案で必ず触れるべき論点を3〜5個、箇条書きで
3. 実務経験があっても見落としがちな視点（法令・規程・他部門との調整など）
4. 加点される可能性が高い「具体性」のポイント（一般論で終わらせず、何を書くと差がつくか）

模範解答の文章そのものは書かないでください。あくまで論点整理までにとどめてください。
```

### 自己採点・添削プロンプト（Live → Forge）

論点を見ながら実際に答案を書いたら、次のプロンプトで添削してもらう。自分の実務経験に基づく答案であることを前提に、AIには「編集者」として動いてもらう。

```
以下は、情報処理安全確保支援士（SC）科目Bの練習問題に対して、私が実際に書いた答案です。

【ケースと論点】
（先ほどAIが整理した論点をここに貼り付ける）

【私の答案】
（自分で書いた答案をそのまま貼り付ける）

採点者の視点で、この答案を添削してください。

1. 論点のうち、答案で触れられているもの／抜けているものを整理
2. 抽象的な表現になっている箇所を指摘し、「もっと具体的に書くとしたら」の方向性だけ示す（文章を書き直さないでください）
3. 「指導・助言する立場」としての文体になっているか（作業者目線の記述になっていないか）を評価
4. 総合評価と、次に書き直すべき優先順位を1つだけ提示

模範解答は不要です。あくまで私の答案に対する添削としてフィードバックしてください。
```

このループを1つのケースにつき2〜3周（添削→書き直し→再添削）すると、自分の実務経験を試験向けの文体に変換する感覚がつかめてくる。慣れてきたら[第12章の技能31項目](/course/sc/12-practice-casestudy/)から別のケースを選び、同じループを回そう。

## 学習の方向性に迷っている人向け（中間スコア層）

[SC 20時間コース](/course/sc/)冒頭の25問診断テストで正解数が伸び悩んだ場合、単純に「知識が足りない」のではなく、<strong>実務経験のどの部分が試験範囲と噛み合っていないのか</strong>が言語化できていないことが多い。その場合は、答案添削の前に、まず学ぶべき方向性そのものをAIとの対話で掘り下げるとよい。

```
あなたは優秀なエグゼクティブコーチ兼、情報処理安全確保支援士（SC）試験の学習アドバイザーです。

私は情報処理安全確保支援士（SC）の学習を進めていますが、25問の自己診断テストで正解数が伸び悩み、何をどう学び直せばいいのか自分でもまだ言葉にできていません。

【対話の進め方】
1. 一度に複数の質問をせず、必ず1回につき1つだけ質問してください。
2. 答えにくい質問には、具体的な選択肢や例を添えて答えやすくしてください。
3. 私の返答を深掘りし、「それは具体的にどの業務の話か」「なぜそこで迷ったのか」を掘り下げてください。
4. 対話を通じて、次の3つを順番に明らかにしてください。
   - ①診断テストで間違えた問題に共通する傾向（知識不足なのか、実務用語との対応づけができていないのか）
   - ②普段の実務でセキュリティに関わる場面のうち、自信を持って説明できないもの
   - ③その2つを踏まえて、SC12章のうち優先して着手すべき章
5. 3つが出揃ったら、最後に「今の弱点の正体」と「最初に着手すべき章」を要約してください。

準備ができたら、まず最初の質問をしてください。
```

対話の中で浮かび上がった章は、[SC 20時間コース](/course/sc/)の該当章から着手すればよい。方向性が定まれば、あとは本記事前半の答案添削ループと組み合わせて、知識のインプットと科目Bの表現力を並行して鍛えていける。

## まとめ

SCの科目B対策で最も効果が高いのは、AIに答えを作らせることではなく、<strong>自分の実務経験を試験の言葉に翻訳する作業をAIに手伝わせる</strong>ことだ。

論点だけを先に整理させ、答案は自分の言葉で書き、書いた後にAIに添削してもらう——このS.E.L.Fループを回すほど、「指導・助言する立場」としての文章が自然に書けるようになる。学習の方向性そのものに迷っている場合は、答案を書く前にまず対話で弱点の正体を言葉にしてから始めよう。

全体の攻略ルートは[情報処理安全確保支援士（SC）完全攻略ガイド](/method/sc-hub/)にまとめている。
