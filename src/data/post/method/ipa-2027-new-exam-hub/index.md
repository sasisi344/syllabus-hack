2027年度のIPA新試験を受けたいのに、新しいシラバスに合う教材が見つからず、何から始めるか迷っていませんか。

教材を選ぶ手がかりは、受けたい区分のシラバス案と、その範囲を学べるコースの対応関係です。

この記事では、シラバス案9本に対する無料コース・演習の入口と、準備中の範囲を並べます。

読み終えたら、自分が使う教材を選び、IPAのサンプル問題へ進む順番を決められます。

## 2027年度の新試験で何が変わるか

IPAの新試験制度は<strong>2027年度から開始予定</strong>です。ITパスポート（IP）・情報セキュリティマネジメント（SG）・基本情報技術者（FE）は変更を伴って続き、データマネジメント試験（DM、仮称）が新設される予定です。[IPAの制度見直し案](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

応用情報と、情報処理安全確保支援士（SC）を除く高度試験は、プロフェッショナルデジタルスキル試験（PD、仮称）へまとめ直される予定です。以下の表も予定として読み、区分ごとの具体的な実施日・申込期間はIPAの発表で確認してください。[IPAの制度見直し案](https://www.ipa.go.jp/shiken/syllabus/henkou/2025/20260331.html)

| 区分 | 新制度での扱い |
| --- | --- |
| IP・SG・FE | シラバス等の変更を伴って継続予定 |
| DM（仮称） | 新設予定 |
| PDのマネジメント／データ・AI／システム（いずれも仮称） | 応用情報・高度試験を再編して新設予定 |
| SC | 一部を変更して継続予定 |

2026年11月時点、学習の基準となる公開資料はシラバス<strong>案</strong>で、内容が変わる可能性があります。制度の詳しい説明は[2027年度のIPA試験再編](/trend/ipa-2027-restructuring/)、今年受けるか待つかは[CBT化と新制度の判断ガイド](/method/cbt-2026-syllabus-complete-guide/)へ進んでください。[IPAのシラバス案掲載ページ](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html)

区分自体がまだ決まらない場合は、[区分選びと学習計画の立て方](/method/new-ipa-exam-study-strategy/)を先に確認すると、次のコース選びがしやすくなります。

## 入門の対策：IP・SG・FE

IT全般の基礎から始めるなら、[IPの20時間コース](/course/ip/)が入口です。経営・DX・IT基礎・データとAI・セキュリティを8章に整理し、16問の診断から学習ルートを決められます。

部門の情報セキュリティ担当になった方や、IPの次に進む方には、[SGの20時間コース](/course/sg/)があります。こちらも8章・16問の診断付きで、脅威や対策を、管理体制・法務・実務の判断へつなぎます。

両コースとも、診断30分・章学習18時間・総復習90分で20時間が目安です。診断後は案内された章を学び、正解しても理由を説明できない内容は、その節へ戻って確認しましょう。

FEを受ける方は、上表の学習hubで進め方を確認し、演習で説明できない分野を拾います。<strong>FEの20時間コースはまだありません</strong>。IP・SGのコースでFE全体を学べると扱わず、FEのシラバス案に照らして教材を選んでください。

## 新設のデータ系の対策：DM・PD-D

日常の業務でデータを扱う担当者には、[DMの20時間コース](/course/dm/)が向いています。8章でデータの管理・品質・統計・AI利活用などを学び、最後は実務ケーススタディへ進む構成です。

DMは10問の診断付きです。初めてなら標準20時間、IT・データ実務の経験があれば実務者12時間の進め方を確認し、診断で弱かった章と、統計の計算例題・実務の章を重点的に使えます。

データ基盤や分析、AI活用を支える設計まで学びたい方には、[PD-Dの20時間コース](/course/pd-d/)があります。8章でデータ管理・品質、基盤とクラウド、統計、データベースとSQL、機械学習、生成AI・AIエージェントを扱い、実務ケースで結び付けます。

PD-Dは16問の診断と総復習を含む設計です。経験に応じて次の進め方を選び、得意な技術だけで学習を終えないようにします。

| PD-Dの学習パターン | 時間の目安 | 重点的に進める章 |
| --- | --- | --- |
| 標準：データ・AIの実務が初めて | 20時間 | 診断→第1〜8章→総復習 |
| データエンジニア・DB経験者 | 12時間 | 診断→第1・2・4・7章→第8章→総復習 |
| 分析者：集計・分析・BIの経験がある | 12時間 | 診断→第1・2・3・5・7章→第8章→総復習 |
| AI実務者：開発・導入の経験がある | 12時間 | 診断→第1〜5章→第8章→総復習 |

まずは診断を受け、自分の経験と合うパターンを選びましょう。これらの時間はコースを使う配分で、合格までに必要な時間の予測ではありません。

## PDのマネジメント・システムの対策

組織の変革やプロジェクトの管理を学ぶなら、[PD-Mの20時間コース](/course/pd-m/)へ進みます。8章で経営戦略・サービス管理・プロジェクト管理・ガバナンスを整理し、実務ケースで管理者としての判断を考えます。

システムの設計・実装・運用を学ぶなら、[PD-Sの20時間コース](/course/pd-s/)が入口です。8章でクラウド・ネットワークなどの基盤から開発工程・方法論へ進み、AI駆動開発と実務ケースも扱います。

どちらも10問の診断と総復習があり、標準20時間・実務者12時間の進め方を用意しています。診断で弱点を確認し、PD-Mはサービス・プロジェクト管理、PD-Sは開発工程・方法論・AI駆動開発を中心に、自分が説明できない部分へ戻ってください。

両コースは科目A-2（専門知識）・科目B（技能）を対象とし、科目A-1は含みません。応用情報・高度試験との関係から選びたい方は、[応用情報・高度試験と新試験の選び方](/method/advanced-ipa-hub/)を確認してください。

## セキュリティの対策：SCと科目A-1

セキュリティの知識を整理し、弱点に時間を配分したい方には、[SCの学習コース](/course/sc/)があります。12章を25問の診断で確認し、脅威・管理策・認証・実装技術などの苦手な章を選んで学びます。

SCの20時間は<strong>コース全体ではなく、苦手な1章に最大20時間をかける配分</strong>です。経験が浅い場合は専門知識の章を順に学び、実務ケースへ進む案内があります。

診断後は理由を説明できない章へ戻り、総復習で確認してください。仕上げの演習でも、既知の用語を選べることと、場面に合う対策を説明できることを分けて振り返ります。

科目A-1（共通知識）のシラバス案は、SCやPDの専門分野とは別に確認が必要です。当サイトの専用対策は準備中で、各コースの範囲外です。コースに関連する基礎知識があっても、科目A-1を網羅する教材としては扱いません。

コースの後は、次の順番で使うと、知識と判断のどちらを補うべきか整理できます。

1. コースの総復習を終え、理由を説明できなかった分野をメモする。
2. 受けたい区分のサンプルを解く。DMは科目Aで知識を確かめてから科目Bへ、PD・SCは科目Bで場面に応じた判断を考える。
3. 自分の解答理由をシラバス案の項目と対応づけ、説明できない内容の章へ戻る。

サンプルは新分野・形式のイメージを共有する資料であり、本試験と同じ作成・チェックの過程を経たものではありません。サンプルだけから頻出分野や本番の難しさを決めつけないようにします。[IPAのサンプル問題の注記](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260622.html)

教育目的など制度の意義に反しない使い方であれば、問題集・テキストでの利用に許諾や使用料は不要とされ、出典の明記が求められています。教材として利用するときは出典を書き、IPAの利用条件を確認してください。[IPAの利用に関する注記](https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260622.html)

## AIを専任講師にする学習プラン

### AI活用で専任講師を月額20ドルで雇う感覚

同じ疑問を繰り返し聞ける生成AIは、専任講師に相談するように使えます。見出しの「月額20ドル」は学び方の比喩であり、特定サービスの現行料金を示すものではありません。

たとえばDMなら「データ品質の問題と分析方法の問題はどう見分けるか」、PD-Dなら「データ基盤の経験はあっても、ガバナンスの説明が抜けていないか」を相談できます。PD-M・PD-Sなら、自分が知っている管理・開発の手順を、コースの学習目標に当てはめる使い方ができます。

AIには答えを覚えさせてもらうより、<strong>自分の説明のどこが曖昧かを質問してもらう</strong>と、読み直す節を選びやすくなります。以下のプロンプトには、使うシラバス案の版とコースの目次を添えてください。

【受験したい区分】（未定でも可）

### 現場経験者向け

実務でできることを、そのまま試験範囲の習得済み判定にしないのが出発点です。業務の説明とシラバス案の中分類を対応づけ、自分で理由を説明できない箇所を見つけます。
