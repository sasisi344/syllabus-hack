AIを使ったサイバー攻撃や情報漏えいのニュースが、2026年に入って目立つようになりました。

職場でセキュリティ研修が増えた、会社から情報セキュリティマネジメント試験（SG）を受けるように言われた。

そんなきっかけでSGに興味を持ったものの、「未経験の自分には難しいのでは」と不安になっていませんか。

<strong>SGが簡単かどうかは、日頃のセキュリティ意識で大きく変わります。</strong>

この記事では、SGが「簡単なほう」と言われる理由と、簡単にはいかない人の条件を整理します。

読み終えたときには、自分がどのくらいの期間で、何から学べばいいかを判断できるようになります。

---

## SGは出題範囲が狭く簡単なほうと言われる理由

SGは、ITパスポートと同じくIPA（情報処理推進機構）が実施する国家試験です。

IPAの試験の中では、ITパスポートと並んで<strong>出題範囲が狭い</strong>試験にあたります。

基本情報技術者（FE）とは異なり、アルゴリズムやプログラミングの出題もありません。

その代わりに問われるのは、社内で起こり得るインシデント（情報漏えい、マルウェア感染など）への対応といった「マネジメント」の考え方です。

だから、普段からセキュリティに興味がある人にとっては、<strong>すでに知っていることが多く出題されます。</strong>

たとえば、次のような知識です。

- 不審なメールの添付ファイルを開かない理由
- パスワードの使い回しが危ない理由
- 社外にデータを持ち出すときのルール

日頃から情報にアンテナを張っている人なら、SGは比較的取り組みやすい試験です。

では、どんな人にとっては簡単にいかないのでしょうか。

## 未経験の非エンジニアが簡単にいかない理由

一方で、<strong>非エンジニアで、セキュリティやネットワークについて何も知らない</strong>場合は話が別です。

SGの問題文には、「サーバー」「ネットワーク」「暗号化」「認証」といった前提の用語が当たり前に出てきます。

この前提がないと、問題を解く前に、問題文を読むところで止まってしまいます。

出題範囲が狭いことと、自分にとって簡単であることは別の話です。

ただ、試験を受ける必要がある、合格する必要があるという人にとって、これは「無理」という意味ではありません。

前提の用語から順に積み上げれば、未経験からでも合格を目指せます。

では、自分はどこから始めればいいのでしょうか。

## あなたの現在地から選ぶ3つのルート

SGは <strong>CBT方式（通年受験）</strong> のため、自分のペースで学習と受験の時期を決められます。

ただし、ITの知識がどのくらいあるかで、学習の進め方と期間が変わります。

### セキュリティもネットワークも知らない（約2ヶ月以上）

PCの仕組みやIT用語に馴染みがない場合は、いちばん時間がかかります。

まずは「サーバーって何？」「ネットワークって何？」という基礎から学びましょう。

AIに「身近な例え話で」と指定して、用語を1つずつ噛み砕いていくと進めやすくなります。

この段階の方は、無料の<a href="/course/sg/">情報セキュリティマネジメント20時間コース</a>で、知識の全体像を先につかんでおくのがおすすめです。

### ニュースで用語を聞いたことがある（約1ヶ月〜）

普段からネットに触れ、「マルウェア」や「フィッシング詐欺」という言葉を聞いたことがあるレベルです。

概要はなんとなく理解できているため、すぐに問題演習に入れます。

過去問やアプリを解きながら、曖昧な用語だけをAIに質問して理解を固めていきましょう。

### ITパスポート（IP）合格者（数週間〜）

ITパスポートに合格しているなら、SGの科目Aの基礎はすでにできています。

「情報セキュリティ」と「マネジメント・法務」の項目に絞って学び、早めに科目B対策へ進みましょう。

## 受験のタイミングはアプリで正答率80%

CBT試験で迷いやすいのが、「いつ本番を受ければいいのか」という受験のタイミングです。

目安として、<strong>SG対策アプリや過去問で、安定して正答率80%以上を出せるようになったら</strong>受験を検討しましょう。

本番の合格ラインは60%なので、80%を出せていれば、本番の緊張や初見の問題にも余裕を持って対応できます。

80%を超えたら、先延ばしにせず受験予約を入れてしまうのがおすすめです。

## 科目A（知識問題）は用語を理解に変える

科目Aは、セキュリティやIT全般の知識を問う四肢択一の問題です。

出題範囲はITパスポートと重なる部分も多くあります。

見慣れないセキュリティ用語（クロスサイトスクリプティング、WAF、PKIなど）は、テキストで丸暗記しようとすると挫折しがちです。

<strong>用語の意味と、ほかの用語との関係をセットで理解する</strong>と記憶に残ります。

AIには、次のように聞いてみましょう。

```
WAF（Web Application Firewall）とファイアウォール、IDS/IPSの違いがわかりません。
現実世界の「お城の防衛」に例えて、それぞれが何を守っているのかを説明してください。
```

例え話で役割の違いをつかんでから問題に戻ると、選択肢の違いが読み取れるようになります。

科目Aは過去問に似た問題が多く出るので、<strong>同じ分野のドリルを繰り返して、用語を見た瞬間に意味が思い浮かぶ状態</strong>を目指します。[科目Aのアプリ](/app/sg-quiz/)では、ストラテジ系・マネジメント系・テクノロジ系・実務の分野別に解けます。

間違えた問題は、解答後の「AIにもっと詳しく聞く」で、なぜほかの選択肢が不適切なのか、実際の職場ではどんな規程や技術的対策で運用されているのかを聞いてみてください。正解の根拠まで確認できると、言い回しが変わった問題にも対応しやすくなります。

## 科目B（ケーススタディ）は担当者になったつもりで解く

SGでいちばんの難関が科目Bです。

企業で起きたサイバー攻撃や社内不正のシナリオを読み、「どの規程に違反しているか」「どう対処すべきか」を答える長文読解問題です。

過去問を数問解いてパターンをつかんだら、AIに似たケーススタディを作ってもらいましょう。

```
あなたは情報セキュリティマネジメント試験の作問者です。
「ランサムウェア感染」をテーマにした、科目Bレベルのケーススタディ問題を1問作成してください。
社員の不注意なメール開封からインシデントが発生するシナリオとし、設問は「対応の初動として正しいものはどれか」としてください。
最後に、正解の理由と、ほかの選択肢が誤りである理由も説明してください。
```

<strong>架空の会社のセキュリティ担当者になったつもりで解く</strong>と、長文の状況を把握する力がついてきます。

読むときは、シナリオの中から「脆弱性」と「脅威」を見つけ、情報セキュリティマネジメントの観点でふさわしい「管理策」を選ぶ流れを意識します。<strong>「誰が、何のために、どのルールに基づいて」行動すべきか</strong>をたどると、選択肢を絞りやすくなります。[科目Bのアプリ](/app/sg-subject-b-quiz/)で、実際にシナリオを読みながら試せます。

AI攻撃や情報漏えいのニュースを見たときに「自分の会社ならどう対応するか」を考えるのも、そのまま科目Bの練習になります。

## まとめ

SGは出題範囲が狭く、日頃からセキュリティに関心がある人にとっては簡単なほうの試験です。

一方で、非エンジニアでセキュリティやネットワークを何も知らない場合は、前提の用語から積み上げる必要があります。

これで、自分がどのルートから始めて、どのくらいの期間を見込めばいいかを判断できるはずです。

SGは単語テストではなく、「もし自社で情報漏えいが起きたらどうするか」という危機管理の考え方を証明する資格です。

まずは今の実力を測るところから始めてみましょう。
