記述式や論文の問題を練習していて、「この答案で点がもらえるのか、自分では判断できない」と感じていないでしょうか。

資格試験は、難易度が上がるほど記述式や論文の問題が増えていきます。1問あたりの配点も大きいので、できるだけ正解に近い答案を書きたいところです。

けれど記述式は、数学の証明問題と同じように、<strong>説明の仕方によって正解がいくつも存在する</strong>特殊な問題です。解答例が手元にあっても、自分の答案と言い回しが違えば、それが正解なのかどうかを判断するのは難しくなります。

分かれ目は、解答例と一字一句そろえることではなく、<strong>自分の答案を外の目で採点してもらい、より伝わる説明の仕方を学べるかどうか</strong>です。

この記事では、記述式の採点が難しい理由を整理したうえで、生成AIに採点とより良い説明の仕方を教えてもらう練習法を、実際に記述式がある試験を例にしたプロンプトで紹介します。

## 記述式は、難易度が上がるほど増え、1問が重い

選択式の試験では、知識があれば正解の選択肢を選べます。一方、記述式では、知識を自分の言葉で組み立てて説明する力が問われます。そのため、上位の資格ほど記述式や論文の比重が大きくなります。

| 試験 | 記述式・論文の形 |
| --- | --- |
| 応用情報技術者 | 午後の問題で、数十字程度の記述を求める設問が多い |
| IPAの高度試験（ITストラテジスト、プロジェクトマネージャなど） | 自分の経験をもとに、設問に沿って書く論文 |
| 行政書士 | 40字程度で答える記述式の問題 |
| 中小企業診断士（2次試験） | 企業の事例を読み、助言や分析を文章で答える |

いずれも1問ごとの配点が大きく、記述式の出来が合否を左右します。

### 解答例があっても、自己採点が難しい

記述式の答えは、同じ内容でも書き方がいくつもあります。市販の問題集でも、同じ問題の解答例が本によって違うことがあります。IPAの高度試験の論文のように、そもそも解答例が公開されず、出題の趣旨と採点講評だけが公開される試験もあります。

自分の答案と解答例の言い回しが違うとき、「要素は入っているから正解」なのか「論理が足りないから部分点」なのかを、自分で判断するのは簡単ではありません。

では、その判断を誰に頼めばいいのでしょうか。

## AIに採点してもらうと、説明の仕方まで教えてもらえる

添削のサービスや講師に頼めれば理想的ですが、費用も時間もかかります。そこで使えるのが、生成AIです。

AIに採点を頼むと、点数をつけるだけでなく、次のようなことまで説明してくれます。

- 設問が求めている要素のうち、答案に入っているものと足りないもの
- 論理が飛んでいる部分と、そこを埋める書き方
- 同じ内容を、より短く、より伝わる形で書いた例

正解がいくつもある問題だからこそ、「自分の答案のどこを、どう直せばよくなるか」を具体的に教えてもらえることに価値があります。

ただし、AIの採点は本物の採点基準ではありません。点数そのものより、<strong>指摘された足りない要素と、説明の仕方の改善点</strong>に注目して使ってください。

### 採点を頼む前に、材料をそろえる

AIの採点の精度は、渡す材料で変わります。

- 問題文と設問（長い場合は要約でもよい）
- 公開されている解答例、出題の趣旨、採点講評（あれば）
- 自分の答案
- 制限字数

解答例や採点講評があれば一緒に渡すと、AIはそれを基準に採点できます。ない場合は、「採点基準を先に作ってから採点して」と頼みます。

では、試験ごとのプロンプトを見ていきます。

## 試験別の練習プロンプト

### 応用情報技術者（午後の記述）

```text
応用情報技術者試験の午後問題の記述式答案を採点してください。

【問題文の要約】
【設問】（制限字数：**〇〇字**）
【IPAの解答例】（あれば）
【私の答案】

次の順で答えてください。
1. 解答例と比べて、**入っている要素**と**足りない要素**
2. 問題文の状況から答えまでの論理に、飛躍がないか
3. 10点満点での採点と、その理由
4. 制限字数の中で、より伝わる書き方の例を1つ
```

答えの形がひとつではない理由と、要素と論理で答案をつくる考え方は、[応用情報の記述式で点が取れない理由](/method/ap-grader-blackbox-hack/)で詳しく扱っています。

### IPAの高度試験（論文）

```text
IPAの高度試験（**〇〇試験**）の論文を練習しています。
出題の趣旨と採点講評、私の論文を貼ります。

採点の前に、出題の趣旨と採点講評から**採点の観点**を3〜5個書き出してください。
そのうえで、
1. 設問のア・イ・ウそれぞれに、過不足なく答えているか
2. 自分の経験に基づく**具体的な状況・数値・判断の理由**が書かれているか
3. 一般論だけで終わっている段落はどこか
4. A〜Dの4段階での評価と、Aに近づけるために書き足すべき内容
を指摘してください。褒めるより、足りない点を優先してください。
```

論文では、AIに本文を書かせるのではなく、自分の経験を書いた答案の弱いところを指摘してもらう使い方にとどめます。経験の中身は、自分にしか書けません。

### 行政書士（40字の記述）

```text
行政書士試験の記述式の問題を練習しています。
【問題文】
【私の答案】（40字程度）

1. 問題が求めている**法律上の要件や効果**が答案に入っているか
2. 必要なキーワードが抜けていないか
3. 40字程度に収めた、より正確な答案の例
を示してください。根拠となる条文の考え方も一言添えてください。
```

短い字数で答える問題は、要素の抜けがそのまま失点になります。何が入っていれば点になるのかを、AIとのやりとりで確かめます。

### 中小企業診断士（2次試験の事例）

```text
中小企業診断士の2次試験（事例**〇**）の練習をしています。
【与件文の要約】
【設問】（制限字数：**〇〇字**）
【私の解答】

1. 与件文のどの記述を根拠にしているか、根拠が足りない部分はどこか
2. 設問の問いかけ（例：「助言せよ」「理由を述べよ」）に正しく答えているか
3. 字数内で、要素を多く盛り込んだ別の書き方の例
を示してください。
```

## AIの採点を、次の答案に活かす

採点してもらったら、そこで終わりにせず、次の手順で書き直します。

1. 指摘された「足りない要素」を書き出す
2. 自分の言葉で答案を書き直す（AIの模範例をそのまま写さない）
3. 書き直した答案を、もう一度採点してもらう

AIの模範例をそのまま覚えても、本番で同じ問題は出ません。大事なのは、<strong>何が足りなかったのかを知り、自分の言葉で書き直す</strong>ことです。この繰り返しで、どんな問題にも使える説明の型が身についていきます。

AIの採点にも誤りは混ざります。法律の要件や技術の内容で迷ったら、公式の解答例や採点講評、条文、テキストで確かめてください。

## まとめ

記述式や論文の問題は、試験の難易度が上がるほど増え、1問の配点も重くなります。説明の仕方で正解がいくつも存在するため、解答例があっても自己採点は簡単ではありません。

- 採点を頼むときは、問題文・解答例や採点講評・自分の答案・制限字数をそろえて渡す
- 点数そのものより、足りない要素と、より伝わる説明の仕方に注目する
- 模範例を写さず、自分の言葉で書き直し、もう一度採点してもらう

これで、解答例と言い回しが違う答案でも、どこを直せば点につながるのかを、AIとの練習で確かめられるはずです。

IPAの高度試験の全体像と論文の進め方は、[高度情報処理技術者試験 合格ロードマップ](/method/advanced-ipa-hub/)にまとめています。
