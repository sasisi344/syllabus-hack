応用情報を3ヶ月後に受けると決めたものの、範囲の広さに圧倒されていないでしょうか。

真面目な人ほど「全部やらなければ」と考えますが、応用情報は満点を取る試験ではありません。合格に必要なのは、科目A・科目Bともに6割です。

分かれ目は、どの問題を捨てるかを、勉強を始める前の自分の得点から決められるかどうかです。

この記事では、無勉強で過去問を解いて今の実力を測るところから始め、得意と苦手をはっきりさせ、6割を取るために何を伸ばして何を捨てるかを組み立てる手順を整理します。

読み終えたときには、3ヶ月の時間をどの分野に使うかを、自分の点数をもとに決められるはずです。

---

## 応用情報は6割で合格する試験

応用情報技術者試験は、科目Aと科目Bの2つの試験で構成されています。

| 試験 | 形式 | 試験時間 | 合格基準 |
|---|---|---|---|
| 科目A（旧 午前） | 四肢択一 80問 | 150分 | 60点以上（100点満点） |
| 科目B（旧 午後） | 記述式。11問から5問を解答（情報セキュリティは必須、残り10分野から4問を選択） | 150分 | 60点以上（100点満点） |

2026年度から応用情報はCBT方式（会場のパソコンで受ける方式）になり、「午前」は科目A、「午後」は科目Bに名前が変わりました。出題形式・問題数・配点・合格基準は変わっていません。科目Aが基準点に届かないと、科目Bは採点されません。

過去問は、2025年度までの「午前」「午後」の名前のまま公開されています。この記事で過去問を解くときは、午前＝科目A、午後＝科目Bと読み替えてください。

出典: [応用情報技術者試験｜IPA](https://www.ipa.go.jp/shiken/kubun/ap.html)、[応用情報技術者試験、高度試験及び情報処理安全確保支援士試験におけるCBT方式での実施について｜IPA](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc-cbt.html)

科目Bの選択分野は、経営戦略・プログラミング・システムアーキテクチャ・ネットワーク・データベース・組込みシステム開発・情報システム開発・プロジェクトマネジメント・サービスマネジメント・システム監査の10分野です。

どちらも、4割を落としても合格ラインに届きます。満点を目指す必要はなく、「6割を積み上げる」ことに考え方を切り替えるのが出発点です。

### 捨て問とは、理解が追いつかない問題に時間を使わないこと

この記事でいう「捨て問」は、勉強をサボるための言い訳ではありません。

<strong>3ヶ月の中でどうしても理解が追いつかない問題に、時間を使わない</strong>という判断のことです。1つの難問に10時間かけるより、その10時間で解ける問題を増やしたほうが、6割には早く届きます。

では、自分にとって「理解が追いつかない問題」はどれなのでしょうか。それは、勉強を始める前に一度、過去問を解いてみるとわかります。

## 最初の1週間は、何も勉強せずに過去問を解く

3ヶ月という期限があるなら、最初にやるべきことは参考書を開くことではありません。<strong>今の自分が、無勉強で何割取れるか</strong>を測ることです。

過去問は、IPAの公式サイトで無料で公開されています。

### 科目Aは1回分を通しで解く

科目Aの過去問を1回分（80問）、時間を計って解きます。わからない問題も、勘で選んでかまいません。

採点したら、分野ごとの正答率を書き出します。

| 分野 | 問題数 | 正解数 | 正答率 |
|---|---|---|---|
| テクノロジ系（基礎理論・アルゴリズム・コンピュータシステム・技術要素・開発技術） | | | |
| マネジメント系（プロジェクトマネジメント・サービスマネジメント・システム監査） | | | |
| ストラテジ系（システム戦略・経営戦略・企業と法務） | | | |

文系・未経験の場合、テクノロジ系は低く、ストラテジ系は思ったより取れる、という結果になることが少なくありません。

### 科目Bは11分野の問題文を読んでみる

科目Bは、いきなり全分野を解く必要はありません。1回分の過去問で11分野すべての問題文に目を通し、分野ごとに次の3段階で印をつけます。

- <strong>読める</strong>：何を聞かれているかがわかり、解答の方向がなんとなく浮かぶ
- <strong>読めるが答えられない</strong>：状況はわかるが、用語や知識が足りない
- <strong>読めない</strong>：問題文の状況そのものがイメージできない

印をつけ終えたら、「読める」分野だけでも実際に解いて、解答例と比べてみてください。

この1週間で、点数よりも大事なものが手に入ります。それは、自分の得意と苦手の地図です。

## 得意と苦手をはっきりさせる

捨て問戦略をとるなら、最優先は<strong>得意と苦手をはっきりさせておく</strong>ことです。ここが曖昧なままだと、捨てる問題も伸ばす分野も決められません。

診断の結果を、分野ごとに4つに分けます。

| 判定 | 状態 | 3ヶ月での扱い |
|---|---|---|
| ◎ 得点源 | 無勉強でも半分以上取れた・読めた | 過去問を回して取りこぼしをなくす |
| ○ 伸びしろ | 読めるが知識が足りない | 用語と典型パターンを入れれば点になる |
| △ 時間がかかる | 読めるが、理解に時間がかかりそう | 科目Aは頻出問題だけ拾う。科目Bでは選ばない |
| × 捨て候補 | 問題文の状況がイメージできない | 3ヶ月では時間を使わない |

### 文系が得点源にしやすい分野

科目Bの選択分野のうち、文系・未経験の人が◎や○になりやすいのは、次の4つです。

- <strong>経営戦略</strong>：企業の事例を読み、戦略や施策の意図を答える。文章を読む力がそのまま生きる
- <strong>プロジェクトマネジメント</strong>：スケジュールや体制、トラブル対応の話。仕事の経験が手がかりになる
- <strong>サービスマネジメント</strong>：ITサービスの運用ルールや障害対応。覚える用語が比較的少ない
- <strong>システム監査</strong>：業務の手順に足りない統制を指摘する。問われ方の型が限られている

ただし、これはあくまで「なりやすい」傾向です。診断で読めなかったなら、無理に選ぶ必要はありません。逆に、プログラミングやデータベースが意外と読めたなら、それはあなたの得点源です。

情報セキュリティは科目Bの必須問題なので、捨てる選択肢はありません。科目Aでも出題が多いため、どの判定であっても最優先で手をつけます。

自分の地図ができたら、次は3ヶ月の時間を、地図のどこに使うかを決めます。

## 苦手を伸ばすか、得意を盤石にするか

6割に届く道は、「苦手を伸ばす」か「得意を盤石にする」かの2つです。どちらを選ぶかは、無勉強の得点で決まります。

| 科目Aの無勉強の得点 | 優先すること |
|---|---|
| 4割未満 | 苦手の中でも頻出の分野（セキュリティ・マネジメント系・ストラテジ系）の底上げ。テクノロジ系の計算問題は後回し |
| 4〜5割 | 得意分野を盤石にしつつ、○（伸びしろ）の分野だけを伸ばす |
| 5割以上 | 科目Aは過去問を回して維持。浮いた時間を科目Bの記述練習に回す |

科目Bは、もっと単純です。<strong>◎と○の分野から、本番で選ぶ4分野と予備の1分野を決めます</strong>。

予備を持つのは、特定の分野の問題が難しくなる年があるからです。本番で問題文を見て「今年の経営戦略は読めない」と感じたら、予備の分野に切り替えます。逃げ道が1つあるだけで、本番の焦りが大きく変わります。

### 伸ばすか盤石にするかで迷ったら

迷ったときの判断基準は、「あと何時間で何点増えそうか」です。

×の分野を0点から6割にするより、○の分野を4割から7割にするほうが、ほとんどの場合は短い時間で済みます。苦手をゼロから育てるのは、合格したあとでも遅くありません。

では、得意な分野の中にも出てくる「捨ててよい問題」は、どう見分ければいいのでしょうか。

## 捨ててよい問題の見分け方

### 過去問の形をした問題は捨てない

どの試験にも出題の傾向があり、応用情報でも、過去問の数字や状況設定を変えた問題が多く出題されます。過去問で一度見た形の問題は、勉強すれば取れる問題です。苦手な分野でも、ここは捨てずに拾います。

### 見たことのない新しい問題は、時間を使わない

一方で、IT業界では新しい技術や用語が次々と生まれ、試験にも新しい論点が追加されていきます。

初めて出題された論点は、過去問で練習した人がいません。本当にわからない問題は、ほかの受験者の多くにとってもわからない問題である可能性が高いのです。

本番で見たことのない問題に出会ったら、焦らなくて大丈夫です。科目Aなら、迷ったら1つ選んで印をつけ、次の問題に進みます。全問を解き終えて時間が残っていれば、戻って考え直せばいい。

### 科目Aで5分以上かかる計算は後回し

科目Aの計算問題のうち、解き方は知っていても5分以上かかりそうなものは、後回しにします。1問に5分かけると、その間に暗記で解ける問題を3〜4問解けたかもしれないからです。

ここまでが「何を捨てるか」です。最後に、捨てずに取りにいく科目Bの記述で、どう点を積み上げるかを見ていきます。

## 記述式は模範解答にこだわらなくていい

科目Bの記述式で手が止まる人の多くは、「正しい答えを書かなければ」と考えています。

IPAが公開している解答例と一字一句同じである必要はありません。記述式は、設問が求めている要素が答案に入っているかで点がつく形式です。完璧な文章でなくても、伝えたいことが入っていれば部分点につながります。

- <strong>問題文の言葉を使う</strong>：答えの手がかりは、たいてい問題文の中にある。問題文に出てきた用語や状況を使って書く
- <strong>伝えたいことを先に書く</strong>：理由を聞かれたら、まず理由そのものを書く。前置きで字数を使わない
- <strong>空欄にしない</strong>：空欄は必ず0点になる。自信がなくても、感覚でいいから考えたことを書く

この考え方は、◎や○の分野ほど効いてきます。知識があるのに「うまく書けない」から失点していた分を、取り戻せるからです。

## 3ヶ月の配分

ここまでの手順を、3ヶ月の配分にまとめます。

| 期間 | やること |
|---|---|
| 1週目 | 無勉強で科目A1回分を解く。科目B11分野の問題文を読み、得意と苦手の地図をつくる |
| 1ヶ月目 | 情報セキュリティの基礎を固める。科目Aは頻出分野の過去問を回す |
| 2ヶ月目 | 科目Bで選ぶ4分野＋予備1分野の過去問を解き、解答例と比べて記述の型をつかむ |
| 3ヶ月目 | 科目A・科目Bを時間を計って通しで解く。得意分野の取りこぼしをなくすことに集中する |

2ヶ月目の途中で、選んだ分野がどうしても点にならないと感じたら、予備の分野と入れ替えてかまいません。地図は、勉強が進むにつれて書き換えていくものです。

## AIで診断と記述練習を回す

得意と苦手の地図づくりと、記述の練習は、生成AIを相手にすると一人でも進めやすくなります。

### 診断結果から戦略を組んでもらう

1週目の診断が終わったら、結果をそのままAIに渡して、3ヶ月の配分を一緒に考えてもらいます。

```text
応用情報技術者試験を3ヶ月後に受けます。文系・IT未経験です。

無勉強で過去問を解いた結果は次のとおりです。
- 科目A：**48点**（テクノロジ系30%、マネジメント系55%、ストラテジ系65%）
- 科目B：読めた分野＝経営戦略・プロジェクトマネジメント・システム監査
　　　　読めるが答えられない分野＝サービスマネジメント・データベース
　　　　読めなかった分野＝プログラミング・組込みシステム開発・ネットワーク

平日1時間、休日3時間勉強できます。
**科目A・科目Bともに6割**を取るために、
1. 科目Bで選ぶ4分野と予備の1分野
2. 伸ばす分野と、時間を使わない分野
3. 3ヶ月の週ごとの配分
を、理由とあわせて提案してください。
```

提案が「これは無理」と感じる配分なら、そのまま伝えて組み直してもらいましょう。勉強時間や得意分野の前提を変えるたびに、配分を何度でも作り直せるのがAIの強みです。

### 記述の答案を添削してもらう

科目Bの過去問を解いたら、自分の答案をAIに見てもらいます。

```text
応用情報技術者試験の科目B「経営戦略」の過去問を解きました。
問題文、設問、IPAの解答例、私の答案を貼ります。

私の答案について、
- 解答例と比べて、**入っている要素と足りない要素**
- 部分点がもらえそうかどうか
- 問題文のどの言葉を使えば、もっと伝わる答案になったか
を教えてください。言い回しが解答例と違うことは気にしなくてかまいません。
```

最後の一文がポイントです。言い回しの違いではなく、要素が入っているかに絞って見てもらうと、「模範解答どおりに書かなければ」という思い込みから離れられます。

AIの指摘にも誤りは混ざります。用語の定義や数値で迷ったら、IPAの解答例やシラバスに戻って確かめてください。

## よくある質問

<strong>Q. プログラミングは完全に捨ててもいいですか？</strong>

A. 診断で「読めなかった」なら、科目Bの選択から外してかまいません。ただし科目Aにはアルゴリズムの基礎的な問題も出るため、過去問で見た形の簡単な問題だけは拾えるようにしておくと安心です。

<strong>Q. 予備の分野まで準備する時間がありません</strong>

A. 予備は、選ぶ4分野と同じ深さで仕上げる必要はありません。過去問を2〜3回分解いて、問題の雰囲気に慣れておくだけでも、本番で切り替える判断ができるようになります。

<strong>Q. 診断の点数が低すぎて、3ヶ月では無理な気がします</strong>

A. 無勉強の点数は、伸びしろの大きさでもあります。点数そのものより、どの分野が「読める」のかを見てください。読める分野が4つあれば、科目Bの戦い方は組み立てられます。

## まとめ

応用情報の範囲の広さに圧倒されたら、まずは何も勉強せずに過去問を解いてみてください。捨て問戦略は、その点数から始まります。

- 応用情報は、科目A・科目Bともに<strong>6割</strong>で合格する
- 捨て問とは、3ヶ月では理解が追いつかない問題に時間を使わないこと
- 最初の1週間で、無勉強の得点と、分野ごとの得意・苦手の地図をつくる
- 無勉強の得点から、苦手を伸ばすか得意を盤石にするかを決める
- 過去問の形をした問題は拾い、見たことのない新しい問題には時間を使わない
- 記述式は解答例と同じ言い回しでなくていい。伝えたいことを空欄にせず書く

これで、3ヶ月の時間をどの分野に使い、どの問題を捨てるかを、自分の点数から判断できるはずです。

試験の全体像や科目B記述の対策は、[IPA資格の高難易度対策｜応用情報・高度試験と2027年の新試験の選び方](/method/advanced-ipa-hub/)にまとめています。
