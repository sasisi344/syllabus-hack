## 合格までの勉強時間

文系出身・社会人という条件では、標準よりも時間がかかることを前提に計画すべきだ。

| 学習経験 | 目安時間 |
|---|:---:|
| 数学・物理の基礎なし（文系） | 1,200〜1,500時間 |
| 高校理系レベルの復習込み | 1,000〜1,200時間 |
| 社会人で平日1時間・休日3時間確保 | 週11時間 → 1,200時間なら約2年ペース |

<strong>社会人が電験三種の受験者の3〜4割を占める</strong>という調査もあり、働きながらの受験自体は珍しくない。問題は時間の絶対量ではなく、<strong>「わからない箇所で止まったまま何時間も溶かしてしまうこと」</strong>だ。

### AI活用で専任講師を月額20ドルで雇う感覚

文系出身者が電験三種でつまずく最大の壁は、<strong>数式が「暗記対象」に見えてしまうこと</strong>だ。市販テキストは公式を並べるだけで、なぜその式が成立するのかという背景説明が薄い。

- 「なぜオームの法則がV=IRという形になるのか」を、水道管の水流に例えて説明してもらう
- 「キルヒホッフの法則」を、テキストの数式ではなく身近な図でゼロから教えてもらう
- 参考書の数式をスマホで撮影し「この式変形の意味を、途中式を省略せずに教えて」と渡す
- 同じ質問を3回しても怒られない。理解できるまで角度を変えて聞き直せる

生成AIを使えば、<strong>月額20ドル程度で、文系にも根気強く付き合ってくれる専任の電気理論講師を雇うようなもの</strong>になる。1,200時間のうち「詰まって立ち止まる時間」をゼロに近づけることが最大の効果であり、勉強時間そのものを半分にする魔法ではない点は誤解しないでほしい。

## 文系が電験三種でつまずく3つのポイント

理系出身者が「当たり前」として素通りする部分こそ、文系出身者が本当につまずく場所になる。

### 数式の意味より先に形を覚えようとしてしまう

文系の学習パターンは、英単語や年号のように<strong>「形をそのまま覚える」</strong>ことに最適化されている。しかし電験三種の数式は、意味を理解しないまま覚えると、少し問題文の条件が変わっただけで対応できなくなる。

### 単位の意味が体に入っていない

ボルト・アンペア・ワットが「何を測る単位か」を感覚的に理解していないまま計算問題に入ると、答えの桁がおかしくても気づけない。理系出身者は高校物理でこの感覚を無意識に獲得しているが、文系出身者はここを意識的に埋める必要がある。

### なぜこの科目がこの順番で出るのかがわからず迷走する

理論・電力・機械・法規の4科目は独立しているように見えて、実は<strong>理論が他の3科目の土台になっている</strong>。この構造を知らずに法規から手をつけてしまい、電力・機械で理論の知識不足に気づいて挫折するケースが多い。

## AIで数式を翻訳する具体的なプロンプト

文系出身者に最も効果があるのは、<strong>数式を身近な比喩に変換させる</strong>プロンプトだ。

```
私は電験三種の理論科目を勉強している文系出身の社会人です。
数学は高校1年レベルの知識しかありません。

以下の数式について、数式そのものを暗記させるのではなく、
「なぜこの形になるのか」を身近な例え（水の流れ、坂道など）を使って
段階的に説明してください。

対象の数式: [ここにテキストの数式を貼る、または写真を撮って渡す]

説明の最後に、この式を使って解ける典型的な試験問題のパターンも
1つだけ簡単に触れてください。
```

このプロンプトのポイントは、<strong>「解き方」ではなく「なぜその式なのか」を先に聞く</strong>ことだ。仕組みを理解してから公式を見ると、暗記の負担が大きく減る。

理解ができたら、次のプロンプトで自分の理解を検証する。

```
先ほど教えてもらった内容を、自分の言葉で説明してみます。
間違っている部分や、論理が飛躍している部分があれば指摘してください。

[自分の理解を書く]
```

<strong>教えてもらう→自分の言葉で説明する→添削してもらう、というループを回すこと</strong>が、暗記ではなく理解に変える最短ルートになる。

## 社会人が科目合格制度を使い切る計画の立て方

電験三種には<strong>3年以内に4科目すべてに合格すればよい科目合格制度</strong>がある。社会人がこの制度を最大限使うには、闇雲に4科目を1年で受けるのではなく、可処分時間から逆算した計画が必要だ。

```
私は電験三種を受験する社会人です。以下の条件で、
3年間の科目合格プランを作成してください。

- 平日1時間・休日3時間の学習時間が確保できる
- 数学・物理の基礎はほぼゼロ（文系出身）
- 1年目は基礎固めに時間を使いたい

理論・電力・機械・法規の4科目を、どの順番で・どの年度に受験すべきか、
理由も添えて提案してください。
```

一般的には<strong>「理論」を最初の年度に固める</strong>のがセオリーだ。理論は他の3科目の土台になるため、後回しにすると電力・機械の理解が浅いまま暗記に頼ることになる。AIに自分の条件を伝えて計画を作らせれば、この定石を自分の生活リズムに合わせて調整できる。

## まとめ

文系・社会人が電験三種に合格するための3原則：

<strong>1. 数式は「形」ではなく「意味」から理解する</strong>
AIに比喩で説明させ、暗記の負担を減らす。

<strong>2. 科目合格制度を可処分時間から逆算して使う</strong>
理論を最初の年度に固め、3年間で無理なく4科目を積み上げる。

<strong>3. 「詰まって立ち止まる時間」をAIでゼロに近づける</strong>
1,200時間という総量は変わらないが、無駄な停滞時間は大きく減らせる。
