ITパスポートや基本情報技術者試験で、生成AIに関する用語の出題が増えています。

ところが、生成AIの用語は、参考書が出る前に新しい言葉が生まれます。2026年の今は、編集している間にも、新しい用語や使われ方が次々に出てくる状況です。

そこで考えたいのは、固定のテキストを買い足し続ける学び方が、この分野に向いているのかということです。

先に言うと、<strong>生成AIの出題なのだから、生成AIに聞いて、自分用の用語ノートを育てていく</strong>やり方のほうが向いています。

この記事では、そのノートの作り方と、更新のしかたを説明します。最後に、ノートをツールに発展させて、ポートフォリオにする案も紹介します。

## 固定の参考書が追いつきにくい理由

生成AIの分野は、次のような特徴があります。

- 新しい技術や言葉が、試験の改訂より速く生まれる
- 同じ言葉でも、使われ方や説明が短い期間で変わる
- 定義よりも、用例（どう使われるか）で理解する言葉が多い

参考書は、出版の時点の情報を固めたものです。基礎になる用語は役に立ちますが、新しい用語や最近の用例は、載っていないか、古くなっていることがあります。

だからといって、参考書が不要というわけではありません。<strong>公式のシラバスと過去問は軸にして、新しい用語の補強を生成AIで回す</strong>、という分担が現実的です。

## 用語は5つの切り口で聞く

用語を覚えるときは、定義だけを聞くのではなく、次の5つの切り口で聞くと、試験の多様な出し方に対応しやすくなります。

| 切り口 | 聞くこと |
| --- | --- |
| 定義 | 一言で言うと何か |
| 仕組み | どうして、そうなるのか |
| 利点 | 何に役立つのか |
| リスク | どんな問題が起きるのか |
| 事例 | どんな場面で使われるのか |

生成AIには、次のように聞いてみてください。

```text
ITパスポートの試験対策として、「RAG」について教えてください。

- 定義、仕組み、利点、リスク、事例の5つの切り口で、それぞれ2〜3文でまとめる
- 似た用語（ファインチューニングなど）との違いを表にする
- 最後に、**試験で問われそうなポイント**を3つ挙げる
```

説明を読んだら、自分の言葉で言い直して、間違いがないかをAIに確認してもらうと、理解が深まります。

## 「間違い探し」で、理解を確かめる

用語を理解できたか確かめるには、AIに間違いを混ぜて説明してもらい、見つける練習が効果的です。

```text
「ハルシネーション」について、説明を3つ作ってください。
そのうち1つだけ、間違った内容にしてください。
私が間違いを当てますので、答えと理由は、私が答えたあとに教えてください。
```

正解を選ぶだけの学習より、間違いの原因を考えるほうが、知識を組み立て直すことになり、記憶に残りやすくなります。

## 自分用の用語ノートにためる

聞いて終わりにせず、用語ごとにノートにためると、自分専用の教材になります。Notion、スプレッドシート、NotebookLMなど、使い慣れたものでかまいません。

項目の例は次のとおりです。

| 項目 | 内容 |
| --- | --- |
| 用語 | 言葉の名前 |
| 一言の定義 | 自分の言葉で書く |
| 似た用語との違い | 迷いやすい点 |
| 試験での問われ方 | 過去問で見た形 |
| 確認した日・出典 | 公式資料や一次情報の名前 |
| 理解度 | 自信あり・あやしい・わからない |

出典と確認した日を残しておくと、あとで内容が古くなっていないかを見直しやすくなります。NotebookLMを使った用語ノートの作り方は、[NotebookLMの機能と使い方](/method/notebooklm-features-guide/)が参考になります。

## 新しい用語を、定期的に拾って更新する

用語ノートは、一度作って終わりではなく、新しい言葉を足していくことで価値が出ます。

ウェブ検索ができる生成AIに、定期的に次のように頼むと、最新の用語を拾えます。

```text
この1か月で、生成AIの分野で話題になった新しい用語や技術を、5つ挙げてください。

- それぞれ、定義と、どんな場面で使われるかを書く
- 情報源（公式の発表や信頼できる記事）の名前も示す
- ITパスポートや基本情報の試験で出題されそうなものに印をつける
```

AIが挙げた用語は、必ず一次情報で確認してください。AIは、存在しない用語や、古い説明を、もっともらしく答えることがあります（ハルシネーション）。公式のシラバスやIPAの資料と照らして、試験の範囲に関係するかを確かめます。

## 発展：用語データベースをツールにしてポートフォリオにする

ここまでの手作業を、仕組みにすると、ポートフォリオに載せられる作品になります。

- 生成AI用語を、決まった形式（用語・定義・出典・確認日など）のデータとして保存する
- ウェブ検索をもとに、新しい用語の候補を定期的に集める
- 人が確認した用語だけを、データベースに追加する
- 追加した用語から、クイズを自動で出すようにする

実際の取り組みは、[生成AI・AI倫理クイズ](/app/genai-ethics-quiz/)のように、用語クイズとして公開する方法があります。作り方は、[バイブコーディング](/method/vibe-coding/)の考え方で、AIと相談しながら進められます。

こうした作品は、技術だけでなく、<strong>情報が変わり続ける分野をどう追いかけるか</strong>という考え方も示せます。面接や転職の場で、「なぜその仕組みにしたか」を説明する材料になります。

## まとめ

- 生成AIの用語は、新しい言葉が次々に生まれるので、固定の参考書だけでは追いつきにくい
- 軸は公式シラバスと過去問に置き、新しい用語は生成AIに5つの切り口で聞いて補う
- 聞いた内容は、出典と確認日つきの用語ノートにためる
- AIの答えは、必ず一次情報で確かめる
- 余力があれば、用語データベースをツールにして、ポートフォリオにする

まずは、試験に出そうな生成AI用語を1つ選び、5つの切り口で生成AIに聞くところから始めてみてください。
