日商簿記はITパスポートと並んで「社会人が最初に取るべき実用資格」の筆頭に挙がる。
年間受験者数は100万人を超え、企業の経理・財務部門はもちろん、営業・企画職においても「数字を読む力」として評価される。

<strong>ITスキルと財務知識の両方を持つ人材</strong>はAI時代においてさらに希少になる。
ITパスポート・FPと組み合わせると、純粋な技術職とは異なる強みのポジションが作れる。

このページでは、日商簿記2・3級の全体像・難易度・CBT試験の攻略法・AI活用法・キャリアへの使い方を一本にまとめた。

## 日商簿記とは何か

日商簿記は、日本商工会議所が主催する簿記技能の検定試験だ。
1・2・3・初級の4段階があり、就職・転職市場で評価されるのは主に<strong>2級と3級</strong>だ。

簿記とは「企業の取引をルールに従って記録し、財務諸表（貸借対照表・損益計算書）を作る技術」だ。
このスキルがあると、決算書を読んで会社の財務状況を判断できるようになる。

---

## 3級と2級の違い

| 項目 | 3級 | 2級 |
|-----|:---:|:---:|
| 対象企業 | 中小規模の個人商店 | 株式会社（製造業含む） |
| 主な内容 | 日常的な取引の仕訳・帳簿付け | 工業簿記・原価計算が追加される |
| 合格率 | 40〜50% | 15〜25% |
| 標準学習時間 | 100〜150時間 | 300〜500時間 |
| 市場評価 | 「簿記の基礎知識あり」の証明 | 経理担当の採用要件として頻出 |

3級は「仕訳の基礎・財務諸表の読み方」が中心だ。
2級では「製造業の原価計算（工業簿記）」が加わるため、難易度が一段階上がる。

<strong>IT・事務職で転職・就活に使うなら3級から始めて2級を目指す</strong>というルートが一般的だ。

## CBT試験の特徴

日商簿記もCBT（Computer Based Testing）方式に移行している。

### CBTの主なメリット

- <strong>随時受験可能</strong>：年3回の統一試験日に縛られず、好きなタイミングで受けられる
- <strong>即日合否確認</strong>：試験終了直後に合否と得点が分かる
- <strong>再受験しやすい</strong>：不合格でも短期間で再チャレンジできる

### CBT特有の注意点

- 問題用紙がないため、計算は試験会場に用意された白紙・電卓で行う
- 仕訳をどの順番で解くかの手順を事前に決めておく必要がある
- 画面上でT字勘定（勘定科目ごとの仕訳整理）を手書きする感覚を事前に練習しておくこと

## なぜIT系人材に簿記が効くのか

### DX推進担当者に必要な財務感覚

IT投資の稟議を通すには「このシステム導入でROIが何年で回収できるか」を示す必要がある。
この計算には減価償却・キャッシュフローの概念が必要で、簿記2級の知識が直接役立つ。

### フリーランス・副業での経理処理

個人事業主として活動するには確定申告・経費管理・請求書発行が必要だ。
簿記3級があれば自分で帳簿を付けられる。税理士に依頼するコストを節約できる上に、自社の財務状態を正確に把握できる。

### ITパスポート・FPとの組み合わせ

- <strong>ITパスポート + 簿記3級</strong>：「IT×経理」の事務職市場で競合が少ない
- <strong>ITパスポート + FP3級 + 簿記3級</strong>：金融・保険業界のDX担当として強い
- <strong>AWS SAA + 簿記2級</strong>：システム企画・ITコンサル市場で武器になる

## 最短合格ロードマップ

### 3級を100時間で取る手順

<strong>Phase 1（〜40時間）：仕訳の基礎を固める</strong>
簿記の核心は「どの取引をどの勘定科目で記録するか」だ。
勘定科目（現金・売掛金・買掛金・売上・仕入など）と、それが借方・貸方のどちらに来るかを体で覚えることが最初のゴールだ。

市販のテキスト（スッキリわかる、よくわかるシリーズ）を1周し、各章の練習問題を解く。

<strong>Phase 2（〜40時間）：精算表・財務諸表の作成を練習する</strong>
個別の仕訳を「決算整理 → 精算表 → 損益計算書・貸借対照表」の流れでまとめる練習をする。
この流れが自動化されていると本番で時間を使わずに済む。

<strong>Phase 3（〜20時間）：過去問・模擬試験で仕上げる</strong>
CBT模擬試験ソフトや、日商簿記公式サイトの過去問を時間計測して解く。
90分の試験で計算・記述・確認を終わらせる時間感覚を身につける。

## AI活用法 — 仕訳暗記をゲーム化する

簿記の最大の壁は「勘定科目の判断」だ。
「売掛金が増えたら借方か貸方か」を瞬時に判断できるようになるには、繰り返し問題を解くしかない。

以下のプロンプトで無限に練習問題を生成できる。

```
日商簿記3級の仕訳問題を10問作ってください。

条件:
- 商品売買・仕入・売上・返品・手付金のパターンをランダムに混ぜる
- 各問題に金額を入れる
- 答えは別に用意して、私が解答した後で確認できるようにする
- 勘定科目は三分法（仕入・売上）で統一する
```

10問解いてAIに答え合わせしてもらう→間違えた問題のパターンを分析してもらう→同じパターンを5問追加生成する、というサイクルを作れば、市販の問題集が枯渇することはない。

自分で問題を作らせるのが面倒な場合は、[日商簿記3級 仕訳ドリル](/app/boki-shiwake-drill/)で商品売買・現金預金・債権債務・固定資産・決算整理の5分野をそのまま反復演習できる。

仕訳をパターン認識に変えるドリル活用法は[日商簿記の仕訳を「暗記」ではなく「パターン認識」に変えるAIドリル活用法](/method/boki-shiwake-drill-hack/)、2級で追加される工業簿記・原価計算でつまずいた場合は[工業簿記の原価計算が意味不明で心が折れる人へ](/method/boki-genka-keisan-wakaranai-hack/)を参照してほしい。簿記を経理・財務のキャリアにどう活かすかは[日商簿記を経理・財務キャリアに繋げるロードマップ](/career/boki-keiri-career-roadmap/)にまとめている。商業高校で全商簿記を取得済みの人は[全商簿記と日商簿記はどっちが難しい？](/trend/boki-zensho-vs-nissho-comparison-hack/)から読むと、知識の差分を効率よく埋められる。

## 受験前チェックリスト

- 電卓を試験会場に持ち込めるか確認する（電卓は持参が必要）
- CBT試験当日の持ち物（本人確認書類・受験番号）を確認する
- 試験会場の操作画面に慣れておく（CBT体験版でシミュレーションできる）
- 時間配分を決めておく：大問1（仕訳15問）→ 大問2 → 大問3（精算表）の順が一般的
