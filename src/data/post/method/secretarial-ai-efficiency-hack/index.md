## 秘書検定の知識は型、AIは実行エンジン

秘書検定で学ぶのは、敬語の使い分け・電話応対・スケジュール管理・文書作成といった<strong>ビジネスの型</strong>だ。
この型自体は暗記すれば身につくが、実務では「型を毎回ゼロから適用する作業」に時間がかかる。

ここにAIを組み合わせると、<strong>型の知識（判断力）はあなたが持ち、実際の文面作成・整理作業はAIに任せる</strong>という分業ができる。
秘書検定を取っただけの人と、秘書検定の知識をAIに指示できる人とでは、同じ業務でも作業時間が大きく変わる。

他の資格と比べても、秘書検定は「知識をそのままプロンプトの指示に変換しやすい」という特徴がある。敬語のルール・文書の型・優先順位の付け方は、AIへの指示として言語化しやすいからだ。

## 実践プロンプト集 — 秘書業務のAI効率化

### スケジュール調整

複数人の予定を調整するとき、優先順位の判断は人間が行い、候補日程の洗い出しと文面作成はAIに任せる。

```
以下の条件で会議候補日程を3案作成し、それぞれの案内メールの文面（社外向け・丁寧語）も作成してください。

- 参加者: 社内2名（役職者含む）、社外1名
- 希望期間: 来週月曜〜金曜
- 会議時間: 60分
- 社外の方が最優先。役職者の予定は動かせない前提とする
```

秘書検定で学ぶ「誰の予定を最優先にすべきか」という判断軸をプロンプトの条件に組み込むことで、AIの出力がそのまま使える精度になる。

### 議事録の要点整理

議事録は「発言をそのまま書き起こす」のではなく、「意思決定と次のアクションを抽出する」のが秘書検定的な型だ。

```
以下の会議メモを、次の3項目に整理してください。

1. 決定事項（誰が・何を決めたか）
2. 保留事項（誰が・いつまでに再検討するか）
3. 次のアクション（担当者・期限を明記）

[会議メモを貼り付け]
```

秘書検定の「要点整理」の型をそのまま指示文に落とし込むと、AIが議事録の構造化を代行してくれる。

### 来客対応・電話応対のシミュレーション練習

秘書検定の知識を「知っている」状態から「とっさに出てくる」状態にするには、実践練習が欠かせない。

```
私が秘書役、あなたが取引先からの電話をかけてきた役をやってください。
「担当者が不在の際の伝言メモの取り方」を練習したいので、
ランダムな要件で電話をかけてきてください。私が対応した後、
秘書検定のマナー基準から見て改善点を指摘してください。
```

AI活用で専任講師を月額20ドルで雇う感覚とは、この「本番前に何度でも練習できる」点にある。人間相手のロールプレイ研修は回数が限られるが、AI相手なら深夜でも休憩中でも練習でき、遠慮なく何度も同じ場面を繰り返せる。

## 秘書検定の知識を講師業に転用する視点

秘書検定はビジネスマナー研修の講師業とも相性がいい。
AIを使えば、研修資料の叩き台作成・ロールプレイ用のシナリオ生成・受講者向けクイズ作成といった、講師準備の下ごしらえを大幅に短縮できる。

```
秘書検定2級の「来客応対」の単元について、
新入社員研修用の15分のロールプレイシナリオを3パターン作成してください。
各シナリオには、よくある失敗例も1つずつ含めてください。
```

講師として独立・副業を考えている場合、資格の知識をAIで教材化するスキルは大きな差別化になる。
