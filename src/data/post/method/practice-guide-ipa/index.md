## AIを使った勉強の基本の流れ

AIは、問題を大量に出す道具としてではなく、<strong>理解を深める相手</strong>として使うと、効果が出やすくなります。基本の流れは次の4つです。

1. <strong>範囲を伝える</strong>：シラバスをAIに読ませて、学ぶ範囲の境界線を決める
2. <strong>身近な例で理解する</strong>：専門用語を、自分の仕事や生活に例えて説明してもらう
3. <strong>自分の言葉で確かめる</strong>：自分で説明して、抜けている点を指摘してもらう
4. <strong>間違いを分析する</strong>：間違えた理由を、パターンとして見つける

どの試験でも、この4つを回すことが土台になります。

## AIツールの使い分けの目安

どのツールも、できることは重なっています。次の表は、使い分けの目安です。

| ツール | 向いている使い方 |
| --- | --- |
| Claude | 長い資料やシナリオの読み込み、記述の添削 |
| ChatGPT | 例え話での説明、4択問題の追い込み、理解の確認 |
| Gemini | 公式情報の確認、最新の用語の背景を調べる |
| NotebookLM | 自分が入れた資料の範囲内での質問と、問題の作成 |

ツールの機能や得意不得意は、変わっていきます。迷ったら、ひとつのツールに絞って使い込むほうが、続けやすくなります。

## AIだけにしない

AIの説明には、間違いが混ざることがあります。AIだけに頼らず、次の組み合わせで使ってください。

| 学習手段 | 向いていること | 気をつけること |
| --- | --- | --- |
| 参考書・公式の資料 | 全体像の把握、信頼できる正確な情報 | 量が多く、途中で挫折しやすい |
| 生成AI | 疑問をその場で解消する、自分に合わせた説明 | 誤りが混ざるため、公式資料で確認する |
| 両方を使う | 正確な知識を、早く理解できる | 役割を決めて使う |

用語の定義や計算の結果は、公式のシラバスや過去問で必ず確かめてください。
