秘書検定を受ける前に、2級と3級のどちらが必要で、どのくらい準備すべきか迷うことがあります。

分かれ目は勤務年数だけではなく、場面に応じた対応の理由を説明できるかです。公式例題で現在の理解を確かめ、費用と学習枠を決める手順を整理します。

筆者は秘書検定を未受験です。試験制度は公式情報から整理し、後半のAI実行記録は試験の合格体験と区別しています。

## 秘書検定2級・3級で身につく知識を先に見る

秘書検定の出題は、理論の「必要とされる資質・職務知識・一般知識」と、実技の「マナー・接遇・技能」の5分野です。2級・3級の「実技」は、面接試験を意味する言葉ではありません。[実務技能検定協会・受験要項](https://jitsumu-ginou-kentei.jp/HS/guide)

次の表は、その5分野を学習後の確認に置き換えたものです。受かっただけで実務全般ができると保証されるわけではありません。

| 分野 | 学習後に説明してみること | 職場で確かめること |
| --- | --- | --- |
| 必要とされる資質 | 機密を守りつつ、相手を放置しない対応 | 誰に情報を伝えてよいか |
| 職務知識 | 上司の補佐と、自分で決めてよい範囲の違い | 不在時の連絡・報告手順 |
| 一般知識 | 業務で使う基礎的な言葉の意味 | 職場での用法 |
| マナー・接遇 | 相手との関係に応じた敬語・案内 | 自社の応対ルール |
| 技能 | 文書・資料・日程を扱う際の手順 | 様式や保存先 |

たとえば敬語は、目上の人の動作なら常に尊敬語にするのではなく、誰に向けて話しているかも見ます。協会の公開例題では、来客に自社の上司の外出を伝える場面などを確認できます。[協会・問題を解いてみよう](https://jitsumu-ginou-kentei.jp/HS/example)

次に、この理解を級選びに使います。

## 2級と3級は公式例題のつまずき方で選ぶ

2・3級は受験資格の制限がなく、3級合格を経ずに2級を受けることもできます。[協会・受験要項](https://jitsumu-ginou-kentei.jp/HS/guide)

| 例題を解いた状態 | 選び方の提案 | 先に準備する内容 |
| --- | --- | --- |
| 用語や敬語の基本で止まる | 3級の範囲から土台を作る | 言葉の意味と基本的な応対 |
| 3級の選択理由を説明でき、2級の場面判断で迷う | 2級を候補にする | 判断の前提と、他の選択肢が不適切な理由 |
| 職場の慣習と公式解説が食い違う | 級より先に試験上の前提を整理 | 問題文の条件と解説の根拠 |
| 合格証が必要な期限がある | 級・受験方式・結果通知時期を先に確認 | 期限から逆算した受験計画 |

これは本記事の学習開始の基準であり、少数の例題だけで合否を予測するものではありません。

## 費用は受験方式と教材費を分けて見積もる

2026年10月時点、第140回の会場受験の受験料は3級3,800円、2級5,200円です。これは会場受験の掲載額です。[協会・第140回受験要項](https://jitsumu-ginou-kentei.jp/HS/guide)

2・3級にはCBT方式もあります。会場受験と同じ料金・時間・申込条件だと決めつけず、選んだ方式の案内を確認してください。[試験運営会社・秘書技能検定CBT](https://cbt-s.com/examinee/examination/hisyokentei.html)

予算は「選んだ級・方式の受験料＋教材費＋交通費」で作ります。再受験も検討する場合は、その分を別枠にしておくと、最初の申込みだけの金額と混同しません。

筆記試験の合格基準は、理論・実技それぞれ60％以上です。合計で60％ならよい、とは扱いません。[協会・合格基準](https://jitsumu-ginou-kentei.jp/HS/guide)

## 勉強時間は経験年数で固定せず、領域別に配分する

今回確認した公式資料では、全員に共通する標準学習時間は確認できませんでした。「社会人なら何時間で合格」とは言い切らず、初回の例題・演習で配分を決めます。

| 学習状況 | 最初の学習枠 | 次に増やす時間 |
| --- | --- | --- |
| ビジネスマナーに触れたことがない | 3級例題と基本用語を照合 | 各分野の意味と具体例 |
| 電話・来客対応の経験がある | 理論と実技を分けて誤答を記録 | 経験で判断して外した論点 |
| 関連分野を学習済み | 選んだ級の問題を時間を測って解く | 記述や迷った選択肢の理由 |

たとえば「平日20分を3回、週末60分」なら、週2時間の学習枠です。これは計画の計算例で、合格までの必要時間ではありません。

理論だけ正答が増えても実技の誤答が残るなら、次週は実技に時間を移します。自分の正答理由を説明できるかも確認し、暗記した答えだけで進捗を判定しないようにします。

## AI対話でビジネスマナーのなぜを理解する学習ループ

上座・下座のように場面で判断が変わる内容は、AIに理由を尋ね、自分の理解を返して、教材で確かめます。次は筆者が実際に使った2つのプロンプトと、その記録です。

```text
秘書検定2級の「マナーと接遇」分野で、
来客対応の際の上座・下座のルールを
覚えるのが苦手です。

暗記ではなく、なぜそのルールになっているのか、
背景にある考え方から教えてください。
```

```text
教えてもらった考え方を自分の言葉で
整理してみました。

「入り口から遠い席ほど、外部からの視線や
人の出入りに気を取られにくく、落ち着けるため
上座とされる」という理解です。

この理解で合っていますか？
他の場面（会議室・タクシーの座席など）にも
同じ考え方が応用できるか教えてください。
```

### Claudeで実行した結果

2つのプロンプトを、同じ会話の中でClaude（Sonnet 5.5、有料プラン）に続けて送りました（2026年10月）。

1つ目への回答は、「上座・下座は一つの考え方から説明できる」という一文から始まりました。

> お客様（目上の人）に、いちばん快適で安全で、落ち着ける場所を差し上げる

上座の条件は3つに分けられていました。出入口から遠いこと、床の間や景色などよいものが見えること、他の人が相手のほうを向いて敬意を払いやすい配置であることです。下座は出入口に近く、案内や世話をする人が動きやすい席なので、席次は「誰が楽に過ごすか」と「誰が動いて世話をするか」の役割分担でもある、という説明でした。

場面別の表もありました（一部）。

| 場面 | 上座 | 理由 |
| --- | --- | --- |
| 応接室 | 出入口から遠い席 | 落ち着けて、出入りに煩わされない |
| 応接室の椅子 | ソファ（長椅子） | ひじ掛け椅子より座り心地がよい |
| 和室 | 床の間の前 | 床の間という一番のもてなしが見える |
| 車（運転手つき） | 運転席の後ろ | 最も安全で、乗り降りも楽 |
| 車（自分で運転） | 助手席 | 運転する人を一人にしない配慮 |

2つ目で自分なりの理解を送ると、「その理解で合っている」と答えたうえで、補足が付きました（要約）。

> - 上座の理由は「出入口からの距離」だけではなく、「よいものが見える」という軸もある。ふだんは同じ方向を指すが、ぶつかる場面では後者が優先される
> - タクシーは、運転席の後ろ → 助手席の後ろ → 後部座席の中央 → 助手席の順。後ろが上なのは、安全で落ち着けるから
> - 自分や同僚が運転する車では助手席が上座。ここでは「落ち着き」より「相手を後ろに一人で座らせない」配慮が優先される

自分の言葉でまとめた理解が「出入口からの距離」の1本だけだったのに対し、回答は「よいものが見える」というもう1本の軸を足し、車の例外もその2本で説明していました。暗記に戻らずに、例外まで理由でつながります。

席次は、テキストや過去問の解説でも確かめてください。エレベーターの立ち位置などは、資料によって説明が分かれることがあります。


記録の表はAIが出した説明であり、公式の席次基準を新しく定めるものではありません。試験では教材・問題文の条件を確認し、実際の応対では相手の事情や職場の決まりを踏まえます。

新たに試す場合は、次の照合指示を追加できます。

```text
今の席次の説明を、次の教材メモと照合してください。
【利用できる教材の説明を自分の言葉で記入】
一致する点、説明しすぎている点、資料では不明な点を分けてください。
資料にない「最も安全」などの理由は、根拠を作らず不明としてください。
```

> [!think]
> 席次の説明は文章だと難しいので、図解にしてくれたほうが助かります。その場合も、まずAIが席次の概念を理解している必要があります。マナーは人によって考えがぶれ、マナー講師の話がノイズになりやすいので、Claudeに頼むなら「秘書検定で出題される席次について」と前提条件をつけたほうがいいです。

## まとめ

秘書検定2級・3級は、公式例題のどこで迷うかを見て選びます。費用は受験方式ごとに確認し、勉強時間は理論と実技の誤答に合わせて配分してください。

最初の一歩は、公式例題を一つ解き、選択理由を書いて解説と比べることです。自分に必要な知識と、受けたい級の距離を確認できます。
