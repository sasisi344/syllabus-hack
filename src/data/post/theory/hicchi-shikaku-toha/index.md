求人票で「資格者を募集」「選任できる方」と見ても、資格を持っていれば条件を満たすのかは分かりません。

必置資格を調べるときの軸は、どの事業所・設備に、どの役割の人を置く制度なのかです。代表例を比較し、資格取得前と応募前に確認する条件を整理します。

筆者は宅建・電験三種・危険物取扱者・衛生管理者を未受験で、選任業務の体験談は掲載していません。本記事は公的資料による制度の整理で、個別の事業所に対する法的判定ではありません。

## 必置資格とは配置義務から見た呼び方

必置資格は、ある事業や設備の条件に応じて有資格者等の配置が求められる資格を指す呼び方です。「その資格で何ができるか」に加え、「事業者がどんな体制を作る必要があるか」から見ます。

ただし、全資格で同じ配置ルールがあるわけではありません。専任、専属、選任という言葉も、それぞれの制度の条件に沿って確認します。

たとえば宅建業の事務所には、業務に従事する者の数に対して5分の1以上の専任の宅建士が必要です。これは会社全体の従業員数だけで計算する基準ではありません。[国土交通省・免許申請の手引き](https://www.skr.mlit.go.jp/kensei/sangyou/02_hudosan/01-takken/manual/takken-manual.pdf)

そのため、求人の「資格保有者歓迎」と「法令上の役割へ選任予定」は分けて読みます。具体的には次の比較が役立ちます。

## 代表例は資格名と役割を分けて比較する

以下は2026年10月時点の代表例です。人数や要件をすべて網羅する表ではなく、確認先を絞るための比較です。

| 資格・役割 | 配置を確認する単位・条件 | 資格以外に確かめること |
| --- | --- | --- |
| 専任の宅地建物取引士 | 宅建業の事務所ごとの業務従事者数に応じた人数 | 専任として働く場所・実際の勤務形態 |
| 電気主任技術者 | 自家用電気工作物の保安監督体制 | 設備・資格種別・選任か外部委託か |
| 危険物保安監督者 | 法令で定める危険物施設 | 対象危険物を扱える甲種・乙種の免状と実務経験 |
| 衛生管理者 | 常時50人以上の労働者を使用する事業場 | 業種に合う資格・人数・専属等の条件 |

宅建士の事務所の割合は上記の[国土交通省資料](https://www.skr.mlit.go.jp/kensei/sangyou/02_hudosan/01-takken/manual/takken-manual.pdf)で確認できます。案内所等は対象業務に応じて別の条件があるため、一律に事務所と同じ比率を当てはめません。[東京都・業務を行う場所の届出](https://www.juutakuseisaku.metro.tokyo.lg.jp/application/820-04-0sinseiyousiki)

電気主任技術者は選任が原則ですが、対象設備や契約等の条件を満たし、承認を受けた外部委託の制度もあります。「外部の人が担当する＝名義貸し」とは限りません。[中部近畿産業保安監督部・主任技術者の手続き](https://www.safety-chubu.meti.go.jp/denryoku/jikayou/syugi.html)

危険物では、免状の保有と危険物保安監督者の選任を混同しないことが大切です。対象となる施設の保安監督者には、甲種または乙種の危険物取扱者で、6か月以上の危険物取扱いの実務経験を持つ者を選任します。[熊谷市・危険物保安監督者の届出](https://www.city.kumagaya.lg.jp/shinsei/syoubou/kikenbutuhoankantoku.html)

衛生管理者は会社全体ではなく事業場の労働者数を確認し、業種に応じた資格と人数を確認します。[厚生労働省・衛生管理者の選任](https://www.mhlw.go.jp/seisakunitsuite/bunya/koyou_roudou/roudoukijun/faq/5.html)

次に、これらの違いを求人での質問に変えます。

## 求人で確認する条件と、判断を止める条件

配置義務があることは、その資格だけで採用されることや高い手当が出ることの保証ではありません。応募前に、具体的に任される役割と支援体制を確認します。

| 求人・面談で分かった条件 | 次に取る行動 |
| --- | --- |
| 資格保有が応募条件で、選任は予定していない | 担当する実務と教育体制を聞く |
| 入社後すぐの選任を予定している | 設備・事業場・担当範囲、追加の経験要件を確認する |
| 複数拠点を担当するという説明がある | 兼任等が制度上認められる条件と手続きの担当を確認する |
| 出勤や職務遂行は不要で、名義だけ使うと言われる | 応じず、所管行政の窓口に具体的な条件を確認する |
| 「何かあっても責任はない」とだけ説明される | 職務・権限・報告経路が書面で分かるまで判断を止める |

宅建士の資格を、勤務実態のない形で使用させた場合の処分や責任については、行政も注意を促しています。[熊本県・宅地建物取引業者の法令遵守](https://www.pref.kumamoto.jp/soshiki/115/4630.html)

処分の種類や要件は資格・行為によって異なります。すべての必置資格が同じ条文で処罰されるとは説明せず、該当制度の窓口で確認してください。

資格の取得計画そのものは、[宅建のハブ](/method/takken-hub/)や[電験三種のハブ](/method/denken-hub/)で確認できます。ここでの制度理解と、試験合格後に実際の役割を果たせる準備は、分けて考えます。

## AIで制度を読むときは根拠と推測を分ける

制度の理由をAIに質問するときは、法令や公式資料に書いてあることと、理解のための説明を分けて受け取ります。次は筆者が実行した元のプロンプトと記録です。

```text
宅地建物取引士の設置義務が「従業者5人に1人」と定められている背景を、
消費者保護の観点から教えてください。この基準がなぜこの数値なのか、
制度趣旨から説明してください。
```

### ChatGPTで実行した結果

1つ目のプロンプトを、ChatGPT（有料プラン）で実行しました（2026年10月）。

回答の結論は「5人に1人は、事務所の規模に応じて専門家を置き、消費者が十分な説明を受けて契約できる体制を確保するための最低基準」でした。理由は次のように説明されていました（要約）。

> - 不動産取引は金額が大きく、権利関係や法令の制限も複雑。一般の消費者は業者より知識が少ないため、重要事項説明などの規制がある
> - 宅建士に説明を義務づけるだけでなく、事務所ごとに専任の宅建士を置かせて、説明や質問に実際に対応できる体制にしている
> - 「各事務所に1人」ではなく人数に比例させるのは、従業者が何十人になっても宅建士が1人だけだと、対応が集中して消費者保護が形だけになるおそれがあるから

数え方も正確でした。基準は、宅建業に従事する者の<strong>5分の1以上</strong>の専任の宅建士です。従事者が5人なら1人、6人なら2人が必要で、宅建士自身も従事者の人数に含みます。

興味深いのは、「なぜ5なのか」への答えです。

> 公的資料では、「1人の宅建士が対応できる業務量を計算した結果、5人になった」といった数値の算定根拠までは確認できなかった。消費者保護に必要な専門家の密度を確保しつつ、事業者の負担も考えた政策的な最低基準と捉えるのが妥当

プロンプトは「なぜこの数値なのか」を聞いていますが、ChatGPTはそれらしい理由を作らず、「根拠は確認できない」と答えました。制度の趣旨（規模に比例して専門家を置く）は説明できても、数値そのものの理由は資料にない、という線引きです。

AIに制度の理由を聞くときは、「趣旨から説明できること」と「資料で確認できること」を分けて答えさせると、作り話を混ぜずに理解できます。

別の資格と比較する場合は、免状と役職名を分けて指示します。

```text
次の公的資料の本文だけを使って比較してください。
【危険物保安監督者の選任資料】
【電気主任技術者の選任・外部委託の資料】
比較軸は対象施設、必要な資格と経験、選任の手続き、例外制度です。
「資格を持つこと」と「役職に選任されること」を分けて説明し、
資料にない条件は不明としてください。
```

## まとめ

必置資格は、配置される事業所・設備の条件と、実際に担う役割まで確認して判断します。資格を持つだけで選任要件を満たすとは限らず、認められた外部委託と名義だけの利用も区別が必要です。

求人を一つ選び、「どこで・どの役割を・どんな権限と支援で担当するか」を書き出してください。不明な項目が、応募前に聞くべき質問になります。
