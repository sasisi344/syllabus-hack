CSR、SDGs、ESG、ガバナンス、コンプライアンス。ストラテジ系の企業活動の分野には、どれも「企業が社会に対して果たす責任」に関わる、似た言葉が並びます。

名前を並べて眺めるだけでは、「何についての言葉なのか」が混ざりやすいところです。

この記事では、これらの用語を1ページに並べて、<strong>誰が・何のために・何をするのか</strong>で整理します。読み終えたときに、選択肢の言葉を見て、どの用語の説明かを見分けられるようにします。

## 用語の全体像

まず、一覧で位置づけを比べます。

| 用語 | ひとことで | 主体・視点 |
| --- | --- | --- |
| CSR | 企業が社会に対して果たす責任と、その活動 | 企業の「活動」 |
| SDGs | 2030年までに達成する17の国際目標 | 国連が掲げる「目標」 |
| ESG投資 | 環境・社会・ガバナンスを評価に加える投資 | 投資家が企業を見る「基準」 |
| コーポレートガバナンス | 経営を監視・監督する仕組み（企業統治） | 経営を律する「枠組み」 |
| コンプライアンス | 法令だけでなく、倫理や社内規定も守ること | 日々の「行動」 |
| GX | 脱炭素と経済成長を両立させる変革 | 環境への「変革」 |

試験では、<strong>CSRは企業の活動、SDGsは目標、ESGは投資の基準</strong>と整理しておくと、混同しません。

これらの根底には、<strong>サステナビリティ（持続可能性）</strong>という共通の考え方があります。「将来の世代のニーズを損なわずに、現在の世代のニーズを満たす」という考え方で、企業はCSRとして社会に貢献し、それがSDGsの達成に寄与し、その取り組みがESG投資の評価対象になる、という流れでつながります。

## CSR｜企業の社会的責任

<strong>CSR（Corporate Social Responsibility）</strong>は、企業が利益を追求するだけでなく、環境、社会、従業員、顧客、地域社会など、あらゆる利害関係者に対して責任を果たし、社会全体の持続可能な発展に貢献しようとする考え方です。単なる慈善活動ではなく、企業の存続と成長に欠かせない経営戦略の一部と位置づけられます。

試験では、<strong>企業が主体となって行う取り組み</strong>という点が重要です。具体例として、法令遵守の徹底、環境保護活動（省エネ、リサイクル）、適切な労働環境の提供、地域社会への貢献、製品・サービスの安全性の確保などが挙がります。

ITの分野では、個人情報の保護や情報セキュリティ対策が代表的なCSRです。アクセシビリティに配慮したWebサイトの開発や、デジタルデバイド（情報格差）の解消に向けた取り組みも、ITを活かしたCSRです。

## SDGs｜国連が掲げる17の目標

<strong>SDGs（Sustainable Development Goals）</strong>は、2015年の国連サミットで採択された「持続可能な開発のための2030アジェンダ」に記された、<strong>2030年までに達成する17の国際目標</strong>です。「誰一人取り残さない」ことを掲げ、貧困、飢餓、教育、気候変動などの課題の解決を目指しています。

2000年から2015年まで取り組まれた<strong>ミレニアム開発目標（MDGs）</strong>の後継です。MDGsが主に途上国の課題に焦点を当てたのに対し、SDGsは先進国を含むすべての国が取り組む普遍的な目標で、経済・社会・環境の三側面を統合して解決しようとする点が特徴です。

試験では、「国連が提唱する地球全体の目標」であることと、「17」という数字が問われます。目標4「質の高い教育をみんなに」や目標9「産業と技術革新の基盤をつくろう」のように、特定の目標とITの関連を問う形でも出ます。

ITは、SDGsの達成を支える道具です。遠隔医療やオンライン教育は「健康と福祉」「質の高い教育」に、AIによる農業の効率化や気象予測は「飢餓をゼロに」「気候変動に具体的な対策を」に貢献します。

## ESG投資｜企業を評価する新しい物差し

<strong>ESG投資</strong>は、財務情報だけでなく、<strong>環境（Environment）・社会（Social）・ガバナンス（Governance）</strong>への配慮を評価に加えて行う投資です。これらの非財務の要素が、企業の長期的な成長性や持続可能性に影響する、という考え方に基づきます。

試験では、ESGが<strong>投資家（お金を出す側）が企業を評価する基準</strong>であることが問われます。3つの要素の内容は、次のとおりです。

| 要素 | 内容の例 |
| --- | --- |
| E（環境） | 再生可能エネルギーの利用、CO2排出量の削減 |
| S（社会） | 多様な人材の活用、労働環境の改善 |
| G（ガバナンス） | 透明性の高い経営体制、情報開示 |

ITは3つの側面で貢献します。環境（E）では、クラウド活用による省電力化やIoTによるエネルギー管理、社会（S）では、テレワーク環境の整備による働き方改革、ガバナンス（G）では、データガバナンス体制の強化や、ブロックチェーンによる透明性の高い情報管理が挙げられます。

## コーポレートガバナンス｜経営を監視・監督する仕組み

<strong>コーポレートガバナンス（企業統治）</strong>は、経営者の不正を防ぎ、企業が株主をはじめとする多様な利害関係者の利益を考えて、公正かつ効率的に経営されるための<strong>監視・監督の仕組み</strong>です。不正の防止だけでなく、中長期的な企業価値の向上を目指します。

| キーワード | 内容 |
| --- | --- |
| ステークホルダー | 株主、顧客、従業員、取引先、地域社会など、企業の活動によって利益や不利益を受ける利害関係者 |
| アカウンタビリティ（説明責任） | 経営者が自分の判断と結果の根拠を、ステークホルダーに説明する責任 |
| ディスクロージャー（情報開示） | 財務状況や経営成績、事業の内容を、株主や投資家、社会に透明性をもって公開すること |

試験では、ガバナンスの「誰のため、何のため」が問われます。

1. <strong>ステークホルダーの視点</strong>：株主の利益だけでなく、顧客の満足、従業員の働きがい、地域社会への貢献まで、幅広い利害関係者の声を経営に反映しているか。特定の利害関係者の利益だけを追う選択肢は、誤りになりやすい
2. <strong>経営の透明性</strong>：正確な財務情報や経営状況を外部に公表しているか
3. <strong>役割分担</strong>：経営を「実行」する側と、それを「監督」する取締役会や監査役を分けて、チェック機能を働かせているか。社外取締役のような独立した立場の役員の監視が重要

### ITガバナンスとの関係

<strong>ITガバナンス</strong>は、コーポレートガバナンスの一部で、ITを適切に活用して組織の目標を達成するための統治です。ITは企業の競争力に直結するため、ITの戦略的な活用とリスク管理は、ガバナンスの重要な柱になっています。

## コンプライアンス｜法令だけでなく、倫理まで含めて守る

<strong>コンプライアンス（法令遵守）</strong>は、法令だけでなく、社内規定や社会的な倫理まで守り、誠実に活動することです。試験では、「法律さえ守れば何をしてもよいのか」というひっかけがよく出ます。答えは「いいえ」で、法律に直接違反していなくても、公正な競争に反する広告や、社員に一方的な不利益を与える契約は、コンプライアンス違反とみなされることがあります。

| 項目 | 内容 |
| --- | --- |
| 社会規範 | 法律の条文にはなくても、人として、企業として守るべき良識（ハラスメントの禁止、環境への配慮、個人情報の適切な取り扱いなど） |
| 内部統制 | 不正を防ぐための組織的な仕組み。業務の流れを管理し、リスクを減らす。土台になるのはコンプライアンスの意識 |
| 内部通報制度 | 不正や違反を、従業員が窓口に報告できる仕組み。公益通報者保護法により、通報者が不利益な扱いを受けないよう保護されている |

ガバナンスとコンプライアンスの関係は、<strong>ガバナンスが枠組み、コンプライアンスが実務</strong>と覚えると整理できます。

実効性を確保するには、経営陣から現場まで全員が受ける教育と、違反を見つけたときの通報窓口が欠かせません。情報セキュリティの面では、個人情報保護法をはじめとする法令を守り、情報漏えいや不正アクセスを防ぐ技術的・組織的な対策も、コンプライアンスの範囲に含まれます。

## GX｜脱炭素と経済成長を両立する変革

<strong>GX（グリーントランスフォーメーション）</strong>は、化石燃料に依存した経済から、太陽光や風力などのクリーンエネルギーを主軸にした経済へ転換し、環境を守りながら経済成長も目指す取り組みです。単なる環境保護ではなく、企業の競争力や新しい市場を生む、ビジネスの変革でもあります。企業の社会的責任（CSR）を果たし、SDGsの達成にもつながります。

試験では、「GXを進めるために、ITをどう活用するか」が問われます。

| 取り組み | 内容 | 試験・実務のポイント |
| --- | --- | --- |
| 排出データの見える化 | サプライチェーン全体のCO2排出量を計測・管理するシステムの導入 | Scope 1（自社の直接排出）、Scope 2（購入した電力などによる排出）、Scope 3（それ以外の間接排出）の区別。IoTセンサーのデータをクラウドで分析して可視化する |
| IT自体の省エネ（グリーンIT） | データセンターの冷却効率化、仮想化によるサーバー台数の削減 | データセンターのエネルギー効率を示す指標PUE。オンプレミスからクラウドへの移行も省エネになる |
| 業務効率化によるGX | AIによる配送ルートの最適化で、走行距離と燃料消費を減らす | DX（デジタル技術による業務変革）が、結果としてGXに貢献する |

GXとDXは、<strong>グリーン（環境）</strong>と<strong>トランスフォーメーション（変革）</strong>に分けて考えると整理できます。たとえば、AIによる配送ルートの最適化は、業務を変えるDXであり、その結果としての燃料の削減がGXです。

## 生成AIで理解を確かめる

抽象的な用語は、具体的な事例に当てはめて考えると、違いがはっきりします。

```text
あるAI企業が、不当にデータを収集したことがニュースになりました。
コーポレートガバナンスが欠けていた場合、
どのステークホルダーに、どのような悪影響があり、
経営者はどのような説明責任を果たすべきか整理してください。
```

```text
ある会社が、法律には違反していないものの、
社員に明らかに不利益を与えるギリギリの契約を結ぼうとしています。
この行為は、コンプライアンスの観点でどのように批判される可能性がありますか。
「企業倫理」という言葉を使って答えてください。
```

```text
ある運送会社が、配送ルートの最適化AIを導入して燃料を10%削減しました。
この取り組みが、GXとDXのどちらの観点でも評価される理由を、
2行で分かりやすく答えてください。
```

AIの回答を読む前に、自分で理由を書いておくと、用語の境目が自分の言葉で説明できているかを確かめられます。

## まとめ

- CSRは企業の<strong>活動</strong>、SDGsは国連の17の<strong>目標</strong>、ESG投資は投資家が企業を見る<strong>基準</strong>。根底にはサステナビリティの考え方がある
- コーポレートガバナンスは経営を監視・監督する<strong>枠組み</strong>、コンプライアンスはその枠組みを機能させる<strong>実務</strong>。法令だけでなく、倫理や社内規定まで含む
- GXは脱炭素と経済成長の両立。IT自体の省エネ、排出データの見える化、業務効率化の3つで、ITが貢献する
- ITは、個人情報の保護、アクセシビリティ、クラウドによる省電力などを通じて、これらの取り組みを支える

選択肢の言葉が「活動」「目標」「基準」「枠組み」「実務」のどれの話かを見分けられれば、似た用語でも迷いにくくなります。次は、人への投資の開示基準を扱う[人的資本経営](/trend/human-capital-management/)に進むと、ガバナンスの流れがつながります。
