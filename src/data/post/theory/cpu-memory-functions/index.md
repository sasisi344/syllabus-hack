CPUは演算・制御、メモリは処理中の一時記憶、ストレージは電源を切った後も残す保存を担います。「計算する」「広げる」「しまう」の役割で分けると、違いが見えてきます。

この記事では、3つの部品を、事務作業にたとえて整理します。CPUは<strong>頭脳</strong>、メモリは<strong>作業机</strong>、ストレージは倉庫です。

読み終えたときに、試験で出る性能の指標と、部品どうしの関係を、自分の言葉で説明できるようにします。

## 3つの役割

| 部品 | たとえ | 役割 | 電源を切ると |
| --- | --- | --- | --- |
| CPU（中央処理装置） | 頭脳 | 命令を解読し、計算や制御を行う | （データを保持しない） |
| メモリ（主記憶装置） | 作業机 | 処理中のデータやプログラムを一時的に置く | データが消える（揮発性） |
| ストレージ（補助記憶装置） | 倉庫 | OS、アプリ、写真、動画などを長期に保存する | データが残る（不揮発性） |

メモリ（机）が広いほど、CPU（人）は効率よく作業できます。CPUが高速でもメモリが狭いと、データを外から何度も読み込むことになり、処理が滞ります。

この「頭脳」と「机」のバランスが、コンピュータの総合的な性能を決めます。

遅いという症状だけで、交換する部品を決めることはできません。まず、どの場面で待つかを分けます。

- 計算や動画の処理そのものに時間がかかるなら、CPUと、その処理が複数コアを使えるかを確認する
- 複数のアプリを同時に開くと滞るなら、メモリの使用状況を確認する
- 起動やファイルの読み込みで待つなら、ストレージの読み書きを確認する
- 保存できる量が足りないなら、ストレージの容量を確認する

## CPU｜性能を表す指標

CPUの性能は、処理の速さと、一度に処理できる量で決まります。

| 指標 | 内容 | 試験・実務でのポイント |
| --- | --- | --- |
| クロック周波数 | CPUが1秒間に処理できるサイクル数。MHz（メガヘルツ）、GHz（ギガヘルツ）で示す | 同じ設計・条件なら動作速度を比べる指標になる。異なるCPUの性能を周波数だけでは決められない |
| マルチコア | 1つのCPUチップに、複数の処理回路（コア）が入っていること | 複数のタスクを並行して処理できる。処理を並列化できる動画編集やデータ分析などで効果を得やすい |

クロック周波数を比べる条件は、[インテルのクロック周波数の解説](https://www.intel.co.jp/content/www/jp/ja/gaming/resources/cpu-clock-speed.html)でも確認できます。

## メモリ｜揮発性と、速度差を埋める仕組み

メモリは、主に<strong>RAM（Random Access Memory）</strong>を指します。電源を切るとデータが消える<strong>揮発性</strong>があり、一時的な作業領域として使われます。

永続的な保存には、ストレージを使います。試験では、RAMの揮発性と、その対義語の不揮発性（ROMやストレージ）の違いがよく出ます。

### 記憶階層｜速いほど小さく、高価

CPUは非常に高速なのに対し、メモリはアクセスが遅く、CPUに待ち時間が生じます。この速度差を埋めるために、CPUの近くに、高速で小容量の記憶装置が置かれています。

| 記憶装置 | 位置 | 特徴 |
| --- | --- | --- |
| レジスタ | CPUの内部 | 最も高速。処理中のデータ、演算結果、次に実行する命令のアドレスを保持する |
| キャッシュメモリ | CPUの内部・近く | 次に必要になりそうなデータを先に読み込んでおき、待ち時間を短縮する。CPUに近い順に、L1、L2、L3があり、L1が最も高速で小容量、L3が低速で大容量 |
| 主記憶（メモリ、RAM） | CPUの外 | 作業机。キャッシュより遅いが、大きな容量を持つ |
| 補助記憶（ストレージ） | さらに外 | 倉庫。最も遅いが、大容量で安く、データが残る |

次の図はアクセス速度と容量を整理するための一般的な順序です。すべてのデータが必ずこの順番に移動する、という意味ではありません。

```mermaid
flowchart LR
  R[レジスタ] --> C[キャッシュメモリ]
  C --> M[主記憶 RAM]
  M --> S[補助記憶 HDD・SSD]
```

左ほど高速・小容量、右ほど低速・大容量という傾向と、各装置の役割を結びつけます。

## ストレージ｜HDDとSSDの違い

ストレージは、電源を切ってもデータが消えない<strong>不揮発性</strong>の記憶装置です。OS、アプリ、文書、写真など、すべてのデータが保存されます。

代表的な種類が、HDDとSSDです。

| 項目 | HDD（ハードディスク） | SSD（ソリッドステートドライブ） |
| --- | --- | --- |
| 仕組み | 磁気ディスクを回転させ、ヘッドを動かして読み書きする | フラッシュメモリ（半導体）に電気的にデータを記録する |
| 速度 | 読み書きの前にヘッドが動く待ち時間（シークタイム）があり、遅め | 可動部がなく、非常に高速 |
| 衝撃 | 精密な部品で、落下などの衝撃に弱い | 耐衝撃性が高い |
| 音・消費電力 | 稼働音がする | 静かで、消費電力が少ない |
| 価格と容量 | 安く、大容量 | 同じ容量だと高め |
| 向いている用途 | 頻繁にアクセスしない大容量データの保存（バックアップ、アーカイブ） | OSや、よく使うアプリのインストール先 |

現代のPCでは、起動ドライブにSSD、データの保存にHDDという組み合わせも一般的です。試験では、<strong>HDD（磁気・回転）</strong>と<strong>SSD（半導体・高速）</strong>という仕組みの違いを起点に、速度、耐衝撃性、静音性、消費電力、価格、寿命（書き換え回数）といった比較の項目を、論理的に導けるようにしておきます。

## 生成AIで買い替えの相談をしてみる

性能の違いは、具体的な利用場面を想定させると、理解が深まります。

```text
あなたはPCショップの店員です。
動画編集（重い作業）をしたいお客さんに、
「CPUのコア数」「メモリ(RAM)の容量」「キャッシュメモリ」の重要性を、
仕事の効率がどう変わるかの観点から、ITパスポートの試験用語を使って説明してください。
```

```text
あなたはPC選定のコンサルタントです。
大量の写真の保存がメインの人と、動画編集をサクサク進めたい人の2人に、
HDDとSSDのどちらを勧めるべきか、ITパスポートの試験用語を使って理由とともに説明してください。
```

大量の写真の保存には、HDDの「コストパフォーマンスと容量」が、動画編集には、SSDの「高速なデータ転送」が重要だと、利用目的から選び方を導けるかを確かめてください。

## まとめ

- CPUは<strong>演算・制御</strong>、メモリは<strong>一時記憶</strong>、ストレージは<strong>永続的な保存</strong>を担う
- CPUの性能は、クロック周波数（速さ）とマルチコア（同時に処理できる量）で見る
- 記憶装置は、CPUに近いほど（レジスタ、キャッシュ、メモリ、ストレージの順に）高速で小容量
- HDDは安く大容量、SSDは高速で耐衝撃性に優れる。仕組みの違いから特徴を導く

全体像は[ITパスポートの20時間コース](/course/ip/)と[合格ロードマップ](/method/itp-hub/)で学べます。次は、これらのハードウェアを管理するソフトウェアである[OS（オペレーティングシステム）](/theory/os-operating-systems/)を読むと、ハードとソフトのつながりが整理できます。
