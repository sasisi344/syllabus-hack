P/Lでは利益が出ているのに、手元の現金は減っている。数字が食い違うように見えるのは、それぞれの表が別の対象を見ているためです。

用語を一つずつ覚える前に、同じ取引を3表で追うと違いが見えてきます。掛け売りの仮想例から始め、採算ラインの損益分岐点と、投資効率のROIまで整理します。

## 3表は、見る対象と時間が違う

財務諸表は、財政状態・経営成績・キャッシュフローの状況などを外部へ示す書類です。[日本取引所グループ「財務諸表」](https://www.jpx.co.jp/glossary/sa/165.html)

そのうち、学習の入口で比べたいのが次の3つです。

| 表 | 見る対象 | 見る時間 | 答えられる問い |
| --- | --- | --- | --- |
| P/L：損益計算書 | 収益・費用・利益 | 一定期間 | その期間に、どれだけ利益を得たか |
| B/S：貸借対照表 | 資産・負債・純資産 | ある時点 | 何を持ち、どんな負担や持分があるか |
| C/F：キャッシュフロー計算書 | 現金及び現金同等物の増減 | 一定期間 | 資金がどこから入り、何に出たか |

B/Sの基本式は「資産＝負債＋純資産」です。左右が一致することと、資金繰りに余裕があることは別なので、資産の中身と支払時期も見ます。

次の例では、現金と売掛金がどう違うかを確かめます。

## 60万円で仕入れ、100万円で掛け売りするとどうなるか

以下は学習用の単純化した例です。期首に現金100万円・資本金100万円があり、負債はなく、税金や他の費用・取引はないものとします。

商品を現金60万円で仕入れ、すべてを100万円で売り上げます。ただし代金は翌期に受け取る掛け売りとし、期末まで入金されません。

| 見る表 | この期間・期末に表れるもの | 読み取れること |
| --- | --- | --- |
| P/L | 売上100万円－売上原価60万円＝利益40万円 | 売上と対応する費用から利益が出ている |
| B/S | 現金40万円＋売掛金100万円＝資産140万円 | 利益の分が、現金ではなく未回収の債権に含まれる |
| B/Sの右側 | 負債0円＋純資産140万円 | 資本金100万円に利益40万円が積み上がる |
| C/F | 営業活動の収入0円－支出60万円＝60万円の減少 | この期間に現金で払った分が先行する |

掛け売りは売上の計上時に現金が増える取引ではないため、利益と現金の動きは一致しません。[日本公認会計士協会「キャッシュ・フロー計算書」](https://jicpa.or.jp/cpainfo/introduction/keyword/post-7.html)

翌期に売掛金100万円を回収すると、現金は140万円、売掛金は0円になります。これは代金の回収なので、同じ売上をもう一度計上しません。

```mermaid
flowchart LR
  A["期首：現金100万円"] --> B["仕入代金60万円を支払う"]
  B --> C["商品を100万円で掛け売り"]
  C --> D["期末：利益40万円・現金40万円・売掛金100万円"]
  D --> E["翌期：代金を回収"]
  E --> F["現金140万円・売掛金0円"]
```

この例だけで倒産の危険を断定はできません。ただし、回収前に支払期限が来て、手元の現金や調達資金で払えなければ、黒字でも支払いが止まる可能性があります。

## P/Lの利益とC/Fの区分を読み違えない

P/Lで本業の利益を見たいなら、売上総利益から販売費・一般管理費を引いた営業利益を見ます。営業外の収益・費用も加味したものが経常利益です。

日本基準の基本形では、経常利益に特別利益・特別損失を加減して税引前当期純利益、さらに法人税等を差し引いて当期純利益へ進みます。

一方、C/Fは営業活動・投資活動・財務活動に分けて資金の動きを見ます。本業に関わる収支、設備の取得などの収支、借入や返済などの収支を分ける考え方です。[J-FLEC「キャッシュ・フロー計算書」](https://www.j-flec.go.jp/links/jikan/word/044.html)

営業C/Fがプラスなら常に健全、投資C/Fがマイナスなら常に悪い、とはいえません。資金が増減した原因を、B/Sや説明資料と合わせて読みます。

利益が出る売上の水準を知りたいときは、3表から一歩進んで、費用の分け方を考えます。

## 損益分岐点は、固定費を回収できる売上高

売上に応じて増える費用を変動費、想定する範囲では売上にかかわらず一定の費用を固定費とします。売上から変動費を引いた残りが限界利益で、ここから固定費をまかないます。[中小機構 J-Net21「損益分岐点を使った目標売上高」](https://j-net21.smrj.go.jp/startup/manual/list5/5-2-9.html)

利益が0円になる売上高を求める基本式は、次のとおりです。ここでは固定費が一定、変動費が売上に比例すると仮定します。

```text
損益分岐点売上高 ＝ 固定費 ÷（1－変動費率）
目標利益を得る売上高 ＝（固定費＋目標利益）÷（1－変動費率）
```

月の固定費40万円、変動費率60％なら、損益分岐点売上高は40÷0.4＝100万円です。月20万円の利益を目指すなら、（40＋20）÷0.4＝150万円が必要になります。

売上150万円のとき、変動費90万円、固定費40万円なので、利益は20万円です。最後にこの形で戻して検算すると、分母の取り違いを見つけられます。

損益分岐点比率は「損益分岐点売上高÷実際売上高×100」、安全余裕率は「（実際売上高－損益分岐点売上高）÷実際売上高×100」です。この例では約66.7％と約33.3％で、分子・分母を逆にしないようにします。

## ROIは、利益と投資額の前提をそろえて計算する

ROI（Return on Investment）は、投資に対して得た利益の割合を見る指標です。ただし、利益に何を含めるか、どの期間を見るか、投資額をどう置くかで結果が変わります。

以下はこの例だけの定義として、「年間の純効果÷初期投資額×100」を使います。初期投資100万円、年間の費用削減40万円、追加の年間運用費10万円なら、純効果は30万円、年単位のROIは30％です。

年間40万円の削減をすべて利益とみなすと、追加運用費を落とします。逆に、設問で利益が費用控除後と示されているなら、同じ費用をもう一度引かないようにします。

複数年の効果を比べるときは、期間の合計か年平均かも統一します。TCOは導入・運用・保守・終了までの総費用、NPVは将来の正味の資金収支を現在価値に割り引いて合計した値、IRRはNPVが0になる割引率で、同じ数字の別名ではありません。

## 何を聞かれたかで、表と指標を選ぶ

| 設問の条件・問い | 最初に見るもの |
| --- | --- |
| 本業でどれだけ利益が出たか | P/Lの営業利益 |
| 期末に何を持ち、何を返す必要があるか | B/Sの資産・負債とその内訳 |
| 利益はあるのに現金が減った理由は何か | C/Fと、売掛金・在庫・債務などの増減 |
| 売上がいくらあれば赤字を脱するか | 固定費・変動費率と損益分岐点 |
| 投資額に対する利益の割合はどの程度か | 期間と算定条件をそろえたROI |

AIを使う場合も、先に自分で計算し、その説明に矛盾がないかを確認してもらいます。

```text
会計の理解を確認したいです。以下は仮想例です。
期首の現金100万円・資本金100万円、負債なし。
当期に商品を現金60万円で仕入れ、すべて100万円で掛け売りした。
回収は翌期。他の取引、税金、費用、配当はない。
私の説明：（当期の利益、期末の現金と売掛金、営業C/Fを記入）

私の説明がP/L・B/S・C/Fの間で一致しているか点検してください。
B/Sの左右が一致するかも確認してください。
次に、翌期の代金回収を売上に二重計上していないか質問してください。
この情報だけで倒産や投資の可否を断定しないでください。
```

## まとめ

P/Lは期間の利益、B/Sは時点の財産、C/Fは期間の資金の動きです。同じ掛け売りでも、売上・債権・入金が別のタイミングで表れるため、利益と現金はずれます。

採算を問われたら損益分岐点、投資効率を問われたら条件をそろえたROIへ進みます。まずは上の60万円・100万円の例を、表を見ずに説明してみてください。
