インターネット上の通信は、すべて<strong>TCP/IP</strong>という共通ルールの上に成り立っている。
基本情報技術者試験の科目Aでは、このTCP/IPの階層構造とIPアドレスの計算問題が毎回のように出題される。

この記事ではネットワーク基礎の中核となる3テーマを、<strong>仕組み → 具体例 → 試験での出題パターン</strong>の順で解説する。

## TCP/IPの階層構造 — 通信を役割分担する仕組み

TCP/IPは、通信の役割を4つの階層に分けて処理する仕組みだ。各階層が自分の役割だけに集中することで、複雑な通信を整理して実現している。

| 階層 | 役割 | 代表的なプロトコル |
|---|---|---|
| アプリケーション層 | ユーザーが使うサービスの通信形式を定める | HTTP, HTTPS, FTP, SMTP, DNS |
| トランスポート層 | データを確実に、または高速に届ける方式を決める | TCP, UDP |
| インターネット層 | 通信相手までの経路（ルーティング）を決める | IP |
| ネットワークインタフェース層 | 物理的な信号のやり取りを行う | Ethernet, Wi-Fi |

### TCPとUDPの違い

トランスポート層には2つの代表的なプロトコルがある。試験では両者の違いを問う設問が頻出だ。

- <strong>TCP</strong>：通信の到達確認・再送制御を行い、確実にデータを届ける（メール・Webページ閲覧など、正確性が重要な通信）
- <strong>UDP</strong>：到達確認をせず高速に送り続ける（動画配信・音声通話など、多少の欠落より速度が重要な通信）

「信頼性重視ならTCP、速度重視ならUDP」という対比を軸に覚えると、応用問題でも判断しやすくなる。

## IPアドレスとサブネットマスク — 住所とグループ分けの仕組み

IPアドレスは、ネットワーク上の機器を識別する「住所」だ。
IPv4では32ビットの数値を8ビットずつ4つに区切り、`192.168.1.1` のように10進数で表記する。

### ネットワーク部とホスト部

IPアドレスは<strong>ネットワーク部</strong>（所属するネットワークを示す部分）と<strong>ホスト部</strong>（そのネットワーク内での個体識別部分）に分かれる。この境界を示すのが<strong>サブネットマスク</strong>だ。

例えば `192.168.1.0/24` という表記は、先頭24ビットがネットワーク部であることを意味する。

```
IPアドレス:     192.168.1.10
サブネットマスク: 255.255.255.0  (先頭24ビットが1)
→ ネットワーク部: 192.168.1.0
→ ホスト部:      .10（このネットワーク内での個体番号）
```

### サブネット計算問題の解き方

科目Aで頻出なのが「あるIPアドレスとサブネットマスクから、同一ネットワーク内に収容できるホスト数を求めよ」というタイプの計算問題だ。

ホスト部のビット数を n とすると、収容可能なホスト数は<strong>2のn乗 − 2</strong>で求められる（ネットワークアドレスとブロードキャストアドレスの2つを除くため）。

例: `/24`（ホスト部8ビット）の場合、2の8乗 − 2 = 254台まで収容できる。

## ポート番号 — 同じIPアドレス内でサービスを識別する仕組み

1台のサーバーが複数のサービス（Webサーバー・メールサーバーなど）を同時に提供する場合、IPアドレスだけでは「どのサービス宛の通信か」を区別できない。この区別に使われるのが<strong>ポート番号</strong>だ。

### 代表的なウェルノウンポート

| ポート番号 | プロトコル | 用途 |
|---|---|---|
| 80 | HTTP | Webページの閲覧 |
| 443 | HTTPS | 暗号化されたWebページの閲覧 |
| 25 | SMTP | メール送信 |
| 53 | DNS | ドメイン名の名前解決 |

試験では、これらの代表的なポート番号と対応するプロトコル・用途の組み合わせを問う設問が頻出する。

## AIで覚える実践テクニック

ネットワーク基礎は「用語の丸暗記」よりも「実際の通信の流れを追う」方が理解が定着しやすい。以下のプロンプトで、計算問題や通信の流れを対話形式で確認できる。

```
IPアドレス 172.16.5.20、サブネットマスク 255.255.255.192 の場合、
ネットワークアドレス・ブロードキャストアドレス・
収容可能なホスト数をそれぞれ計算し、計算過程も示してください。
```

```
ブラウザでWebサイトを開くとき、TCP/IPの4階層それぞれで
どのような処理が行われるか、リクエストからレスポンスまでの
流れを時系列で説明してください。
```

サブネット計算は数をこなすほど速くなるため、AIに条件を変えた問題を繰り返し出させる反復練習が効果的だ。IPアドレス計算の理解に苦戦している場合は、[IPアドレス計算が「意味不明」なのはテキストのせいだ](/method/ip-address-ai-metaphor-hack/)も参照してほしい。
